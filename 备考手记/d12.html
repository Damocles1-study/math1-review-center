一、二次型：去掉交叉项

$f=x^TAx$，$A$ 实对称。$x_i^2$ 系数放 $a_{ii}$；$x_ix_j$ 系数除以 2放 $a_{ij},a_{ji}$。$x_1^2+4x_1x_2$ 对应 $\begin{pmatrix}1&2\\2&0\end{pmatrix}$。

  • 正交变换（大题主力）：$x=Qy$，$f=\lambda_1y_1^2+\cdots+\lambda_ny_n^2$。标准形系数 = 特征值。昨天那个矩阵直接得 $2y_1^2-y_2^2-y_3^2$。
  • 配方法：逐个变量配平方；只有交叉项先令 $x_1=y_1+y_2,x_2=y_1-y_2$。变换只要求可逆，系数不一定是特征值。

$x_1^2+2x_1x_2+2x_2^2+4x_2x_3+x_3^2=(x_1+x_2)^2+(x_2+2x_3)^2-3x_3^2$，$p=2,q=1$。

惯性定理：正负系数个数不随可逆变换改变。$p$ = 正特征值数，$q$ = 负特征值数。

二、四个「关系」对比（昨晚欠的）

关系定义看什么
矩阵等价$PAQ=B$，可逆 $P,Q$同型、秩同
向量组等价互相线性表示能否互表（秩同是必要）
相似$P^{-1}AP=B$特征值全同（实对称时充要）
合同$C^TAC=B$实对称时 $p,q$ 同

相似 ⟹ 合同 ⟹ 等价（实对称）。反之都不成立。

三、正定

等价条件

对任意 $x\neq0$，$f\gt0$ ⟺ 特征值全正 ⟺ $p=n$ ⟺ 顺序主子式全正 ⟺ $A=C^TC$。 必要：$a_{ii}\gt0$，$\vert A\vert\gt0$。

例：$x_1^2+x_2^2+5x_3^2+2tx_1x_2-2x_1x_3+4x_2x_3$：$D_2=1-t^2\gt0$，$D_3=-5t^2-4t\gt0$ ⟹ $-\frac45\lt t\lt0$。

四、进入三维：向量

$a\cdot b=\vert a\vert\vert b\vert\cos\theta$；$a\perp b$ ⟺ 点积 0。 $a\times b=\begin{vmatrix}i&j&k\\a_1&a_2&a_3\\b_1&b_2&b_3\end{vmatrix}$，长度 = 平行四边形面积，方向右手系。$a\parallel b$ ⟺ 叉积 0。 混合积 $(a\times b)\cdot c$ = 行列式 = 六面体体积，共面 ⟺ 为 0。

五、平面与直线

  • 平面：$Ax+By+Cz+D=0$，法向量 $(A,B,C)$。过三点：两向量叉积得法向量。例 $A(1,0,0),B(0,1,0),C(0,0,2)$：$2x+2y+z=2$。
  • 直线：$\frac{x-x_0}{l}=\frac{y-y_0}{m}=\frac{z-z_0}{n}$。两平面交线方向 $n_1\times n_2$。求交点先化参数式。
  • 点到面距离：$\dfrac{\vert Ax_0+By_0+Cz_0+D\vert}{\sqrt{A^2+B^2+C^2}}$。线面夹角用 $\sin$：$\sin\varphi=\frac{\vert s\cdot n\vert}{\vert s\vert\vert n\vert}$。

六、曲面：照着画才记得住

旋转曲面：到轴的距离不变、高度不变。$yOz$ 曲线绕 $z$ 轴：$y$ 换成 $\pm\sqrt{x^2+y^2}$。$z=y^2$ ⟹ $z=x^2+y^2$。

投影：消去 $z$ 得柱面，再加 $z=0$。$z=x^2+y^2$ 与 $z=2-x^2-y^2$ ⟹ $x^2+y^2=1,\ z=0$。后面定积分区域就用这个。

一、三级调度与指标

高级（作业，外存→内存，一次）/ 中级（挂起换出）/ 低级（就绪→运行，最频繁）。

指标公式
周转完成 − 到达
带权周转周转 ÷ 服务（≥1）
等待周转 − 服务（再减 I/O）
响应首次得 CPU − 到达

二、什么时候能调度

  • 要调度：结束、阻塞、时间片完、高优先级到（抢占）。
  • 不能：处理中断、执行原语、内核临界区。
  • 普通临界区（打印机）可以调度，别人只是进不来。内核临界区保护的是调度器自己的数据。

上下文切换：存 PC、PSW、寄存器到 PCB → 改状态入队 → 选新进程加载现场 → 切页表，TLB 作废。线程切换不换地址空间。 闲逛进程：就绪空时运行，优先级最低。

三、六种算法

算法抢占饥饿照顾谁
FCFS否否长作业、CPU 型
SJF/SRTN否/是是短作业，SRTN 周转最优
HRRN否否折中
RR是否响应
优先级都有静态会紧迫的
多级反馈是是综合
$$\text{响应比}=\frac{\text{等待}+\text{服务}}{\text{服务}}$$

算一下平均周转：FCFS $(7+9+8+11)/4=8.75$；SRTN $(16+5+1+6)/4=7$，最优。

RR 同时发生时新到的先入队。时间片太大退化 FCFS，太小开销大。 I/O 型优先级高于 CPU 型（用一会儿 CPU 就走了，让设备保持忙）。 多级反馈：新进第 1 级，用完时间片降级，上级空才跑下级，高级来人抢占放回本级队尾。

带 I/O 要画两条时间线：P1 算 10 → I/O 20 → 算 10；P2 算 30。0–10 P1；10–30 P2（P1 I/O）；30–40 P2；40–50 P1。总 50。

用户级线程 OS 只调度进程。多处理机：公共队列（天然均衡要互斥）；私有队列（亲和性好，要负载均衡）。

四、问题：x++ 不是一步

读 → 加 → 写，切换可以在任意两条之间。两个线程各加一次，x 可能只变成 1。

临界资源一次一个；临界区是访问它的代码。互斥：不能同时。同步：有先后。

四条准则

① 空闲让进 ② 忙则等待 ③ 有限等待 ④ 让权等待（进不去让出 CPU）。前三条必须。

方法满足缺陷
Peterson①②③忙等
关中断只适合单处理机内核
TSL / Swap①②忙等，可能饥饿
信号量（记录型）全部
管程全部

Peterson：flag[i]=true; turn=j; while(flag[j]&&turn==j);，走廊让路，最后说的人让到底。

五、信号量

void wait(S){ S.value--; if(S.value<0) block(S.L); }
void signal(S){ S.value++; if(S.value<=0) wakeup(S.L); }

value>0 可用数；value<0 等待数。初值：互斥 1，同步 0，资源 = 数量。 整型信号量 while(S<=0); 还是忙等。

PV 三句诀

互斥：一进程内成对。 同步：前操作之后 V，后操作之前 P，分在两个进程。 同步 P 在前，互斥 P 在后，V 无所谓。

六、管程与条件变量

管程把数据和操作封装，一次只有一个进程在内，互斥由编译器保证。 x.wait() 阻塞并放开管程；x.signal() 唤醒一个，没人等就丢了。条件变量没有值，信号量有值会累积。
