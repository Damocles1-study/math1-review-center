二、五种场合

  • 反函数：$\varphi'(y)=\dfrac{1}{f'(x)}$，$\varphi''(y)=-\dfrac{f''(x)}{[f'(x)]^3}$。
  • 隐函数：不解 $y$，两边对 $x$ 求导，$y$ 当 $x$ 的函数。先求出点上的 $y$，求一次导代一次值，比先解 $y'$ 再求导省事。
  • 参数方程：$\dfrac{dy}{dx}=\dfrac{y'_t}{x'_t}$；$\dfrac{d^2y}{dx^2}=\dfrac{\frac{d}{dt}(\frac{dy}{dx})}{x'_t}$。不是 $y''_t/x''_t$。
  • 幂指函数：$u^v=e^{v\ln u}$。$(x^x)'=x^x(\ln x+1)$。
  • 高阶导：$(\frac{1}{x+a})^{(n)}=\frac{(-1)^nn!}{(x+a)^{n+1}}$，$(\sin x)^{(n)}=\sin(x+\frac{n\pi}{2})$。莱布尼茨 $(uv)^{(n)}=\sum C_n^ku^{(n-k)}v^{(k)}$，有多项式时只写前几项：$(x^2e^x)^{(n)}=e^x[x^2+2nx+n(n-1)]$。
例：$e^y+xy=e$，求 $y'(0),y''(0)$

$x=0$ 时 $y=1$。求导：$e^yy'+y+xy'=0$，代入 $y'(0)=-\frac1e$。再求导：$e^y(y')^2+e^yy''+2y'+xy''=0$，代入 $y''(0)=\frac{1}{e^2}$。

$xy'$ 再求导是 $y'+xy''$，加上前面那个 $y'$，共 $2y'$。第一遍我漏了一个。

三、中值定理：一条割线，必有一条切线与它平行

费马：可导的极值点处 $f'=0$（极大点右差商 $\le0$、左差商 $\ge0$）。极值是局部的，最值是全局的。

条件都是「闭连开导」

罗尔：加 $f(a)=f(b)$ ⟹ $f'(\xi)=0$。 拉格朗日：$f(b)-f(a)=f'(\xi)(b-a)$。全程平均时速 80，路上某一刻时速表正好 80。 柯西：$\dfrac{f(b)-f(a)}{g(b)-g(a)}=\dfrac{f'(\xi)}{g'(\xi)}$（$g'\neq0$）。 推论：$f'\equiv0$ ⟹ $f$ 是常数。

辅助函数的原型：证拉格朗日时令 $F=f-\frac{f(b)-f(a)}{b-a}x$，$F(a)=F(b)$，用罗尔。

例：证 $\dfrac{x}{1+x}\lt\ln(1+x)\lt x$（$x\gt0$）

$\ln t$ 在 $[1,1+x]$ 上用拉格朗日：$\ln(1+x)=\frac{1}{\xi}x$，$1\lt\xi\lt1+x$，$\frac1\xi$ 夹在 $\frac{1}{1+x}$ 和 1 之间。

例：$f(0)=f(1)=0$，证存在 $\xi$，$f'(\xi)+f(\xi)=0$

$f'+f$ 乘 $e^x$ 才是某函数的导数：$(e^xf)'=e^x(f'+f)$。令 $F=e^xf$，罗尔。这一步我想不到，先记住。

四、洛必达

洛必达法则

$\frac00$ 或 $\frac\infty\infty$ 型，去心邻域可导，$g'\neq0$，$\lim\frac{f'}{g'}$ 存在或为 $\infty$ ⟹ $\lim\frac fg=\lim\frac{f'}{g'}$。

三步：验型 → 求导 → 看新极限存不存在。新极限不存在只说明法则失效，不能说原极限不存在：$\frac{x+\sin x}{x}\to1$。

洛一次马上等价替换，比连洛三次快。两个结果记住：$x-\sin x\sim\frac{x^3}{6}$，$\tan x-x\sim\frac{x^3}{3}$。

型办法
$0\cdot\infty$一个因子取倒数放分母（$\ln x$ 留在分子）。$x\ln x\to0$
$\infty-\infty$通分、有理化。$\frac{1}{x^2}-\frac{1}{x\tan x}\to\frac13$
$0^0,\infty^0$$e^{v\ln u}$。$x^x\to1$

一、树的恒等式

$n=$ 边 $+1$（除根外每个结点一条边向上）。度为 m 的树：

$$n_0=1+n_2+2n_3+\dots+(m-1)n_m$$

k 叉树第 i 层最多 $k^{i-1}$ 个。森林：棵数 = 结点数 − 边数。 根默认第 1 层。题目另说就按题目。

二、二叉树五条性质

1. $n_0=n_2+1$（$n=n_0+n_1+n_2$，$n-1=n_1+2n_2$，相减）。 2. 第 i 层最多 $2^{i-1}$，高 h 最多 $2^h-1$。 3. 完全二叉树 $h=\lfloor\log_2n\rfloor+1$。 4. 编号关系（下标从 0 则左 2i+1、右 2i+2）。 5. 完全二叉树叶子 $\lceil n/2\rceil$，最后分支 $\lfloor n/2\rfloor$；n 偶时恰有 1 个度 1。

n 个结点的二叉链表有 n+1 个空指针。

最多型：第 k 层有 m 个叶子，后面还有一层。第 5 层 6 个叶子：16−6=10 个非叶，下层 20 个，31+20=51。

三、遍历

void PreOrder(BiTree T){
  if(T==NULL) return;
  visit(T);            // 先序放这；中序放两递归之间；后序放最后
  PreOrder(T->lchild); PreOrder(T->rchild);
}
  • 层序用队列：出一个，入它的孩子。
  • 非递归中序：一路向左压栈，弹出时访问，转右。
  • 时间 O(n)；空间递归 O(h)，层序 O(最宽层)。

还原：必须有中序。先序/后序定根，中序切左右。先序 + 后序不行（只有一个孩子时分不清左右）。

三条秒杀：

  • 先序 = 中序 ⟺ 没有左子树。
  • 先序与后序相反 ⟺ 每层一个结点。
  • 先序固定时不同二叉树数 = 卡特兰（先序≈入栈，中序≈出栈），n=4 时 14。

目标写法

四、线索：废物利用

空左指针指前驱，空右指针指后继；ltag/rtag 区分。做法：写序列，只管空指针。 找后继：中序能直接；后序线索树仍要栈或父指针（后继可能是父结点）。

五、孩子兄弟法：家谱改造

树森林二叉树
先根先序先序
后根中序中序

没有后序的对应。数量：森林叶子 = 二叉树左空数；右空数 = 分支结点数 + 1。 三种存储：双亲（并查集）、孩子、孩子兄弟。

六、哈夫曼：每次取最小的两个

  • n 个叶子共 2n−1 个结点，没有度 1。
  • 不唯一，但 WPL 唯一。
  • m 叉要补 0 权虚结点使 $(n-1)\bmod(m-1)=0$。
  • 前缀编码：任何编码不是另一个的前缀；所有字符都在叶子上就天然满足。
  • 判能否同树：父 = 两子之和。

七、并查集

S[x] 存父亲下标，根存负数（绝对值是大小）。

int Find(int S[],int x){
  int root=x; while(S[root]>=0) root=S[root];
  while(x!=root){int t=S[x];S[x]=root;x=t;}  // 路径压缩
  return root;
}

无优化 O(n)；按大小合并 O(log n)；再压缩几乎 O(1)。应用：连通分量数、Kruskal 判环。
