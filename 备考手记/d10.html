一、秩 = 真正独立的信息条数

行阶梯形的非零行数。初等变换不变。

秩的公式（默写）

$r(A)=r(A^T)=r(A^TA)$；可逆 $P,Q$：$r(PAQ)=r(A)$。 $r(A+B)\le r(A)+r(B)$；$r(AB)\le\min\{r(A),r(B)\}$。 $A_{m\times n}B_{n\times s}=O$ ⟹ $r(A)+r(B)\le n$。 $r(A,AB)=r(A)$；$\begin{pmatrix}A&O\\O&B\end{pmatrix}$ 的秩 $=r(A)+r(B)$。 $n$ 阶：$r(AB)\ge r(A)+r(B)-n$。 $r(A^*)=n,\ 1,\ 0$ 对应 $r(A)=n,\ n-1,\ \lt n-1$。

分块也能做初等变换：$\begin{pmatrix}A&AB\\O&B\end{pmatrix}$ 第一块列右乘 $-B$ 加到第二块列，秩 $=r(A)+r(B)$。

二、解的结构

  • 齐次：$r=n$ 只有零解；$r\lt n$ 有非零解，基础解系 $n-r$ 个。自由变量依次取单位向量。
  • 例：$x_1+x_2-x_3-x_4=0$，$2x_1+2x_2+x_3+x_4=0$ ⟹ $\xi_1=(-1,1,0,0)^T$，$\xi_2=(0,0,-1,1)^T$。
  • 非齐次解之差是齐次解；非齐次解 + 齐次解仍是非齐次解。
  • $AB=O$ 的另一层读法：$B$ 的每一列都是 $Ax=0$ 的解。
  • 同解：$r(A)=r(B)=r\begin{pmatrix}A\\B\end{pmatrix}$。公共解：联立。
大题：$x_1+x_2+ax_3=1,\ x_1+ax_2+x_3=1,\ ax_1+x_2+x_3=-2$

方阵先算 $\vert A\vert=-(a+2)(a-1)^2$。 (1) $a\neq1,-2$：唯一解。三式相加 $(a+2)(x_1+x_2+x_3)=0$，于是 $x_1=-\frac{2}{a-1}$，$x_2=x_3=\frac{1}{a-1}$。 (2) $a=1$：$r(A)=1$，$r(A\mid b)=2$，无解。 (3) $a=-2$：$r=2\lt3$，通解 $(1,0,0)^T+k(1,1,1)^T$。

这题第一次手写丢了 $a=1$ 这一支，直接约掉 $(a-1)$。讨论型的题，约因子前先想它是不是 0。

三、向量组：相关就是有人多余

$A=(\alpha_1,\dots,\alpha_n)$ 按列排。翻译表：

话翻译
$\beta$ 可由 $\alpha$ 表示$Ax=\beta$ 有解
相关$Ax=0$ 有非零解，$r(A)\lt n$
无关$r(A)=n$
方阵相关$\vert A\vert=0$
基本结论

个数 > 维数 ⟹ 相关。部分相关 ⟹ 整体相关；整体无关 ⟹ 部分无关。 无关的加长仍无关，相关的减短仍相关。 $\alpha$ 无关、加 $\beta$ 后相关 ⟹ $\beta$ 被唯一表示。 少数表示多数，多数必相关。

两种等价别混：矩阵等价 = 同型且秩同；向量组等价 = 能互相表示。向量组等价则秩同，秩同不一定等价。

$C=AB$：$C$ 的列是 $A$ 的列的组合；$B$ 可逆时 $C,A$ 列向量组等价。

证无关：$\beta_1=\alpha_1+\alpha_2$，$\beta_2=\alpha_2+\alpha_3$，$\beta_3=\alpha_3+\alpha_1$，写成 $(\beta)=(\alpha)C$，$\vert C\vert=2\neq0$。

极大无关组：按列排，只做行变换，首元所在列对应的原向量。读最简形表示其余：$\alpha_3=\alpha_1+\alpha_2$，$\alpha_4=2\alpha_1-\alpha_2$。

四、基、坐标、正交化

  • 过渡矩阵：$(\beta)=(\alpha)C$，$C=A^{-1}B$；坐标 $x=Cy$（旧 = $C$ × 新）。
  • 内积 $\alpha^T\beta$；正交矩阵 $A^TA=E$，$\vert A\vert=\pm1$。
  • 施密特：新向量减去在已有方向上的投影。
$$\beta_2=\alpha_2-\frac{(\alpha_2,\beta_1)}{(\beta_1,\beta_1)}\beta_1$$

术式408 第 21–22 话：CPU 数据通路与控制器；指令流水线与多处理器
实用 3 小时 40 分（时空图手画了六张）进度 23/52 话（44%）

一、CPU 里面

运算器：ALU、GPR、PSW、暂存器。控制器：PC、IR、译码器、时序、CU。

寄存器位数程序员可见？
PC地址位数（按字对齐可少）可见
GPR、PSW可见
MAR地址位数不可见
MDR存储字长不可见
IR指令字长不可见

时钟周期 < 机器周期 < 指令周期。

二、四个周期

微操作（默写）

取指：PC→MAR；MEM→MDR；MDR→IR；PC+1→PC。 间址：Ad(IR)→MAR；MEM→MDR；MDR→Ad(IR)。 中断：SP−1→SP，SP→MAR；PC→MDR 写内存；向量地址→PC。

CPU 区分指令和数据：看处于指令周期的哪个阶段。空操作也要取指，PC 也加 1。

三、数据通路

走一遍 add R1,[R2]：

拍微操作信号
1PC→MARPCout, MARin
2MEM→MDR, PC+1→PCMemR, MDRin
3MDR→IRMDRout, IRin
4R2→MARR2out, MARin
5MEM→MDRMemR, MDRin
6MDR→YMDRout, Yin
7R1+Y→ZR1out, ALU+, Zin
8Z→R1Zout, R1in

单周期 CPI=1，时钟按最慢指令定，不能用单总线。多总线和专用通路可以同周期走多个数。

四、控制器

硬布线：条件反射，快，改不了（RISC）。微程序：查手册，慢，易改（CISC）。

层次：机器指令 → 微程序 → 微指令 → 微命令 → 微操作。控存在 CPU 内，用 ROM，按地址访问。公共取指微程序只算一份。

编码：直接编码一位一命令；字段直接：$m$ 个互斥命令要 $\lceil\log_2(m+1)\rceil$ 位，+1 留给什么都不做。3、7、15 个 ⟹ 2+3+4=9 位。下地址 $\lceil\log_2$ 总数$\rceil$。 水平型并行长快；垂直型一条一动作短慢。

五、流水线：洗衣服不等

量公式
总时间$T=(k+n-1)\Delta t$
吞吐率$TP=n/T$，理想 $1/\Delta t$
加速比$S=nk\Delta t/T$，趋近 k
效率$E=S/k$
周期最慢段 + 段寄存器延迟

5 段、$\Delta t=2$、100 条：$T=208$，$TP\approx.48$，$S\approx4.8$，$E\approx.96$。

利于流水线：定长规整、只 Load/Store 访存、数据对齐，就是 RISC。

六、三种冒险

无转发、WB 前半写 ID 后半读：距离 ≥ 3 条安全。距离 1 阻 2，距离 2 阻 1。

转移要到 EX 才知道：损失 2 拍；放 ID 损失 1 拍；MEM 损失 3 拍。

七、高级与多处理器

超标量：一周期发多条，CPI 可 <1，不缩短功能段时间。超流水：切更短。VLIW：编译器打包。动态：乱序执行顺序提交。

Flynn：SISD 单核；SIMD 向量、GPU；MISD 几乎没有；MIMD 多核。硬件多线程：细粒度每拍切、粗粒度遇阻才切、SMT 同拍发多线程。SMP 共享内存 UMA，要 Cache 一致性。
