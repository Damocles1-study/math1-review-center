一、二重积分：先画图

$\iint_Df\,d\sigma$ 是曲顶柱体体积。

方式写法信号
直角$\int_a^bdx\int_{\varphi_1}^{\varphi_2}f\,dy$边界是直线、抛物线
极坐标$\int_\alpha^\beta d\theta\int_{r_1}^{r_2}f\,r\,dr$（别漏 $r$）圆、扇形；含 $x^2+y^2$、$\frac yx$

换序：内层积不出（$\frac{\sin y}{y}$）。限 → 不等式 → 画 $D$ → 重读。$\int_0^1dx\int_x^1\frac{\sin y}{y}dy=\int_0^1\sin y\,dy=1-\cos1$。

$x^2+y^2\le2x$：$r\le2\cos\theta$，$\theta\in[-\frac\pi2,\frac\pi2]$。例：$\iint\sqrt{x^2+y^2}d\sigma=\frac83\int\cos^3\theta\,d\theta=\frac{32}{9}$。

$\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt\pi}{2}$ 今天终于证了：$4I^2=\iint_{\mathbb R^2}e^{-r^2}r\,dr\,d\theta=\pi$。第六天只是记结果。

对称性：

  • 普通：$D$ 关于 $y$ 轴对称，$f$ 对 $x$ 奇 ⟹ 0；偶 ⟹ 2 倍。
  • 轮换：$D$ 关于 $y=x$ 对称，$x,y$ 可互换。$\iint y^2=\frac12\iint(x^2+y^2)$。单位圆上 $\iint(x+y^2)d\sigma=\frac\pi4$。
  • $\max,\min,\vert\cdot\vert$：切区域，去符号。

二、三重积分

三种坐标

直角：投影法 $\iint_Dd\sigma\int_{z_1}^{z_2}f\,dz$（穿针）；截面法 $\int_c^ddz\iint_{D_z}f\,d\sigma$（被积只含 $z$ 且截面好算）。 柱：$dV=r\,dr\,d\theta\,dz$。旋转体、含 $x^2+y^2$。 球：$x=\rho\sin\varphi\cos\theta,\ y=\rho\sin\varphi\sin\theta,\ z=\rho\cos\varphi$，$dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$。球、锥、含 $x^2+y^2+z^2$。

  • 截面：$\iiint z\,dV$（$x^2+y^2\le z\le1$）$=\int_0^1z\cdot\pi z\,dz=\frac\pi3$。
  • 柱：同一区域 $\iiint(x^2+y^2)=\frac\pi6$。
  • 球：单位球 $\iiint(x^2+y^2+z^2)=2\pi\cdot2\cdot\frac15=\frac{4\pi}{5}$。

形心：$\bar z=\frac{\iiint z\,dV}{V}$。半球 $\bar z=\frac{\pi/4}{2\pi/3}=\frac38$。

三、第一类曲线积分：给铁丝称重

$\int_Lf\,ds=\int_\alpha^\beta f\sqrt{x'^2+y'^2}dt$，$\alpha\lt\beta$，$ds$ 恒正，与走向无关。 先代方程：$\oint_{x^2+y^2=4}(x^2+y^2)ds=4\cdot4\pi=16\pi$。对称和轮换一样能用：$\oint_{x^2+y^2=1}(x^2+xy)ds=\pi$。

四、第一类曲面积分：给薄膜称重

$\iint_\Sigma f\,dS=\iint_Df\sqrt{1+z_x^2+z_y^2}d\sigma$。

曲面$dS$
上半球面 $z=\sqrt{1-x^2-y^2}$$\frac{d\sigma}{z}$
锥面 $z=\sqrt{x^2+y^2}$$\sqrt2d\sigma$
平面 $x+y+z=1$$\sqrt3d\sigma$

$\iint_{\text{半球}}z\,dS=\pi$；锥面 $\iint(x^2+y^2)dS=\frac{\sqrt2\pi}{2}$。

实用 3 小时 45 分（地址切分练了八个例子）进度 33/52 话（63%）

一、Cache：四件事

放哪（映射）、满了赶谁（替换）、写了怎么同步（写策略）、程序命中率。缺失时搬一整块（空间局部性）。

$$T=H\,T_c+(1-H)(T_c+T_m)=T_c+(1-H)T_m\ \text{（先查后访）}$$
$$T=H\,T_c+(1-H)T_m\ \text{（同时访问）}$$
$$CPI=CPI_0+\text{每条访存次数}\times\text{缺失率}\times\text{缺失损失}$$

$T_c=2,T_m=20,H=95\%$：3ns 或 2.9ns。$CPI_0=2$，1.3 次，2%，100 周期：4.6。2% 让速度慢一倍多。

二、三种映射 = 停车场

切地址三步

① 块内 = $\log_2$ 块大小（换算成编址单位）。② 组号 = $\log_2$(行数/路数)。③ 其余是标记。 定位：块号 = 地址 ÷ 块大小；组号 = 块号 % 组数；标记 = 块号 ÷ 组数。

0x12345：块号 1165。直接映射行 13、标记 9；4 路组 13、标记 36。

缺失三类：冷启动、容量、冲突。序列 0 4 0 4 0 4，4 行：直接映射全缺（抢一行），2 路只缺两次。

总容量：行数 ×（数据 + 标记 + 有效 1 + 脏 1 + 替换 $\log_2$路）。上例回写 + LRU：$512+21+1+1+2=537$，×128。

三、替换与写

替换只有全相联和组相联要选。随机、FIFO、LRU（常用）、LFU。LRU 计数器：命中清 0，比它小的加 1；满了赶走最大的。循环访问块数大于路数时抖动（2 路 A B C A B C 全缺）。

命中不命中
全写同写 Cache 和主存（加写缓冲）非写分配
回写只写 Cache，置脏位写分配

多级：L1 分离 I/D（消除结构冒险）。多核要一致性协议。

四、C 程序命中率

读后写：a[k]=a[k]+1，每块 16 次访问只缺 1 次，6.25%。

五、程序怎样进内存

编译（逻辑地址从 0）→ 链接 → 装入（物理地址）。

装入特点
绝对编译时算好，单道
静态重定位装入时改完，不能再移
动态重定位运行时靠重定位寄存器，可移动

链接：静态 / 装入时动态 / 运行时动态。 内存映像：代码、数据、堆（向上）、栈（向下）。 保护：重定位 + 界地址：先比长度，再加基址。共享：可重入代码。 覆盖（程序员）、交换（整个进程，中级调度）。

六、连续分配

内部碎片：分给你用不完。外部碎片：分区之间切不出去（靠紧凑）。

算法找法后果
首次地址从低到高综合最好
邻近接着上次大块被切
最佳容量从小到大小碎片最多
最坏最大的大块没了

回收看邻居：前后都不空 +1，一边 0，两边 −1。

七、分页

$P=A\div$页大小，$W=A\%$页大小；先判 P 不越界；物理 = F×页大小+W。

多级页表：一页放 页大小÷表项大小 项，每级位数 = $\log_2$ 这个数。4KB、4B：10+10+12。k 级访存 k+1 次。优点是不要求大块连续、不用的区域不建，不减访存次数。

分页分段
目的系统用户
大小固定不固定
地址一维二维
碎片内部外部
共享保护难方便

段表存段长，先判越界再相加。段页式：段号 + 页号 + 偏移。
