一、极限到底在问什么

第一页就让我画图：指数、对数、反正切。以前觉得背定义域就行，现在才明白要记的是尽头往哪儿走。

极限的定义（ε–δ）

$\lim\limits_{x\to x_0}f(x)=A$：对任意 $\varepsilon\gt0$，存在 $\delta\gt0$，当 $0\lt\vert x-x_0\vert\lt\delta$ 时，$\vert f(x)-A\vert\lt\varepsilon$。

书上的比方是打靶：对方随便指定多小的靶心，我都能说出「$x$ 靠多近就能打进去」。考试不让用它证题，它只用来判断对错：

  • $0\lt\vert x-x_0\vert$ 这个「去心」的意思是极限和 $f(x_0)$ 无关，这一点甚至可以没定义。
  • 只看足够靠近的局部，改有限项、改一个点的值，都不影响极限。
左右极限判据

极限存在 ⟺ 左、右极限都存在且相等。

必须分左右的三种情况：$e^{1/x}$ 型、$\arctan\frac1x$ 型（都是 $x\to0$）、分段点。还有 $\sqrt{x^2}=\vert x\vert$，$x\lt0$ 时等于 $-x$。

例：$\lim\limits_{x\to0}\dfrac{1+2e^{1/x}}{1+e^{1/x}}$

$x\to0^+$：$e^{1/x}\to+\infty$，上下同除 $e^{1/x}$，得 $2$。 $x\to0^-$：$e^{1/x}\to0$，直接得 $1$。左右不等，极限不存在。

同除这一步我第一次没想到，盯着 ∞/∞ 发呆。谁大就除谁。

二、三条性质

  • 唯一；局部有界；局部保号：$A\gt0$ ⟹ 去心邻域内 $f\gt0$。
  • 反向：附近 $f\ge0$ ⟹ $A\ge0$。$f\gt0$ 也只能推出 $A\ge0$（$x^2\gt0$，极限却是 0）。
例（保号的固定写法）

$\lim\limits_{x\to a}\dfrac{f(x)-f(a)}{(x-a)^2}=-1$ ⟹ 由局部保号性，附近比值 $\lt0$；分母恒正 ⟹ $f(x)\lt f(a)$。

这个动作记下来：把「比值的极限」翻译成「函数值的大小」。

三、无穷小：谁跑得快

无穷小不是很小的数，是正在趋于 0 的变量。$\lim f=A$ ⟺ $f=A+\alpha$，$\alpha$ 是无穷小。

三条运算：有限个的和、积还是无穷小；无穷小 × 有界 = 无穷小（$x\sin\frac1x\to0$，虽然 $\sin\frac1x$ 没极限）。

比值 $\alpha/\beta$ 的极限名字记号
0$\alpha$ 是 $\beta$ 的高阶$\alpha=o(\beta)$
$c\neq0$同阶$c=1$ 时 $\alpha\sim\beta$
$\alpha/\beta^k\to c\neq0$$k$ 阶

增长速度排序（$x\to+\infty$）：$\ln^\alpha x\ll x^\beta\ll a^x\ll x^x$；数列：$\ln n\ll n^\beta\ll a^n\ll n!\ll n^n$。

四、四则运算的前提

$\lim(f\pm g)$、$\lim fg$、$\lim f/g$ 能拆的前提：两个极限都存在（除法分母极限非零）。$\sqrt{x^2+x}-x$ 不能拆成 $\infty-\infty$。

推论，反求参数的第一步：$\lim\frac fg$ 存在且 $\lim g=0$ ⟹ $\lim f=0$。

五、连续 = 取极限等于直接代入

连续

$\lim\limits_{x\to x_0}f(x)=f(x_0)$，即 左极限 = 右极限 = 函数值。

「笔不离纸」。初等函数在定义区间内都连续，可以直接代入，极限还能穿进连续函数里。所以真正要操心的只有：定义域的边界点、分段函数的分段点。

  • 第一类：左右极限都存在。相等 = 可去；不等 = 跳跃。
  • 第二类：至少一侧不存在。趋于 ∞ = 无穷；来回摆 = 振荡（$\sin\frac1x$）。
  • 找间断点两步：列无定义点和分段点 → 每点算左右极限。

例：$f=\dfrac{x^2-1}{x^2-x}$，约分得 $\dfrac{x+1}{x}$。$x=1$ 极限是 2，可去；$x=0$ 趋于 ∞，无穷。

六、闭区间三定理

条件必须写上卷面：闭区间、连续。

  • 最值：有界，能取到 $M,m$。
  • 介值：$\mu\in[m,M]$ ⟹ 存在 $\xi$，$f(\xi)=\mu$。
  • 零点：$f(a)f(b)\lt0$ ⟹ 存在 $\xi\in(a,b)$，$f(\xi)=0$。
例：$pf(a)+qf(b)=(p+q)f(\xi)$（$p,q\gt0$）

整理成 $f(\xi)=\dfrac{pf(a)+qf(b)}{p+q}$。右边是加权平均 ⟹ $m\le$ 右边 $\le M$ ⟹ 介值定理。

二、数据结构是什么

逻辑结构（什么关系：线性、树、图、集合）/ 存储结构（怎么放：顺序、链式、索引、散列）/ 运算。 判别法：去掉「用什么存」这词还有意义吗？有 = 逻辑。「有序表」是逻辑，「循环队列」是存储（规定用数组取模）。

算法五特性：有穷、确定、可行、输入、输出。可以零输入，至少一个输出。

三、时间复杂度：设 t

$O(1)\lt O(\log n)\lt O(n)\lt O(n\log n)\lt O(n^2)\lt O(n^3)\lt O(2^n)\lt O(n!)\lt O(n^n)$ 这行手抄一遍。

四、顺序表

逻辑相邻 = 物理相邻；$LOC(a_i)=LOC(a_1)+(i-1)\cdot$sizeof，随机存取，插删要挪。

  • 平均移动：插入 n/2；删除 (n−1)/2。平均比较：查找 (n+1)/2。
  • 插入从后往前挪，删除从前往后挪，反了会覆盖。
  • 位序从 1，下标从 0，最容易错。
bool ListInsert(SqList &L,int i,int e){
  if(i<1||i>L.length+1) return false;  // 判位置
  if(L.length>=MaxSize) return false;  // 判满
  for(int j=L.length;j>=i;j--) L.data[j]=L.data[j-1];
  L.data[i-1]=e; L.length++; return true;
}
