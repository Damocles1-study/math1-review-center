一、证不等式

固定流程：移项令差函数 → 求导 → 看符号，看不出就再求一阶。

  • 单调法：$F=(1+x)\ln(1+x)-\arctan x$，$F(0)=0$，$F'=\ln(1+x)+\dfrac{x^2}{1+x^2}\gt0$。
  • 最值法：$e^x\ge1+x$，$F=e^x-1-x$ 在 0 处取最小值 0。

二、根的个数：画山形数交点

存在靠零点定理，唯一靠单调，带参数先分离。

结论：$k\gt\frac1e$ 无根；$k=\frac1e$ 或 $k\le0$ 一个；$0\lt k\lt\frac1e$ 两个。

三、中值等式：还原辅助函数

把 $\xi$ 换成 $x$，反问这是谁的导数的因子，然后用罗尔。今天解决了三天前的卡点：

要证$F(x)$
$f'+\lambda f=0$$e^{\lambda x}f$
$f'+g'f=0$$e^{g}f$
$\xi f'+nf=0$$x^nf$
$\xi f'-nf=0$$f/x^n$
$f'g+fg'=0$$fg$
$f'g-fg'=0$$f/g$

记法：$(x^nf)'=x^{n-1}(xf'+nf)$；$(e^{g}f)'=e^g(f'+g'f)$。全是乘积求导，提公因子。

例：两个中值。$f(0)=0,f(1)=1$

(1) 零点定理得 $f(\xi)=1-\xi$。 (2) 在 $[0,\xi],[\xi,1]$ 上各用拉格朗日：$f'(\eta)=\frac{1-\xi}{\xi}$，$f'(\zeta)=\frac{\xi}{1-\xi}$，相乘为 1。 第 (1) 问就是为第 (2) 问准备的分点。

每次用中值定理前「连续、可导」这句都要写，这是采分点。

四、不定积分：求导的逆运算，靠认形状

$F'=f$，$\int f\,dx=F+C$。连续函数一定有原函数。积分表比导数表多这几个要专门背：

被积结果
$\tan x$$-\ln\vert\cos x\vert+C$
$\cot x$$\ln\vert\sin x\vert+C$
$\sec x$$\ln\vert\sec x+\tan x\vert+C$
$\csc x$$\ln\vert\csc x-\cot x\vert+C$
$\frac{1}{a^2+x^2}$$\frac1a\arctan\frac xa+C$
$\frac{1}{\sqrt{a^2-x^2}}$$\arcsin\frac xa+C$
$\frac{1}{\sqrt{x^2+a^2}}$$\ln(x+\sqrt{x^2+a^2})+C$
$\frac{1}{x^2-a^2}$$\frac{1}{2a}\ln\vert\frac{x-a}{x+a}\vert+C$

四招

1. 凑微分：复合函数 × 里层导数。$\int\frac{\ln^2x}{x}dx=\frac{\ln^3x}{3}+C$。配方：$\int\frac{dx}{x^2+2x+5}=\frac12\arctan\frac{x+1}{2}+C$。 2. 换元去根号：$\sqrt{a^2-x^2}$ 令 $x=a\sin t$；$\sqrt{a^2+x^2}$ 令 $x=a\tan t$；$\sqrt{x^2-a^2}$ 令 $x=a\sec t$；$\sqrt[n]{ax+b}$ 令它 $=t$。 3. 分部：$\int u\,dv=uv-\int v\,du$，「反对幂指三」靠前的当 $u$。循环型解方程：$\int e^x\sin x\,dx=\frac12e^x(\sin x-\cos x)+C$。 4. 有理拆项：$(x-a)$ 对 $\frac{A}{x-a}$；$(x-a)^2$ 对两项；不可约二次对 $\frac{Ax+B}{x^2+px+q}$。

一、拓扑排序

AOV：顶点是活动。不断删入度 0 的顶点。

  • 判环：输出数 < n。
  • 时间：表 O(n+e)，矩阵 O(n²)。
  • 每轮入度 0 恰好一个 ⟺ 唯一。
  • 矩阵主对角线以下全 0 ⟹ 存在，但不一定唯一。
  • 逆拓扑：删出度 0；DFS 退出序。

DAG 描述表达式：相同子式共用。$(x+y)((x+y)/x)$：x,y,+,/,* 共 5 个顶点。

二、关键路径：全班等最慢的那个人

AOE：边是活动，顶点是事件。工期 = 最长路径。

$$ve[k]=\max(ve[j]+w),\quad vl[k]=\min(vl[j]-w),\quad e=ve[\text{起}],\quad l=vl[\text{终}]-w$$
  • 关键路径可能多条。缩工期要覆盖所有关键路径（共有活动，或每条各选一个）。
  • 关键活动缩多了就不关键了。

三、查找：一把尺子 ASL

顺序：成功 $\frac{n+1}{2}$；失败（哨兵）$n+1$。

折半要求有序 + 顺序存储。判定树：

  • 高度 $\lceil\log_2(n+1)\rceil$ = 最多比较次数。
  • 全树必须始终如一地向下（或向上）取整。
  • 失败结点 n+1 个。
  • 比较序列判断：每一步都收窄范围。

分块：块内无序块间有序。$ASL=\frac{b+1}{2}+\frac{s+1}{2}$，$s=\sqrt n$ 最小，为 $\sqrt n+1$。$n=10000$：101。

四、散列：储物柜

  • 除留余数 $H=k\%p$，p 取不大于表长的最大质数。
  • 开放定址：线性（1,2,3）、平方（$1^2,-1^2,2^2$）、双散列。拉链。
  • $\alpha=n/m$。ASL 只看 α，不看 n。
  • 开放定址不能直接删，只能标记。
  • 聚集直接影响 ASL。

失败除以 p：散列函数可能取值的个数，不是表长。

五、B 树：让树矮

磁盘 I/O 比内存慢十万倍，一个结点占一块。

m 阶 B 树

至多 m 棵子树、m−1 个关键字。 根至少 2 棵（1 个关键字）；其他至少 $\lceil m/2\rceil$ 棵、$\lceil m/2\rceil-1$ 个关键字。 所有叶子同一层。失败结点 n+1。 最多 $m^h-1$；最少 $2\lceil m/2\rceil^{h-1}-1$。

5 阶高 3：最多 124，最少 17。

B 树B⁺ 树
n 关键字n+1 棵子树n 棵子树
信息所有结点全在叶子
查找可中途成功走到叶子
叶子无链串成链，支持顺序

书的目录：非叶是目录，叶子是正文。适合数据库范围查询。
