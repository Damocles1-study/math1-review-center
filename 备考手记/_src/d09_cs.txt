# 一、指令 = 干什么 + 对谁干
零、一、二、三地址：`OP` / `OP A`（另一个隐含 ACC）/ `OP A1,A2` / `OP A1,A2,A3`。
定长译码快适合流水线（RISC）；变长省空间（CISC）。

**扩展操作码**：短码不能是长码的前缀。从地址多的开始：k 位有 $2^k$ 种，分走 a 条，剩 $2^k-a$ 个前缀，每个再扩 m 位。
16 位、地址 4 位：三地址 0000~1110 共 15 条；二地址 1111 0000~1111 1110 共 15 条……每层留一个 1111。

# 二、寻址：形式地址 A → 有效地址 EA
:::sk 400 170 | 同一组数算一遍。A=2000H，R=1000H；M[1000]=5000，M[2000]=3000，M[3000]=4000
s.box(290,10,92,136,'k',1);
for i,(a,v) in enumerate((('1000','5000'),('2000','3000'),('3000','4000'))):
    s.line(290,44+i*34,382,44+i*34,'k',.8);s.text(296,36+i*34,a,10.5,'g',rot=0);s.text(346,36+i*34,v,12,'k','start',rot=0)
s.text(322,160,'主存',12,'k','middle')
rows=[('立即','无','2000'),('直接','2000','3000'),('间接','(2000)=3000','4000'),('寄存器','无','1000'),('寄存器间接','1000','5000'),('变址','1000+2000','4000')]
s.cells(6,8,[['方式','EA','操作数']]+[list(r) for r in rows],cw=[80,92,60],ch=21,size=11.5)
:::
| 方式 | EA | 访存 | 用途 |
| 立即 | 无 | 0 | 常数 |
| 直接 | A | 1 | 简单，范围小 |
| 间接 | (A) | 2 | 扩大范围、指针 |
| 寄存器 | 无 | 0 | 快 |
| 寄存器间接 | (R) | 1 | |
| 相对 | (PC)+A | 1 | 转移，位置无关 |
| 基址 | (BR)+A | 1 | 重定位，BR 由 OS 管 |
| 变址 | (IX)+A | 1 | ==数组==，程序改 IX |
| 堆栈 | SP | 软栈 1 | |

:::def 相对寻址的 PC
取指时 PC 已经加过这条指令的长度：$EA$ = 当前地址 + 指令长 + 位移（补码，要符号扩展）。
3000H，长 4，位移 −8：2FFCH。
:::
A 有 n 位：直接范围 $2^n$；相对 $-2^{n-1}\sim2^{n-1}-1$。

# 三、读汇编（只读不写）
`mov dest,src`。`[ ]` 才访存，`lea` 里的 `[ ]` 不访存（常用来做乘加）。
`cmp a,b` 做 a−b 只改标志，下一条就是条件转移：`jg jl`（有符号）、`ja jb`（无符号）。

:::sk 400 120 | C 条件是反着写的：`if(a>b)` 汇编跳走的是 `a<=b`。for 循环三个特征：开头比较跳出、中间变址、末尾向回 jmp
s.text(10,20,'if (a>b) x=a; else x=b;',12.5,'b')
for i,t in enumerate(('cmp eax,[ebp+12]','jle ELSE','mov [ebp-4],eax','jmp END','ELSE: …')):
    s.text(14,40+i*16,t,11,'k',rot=0)
s.bend(120,52,70,100,k=-20,c='r');s.text(128,60,'反着跳',11,'r')
s.text(210,20,'for(i=0;i<n;i++) sum+=a[i];',12.5,'b')
for i,t in enumerate(('L1: cmp ecx,[ebp+12]','jge L2','mov eax,[edx+ecx*4]','add [ebp-4],eax','add ecx,1','jmp L1')):
    s.text(214,38+i*14,t,10.5,'k',rot=0)
s.bend(360,108,330,40,k=24,c='r')
:::

# 四、栈帧（今天最重要）
:::sk 400 190 | 从高地址往低长。为什么 `[ebp+8]`：ebp 指旧 ebp，往上 4 是返回地址，再往上才是第一个参数
L=[('实参 2','[ebp+12]','k'),('实参 1','[ebp+8]','k'),('返回地址','[ebp+4]','r'),('旧 ebp','[ebp]','b'),('局部变量 1','[ebp−4]','k'),('局部变量 2','[ebp−8]','k')]
for i,(t,a,c) in enumerate(L):
    s.box(70,10+i*28,120,28,c,1);s.text(130,28+i*28,t,12,c,'middle',rot=0);s.text(198,28+i*28,a,12,c,rot=0)
s.text(14,20,'高地址',11,'g');s.text(14,176,'低地址',11,'g');s.arrow(40,30,40,160,'g',.9)
s.arrow(60,108,70,108,'b');s.text(36,112,'ebp',11,'b');s.arrow(60,178,70,178,'p');s.text(36,182,'esp',11,'p')
s.text(270,28,'call 压入返回地址',11.5,'r');s.text(270,48,'push ebp',11.5);s.text(270,64,'mov ebp,esp',11.5);s.text(270,80,'sub esp,16',11.5)
s.text(270,106,'leave',11.5);s.text(270,122,'ret',11.5);s.text(270,146,'返回值放 eax',11.5,'r')
:::
参数从右向左压。调用者保存 eax ecx edx；被调用者保存 ebx esi edi。递归 n 层 n 个栈帧。这就是第二天那张递归工作栈的真实样子。

**从机器码读地址**：`call` 相对寻址，偏移 = 目标 − ==下一条==地址。00401020H、长 5、目标 00401000H：FFFFFFDBH，小端写 `E8 DB FF FF FF`。
函数长度 = 末条地址 + 末条长度 − 首条地址。

# 五、链接与 RISC
编译 → 汇编（.o，地址从 0 开始）→ 链接（**符号解析** + **重定位**）。静态库进文件；动态运行时才链接。
节：.text / .rodata / .data / .bss（不占文件空间）。

| | CISC | RISC |
| 指令 | 多，变长 | 少，定长 |
| 访存 | 很多都能 | 只有 Load/Store |
| 周期 | 多周期 | 大多一周期 |
| 控制 | 微程序为主 | 硬布线 |
