# 一、二维：概率就是区域上的二重积分
$P((X,Y)\in D)=\iint_Df\,dxdy$。二重积分现在派上用场了。
- 边缘：$f_X=\int f\,dy$（离散：行列求和）。
- 条件：$f_{Y\vert X}=\dfrac{f}{f_X}$。
- 独立：$f=f_Xf_Y$（离散每格都要成立）。

:::eg 大题：$f=6x$（$0\lt x\lt y\lt1$，由 $\int=1$ 得 $c=6$）
先画三角形，所有积分按它定限。
$f_X=\int_x^16x\,dy=6x(1-x)$，$f_Y=\int_0^y6x\,dx=3y^2$，$f\neq f_Xf_Y$，不独立。
$P(X+Y\lt1)=\int_0^{1/2}dx\int_x^{1-x}6x\,dy=\frac14$。
$f_{Y\vert X}=\frac{1}{1-x}$（$x\lt y\lt1$），$(x,1)$ 上均匀。
:::

**$Z=g(X,Y)$**：$F_Z=\iint_{g\le z}f$。
:::def 和、max、min、可加性
卷积：$f_Z(z)=\int f(x,z-x)dx$，独立时 $f_X(x)f_Y(z-x)$。
$F_{\max}=F_XF_Y$，$F_{\min}=1-(1-F_X)(1-F_Y)$。同分布 $F^n$，$1-(1-F)^n$。
独立可加：二项（同 $p$）、泊松、正态。
:::
- 卷积例：两个 $E(1)$：$\int_0^ze^{-z}dx=ze^{-z}$。定限：$x\gt0$ 且 $z-x\gt0$。
- $U(0,1)$：$f_{\max}=2z$，$f_{\min}=2(1-z)$。
- **离散混连续**：$F_Y=\sum P(X=i)P(Y\le y\vert X=i)$。$P(X=1)=\frac13,P(X=2)=\frac23$，$Y\vert X=i\sim U(0,i)$：$0\le y\lt1$ 时 $\frac23y$，$1\le y\lt2$ 时 $\frac{1+y}{3}$。
- 二维正态：边缘正态，线性组合仍正态。==各自正态不一定联合正态。==

# 二、数字特征
期望是重心，方差是分散度。
$E(aX+bY+c)=aEX+bEY+c$（==不要独立==）。$E[g(X)]=\int g f$。
$DX=E(X^2)-(EX)^2$；$D(aX+b)=a^2DX$；$D(X\pm Y)=DX+DY\pm2\mathrm{Cov}$。

| 分布 | $EX$ | $DX$ |
| $B(n,p)$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $\lambda$ | $\lambda$ |
| $G(p)$ | $\frac1p$ | $\frac{1-p}{p^2}$ |
| $U(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| $E(\lambda)$ | $\frac1\lambda$ | $\frac{1}{\lambda^2}$ |
| $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |

$X\sim P(2)$：$E(X^2)=2+4=6$。$f=2x$：$EX=\frac23$，$DX=\frac{1}{18}$，$E(e^X)=2$。$E\vert Z\vert=\sqrt{\frac2\pi}$。

# 三、协方差与相关
$\mathrm{Cov}=E(XY)-EXEY$，双线性。$\rho=\dfrac{\mathrm{Cov}}{\sqrt{DX}\sqrt{DY}}$，$\vert\rho\vert=1$ ⟺ 线性关系。

- 不相关 ⟺ $E(XY)=EXEY$ ⟺ $D(X\pm Y)=DX+DY$。
- ==独立 ⟹ 不相关，反之不成立；二维正态中等价。==
- $D(2X-3Y+1)$，$\mathrm{Cov}=1$：$4+36-12=28$。
- 接上面的三角形：$\mathrm{Cov}=\frac25-\frac38=\frac{1}{40}$，$\rho=\frac{\sqrt3}{3}$。
