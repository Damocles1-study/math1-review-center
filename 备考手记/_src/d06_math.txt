# 一、定积分是和式的极限
$$\int_a^bf(x)dx=\lim_{\lambda\to0}\sum f(\xi_i)\Delta x_i$$
:::sk 280 120 | 切细再加：矩形越窄，锯齿越贴曲线。见到 $n$ 项和就想这张图
s.line(16,102,270,102,'k',1);s.line(30,110,30,10,'k',1)
s.curve([(30,70),(90,42),(160,34),(220,46),(258,60)])
xs=[60+22*i for i in range(9)];ys=[58,48,42,38,35,36,39,44,50]
for x,y in zip(xs,ys):
    s.line(x,102,x,y,'p',.8);s.line(x,y,x+22,y,'p',.8);s.line(x+22,y,x+22,102,'p',.8)
s.text(106,88,'f(ξ_{i})Δx_{i}',12,'b');s.text(58,116,'a',12);s.text(256,116,'b',12)
:::
**实用形式**：$\lim\limits_{n\to\infty}\dfrac1n\sum\limits_{k=1}^{n}f(\frac kn)=\int_0^1f(x)dx$。$\sum\frac{1}{n+k}=\frac1n\sum\frac{1}{1+k/n}\to\int_0^1\frac{dx}{1+x}=\ln2$。

性质：线性、可加、保序、估值。**积分中值定理**：$f$ 连续 ⟹ 存在 $\xi\in[a,b]$，$\int_a^bf=f(\xi)(b-a)$。

算不出来的积分通常也不用算：限相同比被积函数，限不同拆开看多出来那段的符号。

:::def 区间再现
$\int_a^bf(x)dx=\int_a^bf(a+b-x)dx$，两种写法相加常能消分母。
例：$I=\int_0^{\pi/2}\dfrac{\sin x}{\sin x+\cos x}dx$，再现后相加 $2I=\frac\pi2$，$I=\frac\pi4$。
:::

# 二、把微分和积分接起来
:::def 变限积分求导 + 牛—莱
$\dfrac{d}{dx}\int_{\psi(x)}^{\varphi(x)}f(t)dt=f(\varphi)\varphi'-f(\psi)\psi'$
$\int_a^bf=F(b)-F(a)$
:::
==被积函数含 $x$ 时不能直接套==：$\int_0^x(x-t)f(t)dt$ 先拆开提 $x$，得 $F'=\int_0^xf$，$F''=f(x)$；$\int_0^xf(x-t)dt$ 先换元 $u=x-t$。

例：$\lim\limits_{x\to0}\dfrac{\int_0^{x^2}\sin t\,dt}{x^4}$ 洛一次 $\frac{2x\sin x^2}{4x^3}\to\frac12$。第三天那道 2010-9 现在才真懂。

# 三、计算工具
- 换元**换上下限，不回代**；分部 $uv\vert_a^b-\int v\,du$。
- 对称：奇函数 $\int_{-a}^a=0$；偶函数 $=2\int_0^a$。周期：$\int_a^{a+T}=\int_0^T$。
- 圆的方程看面积：$\int_{-1}^1\sqrt{1-x^2}dx=\frac\pi2$。
- 绝对值在零点拆区间。
- 点火：$\int_0^{\pi/2}\sin^nx\,dx=\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots$，偶数末尾 $\frac12\cdot\frac\pi2$，奇数末尾 $\frac23$。$\sin^4$：$\frac34\cdot\frac12\cdot\frac\pi2=\frac{3\pi}{16}$。

# 四、反常积分：一快一慢
:::def 定义
无穷限和瑕积分都是取极限。==区间内部有瑕点或两端无穷必须拆开，每段都收敛才算收敛。==
:::
| $p$ 积分 | 收敛 | 发散 |
| $\int_1^{+\infty}\frac{dx}{x^p}$ | $p\gt1$ | $p\le1$ |
| $\int_0^1\frac{dx}{x^p}$ | $p\lt1$ | $p\ge1$ |

:::sk 300 110 | 无穷远要衰减得足够快，瑕点要爆炸得足够慢。$\frac1x$ 正好卡在中间，两边都发散
ox,oy=70,92;X=lambda x:ox+x*50;Y=lambda y:oy-y*26
s.axes(ox,oy,50,294,102,6,yl='')
s.plot(lambda x:1/x,0.31,4.3,X,Y,n=9)
s.plot(lambda x:1/x**2,0.56,4.3,X,Y,n=8,c='b')
s.plot(lambda x:1/x**.5,0.1,4.3,X,Y,n=8,c='r')
s.line(X(1),oy,X(1),Y(1),'g',.9,dash='3 3');s.text(X(1)-3,oy+13,'1',12)
s.text(X(4.3)-8,Y(1/4.3**.5)-5,'1/√x',12,'r');s.text(X(4.3)-8,Y(1/4.3)-2,'1/x',12);s.text(X(3.3),oy-3,'1/x²',12,'b')
:::
判敛只看奇点处的等价无穷小。**对数奇点从不影响收敛。**
记住：$\int_0^{+\infty}x^ne^{-x}dx=n!$，$\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt\pi}{2}$（推导要等后面学极坐标）。
:::note
$\int_{-1}^{1}\frac{dx}{x^3}$ 不能说奇函数得 0！0 是瑕点，发散。对称性只用于已知收敛的积分。
:::

# 五、面积、体积、弧长
| 量 | 公式 |
| 面积 | $\int(f-g)dx$；极坐标 $\frac12\int r^2d\theta$ |
| 绕 $x$ 轴 | $\pi\int f^2dx$ |
| 绕 $y$ 轴（柱壳） | $2\pi\int x\vert f\vert dx$ |
| 弧长 | $\int\sqrt{1+y'^2}dx=\int\sqrt{x'^2+y'^2}dt=\int\sqrt{r^2+r'^2}d\theta$ |
| 旋转面 | $2\pi\int\vert y\vert ds$ |
