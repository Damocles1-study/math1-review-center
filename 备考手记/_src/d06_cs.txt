# 一、先记「一趟之后长什么样」
稳定性：相同关键字相对次序不变。比较排序下界 $\lceil\log_2(n!)\rceil$，$\Omega(n\log n)$。

# 二、插入、希尔、冒泡
- **直接插入**：理牌。最好 O(n)。稳定。严格大于才挪。折半插入只省比较，==移动不变==，还是 O(n²)。
- **希尔**：按增量分组做直接插入，约 $O(n^{1.3})$，不稳定，只能顺序存储。判增量：看相距 d 的是否各自有序。省的是移动不是比较。
- **冒泡**：每趟一个最值就位，没交换提前结束。最好 O(n)，稳定。

# 三、快排
```
int Partition(int a[],int low,int high){
  int p=a[low];
  while(low<high){
    while(low<high&&a[high]>=p) high--;
    a[low]=a[high];
    while(low<high&&a[low]<=p) low++;
    a[high]=a[low];
  }
  a[low]=p; return low;
}
```

平均 $O(n\log n)$，最坏 $O(n^2)$（已有序或逆序），空间 $O(\log n)$，不稳定。第 k 小只递归一边，平均 O(n)。
**第二趟至少几个就位**：一般 3 个（枢轴在中间），第一趟枢轴在端点时 2 个。==必要条件，只能否定。==

# 四、堆
:::sk 400 136 | 建堆从 ⌊n/2⌋ 向前下沉。上滤一层比 1 次（和父），下滤一层比 2 次（先比两孩子）
s.tree((87,(45,(32,(9,),),(17,)),(78,(65,),(53,))),110,14,dx=56,dy=30,r=10,size=10)
s.text(232,22,'A[1]=87 大根堆',12);s.text(232,44,'排序：堆顶换末尾',12);s.text(232,62,'再对新堆顶下沉',12)
s.text(232,84,'建堆 O(n)，排序 O(n log n)',12,'r')
:::
- 下沉 = 和较大的孩子换，一路往下。
- 插入放末尾上滤；删除末尾补堆顶下滤。
- 最好最坏都是 $O(n\log n)$，空间 O(1)，不稳定。
- 依次插入建堆 ≠ 整体建堆。
- 取前 k 大：大小 k 的小根堆。

**简单选择**：比较恒为 $\frac{n(n-1)}{2}$，交换不超过 n−1，不稳定。

# 五、归并、基数
**归并**：永远 $O(n\log n)$，空间 O(n)，稳定，趟数 $\lceil\log_2n\rceil$。两表合并：比较最少 $\min(m,n)$，最多 $m+n-1$。

**基数**：按位分配收集。$O(d(n+r))$，空间 O(r)，稳定，移动与初始序列无关。

# 六、外排
总时间几乎全是磁盘 I/O。
:::def 四个工具
① 趟数 $S=\lceil\log_kr\rceil$：增大 k 或减小 r。
② 败者树：选最小从 k−1 次降到 $\lceil\log_2k\rceil$ 次。
③ 置换-选择：生成更长的初始段（平均 2w），减小 r。
④ 最佳归并树：哈夫曼。补虚段：$(r-1)\%(k-1)=u\neq0$ 时补 $k-1-u$ 个。
:::
段长 2,3,6,9,12,17,18,24，3 路：7%2=1，补 1 个 0。5、20、47、91，WPL=163，读写 326。
败者树减少比较，==不减少趟数==。

# 七、总表（默写）
| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 每趟就位 |
| 直接插入 | n | n² | n² | 1 | ✓ | ✗ |
| 希尔 | — | n^1.3 | n² | 1 | ✗ | ✗ |
| 冒泡 | n | n² | n² | 1 | ✓ | ✓ |
| 快排 | nlogn | nlogn | n² | logn | ✗ | ✓ |
| 选择 | n² | n² | n² | 1 | ✗ | ✓ |
| 堆 | nlogn | nlogn | nlogn | 1 | ✗ | ✓ |
| 归并 | nlogn | nlogn | nlogn | n | ✓ | ✗ |
| 基数 | d(n+r) | d(n+r) | d(n+r) | r | ✓ | ✗ |

口诀：**快些选堆不稳定**；**选一堆归基与序无关**；链表变慢：希尔、堆。

怎么选：n 小插入/选择；基本有序插入/冒泡；n 大快排堆归并；要稳定归并；放不下外排。
