# 一、拓扑排序
AOV：顶点是活动。不断删入度 0 的顶点。
- 判环：输出数 < n。
- 时间：表 O(n+e)，矩阵 O(n²)。
- ==每轮入度 0 恰好一个 ⟺ 唯一==。
- 矩阵主对角线以下全 0 ⟹ 存在，但不一定唯一。
- 逆拓扑：删出度 0；DFS 退出序。

**DAG 描述表达式**：相同子式共用。$(x+y)((x+y)/x)$：x,y,+,/,* 共 5 个顶点。

# 二、关键路径：全班等最慢的那个人
AOE：边是活动，顶点是事件。工期 = ==最长路径==。

:::sk 400 170 | 手算例子。先拓扑序算 ve，再逆拓扑算 vl。$l-e=0$ 的 b、e、g 是关键活动
P={1:(24,56),2:(100,18),3:(100,94),4:(176,18),5:(176,94),6:(252,56)}
E=[(1,2,'a3','k'),(1,3,'b2','r'),(2,4,'c2','k'),(2,5,'d3','k'),(3,4,'e4','r'),(3,6,'f3','k'),(4,6,'g2','r'),(5,6,'h1','k')]
for a,b,l,c in E:
    s.edge(*P[a],*P[b],10,10,c,arrow=True,w=1.4 if c=='r' else 1.1)
    mx,my=(P[a][0]+P[b][0])/2,(P[a][1]+P[b][1])/2;s.text(mx+2,my-4,l,10,c)
for k,(x,y) in P.items(): s.node(x,y,str(k),r=10,size=10)
s.cells(4,116,[['事件','1','2','3','4','5','6'],['ve','0','3','2','6','6','8'],['vl','0','4','2','6','7','8']],cw=[42,30,30,30,30,30,30],ch=17,size=11)
s.cells(280,8,[['活','e','l'],['a','0','1'],['!b','!0','!0'],['c','3','4'],['d','3','4'],['!e','!2','!2'],['f','2','5'],['!g','!6','!6'],['h','6','7']],cw=[34,30,30],ch=17,size=11)
:::
$$ve[k]=\max(ve[j]+w),\quad vl[k]=\min(vl[j]-w),\quad e=ve[\text{起}],\quad l=vl[\text{终}]-w$$
- 关键路径可能多条。==缩工期要覆盖所有关键路径==（共有活动，或每条各选一个）。
- 关键活动缩多了就不关键了。

# 三、查找：一把尺子 ASL
顺序：成功 $\frac{n+1}{2}$；失败（哨兵）$n+1$。

折半要求==有序 + 顺序存储==。判定树：
:::sk 320 124 | n=11，第 i 层比较 i 次。成功 ASL = (1+4+12+16)/11 = 3。mid 向下取整时每个结点右比左多 0 或 1
s.tree((6,(3,(1,None,(2,)),(4,None,(5,))),(9,(7,None,(8,)),(10,None,(11,)))),150,14,dx=76,dy=34,r=10,size=10)
:::
- 高度 $\lceil\log_2(n+1)\rceil$ = 最多比较次数。
- 全树必须始终如一地向下（或向上）取整。
- 失败结点 n+1 个。
- 比较序列判断：每一步都收窄范围。

**分块**：块内无序块间有序。$ASL=\frac{b+1}{2}+\frac{s+1}{2}$，$s=\sqrt n$ 最小，为 $\sqrt n+1$。$n=10000$：101。

# 四、散列：储物柜
- 除留余数 $H=k\%p$，p 取不大于表长的最大质数。
- 开放定址：线性（1,2,3）、平方（$1^2,-1^2,2^2$）、双散列。拉链。
- $\alpha=n/m$。==ASL 只看 α，不看 n。==
- 开放定址==不能直接删==，只能标记。
- 聚集直接影响 ASL。

:::sk 400 110 | 手算：表长 11，H=k%11，插 22,41,53,46,30,13,1,67。下面一行是比较次数。成功 14/8=1.75；失败 47/11（除 p 不除关键字数）
T=['22','1','46','13','67','','','','41','53','30'];C=['1','1','1','2','4','','','','1','1','3']
for i in range(11):
    s.box(6+i*34,22,34,24,'k',.9);s.text(23+i*34,39,T[i],11.5,'k','middle',rot=0);s.text(23+i*34,16,str(i),10,'g','middle',rot=0)
    s.text(23+i*34,62,C[i],12,'r','middle',rot=0)
s.text(6,86,'30：8 占 9 占 → 10，3 次。67：1,2,3 占 → 4，4 次。',12)
s.text(6,104,'查找失败从 i 走到第一个空位：6,5,4,3,2,1,1,1,9,8,7',12,'b')
:::
**失败除以 p**：散列函数可能取值的个数，不是表长。

# 五、B 树：让树矮
磁盘 I/O 比内存慢十万倍，一个结点占一块。
:::def m 阶 B 树
至多 m 棵子树、m−1 个关键字。
根至少 2 棵（1 个关键字）；其他至少 $\lceil m/2\rceil$ 棵、$\lceil m/2\rceil-1$ 个关键字。
所有叶子同一层。失败结点 n+1。
最多 $m^h-1$；最少 $2\lceil m/2\rceil^{h-1}-1$。
:::
5 阶高 3：最多 124，最少 17。

:::
| | B 树 | B⁺ 树 |
| n 关键字 | n+1 棵子树 | n 棵子树 |
| 信息 | 所有结点 | ==全在叶子== |
| 查找 | 可中途成功 | 走到叶子 |
| 叶子 | 无链 | 串成链，支持顺序 |

书的目录：非叶是目录，叶子是正文。适合数据库范围查询。
