# 一、BST
左 < 根 < 右，==中序递增==（判 BST 就用这条）。新结点必是叶子。
**删除**：叶子直接删；一个孩子让孩子顶替；两个孩子用中序后继（右子树最左）的值替换，再删那个结点。
查找路径判断：每走一步范围收窄。
依次插入 1,2,3,4,5 是一条链，ASL=3；3,1,4,2,5 矮，ASL=2.2。

# 二、AVL
平衡因子 = 左高 − 右高 ∈ {−1,0,1}。
高度 h 最少结点：$N(h)=N(h-1)+N(h-2)+1$：1, 2, 4, 7, 12, 20, 33, 54。

# 三、红黑树
不严格平衡，最长 ≤ 2 × 最短。
:::def 五条
非红即黑；根黑；NIL 黑；==红的孩子必黑==；每条路径==黑结点数相同==（黑高 bh）。
:::
- $h\le2\log_2(n+1)$；黑高 bh 的子树至少 $2^{bh}-1$ 个内部结点。
- 根黑高 k：最少 $2^k-1$，最多 $2^{2k}-1$。
- 新结点染红（染黑必破坏黑高）。
- 父红时看叔叔：**叔红变色往上推；叔黑旋转**（方向同 AVL）。

:::sk 280 108 | 书上那棵，我用红笔画红结点。数每条路的黑结点：都是 2 个（不算 NIL）

:::

# 四、图：存下来
- 无向度和 = 2e；有向入度和 = 出度和 = e。
- 完全图：无向 $\frac{n(n-1)}{2}$，有向 $n(n-1)$。
- 连通最少 n−1 条；强连通最少 n 条（一个环）。
- ==保证任何情况都连通==：$C_{n-1}^2+1$（n−1 个点连满再连一条）。

| 存储 | 适用 | 空间 | 判 i-j |
| 邻接矩阵 | 稠密 | O(n²) | O(1) |
| 邻接表 | 稀疏 | O(n+e) | O(度) |
| 十字链表 | 有向 | O(n+e) | 入度出度都好求 |
| 多重表 | 无向 | O(n+e) | 每条边一个结点，删边方便 |

$A^m[i][j]$ = i 到 j 长度为 m 的路径条数。
邻接表找入度要扫全表；表示==不唯一==，所以遍历序列不唯一；矩阵唯一。

# 五、走一遍
:::sk 340 110 | BFS 水波，队列；DFS 走迷宫，栈。边 0-1、0-2、1-3、2-4、3-4 从 0 出发
pts={0:(36,50),1:(96,20),2:(96,84),3:(160,20),4:(160,84)}
for a,b in ((0,1),(0,2),(1,3),(2,4),(3,4)): s.edge(*pts[a],*pts[b],11,11)
for k,(x,y) in pts.items(): s.node(x,y,str(k),r=11)
s.text(200,36,'BFS 0 1 2 3 4',13,'b');s.text(200,60,'DFS 0 1 3 4 2',13,'r');s.text(200,84,'矩阵 O(n²)  表 O(n+e)',12)
:::
- 复杂度==只看存储==，BFS、DFS 一样。
- BFS 入队时就标记，否则重复入队。
- 连通分量数 = 主循环启动次数。BFS 求无权最短路。DFS 退出序的逆 = 拓扑序。
- 判 BFS 序列按层；判 DFS 看下一个是不是当前的未访问邻居。

# 六、最小生成树
跨越任意割的最小边一定值得选。
| 算法 | 思路 | 时间 | 适合 |
| Prim | 从一点长大，选连接集合的最小边 | O(n²) | 稠密 |
| Kruskal | 边排序，能选就选，并查集判环 | O(e log e) | 稀疏 |

代价唯一，树不一定唯一；边权全不同 ⟹ 唯一（反之不成立）。

# 七、最短路径
**Dijkstra**：烧绳子。每轮选 dist 最小的未确定顶点，松弛。O(n²)。==不能负权==（确定了不再回头）。
:::sk 370 124 | 我的手算表。边 1→2:10，1→5:5，2→3:1，2→5:2，3→4:4，4→1:7，4→3:6，5→2:3，5→3:9，5→4:2
s.cells(6,6,[['选','d(2)','d(3)','d(4)','d(5)'],['1','10','∞','∞','5'],['5','!8','14','!7','·'],['4','8','!13','·','·'],['2','·','!9','·','·'],['3','·','·','·','·']],cw=[34,50,50,50,50],ch=19,size=12)
s.text(252,28,'每行选最小的',12,'r');s.text(252,46,'红 = 被松弛变小',12,'r');s.text(252,70,'结果 8,9,7,5',13,'b')
:::
**Floyd**：`k` 在最外层。允许负边不允许负环。O(n³)。

| 算法 | 问题 | 复杂度 |
| BFS | 无权单源 | O(n+e) |
| Dijkstra | 带权单源 | O(n²) |
| Floyd | 所有点对 | O(n³) |

==Prim 比边权，Dijkstra 比累计距离==，代码只差一句，产出的树多半不同。
