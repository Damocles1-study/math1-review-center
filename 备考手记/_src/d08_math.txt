# 一、一阶：认型，三把钥匙
阶 = 最高导数的阶。通解的独立常数个数 = 阶数；定了常数是特解。
| 型 | 样子 | 钥匙 |
| 可分离 | $y'=f(x)g(y)$ | $\frac{dy}{g(y)}=f(x)dx$ 两边积分 |
| 齐次 | $y'=\varphi(\frac yx)$ | $u=\frac yx$，$y'=u+xu'$ |
| 一阶线性 | $y'+Py=Q$ | 公式 |

:::def 一阶线性通解
$y=e^{-\int Pdx}\Bigl(\int Qe^{\int Pdx}dx+C\Bigr)$
来历：两边乘积分因子 $e^{\int P}$，左边恰是 $(ye^{\int P})'$。
:::
==先把 $y'$ 系数化成 1 再读 $P,Q$。==有时把 $x$ 看成 $y$ 的函数才线性：$\frac{dy}{dx}=\frac{1}{x+y}$ ⟹ $\frac{dx}{dy}-x=y$。

例：$y'=2xy,\ y(0)=3$ ⟹ $y=3e^{x^2}$。$xy'=y+x\tan\frac yx$ ⟹ $\sin\frac yx=Cx$。

**几何建模**：切线 $Y-y=y'(X-x)$，令 $X=0$，$y$ 轴截距是 $y-xy'$。

# 二、二阶：可降阶两种
- 不显含 $y$：$p=y'$，$y''=p'$。
- 不显含 $x$：$p=y'$，$y''=p\frac{dp}{dy}$。

例：$y''=2yy'$，$y(0)=1,y'(0)=1$ ⟹ $p=y^2$ ⟹ $y=\frac{1}{1-x}$。

# 三、线性方程的结构
非齐次通解 = 齐次通解 + 一个特解。**两个非齐次解之差是齐次解。**右端可叠加。$y_1,y_2$ 比值不是常数才能组成通解。

# 四、特征根定一切
:::def 常系数齐次 $y''+py'+qy=0$，$r^2+pr+q=0$
不等实根：$C_1e^{r_1x}+C_2e^{r_2x}$
二重根：$(C_1+C_2x)e^{rx}$
复根 $\alpha\pm i\beta$：$e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$
:::

:::def 非齐次特解设法
$f=P_m(x)e^{\lambda x}$：$y^*=x^kQ_m(x)e^{\lambda x}$，$k$ 是 $\lambda$ 的重数（0/1/2）。
$f=e^{\alpha x}[P_l\cos\beta x+P_n\sin\beta x]$：$y^*=x^ke^{\alpha x}[R_m\cos\beta x+T_m\sin\beta x]$，$m=\max(l,n)$，$k$ 是 $\alpha+i\beta$ 的重数。
:::
:::eg 例：$y''-3y'+2y=xe^x$
$r=1,2$。$\lambda=1$ 单根，$k=1$。设 $u=ax^2+bx$，$y^*=ue^x$，==代入省事法==：$y'=(u'+u)e^x$，$y''=(u''+2u'+u)e^x$，约去 $e^x$ 得 $u''-u'=x$。$a=-\frac12,b=-1$。
通解 $C_1e^x+C_2e^{2x}-(\frac{x^2}{2}+x)e^x$。
:::
$y''+y=\cos x$：$\pm i$ 是根，$y^*=x(a\cos x+b\sin x)$，得 $y=C_1\cos x+C_2\sin x+\frac x2\sin x$。

**不解方程直接积分**：$y''+3y'+2y=0$，$y(0)=1,y'(0)=0$，根全负 ⟹ $y,y'\to0$，两边积分 $-0-3+2\int_0^{+\infty}y=0$，得 $\frac32$。

**欧拉方程**：$x=e^t$，$xy'=Dy$，$x^2y''=D(D-1)y$。$x^2y''-2xy'+2y=0$ ⟹ $y=C_1x+C_2x^2$。
