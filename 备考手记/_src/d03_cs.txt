# 一、树的恒等式
$n=$ 边 $+1$（除根外每个结点一条边向上）。度为 m 的树：
$$n_0=1+n_2+2n_3+\dots+(m-1)n_m$$
k 叉树第 i 层最多 $k^{i-1}$ 个。森林：**棵数 = 结点数 − 边数**。
根默认第 1 层。题目另说就按题目。

# 二、二叉树五条性质
:::sk 300 156 | 完全二叉树按层编号：左 2i，右 2i+1，父 ⌊i/2⌋。自己多画一层才看出来最后一层靠左
s.tree((1,(2,(4,(8,),(9,)),(5,(10,),)),(3,(6,),(7,))),150,16,dx=72,dy=36,r=11,size=11)
:::
1. $n_0=n_2+1$（$n=n_0+n_1+n_2$，$n-1=n_1+2n_2$，相减）。
2. 第 i 层最多 $2^{i-1}$，高 h 最多 $2^h-1$。
3. 完全二叉树 $h=\lfloor\log_2n\rfloor+1$。
4. 编号关系（下标从 0 则左 2i+1、右 2i+2）。
5. 完全二叉树叶子 $\lceil n/2\rceil$，最后分支 $\lfloor n/2\rfloor$；n 偶时恰有 1 个度 1。

n 个结点的二叉链表有 n+1 个空指针。

**最多型**：第 k 层有 m 个叶子，后面还有一层。第 5 层 6 个叶子：16−6=10 个非叶，下层 20 个，31+20=51。

# 三、遍历
:::sk 330 130 | 先中后说的是根。自己走了一遍 `A(B(D,E),C(,F))`
s.tree(('A',('B',('D',),('E',)),('C',None,('F',))),110,16,dx=56,dy=38,r=11)
s.text(226,30,'先 ABDECF',13);s.text(226,54,'中 DBEACF',13);s.text(226,78,'后 DEBFCA',13);s.text(226,102,'层 ABCDEF',13)
:::
```
void PreOrder(BiTree T){
  if(T==NULL) return;
  visit(T);            // 先序放这；中序放两递归之间；后序放最后
  PreOrder(T->lchild); PreOrder(T->rchild);
}
```
- 层序用队列：出一个，入它的孩子。
- 非递归中序：一路向左压栈，弹出时访问，转右。
- 时间 O(n)；空间递归 O(h)，层序 O(最宽层)。

**还原**：==必须有中序==。先序/后序定根，中序切左右。先序 + 后序不行（只有一个孩子时分不清左右）。

**三条秒杀**：
- 先序 = 中序 ⟺ 没有左子树。
- 先序与后序相反 ⟺ 每层一个结点。
- 先序固定时不同二叉树数 = 卡特兰（先序≈入栈，中序≈出栈），n=4 时 14。

**树类代码题三模子**：
| 目标 | 写法 |
| 全局量（高度、WPL） | `return f(左)+f(右)` |
| 要层数 | 参数 depth 往下传 |
| 判定（BST、平衡） | flag 或返回值带回，中序递增判 BST |

# 四、线索：废物利用
空左指针指前驱，空右指针指后继；ltag/rtag 区分。做法：写序列，只管空指针。
找后继：中序能直接；==后序线索树仍要栈或父指针==（后继可能是父结点）。

# 五、孩子兄弟法：家谱改造
:::sk 400 120 | 左手牵大儿子，右手牵下一个弟弟。根没有兄弟，所以根没有右孩子
s.node(80,20,'A',r=11)

没有后序的对应。**数量**：森林叶子 = 二叉树左空数；右空数 = 分支结点数 + 1。
三种存储：双亲（并查集）、孩子、孩子兄弟。

# 六、哈夫曼：每次取最小的两个
:::sk 320 118 | {1,2,4,5}：3、7、12。WPL = 5·1+4·2+2·3+1·3 = 22。权小的离根远
s.node(190,14,'12',r=12,size=11);s.node(130,48,'7',r=12,size=11);s.node(250,48,'5',r=12,size=11,c='b')
s.node(80,82,'3',r=12,size=11);s.node(170,82,'4',r=12,size=11,c='b');s.node(40,110,'1',r=10,size=11,c='b');s.node(110,110,'2',r=10,size=11,c='b')
for a in ((190,14,130,48),(190,14,250,48),(130,48,80,82),(130,48,170,82),(80,82,40,110),(80,82,110,110)): s.edge(*a,11,11)
s.text(214,92,'蓝 = 叶子 = 字符',12,'b')
:::
- n 个叶子共 ==2n−1== 个结点，没有度 1。
- 不唯一，但 ==WPL 唯一==。
- m 叉要补 0 权虚结点使 $(n-1)\bmod(m-1)=0$。
- 前缀编码：任何编码不是另一个的前缀；所有字符都在叶子上就天然满足。
- 判能否同树：==父 = 两子之和==。

# 七、并查集
`S[x]` 存父亲下标，根存负数（绝对值是大小）。
```
int Find(int S[],int x){
  int root=x; while(S[root]>=0) root=S[root];
  while(x!=root){int t=S[x];S[x]=root;x=t;}  // 路径压缩
  return root;
}
```
无优化 O(n)；按大小合并 O(log n)；再压缩几乎 O(1)。应用：连通分量数、Kruskal 判环。
