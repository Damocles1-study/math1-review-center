# 比方
- 第 7 章：嘴上请吃饭手里备刀（重庆谈判）→ 先防一年 → 打出去 → 一锅端 → 后方也在打仗（土改、第二条战线、民主党派倒向）。
- 站起来后三件事：站稳（1949–52）、转型（1953–56）、摸路（1956–76）。
- 改革一串：一篇文章松思想（真理标准）→ 一次全会掉方向盘 → 一份决议定调 → 一次南巡再推一把。

# 错句和张冠李戴
- 不要四面出击是 1950 七届三中全会；真正不结盟是 1982。
- 进入社会主义标志不是 1954 宪法。肝胆相照不是毛泽东提的。
- 拨乱反正完成不是三中全会（是 1981）；思想先导也不是三中全会。
- 宣言书两份：12.13 讲话开辟新时期；南方谈话是「又一个」，没有开启新时期。基本经济制度是十五大。

# 分析题框架
:::def 中国革命为什么胜利
① 三座大山压迫。② 工农小资为主力，民族资产阶级靠拢。③ 根本是党的领导。④ 三大法宝。⑤ 彻底结束半殖民地半封建，为复兴创造根本社会条件。
:::
:::def 社会主义基本制度确立的意义
① 最深刻最伟大的变革，消灭剥削。② 根本政治前提和制度基础。③ 解放生产力。④ 积极引导、逐步过渡、和平赎买。⑤ 为开创中国特色社会主义提供经验、理论、物质基础。
:::
:::def 十一届三中全会
① 思想：解放思想、实事求是。② 政治：停止以阶级斗争为纲，转向经济建设，改革开放。③ 组织：重新确立三条路线。④ 伟大转折，开启新时期。⑤ 改革只有进行时。
:::
