# 认识论
实践：人类能动地改造世界的社会性的物质活动。三特征：直接现实性、自觉能动性、社会历史性。最基本的是物质生产实践；虚拟实践是派生形式。

实践对认识：==来源、动力、目的、唯一检验标准==。
认识的本质：主体在实践基础上对客体的能动反映（摹写性 + 创造性）。

真理：本质属性客观性；一元。价值：主体性、客观性、多维性、社会历史性；多元。自由 = 对必然的认识和对客观世界的改造。

**错句**：意识有直接现实性；规律能改造；真理由相对到绝对再到相对；绝对真理和相对真理是两种真理。

# 历史观：一栋楼
地基（生产力）一变，一楼（生产关系）要翻修，楼上（上层建筑）跟着改。

| 问 | 答 |
| 基本问题 | 社会存在与社会意识 |
| 决定力量 | 物质生产方式 |
| 自然环境 | 永恒必要条件 |
| 人口 | 加速或延缓 |
| 最活跃的 | ==劳动者==（不是科技） |
| 先进生产力标志 | 科学技术 |
| 生产关系决定性的 | 生产资料所有制 |
| 根本动力 | 社会基本矛盾 |
| 直接动力 | 阶级斗争 |
| 进步的根本尺度 | 生产力 |
| 人的本质 | 一切社会关系的总和 |
| 历史创造者 | 人民群众 |

口诀：环境永恒必要、人口加速延缓、生产方式基础决定。

# 比方
- 认识论像学做菜：下厨（实践）→ 知道火候（感性）→ 总结油冒烟再下菜（理性，第一次飞跃）→ 做新菜（第二次飞跃，更重要）→ 端上桌尝（唯一标准）。川菜对不吃辣的人是灾难（价值主体性）。
- 费尔巴哈是只拍风景的游客（直观），马克思要动手改造风景。
- 绝对真理是长河，每滴水都是真河水，但一滴不是整条河。
- 自由像学开车：不懂交规叫乱开，练熟了才人车合一。
- 我是谁看关系：家里是子女，学校是学生。这就是一切社会关系的总和。

**判实践**：超出纯意识活动，实际改变了外部存在物。看书做梦不是；做实验、网上协作开发软件是。
**一词一选**：需要、工具 → 动力；只有亲自 → 来源；为了用 → 目的；检验 → 标准。
**三个依据**：区分时代看生产工具；区分生产方式看所有制；进步尺度看生产力。
**根本**只给基本矛盾，**直接**只给阶级斗争，**杠杆**给科技，**重要力量**给文化。

# 错句再加几条
- 占有了真实的感性材料就等于抓住本质（最高频）。
- 是否有目的性能区分实践和认识（意识也有目的）。
- 认识的反复性决定事物复杂性（因果颠倒）。
- 保护生态是一切活动的首要前提（首要是物质生产）。
- 每个人都是历史创造者（是人民群众整体）；杰出人物可改变基本方向。

# 分析题框架
:::def 认识的辩证过程（调研、试点、推广）
① 实践是认识的基础。② 感性到理性：真实材料 + 科学思维加工。③ 理性到实践更重要：结合实际、中介环节（试点）、群众掌握。④ 落到材料。
:::
:::def 真理与价值（科技伦理、AI）
① 实践受两个尺度制约。② 成功实践是合规律性与合目的性统一。③ 价值以真理为前提，真理受价值引导。④ 既尊重科学规律，又以人民利益为尺度，科技向善。
:::
:::def 人与自然（生态）
① 自然环境是永恒必要条件。② 生命共同体，违背规律遭报复。③ 调节物质变换，保护与发展不根本对立。④ 尊重顺应保护，生态效益与经济效益统一。
:::
:::def 人民群众创造历史
① 物质、精神财富创造者，变革决定力量。② 意愿代表方向，实践决定结局。③ 群众观点和路线，以人民为中心。④ 问需于民、问计于民。
:::
