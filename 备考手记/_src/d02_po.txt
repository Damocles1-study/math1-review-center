# 认识论
实践：人类能动地改造世界的社会性的物质活动。三特征：直接现实性、自觉能动性、社会历史性。最基本的是物质生产实践；虚拟实践是派生形式。

实践对认识：==来源、动力、目的、唯一检验标准==。
认识的本质：主体在实践基础上对客体的能动反映（摹写性 + 创造性）。

:::sk 400 100 | 两次飞跃：更重要的是第二次，回到实践。总规律就是这个循环

s.bend(325,62,44,62,k=-26,c='r');s.text(186,96,'第二次（更重要）回到实践',12,'r','middle')
:::
真理：本质属性客观性；一元。价值：主体性、客观性、多维性、社会历史性；多元。自由 = 对必然的认识和对客观世界的改造。

**错句**：意识有直接现实性；规律能改造；真理由相对到绝对再到相对；绝对真理和相对真理是两种真理。

# 历史观：一栋楼
地基（生产力）一变，一楼（生产关系）要翻修，楼上（上层建筑）跟着改。

| 问 | 答 |
| 基本问题 | 社会存在与社会意识 |
| 决定力量 | 物质生产方式 |
| 自然环境 | 永恒必要条件 |
| 人口 | 加速或延缓 |
| 最活跃的 | ==劳动者==（不是科技） |
| 先进生产力标志 | 科学技术 |
| 生产关系决定性的 | 生产资料所有制 |
| 根本动力 | 社会基本矛盾 |
| 直接动力 | 阶级斗争 |
| 进步的根本尺度 | 生产力 |
| 人的本质 | 一切社会关系的总和 |
| 历史创造者 | 人民群众 |

口诀：环境永恒必要、人口加速延缓、生产方式基础决定。
