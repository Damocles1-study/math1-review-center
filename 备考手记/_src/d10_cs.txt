# 一、CPU 里面
运算器：ALU、GPR、PSW、暂存器。控制器：PC、IR、译码器、时序、CU。
| 寄存器 | 位数 | 程序员可见？ |
| PC | 地址位数（按字对齐可少） | 可见 |
| GPR、PSW | | 可见 |
| MAR | 地址位数 | 不可见 |
| MDR | 存储字长 | 不可见 |
| IR | 指令字长 | 不可见 |

时钟周期 < 机器周期 < 指令周期。

# 二、四个周期
:::def 微操作（默写）
**取指**：PC→MAR；MEM→MDR；MDR→IR；PC+1→PC。
**间址**：Ad(IR)→MAR；MEM→MDR；MDR→Ad(IR)。
**中断**：SP−1→SP，SP→MAR；PC→MDR 写内存；向量地址→PC。
:::
CPU 区分指令和数据：看处于指令周期的哪个阶段。空操作也要取指，PC 也加 1。

| 拍 | 微操作 | 信号 |
| 1 | PC→MAR | PCout, MARin |
| 2 | MEM→MDR, PC+1→PC | MemR, MDRin |

| 4 | R2→MAR | R2out, MARin |

单周期 CPI=1，时钟按最慢指令定，==不能用单总线==。多总线和专用通路可以同周期走多个数。

# 四、控制器
硬布线：条件反射，快，改不了（RISC）。微程序：查手册，慢，易改（CISC）。

层次：机器指令 → 微程序 → 微指令 → 微命令 → 微操作。控存在 CPU 内，用 ROM，==按地址访问==。公共取指微程序只算一份。

**编码**：直接编码一位一命令；字段直接：$m$ 个互斥命令要 $\lceil\log_2(m+1)\rceil$ 位，==+1 留给什么都不做==。3、7、15 个 ⟹ 2+3+4=9 位。下地址 $\lceil\log_2$ 总数$\rceil$。
水平型并行长快；垂直型一条一动作短慢。

# 五、流水线：洗衣服不等
:::sk 400 118 | 时空图。每条指令没变快，但第 5 拍起每拍出一条
ph=['IF','ID','EX','MEM','WB']
for r in range(4):
    s.text(6,27+r*22,'I%d'%(r+1),12,rot=0)
    for j,p in enumerate(ph):
        x=34+(r+j)*42;c='r' if j==4 else 'k';s.box(x,12+r*22,42,22,c,.9);s.text(x+21,27+r*22,p,10.5,c,'middle',rot=0)
for k in range(8): s.text(55+k*42,110,str(k+1),10,'g','middle',rot=0)
:::
| 量 | 公式 |
| 总时间 | $T=(k+n-1)\Delta t$ |
| 吞吐率 | $TP=n/T$，理想 $1/\Delta t$ |
| 加速比 | $S=nk\Delta t/T$，趋近 k |
| 效率 | $E=S/k$ |
| 周期 | ==最慢段 + 段寄存器延迟== |

5 段、$\Delta t=2$、100 条：$T=208$，$TP\approx.48$，$S\approx4.8$，$E\approx.96$。

利于流水线：定长规整、只 Load/Store 访存、数据对齐，就是 RISC。

# 七、高级与多处理器
**超标量**：一周期发多条，CPI 可 <1，==不缩短功能段时间==。**超流水**：切更短。**VLIW**：编译器打包。动态：乱序执行顺序提交。

Flynn：SISD 单核；SIMD 向量、GPU；MISD 几乎没有；MIMD 多核。硬件多线程：细粒度每拍切、粗粒度遇阻才切、SMT 同拍发多线程。SMP 共享内存 UMA，要 Cache 一致性。
