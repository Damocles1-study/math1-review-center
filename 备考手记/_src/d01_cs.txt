# 二、数据结构是什么
**逻辑结构**（什么关系：线性、树、图、集合）/ **存储结构**（怎么放：顺序、链式、索引、散列）/ **运算**。
判别法：去掉「用什么存」这词还有意义吗？有 = 逻辑。「有序表」是逻辑，「循环队列」是存储（规定用数组取模）。

算法五特性：有穷、确定、可行、输入、输出。==可以零输入，至少一个输出。==

# 三、时间复杂度：设 t
$O(1)\lt O(\log n)\lt O(n)\lt O(n\log n)\lt O(n^2)\lt O(n^3)\lt O(2^n)\lt O(n!)\lt O(n^n)$ 这行手抄一遍。

:::def 循环题万能三步
1. 设基本语句执行 t 次。
2. 写第 t 次时循环变量的值。
3. 代入循环条件解 t。
:::
| 代码 | 翻译 | 结果 |
| `for i<=n; for j<=i` | $1+2+\dots+n$ | $n^2$ |
| `for(i=1;i<=n;i*=2)` | $2^t\le n$ | $\log n$ |
| `while(i*i<=n) i++` | $t^2\le n$ | $\sqrt n$ |

:::sk 340 100 | 今天最大的坑：内层次数随外层变化时，==相乘只是上界==。这段是 $1+2+4+\dots\approx2n$，不是 $n\log n$
xs=[20,44,78,130,214]
for x,h,l in zip(xs,[6,12,24,48,80],['1','2','4','8','…']):
    w={20:16,44:24,78:40,130:72,214:112}[x];s.box(x,92-12,w,12,'k',.9);s.text(x+w/2,76,l,11,'k','middle',rot=0)
s.text(20,30,'内层 = i：',12);s.text(20,48,'一条比一条长一倍，总和 ≈ 最后一条的两倍',12,'r')
:::
递归：`T(n)=T(n−1)+O(1)` ⟹ O(n)；`T(n)=2T(n/2)+O(n)` ⟹ O(n log n)；`T(n)=2T(n−1)+O(1)` ⟹ O(2ⁿ)。

**空间**：只算额外的。几个变量 O(1) 叫原地；==递归深度就是空间==（每层压栈）。
不写明时 O() 指最坏。来不及推：代入 n=4、8，看翻几倍。

# 四、顺序表
逻辑相邻 = 物理相邻；$LOC(a_i)=LOC(a_1)+(i-1)\cdot$sizeof，==随机存取==，插删要挪。
- 平均移动：插入 n/2；删除 (n−1)/2。平均比较：查找 (n+1)/2。
- **插入从后往前挪，删除从前往后挪**，反了会覆盖。
- 位序从 1，下标从 0，最容易错。

```
bool ListInsert(SqList &L,int i,int e){
  if(i<1||i>L.length+1) return false;  // 判位置
  if(L.length>=MaxSize) return false;  // 判满
  for(int j=L.length;j>=i;j--) L.data[j]=L.data[j-1];
  L.data[i-1]=e; L.length++; return true;
}
```

| 招 | 用处 | 要点 |
| 逆置 | 循环移位 | 首尾换，走到中点 |
| 快慢指针 | 原地删除 | `k` 写，`i` 读：`if(a[i]!=x) a[k++]=a[i]` |
| 有序合并 | 归并、第 k 小 | 每次取小，走到第 k 步可停；多个数组只推进最小的指针 |
| 下标当哈希 | 缺失、重复 | 值域有限，开 `count[]`，空间换时间 |

**主元素（投票法）**：不同的两两抵消，相同 +1，不同 −1，到 0 换候选，==最后再扫一遍确认==。
