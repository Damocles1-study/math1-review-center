# 一、文件操作
create（分配空间 + 建目录项）、delete、read/write（按指针找块）、close（写回 FCB）。
:::def open 做什么
按路径找目录，把 FCB ==读入内存==，返回描述符，==不读数据==。之后读写不再查目录，`read` 只要 fd。
:::
打开文件表：系统一张（FCB、引用计数）；每进程一张（读写指针、指向系统表）。

# 二、物理结构
| 结构 | 随机访问 | 扩展 | 碎片 |
| 连续 | 最快 | 难 | 外部 |
| 链接 | 差 | 易 | 无（FAT 改善随机） |
| 索引 | 好 | 易 | 索引占空间 |

# 三、目录与链接
打开 /a/b/c：每层目录约 2 次盘（inode + 目录块）。
| | 硬链接 | 软链接 |
| 本质 | 目录项指同一 inode | 新文件，内容是路径 |
| 引用计数 | +1，到 0 才删 | 不变 |
| 跨文件系统 | ==不能== | 能 |
| 原文件删 | 还在 | 断 |

# 四、文件系统
布局：MBR；分区（引导块、超级块、空闲管理、inode、数据）。
空闲：空闲表、空闲链、位图、成组链接。
**位图**：盘块号 = 块号 ÷ (块大小×8) + 起始；字节号 = (块号 % (块大小×8)) ÷ 8。
10GB、簇 4KB：$10\times2^{18}$ 位 = 80 簇。

VFS 四对象：超级块、inode、dentry、file。挂载：接到目录树，原内容被遮住。

# 五、磁盘
$$T_a=\text{寻道}+\frac{1}{2r}+\text{传输}+\text{控制器}$$
10000 转/分：转一圈 6ms，半圈 3ms。寻道 6，4KB÷20MB/s=0.2，控制器 0.2：9.4ms。

:::sk 400 160 | 手算：磁头 100 向增大方向。FCFS 498，SSTF 248，LOOK 250，C-LOOK 322
X=lambda t:20+t*1.9
s.line(20,14,X(190),14,'k',1)
for t in (18,38,55,90,100,150,184): s.line(X(t),10,X(t),18,'k',.8);s.text(X(t),8,str(t),8.5,'g','middle',rot=0)
def tr(l,y0,c,lab):
    pts=[(X(t),y0+i*7) for i,t in enumerate(l)];s.poly(pts,c,1.2,amp=.5);s.text(pts[-1][0]+4,pts[-1][1]+3,lab,11,c)
tr([100,90,58,55,39,38,18,150,160,184],22,'b','SSTF 饥饿')
tr([100,150,160,184,90,58,55,39,38,18],22,'r','LOOK 到请求就回')
:::
| 算法 | 特点 | 缺点 |
| FCFS | 公平 | 慢 |
| SSTF | 每次最近 | 饥饿、黏着 |
| SCAN | 到头再回 | 两端不公平 |
| C-SCAN | 单向 | |
| LOOK/C-LOOK | 不到头就回 | 常用 |

**C-SCAN 返程算不算距离，题目口径不一样**，先看题干，没说就两种都算。

提速：提前读、连续簇、延迟写、磁盘高速缓存。分区不能提速。RAID：镜像、校验提可靠，条带提速度。

**SSD**：==按页读写，按块擦除==。无寻道，调度基本 FCFS。FTL 映射。磨损均衡：动态（写时选低磨损）、静态（搬长期不变的数据）。
