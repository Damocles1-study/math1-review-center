# 一条直线串第 4 章
商品 → 劳动二重性 → 货币 → 劳动力成为商品 → 剩余价值 → 积累 → 危机。

| 问 | 答 |
| 枢纽 | ==劳动二重性== |
| 基石 | ==剩余价值理论== |
| 价值量 | 社会必要劳动时间 |
| 生产率 | 与单件价值量成反比 |
| 货币转化为资本的前提 | 劳动力成为商品 |
| 基本矛盾 | 生产社会化与私人占有 |
| 集中的杠杆 | 竞争和信用 |
| 危机根本原因 | 基本矛盾 |
| 危机本质特征 | 生产相对过剩 |

**剩余价值**：绝对（延长工作日）、相对（缩短必要劳动）、超额（个别低于社会）。
**错句**：具体劳动创造价值；供求决定价值量；不变资本 = 固定资本（原料是流动的）；机器是剩余价值源泉；资本家买的是「劳动」。

生产价格 = 生产成本 + 平均利润。

# 第 5 章：垄断
自由竞争 → 生产集中和资本集中 → 垄断。
| 问 | 答 |
| 起决定作用 | 垄断组织 |
| 金融资本途径 | 金融联系、资本参与、人事参与 |
| 寡头统治 | 经济靠参与制，政治靠个人联合 |
| 国垄实质 | 私人垄断资本利用国家机器 |
| 全球化根本推动 | 科技进步和生产力 |
| 当代最突出 | 国际金融资本的垄断 |
| 三失 | 经济失调、政治失灵、社会融合失效 |

**错句**：对外扩张能化解基本矛盾（只能转嫁）；金融危机是全球化必然产物。
