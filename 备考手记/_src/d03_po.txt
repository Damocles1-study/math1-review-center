# 一条直线串第 4 章
商品 → 劳动二重性 → 货币 → 劳动力成为商品 → 剩余价值 → 积累 → 危机。

| 问 | 答 |
| 枢纽 | ==劳动二重性== |
| 基石 | ==剩余价值理论== |
| 价值量 | 社会必要劳动时间 |
| 生产率 | 与单件价值量成反比 |
| 货币转化为资本的前提 | 劳动力成为商品 |
| 基本矛盾 | 生产社会化与私人占有 |
| 集中的杠杆 | 竞争和信用 |
| 危机根本原因 | 基本矛盾 |
| 危机本质特征 | 生产相对过剩 |

**剩余价值**：绝对（延长工作日）、相对（缩短必要劳动）、超额（个别低于社会）。
**错句**：具体劳动创造价值；供求决定价值量；不变资本 = 固定资本（原料是流动的）；机器是剩余价值源泉；资本家买的是「劳动」。

生产价格 = 生产成本 + 平均利润。

# 第 5 章：垄断
自由竞争 → 生产集中和资本集中 → 垄断。
| 问 | 答 |
| 起决定作用 | 垄断组织 |
| 金融资本途径 | 金融联系、资本参与、人事参与 |
| 寡头统治 | 经济靠参与制，政治靠个人联合 |
| 国垄实质 | 私人垄断资本利用国家机器 |
| 全球化根本推动 | 科技进步和生产力 |
| 当代最突出 | 国际金融资本的垄断 |
| 三失 | 经济失调、政治失灵、社会融合失效 |

**错句**：对外扩张能化解基本矛盾（只能转嫁）；金融危机是全球化必然产物。

# 比方：一家奶茶店串全章
一杯奶茶能解渴（使用价值）能卖钱（价值）。摇的动作造奶茶、搬旧价值（具体劳动），耗的力气添新价值（抽象劳动）。店员 4 小时挣回工资（必要），后 4 小时白干（剩余）。多干几小时是绝对，买机器提效率是相对、超额。赚钱开分店（积累），机器多店员少（有机构成高，失业）。大家都这么干，做得多买得起的跟不上（相对过剩）。
牛奶倒河里同时有人喝不上：不是太多，是买不起。

资本主义像公司成长史：小店竞争 → 大店吃小店 → 联手定价（垄断）→ 和银行合伙（金融资本）→ 拉政府（国垄）→ 开到全世界。追逐剩余价值的本性没变。

**货币四职能**：标价尺度；钱货同时流通；钱货分离（赊、税、薪）支付；存金贮藏。
**生产率提高三连**：产量升、单件价值降、单位时间价值总量不变。

:::eg 必会计算
8 小时，必要 4、剩余 4，$m'=100\%$。绝对法剩余延长 2：必要 4、剩余 6，150%。相对法剩余延长 2：必要 2、剩余 6，300%。
投资 100 万，$c:v=3:1$，$m'=200\%$：$v=25$，$m=50$，利润 50。反推：利润 30、$m'=150\%$ ⟹ $v=20$，$c=80$，有机构成 4∶1。
:::
**三种划分**：c、v 看作用；固定、流动看周转；货币、生产、商品资本看职能。

**错句再加**：无人工厂说明有机构成降低；原材料涨价提高有机构成；资本积累是危机根本原因；虚拟经济脱离实体是危机本质；国家政权取代私人垄断资本。
