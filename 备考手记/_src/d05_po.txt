# 第 3 章：辛亥
| 问 | 答 |
| 第一个革命团体 | 兴中会 1894 |
| 第一个全国性资产阶级政党 | 同盟会 1905，《民报》 |
| 三民主义 | 民族（鞑虏）、民权（民国）、民生（平均地权） |
| 平均地权办法 | 核定地价，增价归公 |
| 论战焦点 | 要不要用革命手段推翻清朝 |
| 最大功绩 | 结束两千多年君主专制 |
| 失败根本原因 | ==帝国主义时代、半殖民地半封建，资本主义方案行不通== |
| 主观根源 | 民族资产阶级软弱妥协 |

错句：平均地权 = 耕者有其田；同盟会是第一个团体；民族主义鲜明反帝。
