# 一、一条路
书上隔着两本书，其实走的是同一条路。这张图今天画了三遍。
CPU 发出的是虚拟地址，Cache 和主存认物理地址，所以先翻译再访问。翻译靠页表，页表在主存，为了不每次跑一趟主存，加一个专门缓存页表项的 TLB。
:::sk 420 170 | VA 切一次（VPN | 偏移），PA 再切一次（标记 | 组 | 块内）。四个部件依次把关
s.box(6,10,52,24,'k');s.text(32,27,'VA',12,'k','middle',rot=0)
s.box(100,10,60,24,'b');s.text(130,27,'TLB',12,'b','middle',rot=0)
s.box(100,70,60,24,'b');s.text(130,87,'页表',12,'b','middle',rot=0)
s.box(100,130,60,24,'r');s.text(130,147,'缺页',12,'r','middle',rot=0)
s.box(226,10,52,24,'k');s.text(252,27,'PA',12,'k','middle',rot=0)
s.box(320,10,60,24,'g');s.text(350,27,'Cache',12,'g','middle',rot=0)
s.box(320,70,60,24,'k');s.text(350,87,'主存',12,'k','middle',rot=0)
s.arrow(58,22,98,22);s.arrow(160,22,224,22,'b');s.text(176,16,'命中',10.5,'b')
s.arrow(130,34,130,68,'r');s.text(136,54,'缺失',10.5,'r');s.arrow(160,78,240,36,'b');s.text(182,70,'有效',10.5,'b')
s.arrow(130,94,130,128,'r');s.text(136,114,'P=0',10.5,'r')
s.arrow(278,22,318,22);s.arrow(350,34,350,68,'r');s.text(356,54,'缺失',10.5,'r')
s.bend(100,142,60,26,k=-26,c='r');s.text(10,100,'重新执行',11,'r')
:::
地址==切两次==：VA 切 VPN | 偏移（偏移不变，只翻译页号）；PA 切 标记 | 组号 | 块内。TLB 全相联时整个 VPN 是标记；组相联时 VPN 再切成 TLB 标记 | TLB 组号。

TLB 用 SRAM 做的相联存储器，只有几十到几千项，命中率还是高：一页几千字节，同一页内访问非常多，这又是局部性。进程切换时要清空或带进程标识，切换后一段全缺失，是上下文切换的隐藏代价。

TLB 是页表的子集，Cache 是主存的子集，下面两条直接推出来：
:::def 不可能的组合
TLB 命中而页表无效（页换出时 TLB 项作废）。
页不在内存而 Cache 命中（换出时 Cache 块也作废）。
:::
**时间**：TLB 命中 $T_t+T_m$；TLB 缺页表有 $T_t+T_m+T_m$；缺页 $T_t+T_m+T_p+T_t+T_m$（==重新执行，TLB 和数据再来一遍==）。

代入 $T_t=10$ns、$T_m=100$ns、$T_p=1$ms：110ns；210ns；$10+100+10^6+10+100=1000220$ns。缺页慢近一万倍，所以缺页率必须非常低。

:::eg 书上的例子走一遍：VA 32、PA 28、页 4KB；TLB 64 项 4 路；Cache 32KB 4 路块 64B
定位数：偏移 12，VPN 20，PPN 16。TLB 16 组，组号 4 位，标记 16 位。Cache 512 行，128 组，组号 7、块内 6、标记 15。
地址 0x12345ABC：VPN=0x12345，偏移 0xABC。TLB 组 0x5，标记 0x1234。假设缺失，查页表（访存 1 次）得 PPN=0x0A7C，填回 TLB。
PA=0x0A7CABC：块内 60，组 42，标记 0x53E。第 42 组比 4 个标记，假设缺失，主存取一块（访存 1 次）。共 2 次。
:::
:::note
组号 + 块内 13 位，比偏移 12 位多一位，多出的那位来自 PPN。所以必须翻译完才知道组号，不能提前查。
:::
**再走一遍**（2016 型）：VA 32、PA 24、页 8KB ⟹ VPN 19、PPN 11。Cache 64KB 2 路块 64B ⟹ 组 512，切 PA：块内 6、组 9、Tag 9，相加校对 24。

**页表项**：有效 P、修改 M、访问 A、保护、页框号。

段式虚存：段表 + 存在位，段长不一，有外部碎片；段页式：段号 + 页号 + 偏移，段表项指页表，以页调入。反置页表：全系统一张，按页框索引，表大小只和物理内存有关，查找要靠散列。

# 二、虚拟内存
书桌和书架：桌上只放现在要看的书，满了放回去一本。能成靠局部性。

三特征：多次性、对换性、虚拟性。==必须基于非连续分配==。实际容量 = min(主存 + 外存, 地址空间)。

页表项多了：存在位 P、访问位 A（硬件置 1）、修改位 M（M=1 换出才写回，M=0 直接丢）、外存地址。
:::def 缺页处理
① 硬件 P=0 → 缺页异常 → 内核。
② 有空闲页框直接用，否则置换，M=1 先写回。
③ 启动磁盘，进程==阻塞==，CPU 跑别人。
④ I/O 完成中断唤醒，改页表。
⑤ ==重新执行==这条指令。
:::
缺页是指令==执行中间==的异常（故障），回到本条；一条指令可能缺页多次（指令跨页、操作数也跨页）。外中断要等指令做完才响应。

调入：预调页（利用空间局部性，进程刚开始时多用）+ 请求调页。从哪调：对换区比文件区快；对换区够就全走对换区；不够时不改的代码页走文件区，会改的走对换区。
# 三、置换算法
:::sk 410 150 | 手算 3 个页框，序列 7 0 1 2 0 3 0 4。LRU 技巧：从当前往回数不同的页号，数到第 3 个就淘汰它
S=['7','0','1','2','0','3','0','4']
F=[('FIFO',['7','7 0','7 0 1','0 1 2','0 1 2','1 2 3','2 3 0','3 0 4'],[1,1,1,1,0,1,1,1]),('LRU',['7','7 0','7 0 1','0 1 2','1 2 0','2 0 3','2 3 0','3 0 4'],[1,1,1,1,0,1,0,1])]
for i,t in enumerate(S): s.text(66+i*44,16,t,13,'k','middle',rot=0)
for r,(n,R,M) in enumerate(F):
    y=26+r*42;s.text(4,y+20,n,12,'b' if r else 'r',rot=0)
    for i,(c,m) in enumerate(zip(R,M)):
        s.box(46+i*44,y,42,32,'r' if m else 'k',1 if m else .7);s.text(67+i*44,y+21,c,9.5,'r' if m else 'k','middle',rot=0)
s.text(4,134,'红框 = 缺页。FIFO 7 次，LRU 6 次。FIFO 有 Belady，LRU 没有。',12)
:::
| 算法 | 特点 |
| OPT | 淘汰最远不用的，不可实现 |
| FIFO | 差，有 ==Belady== |
| LRU | 好，开销大 |
| CLOCK | 接近 LRU，访问位 A 给第二次机会 |
| 改进 CLOCK | (A,M)：第一轮找 (0,0) 不改位；第二轮找 (0,1) 把扫过的 A 清 0 |

Belady 例：`1 2 3 4 1 2 5 1 2 3 4 5`，3 框缺 9 次，4 框缺 10 次。LRU、OPT 是栈算法，页框多时内存里的页总包含页框少时的，所以没有。

CLOCK：A=1 清 0 后移，A=0 就赶走，最多转两圈。改进 CLOCK 最多四轮，优先级 $(0,0)\to(0,1)\to(1,0)\to(1,1)$。为什么 (0,1) 在 (1,0) 前？先看最近用没用（局部性优先），都没用的再挑不用写盘的。

问「置换次数」不是「缺页次数」：装入空页框不算置换。

# 四、页框分配
驻留集：分给进程的页框。太少缺页频繁；太多并发少，而且多到一定程度缺页率也不再降。
| 组合 | 特点 |
| 固定 + 局部 | 页框数不变，赶自己的，开始时难定数目 |
| 可变 + 全局 | 从空闲里给，没了赶别人的，别人缺页会增加 |
| 可变 + 局部 | 赶自己的；太频繁再多给几个 |

==没有固定 + 全局==（全局就是在增加自己的框数）。分多少：平均、按大小比例、按优先级。

写时复制：fork 后共享只读，谁写谁复制（子进程常马上 `exec`，全复制太浪费）。

**抖动**：页框少于工作集。更糟的是 CPU 利用率低时系统可能再加新进程，于是更抖。措施：撤销进程、加内存；扩交换区、提优先级没用。**工作集**：往前窗口内的页==集合==（重复算一个）。

**内存映射文件**：文件映射到地址空间，读写靠缺页，不用 `read`、`write`，多进程可共享。页框回收：空闲低于阈值由后台进程（Linux 的 `kswapd`）提前回收。干净页便宜；文件页写回文件；匿名页（堆、栈）写交换区。

$$T=(1-p)T_m+p\cdot\text{缺页处理时间}$$
代入 $T_m=100$ns，处理 8ms，$p=1/1000$：$T\approx8100$ns，慢 ==81 倍==。想把损失压在 10% 内，约一百万次才能缺一次。改进：缺页率（页框、页大小、算法、程序局部性如按行访问）；转换速度（增大 TLB、页表常驻）；写回频率（攒一批脏页）。
