# 一、第二类曲线积分：力做的功
$\int_LP\,dx+Q\,dy=\int_\alpha^\beta(Px'+Qy')dt$，==$\alpha$ 对应起点，$\beta$ 对应终点，可以 $\alpha\gt\beta$==。反向变号。对比昨天第一类：第一类下限必须小。

# 二、格林：走一圈 = 里面的旋涡加起来
:::def 格林公式
$\oint_LP\,dx+Q\,dy=\iint_D(Q_x-P_y)d\sigma$，正向（走的时候 $D$ 在左手边）。
:::

## 三种局面
| 局面 | 做法 |
| 封闭 | 直接格林 |
| 不封闭 | 补线（常补平行坐标轴的线段），减去所补 |
| 有奇点 | 小圆挖掉，夹层上用格林 |

:::eg 补线：$\int_L(e^x\sin y-2y)dx+(e^x\cos y-2)dy$，上半圆 $x^2+y^2=2x$ 从 $(2,0)$ 到 $(0,0)$
信号：直接代进去没法算，$Q_x-P_y$ 的 $e^x\cos y$ 恰好抵消，得 2。补 $x$ 轴线段 $OA$，半圆盘面积 $\frac\pi2$，$\oint=\pi$；线段上 $y=0$，$P=Q$ 那段积分 0。$I=\pi$。
:::
:::eg 挖洞：$\oint\dfrac{-y\,dx+x\,dy}{x^2+y^2}$ 绕原点
$Q_x=P_y$，但原点是奇点。小圆 $C$ 上参数化，得 $2\pi$。不绕原点的话是 0。
:::
:::sk 200 100 | 挖洞：$L$ 和小圆 $C$ 之间的环上才能用格林
s.circle(100,50,74,'k',1.2,ry=40);s.circle(100,50,16,'r',1.2);s.dot(100,50,2);s.text(104,46,'O',11)
s.hatch([(40,50),(64,24),(100,14),(136,24),(160,50),(116,50),(100,36),(84,50)],gap=9)
s.text(166,28,'L',13);s.text(120,70,'C',13,'r')
:::
:::def 路径无关（单连通）
$Q_x=P_y$ ⟺ 闭路积分 0 ⟺ 与路径无关 ⟺ $Pdx+Qdy=du$，$\int_A^B=u(B)-u(A)$。
:::
凑微分：$(2xy+y^2)dx+(x^2+2xy)dy=d(x^2y+xy^2)$，从 $(0,0)$ 到 $(1,2)$ 得 6。全微分方程通解 $u=C$。

# 三、第二类曲面积分：穿过曲面的流量
$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$。**分面投影**：上 $+$ 下 $-$，前 $+$ 后 $-$，右 $+$ 左 $-$。垂直于某坐标面的曲面，在该面投影积分为 0。

**转换投影**（一次投到 $xOy$，上侧）：
$$\iint_\Sigma Pdydz+Qdzdx+Rdxdy=\iint_D(-Pz_x-Qz_y+R)dxdy$$
例：$z=x^2+y^2$ 上侧，$x\,dydz+y\,dzdx+z\,dxdy$ ⟹ $-\iint(x^2+y^2)=-\frac\pi2$。

# 四、高斯：流出的总量 = 里面的水龙头
:::def 高斯公式
$\oiint_\Sigma Pdydz+Qdzdx+Rdxdy=\iiint_\Omega(P_x+Q_y+R_z)dV$，==外侧==。散度 $\mathrm{div}F=P_x+Q_y+R_z$。
:::
:::eg 补面：$z=x^2+y^2$（$z\le1$）取下侧，$x\,dydz+y\,dzdx+z\,dxdy$
散度 3。补 $z=1$ 上侧，封闭外侧：$3V=3\int_0^1\pi z\,dz=\frac{3\pi}{2}$。顶面 $=\pi$。$I=\frac\pi2$。
:::
:::sk 240 110 | 下侧恰好朝外，补个盖子就封闭了。盖子上 $dydz,dzdx$ 都为 0

:::

# 五、斯托克斯：格林的空间版
旋度 $\mathrm{rot}F=(R_y-Q_z,\ P_z-R_x,\ Q_x-P_y)$。$\oint_LPdx+Qdy+Rdz=\iint_\Sigma\mathrm{rot}F\cdot n\,dS$，方向右手系。
**固定做法**：$L$ 是平面与曲面的交线，取平面上被围住的部分，法向量是常向量。

例：$\oint y\,dx+z\,dy+x\,dz$，球面与 $x+y+z=0$ 的交线：$\mathrm{rot}F=(-1,-1,-1)$，$n=\frac{1}{\sqrt3}(1,1,1)$，圆盘面积 $\pi$，$-\sqrt3\pi$。

| 公式 | 边界 | 内部 |
| 格林 | 平面闭曲线 | 二重积分 |
| 高斯 | 闭曲面 | 三重积分 |
| 斯托克斯 | 空间闭曲线 | 曲面积分 |
