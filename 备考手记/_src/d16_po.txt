# 比方和心法
- 核心价值观是三层楼：国家顶层、社会中层、公民底层。三根柱子：设计先进（先进性）、为谁盖（人民性）、不是样板房（真实性）。
- 道德是一棵树：根是起源，干是社会主义道德（一心为公 → 先公后私 → 顾全大局），两条养分是传统美德和革命道德，四根枝是四德。
- 信号词：不是摆设 → 真实性；人民至上 → 人民性；传统文化、世界文明 → 先进性。
- 传统美德五组：见公见国 → 整体利益；仁爱和 → 仁爱；五伦 → 人伦；忧乐 → 境界；修独齐 → 修养。

==看到普世价值、普适性直接划掉。它和全人类共同价值完全不同。==

# 错句和张冠李戴
- 处于整个上层建筑的核心（错，只是思想观念体系）。平等的帽子是美好状态。
- 三层面是核心价值观独有；体系是四方面，不能说两者都。
- 情感欲望论、动物本能论是旧起源论。归根结底是经济关系，不是社会存在。
- 社会舆论是主要调节形式（错，主要形式是道德评价）。
- 2025 三连错：个人无条件服从集体；抑制个人利益；集体是个人利益总和。
- 奉献社会是公德最高要求（错，是职业道德）。着力点（四德）和重点任务别互换。

# 分析题框架
:::def 培育核心价值观
为什么：① 最持久深层、稳定器。② 当代中国精神集中体现。③ 精神指引、最大公约数。④ 三性站上制高点。怎么做：① 扣好人生扣子。② 勤学修德明辨笃实。③ 内化外化，落细落小落实。
:::
:::def 传统美德、革命道德、红色血脉
① 精髓、源头活水，五组，两创，反复古论虚无论。② 灵魂和红线。③ 红色资源，赓续血脉，培育新人。
:::
:::def 社会公德、网络道德
① 有序公共生活三作用。② 文明礼貌、助人为乐、爱护公物、保护环境、遵纪守法。③ 网络也是真实生活。④ 德法互补。
:::
:::def 择业观和创业观
① 崇高职业理想。② 服从社会需要。③ 做好准备，创业能力。④ 劳动创造幸福。
:::
:::def 家风家庭美德
① 基本细胞、第一所学校。② 品德教育，家风。③ 五项美德。④ 爱家和爱国统一。
:::
:::def 志愿服务、个人品德
① 文明标志、重要载体。② 奉献友爱互助进步。③ 学思并重、省察克治、慎独、知行合一、积善成德。④ 小我融入大我。
:::
