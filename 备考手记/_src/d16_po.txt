# 道德
| 问 | 答 |
| 靠什么 | 舆论、习俗、内心信念 |
| 第一个前提 | 劳动 |
| 客观 / 主观条件 | 社会关系 / 自我意识 |
| 归根结底 | 经济关系 |
| 基本功能 | 认识、规范、调节 |
| 社会主义核心 | 为人民服务 |
| 社会主义原则 | 集体主义 |
| 传统美德根本要求 | 公义胜私欲 |
| 革命道德灵魂 | 理想信念 |
| 革命道德红线 | 全心全意为人民服务 |

:::note
核心和原则别换：核心为人民服务，原则集体主义。
:::
四德：社会公德、职业道德（爱岗、诚信、办事公道、服务群众、奉献社会）、家庭美德、个人品德。
