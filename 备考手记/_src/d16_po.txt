- 最持久最深层的力量；重要稳定器；最大公约数；当代中国精神的集中体现。
- 自由是活力之源；公正是进步标尺、本质要求；法治是政治文明成果；诚信是立身规范。
- 核心价值体系四方面：指导思想、共同理想、民族精神和时代精神、荣辱观。
- 与体系的关系：价值观是体系的精神内核、高度凝练。
- 三性：先进性、人民性（根本）、真实性（与以往的重要区别）。践行：勤学、修德、明辨、笃实。

# 道德
| 问 | 答 |
| 靠什么 | 舆论、习俗、内心信念 |
| 第一个前提 | 劳动 |
| 客观 / 主观条件 | 社会关系 / 自我意识 |
| 归根结底 | 经济关系 |
| 基本功能 | 认识、规范、调节 |
| 社会主义核心 | 为人民服务 |
| 社会主义原则 | 集体主义 |
| 集体主义最高层次 | 无私奉献、一心为公 |
| 独立性表现 | 历史继承性；能动反作用 |
| 主要调节形式 | 道德评价 |
| 传统美德根本要求 | 公义胜私欲 |
| 革命道德灵魂 | 理想信念 |
| 革命道德红线 | 全心全意为人民服务 |
| 全体公民基本准则 | 遵纪守法 |
| 职业道德最高要求 | 奉献社会 |
| 基础性作用 | 个人品德 |
| 认知转行为关键 | 道德意志和道德信念 |
| 志愿服务精髓 | 奉献 |

:::note
核心和原则别换：核心为人民服务，原则集体主义。
:::
四德：社会公德（起码要求）、职业道德（爱岗、诚信、办事公道、服务群众、奉献社会）、家庭美德（尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里互助；家庭教育最重要的是品德教育）、个人品德。
