# 一、秩 = 真正独立的信息条数
行阶梯形的非零行数。初等变换不变。
:::def 秩的公式（默写）
$r(A)=r(A^T)=r(A^TA)$；可逆 $P,Q$：$r(PAQ)=r(A)$。
$r(A+B)\le r(A)+r(B)$；$r(AB)\le\min\{r(A),r(B)\}$。
$A_{m\times n}B_{n\times s}=O$ ⟹ $r(A)+r(B)\le n$。
$r(A,AB)=r(A)$；$\begin{pmatrix}A&O\\O&B\end{pmatrix}$ 的秩 $=r(A)+r(B)$。
$n$ 阶：$r(AB)\ge r(A)+r(B)-n$。
$r(A^*)=n,\ 1,\ 0$ 对应 $r(A)=n,\ n-1,\ \lt n-1$。
:::
分块也能做初等变换：$\begin{pmatrix}A&AB\\O&B\end{pmatrix}$ 第一块列右乘 $-B$ 加到第二块列，秩 $=r(A)+r(B)$。

- **齐次**：$r=n$ 只有零解；$r\lt n$ 有非零解，基础解系 $n-r$ 个。自由变量依次取单位向量。
- 例：$x_1+x_2-x_3-x_4=0$，$2x_1+2x_2+x_3+x_4=0$ ⟹ $\xi_1=(-1,1,0,0)^T$，$\xi_2=(0,0,-1,1)^T$。
- 非齐次解之差是齐次解；非齐次解 + 齐次解仍是非齐次解。
- $AB=O$ 的另一层读法：==$B$ 的每一列都是 $Ax=0$ 的解==。
- 同解：$r(A)=r(B)=r\begin{pmatrix}A\\B\end{pmatrix}$。公共解：联立。

:::eg 大题：$x_1+x_2+ax_3=1,\ x_1+ax_2+x_3=1,\ ax_1+x_2+x_3=-2$
方阵先算 $\vert A\vert=-(a+2)(a-1)^2$。
(1) $a\neq1,-2$：唯一解。三式相加 $(a+2)(x_1+x_2+x_3)=0$，于是 $x_1=-\frac{2}{a-1}$，$x_2=x_3=\frac{1}{a-1}$。
(2) $a=1$：$r(A)=1$，$r(A\mid b)=2$，无解。
(3) $a=-2$：$r=2\lt3$，通解 $(1,0,0)^T+k(1,1,1)^T$。
:::
:::note
这题第一次手写丢了 $a=1$ 这一支，直接约掉 $(a-1)$。讨论型的题，==约因子前先想它是不是 0==。
:::

# 三、向量组：相关就是有人多余
$A=(\alpha_1,\dots,\alpha_n)$ 按列排。翻译表：
| 话 | 翻译 |
| $\beta$ 可由 $\alpha$ 表示 | $Ax=\beta$ 有解 |
| 相关 | $Ax=0$ 有非零解，$r(A)\lt n$ |
| 无关 | $r(A)=n$ |
| 方阵相关 | $\vert A\vert=0$ |

:::sk 320 96 | 三个向量在平面里，第三个没带来新方向（相关）；跳出平面才是新信息（无关）

:::
:::def 基本结论
个数 > 维数 ⟹ 相关。部分相关 ⟹ 整体相关；整体无关 ⟹ 部分无关。
无关的加长仍无关，相关的减短仍相关。
$\alpha$ 无关、加 $\beta$ 后相关 ⟹ $\beta$ 被唯一表示。
少数表示多数，多数必相关。
:::
**两种等价别混**：矩阵等价 = 同型且秩同；向量组等价 = 能互相表示。向量组等价则秩同，秩同不一定等价。

$C=AB$：$C$ 的列是 $A$ 的列的组合；$B$ 可逆时 $C,A$ 列向量组等价。

**证无关**：$\beta_1=\alpha_1+\alpha_2$，$\beta_2=\alpha_2+\alpha_3$，$\beta_3=\alpha_3+\alpha_1$，写成 $(\beta)=(\alpha)C$，$\vert C\vert=2\neq0$。

**极大无关组**：按列排，==只做行变换==，首元所在列对应的原向量。读最简形表示其余：$\alpha_3=\alpha_1+\alpha_2$，$\alpha_4=2\alpha_1-\alpha_2$。

# 四、基、坐标、正交化
- 过渡矩阵：$(\beta)=(\alpha)C$，$C=A^{-1}B$；坐标 $x=Cy$（旧 = $C$ × 新）。
- 内积 $\alpha^T\beta$；正交矩阵 $A^TA=E$，$\vert A\vert=\pm1$。
- 施密特：新向量减去在已有方向上的投影。
