# 改革开放
改革开放：关键一招；全面深化改革是根本动力。十八届三中全会 2013：局部探索到系统集成。根本标准：是否有利于坚持和改善党的全面领导、完善制度。

三个解放：解放思想（思想前提）、解放和发展生产力（鲜明特征和首要任务）、解放和增强活力（关键所在）。方法：摸着石头过河 + 顶层设计。
| 词 | 定位 |
| 总目标 | 完善制度 + 治理现代化 |
| 主线 | 制度建设 |
| 重点 | 经济体制改革 |
| 突破口 | 重要领域和关键环节 |
| 结合点 | 改善人民生活 |
| 进一步深化：主题 | 推进中国式现代化 |
| 牵引 | 经济体制改革 |
| 出发点和落脚点 | 公平正义、人民福祉 |
| 高水平开放标志 | 制度型开放 |
| 开放根本目的 | 增进民生福祉 |

错句：治理体系越完备能力一定越强；彻底消除不确定性；同时满足所有人。

# 比方
- 国家是大船：党是船长（全面领导但不亲手包办），人民是乘客也是船东。
- 时代出卷、党答卷、人民阅卷。问谁评判，答案指向人民，不会是 GDP。
- 改革装修老房子：总目标图纸，主线水电，牵引先动厨房，突破口先砸的墙，落脚住得舒服。
- 三个解放开车：敢不敢开（思想），踩油门（生产力），零件都转（活力）。
- 三次划时代全会：1978、2013、2024（总目标前加「继续」）。

# 错句和张冠李戴
- 事无巨细都去管，直接排除。
- 关键一招是改革开放；关键一步是全面建成小康。
- 开启新时期是十一届三中全会，不是十八届。
- 外资经济是社会主义经济的组成部分（错，是社会主义市场经济）。
- 等现代化实现了再解决共同富裕（错）。

# 分析题框架
:::def 为什么坚持党的全面领导
① 历史形成。② 最本质特征、最大优势、最高政治领导力量。③ 当家作主的保障，复兴的根本保证。④ 集中统一领导是最高原则，全面系统整体而非包办。
:::
:::def 扎实推进共同富裕
① 本质要求。② 全体人民、物质精神；不是少数、不是平均、不是同步。③ 四原则。④ 高质量发展中促进，做大分好，三次分配，橄榄型。⑤ 与人的全面发展统一。
:::
:::def 进一步全面深化改革
① 重要法宝、根本动力。② 六个必然要求。③ 根本标准，以人民为中心，三个解放。④ 主题、牵引、主线、总目标。⑤ 顶层设计与摸着石头结合，统筹改革发展稳定，于法有据，制度型开放。
:::
