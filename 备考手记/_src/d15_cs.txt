# 一、Cache：四件事
放哪（映射）、满了赶谁（替换）、写了怎么同步（写策略）、程序命中率。缺失时搬==一整块==（空间局部性）。

$$T=H\,T_c+(1-H)(T_c+T_m)=T_c+(1-H)T_m\ \text{（先查后访）}$$
$$T=H\,T_c+(1-H)T_m\ \text{（同时访问）}$$
$$CPI=CPI_0+\text{每条访存次数}\times\text{缺失率}\times\text{缺失损失}$$
$T_c=2,T_m=20,H=95\%$：3ns 或 2.9ns。$CPI_0=2$，1.3 次，2%，100 周期：4.6。2% 让速度慢一倍多。

# 二、三种映射 = 停车场
:::sk 410 142 | 32 位地址、块 64B、128 行。路数翻倍，组号少一位，标记多一位
for r,(n,p) in enumerate((('直接映射',[('Tag 19',19,'k'),('行 7',7,'b'),('块内 6',6,'g')]),('全相联',[('Tag 26',26,'k'),('块内 6',6,'g')]),('4 路组相联',[('Tag 21',21,'k'),('组 5',5,'b'),('块内 6',6,'g')]))):
    y=10+r*32;s.text(4,y+15,n,11,'k',rot=0);x=74
    for t,w,c in p:
        W=w*9.6;s.box(x,y,W,22,c,.9);s.text(x+W/2,y+15,t,10.5,c,'middle',rot=0);x+=W
s.text(4,126,'一条线：比较器个数 = 路数。直接 1 个，全相联 = 行数。',12)
:::
:::def 切地址三步
① 块内 = $\log_2$ 块大小（换算成编址单位）。② 组号 = $\log_2$(行数/路数)。③ 其余是标记。
定位：块号 = 地址 ÷ 块大小；组号 = 块号 % 组数；标记 = 块号 ÷ 组数。
:::
0x12345：块号 1165。直接映射行 13、标记 9；4 路组 13、标记 36。

缺失三类：冷启动、容量、冲突。序列 0 4 0 4 0 4，4 行：直接映射全缺（抢一行），2 路只缺两次。

**总容量**：行数 ×（数据 + 标记 + 有效 1 + 脏 1 + 替换 $\log_2$路）。上例回写 + LRU：$512+21+1+1+2=537$，×128。

# 三、替换与写
替换只有全相联和组相联要选。随机、FIFO、LRU（常用）、LFU。LRU 计数器：命中清 0，比它小的加 1；满了赶走最大的。循环访问块数大于路数时抖动（2 路 A B C A B C 全缺）。

| | 命中 | 不命中 |
| 全写 | 同写 Cache 和主存（加写缓冲） | 非写分配 |
| 回写 | 只写 Cache，置脏位 | 写分配 |

多级：L1 分离 I/D（消除结构冒险）。多核要一致性协议。

    s.box(214,20+i*14,14,14,'r',1.3)
s.text(8,76,'步骤：① 块放几个元素 ② 看访问顺序',12)

# 五、程序怎样进内存
编译（逻辑地址从 0）→ 链接 → 装入（物理地址）。
| 装入 | 特点 |
| 绝对 | 编译时算好，单道 |
| 静态重定位 | 装入时改完，不能再移 |
| 动态重定位 | 运行时靠==重定位寄存器==，可移动 |

链接：静态 / 装入时动态 / 运行时动态。
内存映像：代码、数据、堆（向上）、栈（向下）。
保护：重定位 + 界地址：先比长度，再加基址。共享：可重入代码。
覆盖（程序员）、交换（整个进程，中级调度）。

# 六、连续分配
内部碎片：分给你用不完。外部碎片：分区之间切不出去（靠紧凑）。
| 算法 | 找法 | 后果 |
| 首次 | 地址从低到高 | 综合最好 |
| 邻近 | 接着上次 | 大块被切 |
| 最佳 | 容量从小到大 | ==小碎片最多== |
| 最坏 | 最大的 | 大块没了 |

回收看邻居：前后都不空 +1，一边 0，两边 −1。

# 七、分页
:::sk 400 98 | 地址转换：偏移不变，只换页号。基本分页访存两次
s.box(10,12,120,24,'b');s.text(70,29,'页号 2',12,'b','middle',rot=0);s.box(130,12,70,24,'g');s.text(165,29,'偏移 004',11,'g','middle',rot=0)
s.cells(240,6,[['页','框'],['0','105'],['1','—'],['2','!254']],cw=[36,48],ch=20,size=11.5)
s.bend(70,38,240,74,k=16,c='b');s.text(120,88,'查页表',11,'b')
s.box(10,62,1,1,'k',.1)
s.arrow(330,68,356,68,'r');s.text(360,72,'254',12,'r');s.text(360,90,'+004',12,'g')
:::
$P=A\div$页大小，$W=A\%$页大小；先判 P 不越界；物理 = F×页大小+W。

**多级页表**：一页放 页大小÷表项大小 项，每级位数 = $\log_2$ 这个数。4KB、4B：10+10+12。k 级访存 k+1 次。==优点是不要求大块连续、不用的区域不建，不减访存次数==。

| | 分页 | 分段 |
| 目的 | 系统 | 用户 |
| 大小 | 固定 | 不固定 |
| 地址 | 一维 | ==二维== |
| 碎片 | 内部 | 外部 |
| 共享保护 | 难 | 方便 |

段表存段长，先判越界再相加。段页式：段号 + 页号 + 偏移。
