# 一、事件就是集合
对偶律：$\overline{A\cup B}=\bar A\bar B$，$\overline{AB}=\bar A\cup\bar B$。
- 加法 $P(A\cup B)=P(A)+P(B)-P(AB)$；减法 $P(A-B)=P(A)-P(AB)$。
- 古典：数个数。几何：比度量。

# 二、条件概率：把样本空间缩小
$P(B\vert A)=\dfrac{P(AB)}{P(A)}$。乘法 $P(AB)=P(A)P(B\vert A)$。

:::def 全概率 / 贝叶斯
完备事件组 $A_i$：$P(B)=\sum P(A_i)P(B\vert A_i)$；$P(A_i\vert B)=\dfrac{P(A_i)P(B\vert A_i)}{P(B)}$。
信号：两阶段，问结果用全概率；已知结果问原因用贝叶斯。
:::
抓阄公平：不放回，第 $k$ 次抽中概率与 $k$ 无关。3 红 2 白第二次红 $=\frac35$。

# 三、独立
$P(AB)=P(A)P(B)$。两两独立推不出相互独立。至少一个：$1-\prod(1-P(A_i))$。例 $1-0.2\cdot0.3\cdot0.5=0.97$。
==互斥和独立是两回事==：$P(A),P(B)\gt0$ 时互斥必不独立。

# 四、随机变量
$F(x)=P(X\le x)$：单调不减、右连续、$F(-\infty)=0,F(+\infty)=1$。$P(a\lt X\le b)=F(b)-F(a)$，$P(X=a)=F(a)-F(a^-)$ ==跳跃高度==。

连续型：$F=\int f$，$\int f=1$，$F'=f$，$P(X=a)=0$。

例：$F=A+B\arctan x$ ⟹ $A=\frac12,B=\frac1\pi$，$f=\frac{1}{\pi(1+x^2)}$。

| 名称 | 分布 | 背景 |
| $B(n,p)$ | $C_n^kp^k(1-p)^{n-k}$ | $n$ 次试验成功次数 |
| $P(\lambda)$ | $\frac{\lambda^k}{k!}e^{-\lambda}$ | 稀有事件计数 |
| $G(p)$ | $(1-p)^{k-1}p$ | 首次成功 |
| $U(a,b)$ | $\frac{1}{b-a}$ | 等可能 |
| $E(\lambda)$ | $\lambda e^{-\lambda x}$ | 寿命，无记忆 |
| $N(\mu,\sigma^2)$ | $\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | 大量因素之和 |

:::sk 300 106 | 钟形曲线：$\sigma$ 小更高更瘦。$\frac{X-\mu}{\sigma}\sim N(0,1)$，$\Phi(-x)=1-\Phi(x)$

s.line(10,oy,290,oy,'k',1.1)

s.line(X(-2),oy,X(-2),oy-48,'g',.8,dash='3 3');s.line(X(2),oy,X(2),oy-48,'g',.8,dash='3 3')
s.text(X(-2)-8,oy+13,'−2',11);s.text(X(2)-2,oy+13,'2',11);s.text(X(0)+6,18,'N(0,1)',11);s.text(X(-5)-12,oy-24,'N(0,4)',11,'b');s.text(X(5),oy-26,'N(5,9)',11,'r')
:::
**$Y=g(X)$ 分布函数法**：$F_Y(y)=P(g(X)\le y)$ 翻译成 $X$ 的范围，积分，求导。别背公式。
例：$X\sim U(-1,1)$，$Y=X^2$：$F_Y=\sqrt y$，$f_Y=\frac{1}{2\sqrt y}$（$0\lt y\lt1$）。
