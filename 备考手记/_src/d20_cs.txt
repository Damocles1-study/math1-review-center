# 一、网络层其他
路由是后台算表，转发是一直查表。数据报 vs 虚电路：无连接、独立选路 vs 先建立、同路径。SDN：控制平面和数据平面分离；南向下发流表，北向向应用开放。

| 协议 | 要点 |
| ARP | IP→MAC，同网段；请求==广播==，响应单播；跨网段解析网关 |
| DHCP | UDP；发现、提供、请求、确认；前两步广播，Request 也广播 |
| ICMP | IP 承载；ping、traceroute（TTL 依次 1,2,…） |
| NAT | 看到端口，工作到传输层 |
| IPv6 | 128 位，首部固定 40B，==路由器不分片==，无校验和，无广播 |
| 组播 | D 类，低 23 位映射 MAC，IGMP 只在本地 |
| 移动 IP | 归属代理截获，隧道到外部代理 |

路由器：路由选择 + 转发（输入、交换结构、输出），到第 3 层，隔离广播域。

# 三、传输层
端口：20/21 FTP、23 Telnet、25 SMTP、53 DNS、69 TFTP、80 HTTP、110 POP3、143 IMAP、161 SNMP、443 HTTPS。
TCP 四元组标识连接；UDP 按目的端口分用。UDP 首部 8B，无连接，面向报文，伪首部参与校验。

seq：本段第一字节。ack：==期望下一字节==，累积确认。SYN、FIN 占序号，纯 ACK 不占。

# 四、TCP 可靠与拥塞
$RTO=RTT_s+4RTT_d$；重传段的 RTT 不用（Karn）。
发送窗口 = min(rwnd, cwnd)；可发 = 窗口 − 在途。零窗口：持续计时器发 1 字节探测。

:::sk 410 170 | 拥塞窗口逐轮。这张图今天画了三遍。翻倍封顶到 ssthresh；超时回 1；3 冗余降到一半直接线性

:::def 四步
慢开始：每 RTT 翻倍，==不超过 ssthresh==。拥塞避免：每 RTT +1。
超时：ssthresh=cwnd/2，cwnd=1，==立即完成不占 RTT==。
3 重复 ACK：ssthresh=cwnd/2，cwnd=ssthresh，线性。
:::

# 五、应用层
| 协议 | 要点 |
| DNS | UDP 53；主机→本地递归，本地→其他迭代；缓存 |
| FTP | 两条 TCP：控制 21 全程，数据一次一条；主动 20，被动随便 |
| SMTP | TCP 25，推，7 位 ASCII，MIME 编码 |
| POP3 | TCP 110，拉，无状态 |
| IMAP | TCP 143，在服务器操作 |
| HTTP | TCP 80，无状态，Cookie |

| 方式（n 对象 + 1 HTML） | RTT |
| 非持续串行 | $2(n+1)$ |
| 非持续无限并行 | 4 |
| 非持续 m 条并行 | $2+2\lceil n/m\rceil$ |
| 持续非流水线 | $n+2$ |
| 持续流水线 | 3 |

起点差一词差 1 RTT。==给了 MSS 和文件大小就画 cwnd，上表作废。==
