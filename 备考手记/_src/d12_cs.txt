# 一、三级调度与指标
高级（作业，外存→内存，一次）/ 中级（挂起换出）/ 低级（就绪→运行，最频繁）。

| 指标 | 公式 |
| 周转 | 完成 − 到达 |
| 带权周转 | 周转 ÷ 服务（≥1） |
| 等待 | 周转 − 服务（再减 I/O） |
| 响应 | 首次得 CPU − 到达 |

# 二、什么时候能调度
- 要调度：结束、阻塞、时间片完、高优先级到（抢占）。
- ==不能：处理中断、执行原语、内核临界区==。
- 普通临界区（打印机）可以调度，别人只是进不来。内核临界区保护的是调度器自己的数据。

**上下文切换**：存 PC、PSW、寄存器到 PCB → 改状态入队 → 选新进程加载现场 → ==切页表，TLB 作废==。线程切换不换地址空间。
闲逛进程：就绪空时运行，优先级最低。

$$\text{响应比}=\frac{\text{等待}+\text{服务}}{\text{服务}}$$
算一下平均周转：FCFS $(7+9+8+11)/4=8.75$；SRTN $(16+5+1+6)/4=7$，最优。

RR 同时发生时新到的先入队。时间片太大退化 FCFS，太小开销大。
I/O 型优先级高于 CPU 型（用一会儿 CPU 就走了，让设备保持忙）。
多级反馈：新进第 1 级，用完时间片降级，上级空才跑下级，高级来人抢占放回本级队尾。

**带 I/O 要画两条时间线**：P1 算 10 → I/O 20 → 算 10；P2 算 30。0–10 P1；10–30 P2（P1 I/O）；30–40 P2；40–50 P1。总 50。

用户级线程 OS 只调度进程。多处理机：公共队列（天然均衡要互斥）；私有队列（亲和性好，要负载均衡）。

# 四、问题：x++ 不是一步
读 → 加 → 写，切换可以在任意两条之间。两个线程各加一次，x 可能只变成 1。
:::sk 360 110 | 手画交错。写回覆盖写回

for i,(a,b,c) in enumerate((('读 x→0','','0'),('','读 x→0','0'),('','加、写 x=1','1'),('加、写 x=1','','!1'))):
    y=38+i*20;s.text(70,y,a,11.5,'k','middle',rot=0);s.text(190,y,b,11.5,'k','middle',rot=0)
    if c.startswith('!'): s.text(310,y,c[1:],13,'r','middle',rot=0);s.text(326,y,'只加了 1',10.5,'r',rot=0)
    else: s.text(310,y,c,11.5,'k','middle',rot=0)
:::
**临界资源**一次一个；**临界区**是访问它的==代码==。互斥：不能同时。同步：有先后。

:::def 四条准则
① 空闲让进 ② 忙则等待 ③ 有限等待 ④ 让权等待（进不去让出 CPU）。前三条必须。
:::
| 方法 | 满足 | 缺陷 |
| Peterson | ①②③ | 忙等 |
| 关中断 | | 只适合单处理机内核 |
| TSL / Swap | ①② | 忙等，可能饥饿 |
| 信号量（记录型） | 全部 | |
| 管程 | 全部 | |

Peterson：`flag[i]=true; turn=j; while(flag[j]&&turn==j);`，走廊让路，最后说的人让到底。

# 五、信号量
```
void wait(S){ S.value--; if(S.value<0) block(S.L); }
void signal(S){ S.value++; if(S.value<=0) wakeup(S.L); }
```
value>0 可用数；value<0 等待数。初值：互斥 1，同步 0，资源 = 数量。
整型信号量 `while(S<=0);` 还是忙等。

:::def PV 三句诀
互斥：一进程内成对。
同步：前操作之后 V，后操作之前 P，分在两个进程。
==同步 P 在前，互斥 P 在后==，V 无所谓。
:::
# 六、管程与条件变量
管程把数据和操作封装，一次只有一个进程在内，互斥由编译器保证。
`x.wait()` 阻塞并放开管程；`x.signal()` 唤醒一个，==没人等就丢了==。条件变量没有值，信号量有值会累积。
