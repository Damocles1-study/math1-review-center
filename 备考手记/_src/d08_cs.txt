# 一、一台机器
冯·诺依曼：指令和数据都以二进制放在主存，按地址访问，顺序执行。五大部件：运算器、控制器、存储器、输入、输出。
**CPU 怎么区分指令和数据？** 取指周期取到的是指令，执行周期取到的是数据。

# 二、性能公式
$$\text{CPU 时间}=\text{条数}\times\text{CPI}\div\text{主频},\quad\text{MIPS}=\frac{\text{主频}}{\text{CPI}\times10^6}$$
例：2GHz，$10^9$ 条，CPI=$.4\cdot1+.4\cdot3+.2\cdot2=2$，1 秒，MIPS=1000。
- MFLOPS 是==浮点==。
- MIPS 高、主频高不等于快。
- **只改善一部分**：未改善的原样加回。

# 四、C 类型转换：位不变，解释变
:::sk 400 104 | 一串位的四次变身。今天最重要的一张

s.box(10,72,68,24,'b',.9);s.text(44,88,'FF',11.5,'b','middle',rot=0);s.box(78,72,68,24);s.text(112,88,'F6',11.5,'k','middle',rot=0);s.text(154,88,'(short) −10：看原类型，有符号补符号位',11.5,'b')

- 同宽：位不变；无符号 = 补码 + $2^n$。
- 长→短：截断。
- 短→长：看**原类型**，无符号补 0，有符号补符号位。
- int 和 unsigned 混合运算：int 转 unsigned。`n-1` 在 `unsigned n=0` 时是 $2^{32}-1$，死循环。

# 五、加法器与标志
全加器 $S=A\oplus B\oplus C$，$C_{out}=AB+(A\oplus B)C$。减法：Y 取反，Cin=1。串行慢，先行进位（CLA）并行快。

| 标志 | 含义 | 给谁看 |
| ZF | 结果全 0 | 都看 |
| SF | 最高位 | 有符号 |
| OF | $C_n\oplus C_{n-1}$，同号相加变号 | ==有符号== |
| CF | $C_{out}\oplus Sub$ | ==无符号== |

| 运算 | 结果 | ZF SF OF CF |
| 7F+01 | 80 | 0 1 1 0 |
| FF+01 | 00 | 1 0 0 1 |
| 03−05 | FE | 0 1 0 1 |

比较：无符号 X<Y 看 CF=1；有符号 X<Y 看 SF≠OF。双符号位 01 正溢、10 负溢。

**移位**：逻辑补 0；算术右移补符号位，向下取整。$-1>>1=-1$，而 $-1/2=0$（C 向 0 取整）。

**乘除**：n×n=2n 位，`int*int` 只取低 32 位。除法溢出只有 最小负数÷(−1)，除 0 异常。Booth 看相邻两位：01 加、10 减。

# 六、IEEE 754
:::sk 400 66 | float 1+8+23。规格化最高位总是 1 不存，所以 23 位有 24 位精度
s.box(10,12,24,26,'r');s.text(22,30,'S',12,'r','middle',rot=0)
s.box(34,12,110,26,'b');s.text(89,30,'e 8 位（偏置 127）',11,'b','middle',rot=0)
s.box(144,12,240,26);s.text(264,30,'f 23 位（隐含 1.）',11,'k','middle',rot=0)
s.text(10,56,'(−1)^{S} × 1.f × 2^{e−127}',13,'k')
:::
| e | 含义 |
| 1~254 | 规格化，指数 −126~127 |
| 全 0 | 非规格化 ±0.f × $2^{-126}$，含 ±0 |
| 全 1 | f=0 是 ∞，f≠0 是 NaN |

最大 $(2-2^{-23})\times2^{127}$（7F7FFFFF），最小规格化 $2^{-126}$（00800000）。
手转：$-6.5=-1.101\times2^2$，S=1，e=129，C0D00000H。

精度：int→float 可能丢，int→double 不丢，float→double 不丢。大数吃小数。

**加减五步**：对阶（小向大，尾数右移）、尾数运算、规格化、舍入、判溢出。对阶不引起阶码溢出；右规和舍入可能上溢；左规可能下溢；==真溢出看阶码==。

# 七、对齐与大小端
大端：高字节放低地址。小端：低字节放低地址（x86）。
:::sk 330 72 | 0x12345678
s.text(4,24,'大端',12,'r');s.text(4,56,'小端',12,'b')
for i,t in enumerate(['12','34','56','78']):
    s.box(40+i*44,8,44,24);s.text(62+i*44,25,t,12,'k','middle',rot=0)
for i,t in enumerate(['78','56','34','12']):
    s.box(40+i*44,40,44,24,'b');s.text(62+i*44,57,t,12,'b','middle',rot=0)
s.text(226,25,'← 地址增大 →',11,'g')
:::
结构体：成员对齐自身大小；总大小对齐最大成员。`char+int+short`=12，`int+short+char`=8。
