| 方式 | 写法 | 信号 |
| 直角 | $\int_a^bdx\int_{\varphi_1}^{\varphi_2}f\,dy$ | 边界是直线、抛物线 |
| 极坐标 | $\int_\alpha^\beta d\theta\int_{r_1}^{r_2}f\,r\,dr$（==别漏 $r$==） | 圆、扇形；含 $x^2+y^2$、$\frac yx$ |

**换序**：内层积不出（$\frac{\sin y}{y}$）。限 → 不等式 → 画 $D$ → 重读。$\int_0^1dx\int_x^1\frac{\sin y}{y}dy=\int_0^1\sin y\,dy=1-\cos1$。

$x^2+y^2\le2x$：$r\le2\cos\theta$，$\theta\in[-\frac\pi2,\frac\pi2]$。例：$\iint\sqrt{x^2+y^2}d\sigma=\frac83\int\cos^3\theta\,d\theta=\frac{32}{9}$。

**$\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt\pi}{2}$ 今天终于证了**：$4I^2=\iint_{\mathbb R^2}e^{-r^2}r\,dr\,d\theta=\pi$。第六天只是记结果。

**对称性**：
- 普通：$D$ 关于 $y$ 轴对称，$f$ 对 $x$ 奇 ⟹ 0；偶 ⟹ 2 倍。
- 轮换：$D$ 关于 $y=x$ 对称，$x,y$ 可互换。$\iint y^2=\frac12\iint(x^2+y^2)$。单位圆上 $\iint(x+y^2)d\sigma=\frac\pi4$。
- $\max,\min,\vert\cdot\vert$：切区域，去符号。

# 二、三重积分
:::def 三种坐标
**直角**：投影法 $\iint_Dd\sigma\int_{z_1}^{z_2}f\,dz$（穿针）；截面法 $\int_c^ddz\iint_{D_z}f\,d\sigma$（被积只含 $z$ 且截面好算）。
**柱**：$dV=r\,dr\,d\theta\,dz$。旋转体、含 $x^2+y^2$。
**球**：$x=\rho\sin\varphi\cos\theta,\ y=\rho\sin\varphi\sin\theta,\ z=\rho\cos\varphi$，$dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$。球、锥、含 $x^2+y^2+z^2$。
:::

- 截面：$\iiint z\,dV$（$x^2+y^2\le z\le1$）$=\int_0^1z\cdot\pi z\,dz=\frac\pi3$。
- 柱：同一区域 $\iiint(x^2+y^2)=\frac\pi6$。
- 球：单位球 $\iiint(x^2+y^2+z^2)=2\pi\cdot2\cdot\frac15=\frac{4\pi}{5}$。

形心：$\bar z=\frac{\iiint z\,dV}{V}$。半球 $\bar z=\frac{\pi/4}{2\pi/3}=\frac38$。

# 三、第一类曲线积分：给铁丝称重
$\int_Lf\,ds=\int_\alpha^\beta f\sqrt{x'^2+y'^2}dt$，==$\alpha\lt\beta$==，$ds$ 恒正，与走向无关。
**先代方程**：$\oint_{x^2+y^2=4}(x^2+y^2)ds=4\cdot4\pi=16\pi$。对称和轮换一样能用：$\oint_{x^2+y^2=1}(x^2+xy)ds=\pi$。

# 四、第一类曲面积分：给薄膜称重
$\iint_\Sigma f\,dS=\iint_Df\sqrt{1+z_x^2+z_y^2}d\sigma$。
| 曲面 | $dS$ |
| 上半球面 $z=\sqrt{1-x^2-y^2}$ | $\frac{d\sigma}{z}$ |
| 锥面 $z=\sqrt{x^2+y^2}$ | $\sqrt2d\sigma$ |
| 平面 $x+y+z=1$ | $\sqrt3d\sigma$ |

$\iint_{\text{半球}}z\,dS=\pi$；锥面 $\iint(x^2+y^2)dS=\frac{\sqrt2\pi}{2}$。
