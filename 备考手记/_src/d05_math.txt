# 一、证不等式
固定流程：**移项令差函数 → 求导 → 看符号**，看不出就再求一阶。

- 单调法：$F=(1+x)\ln(1+x)-\arctan x$，$F(0)=0$，$F'=\ln(1+x)+\dfrac{x^2}{1+x^2}\gt0$。
- 最值法：$e^x\ge1+x$，$F=e^x-1-x$ 在 0 处取最小值 0。

# 二、根的个数：画山形数交点

# 三、中值等式：还原辅助函数
把 $\xi$ 换成 $x$，反问这是谁的导数的因子，然后用罗尔。**今天解决了三天前的卡点**：
| 要证 | $F(x)$ |
| $f'+\lambda f=0$ | $e^{\lambda x}f$ |
| $f'+g'f=0$ | $e^{g}f$ |
| $\xi f'+nf=0$ | $x^nf$ |
| $\xi f'-nf=0$ | $f/x^n$ |
| $f'g+fg'=0$ | $fg$ |
| $f'g-fg'=0$ | $f/g$ |

记法：$(x^nf)'=x^{n-1}(xf'+nf)$；$(e^{g}f)'=e^g(f'+g'f)$。全是乘积求导，提公因子。

:::eg 例：两个中值。$f(0)=0,f(1)=1$
(1) 零点定理得 $f(\xi)=1-\xi$。
(2) 在 $[0,\xi],[\xi,1]$ 上各用拉格朗日：$f'(\eta)=\frac{1-\xi}{\xi}$，$f'(\zeta)=\frac{\xi}{1-\xi}$，相乘为 1。
第 (1) 问就是为第 (2) 问准备的分点。
:::

# 四、不定积分：求导的逆运算，靠认形状
$F'=f$，$\int f\,dx=F+C$。连续函数一定有原函数。积分表比导数表多这几个要专门背：
| 被积 | 结果 |
| $\tan x$ | $-\ln\vert\cos x\vert+C$ |
| $\cot x$ | $\ln\vert\sin x\vert+C$ |
| $\sec x$ | $\ln\vert\sec x+\tan x\vert+C$ |
| $\csc x$ | $\ln\vert\csc x-\cot x\vert+C$ |
| $\frac{1}{a^2+x^2}$ | $\frac1a\arctan\frac xa+C$ |
| $\frac{1}{\sqrt{a^2-x^2}}$ | $\arcsin\frac xa+C$ |
| $\frac{1}{\sqrt{x^2+a^2}}$ | $\ln(x+\sqrt{x^2+a^2})+C$ |
| $\frac{1}{x^2-a^2}$ | $\frac{1}{2a}\ln\vert\frac{x-a}{x+a}\vert+C$ |

## 四招
1. **凑微分**：复合函数 × 里层导数。$\int\frac{\ln^2x}{x}dx=\frac{\ln^3x}{3}+C$。配方：$\int\frac{dx}{x^2+2x+5}=\frac12\arctan\frac{x+1}{2}+C$。
2. **换元去根号**：$\sqrt{a^2-x^2}$ 令 $x=a\sin t$；$\sqrt{a^2+x^2}$ 令 $x=a\tan t$；$\sqrt{x^2-a^2}$ 令 $x=a\sec t$；$\sqrt[n]{ax+b}$ 令它 $=t$。
3. **分部**：$\int u\,dv=uv-\int v\,du$，「反对幂指三」靠前的当 $u$。循环型解方程：$\int e^x\sin x\,dx=\frac12e^x(\sin x-\cos x)+C$。
4. **有理拆项**：$(x-a)$ 对 $\frac{A}{x-a}$；$(x-a)^2$ 对两项；不可约二次对 $\frac{Ax+B}{x^2+px+q}$。
