# 一、链表：改绳子
每个结点是一个人，`next` 是右手。手里抓不住的人就找不回来了。**铁律：先让新人抓住后面的，再让前面的抓新人。**

:::sk 340 92 | 后插 s：① `s->next=p->next` ② `p->next=s`。反过来 c 就丢了。纸上画两遍就记住了
s.chain(20,14,['a','c'],cw=44,ch=26,gap=120,arrow=True)
s.box(108,60,44,24,'r');s.text(130,76,'s',13,'r','middle',rot=0)
s.bend(152,72,184,42,k=-8,c='r');s.text(170,72,'①',13,'r')
s.bend(66,40,106,70,k=8,c='b');s.text(72,70,'②',13,'b');s.text(20,10,'p',12)
:::
带头结点：第一个结点也有前驱，代码统一。空表 `L->next==NULL`。

| 动作 | 代码 |
| 后插 | `s->next=p->next; p->next=s;` |
| 删后继 | `q=p->next; p->next=q->next; free(q);` |
| 不知前驱前插 | 先后插，再交换 data |
| 删 p 本身 | 拷后继的 data，删后继（尾结点不行） |

头插法建表是**逆序**的；尾插是正序。头插即原地逆置：摘下头结点，逐个头插，`r=p->next` 先存后继。

**双链表**：==插入改 4 个，删除改 2 个==。`p->next->prior=s` 这句要先判 `p->next` 非空。
**循环单链表**判空 `L->next==L`；只设尾指针 r，头尾都 O(1)。
:::note
删尾结点要找前驱：单链表设尾指针也是 O(n)，只有双向才 O(1)。
:::
| 维度 | 顺序表 | 链表 |
| 存取 | 随机 | 顺序 |
| 按序号查 | O(1) | O(n) |
| 有序按值 | 折半 O(log n) | O(n) |
| 插删 | 挪元素 | 改指针 O(1)，找位置 O(n) |
| 密度 | 1 | <1 |

# 二、栈：羽毛球筒
$n$ 个元素合法出栈序列数 $\frac{C_{2n}^n}{n+1}$：n=3 时 5，n=4 时 14，n=5 时 42。
**判合法**：看 x，后面比 x 小（先入）的那些必须==递减==。3,1,2,4 中 3 后面是 1,2 递增，不合法。

| 约定 | 入栈 | 栈空 | 栈满 |
| top 指栈顶，初值 −1 | `S[++top]=x` | `top==-1` | `top==M-1` |
| top 指空位，初值 0 | `S[top++]=x` | `top==0` | `top==M` |

共享栈满：`top1+1==top2`。链栈：表头当栈顶。

# 四、表达式
:::def 中缀转后缀
操作数直接输出；`(` 入栈；`)` 弹到 `(`；运算符：把栈里==高于或等于==它的弹出，再压入；扫完全弹。
后缀求值：遇运算符弹两个，==先弹的是右操作数==。
:::
`a+b*(c-d)/e` ⟹ `abcd-*e/+`。

递归的本质：系统维护栈，每层压一个栈帧（参数、返回地址、局部变量）。三句错话：非递归必须用栈（尾递归不用）；入栈次序定了出栈次序就定；栈两端都能操作。

# 五、矩阵压缩：数前面有几个
$a_{ij}$ 行优先：$(i\cdot n+j)\cdot$size（从 0）。
- 对称下三角（从 1）：$k=\frac{i(i-1)}{2}+j-1$。
- 三对角：共 $3n-2$ 个，$k=2i+j-3$。

==四个约定（下标起点、行列、上下三角）一变全变，别背，数。==
稀疏矩阵：三元组、十字链表。

# 六、KMP：主串指针永不回头
看到了就别白看：失配时前面已经比对过的那段，结尾和开头相同的部分不用再比。

:::sk 340 120 | 手算 `ababaa` 的表。PM → 右移 → 看是否 +1
s.cells(10,8,[['j','1','2','3','4','5','6'],['模式','a','b','a','b','a','a'],['PM','0','0','1','2','3','1'],['next(从0)','-1','0','0','1','2','3'],['next(从1)','!0','!1','!1','!2','!3','!4']],cw=[74,34,34,34,34,34,34],ch=21,size=12)
:::
- 时间 O(n+m)。失配只动 j：`j=next[j]`，右滑 `j-next[j]` 位。
- next[j]=0（从 1）时 i、j 都进。
- nextval：`t[j]==t[next[j]]` 则 `nextval[j]=nextval[next[j]]`，否则 next[j]。
- 暴力最坏 O(nm)。「改 nextval 一定更快」是错的。
