# 第 1 章
两对矛盾：帝国主义和中华民族（最主要）、封建主义和人民大众。两大任务：独立解放；富强幸福。前者为后者扫清障碍。
半殖民地相对独立国家和完全殖民地；半封建相对封建社会和资本主义社会。
侵略首要方式：军事。不能瓜分的根本原因：中华民族不屈不挠。失败最重要原因：社会制度腐败。
第一个不平等条约：南京条约 1842。三元里 1841。「振兴中华」孙中山 1894。觉醒始于甲午后。

# 第 2 章
| 运动 | 要点 |
| 太平天国 | 天朝田亩（土地）、资政新篇（资本主义）；旧式农民战争最高峰 |

| 戊戌 | 第一次正面交锋；三重性质；教训：改良走不通 |

三个局限：不敢否定封建、幻想帝国主义、惧怕群众。

# 比方
- 空想社会主义是只会画饼的设计师：马克思找到配方（唯物史观）、面粉被谁拿走（剩余价值）、烤饼的人（无产阶级）。
- 《资本论》给的是导航方向，不是每个路口的照片。
- 近代中国是老房子：外人破门（鸦片战争），屋里两对冤家，要先夺回房子（独立解放）再修好（富强幸福）。
- 三次探索修破房子：农民想推倒重盖，没新图纸；房东（洋务）只买洋砖洋瓦，结构不动；新住户（维新）想改结构，只敢求房东点头，103 天被赶走。

# 错句和张冠李戴
- 苏联工业化、合作化在 30 年代，列宁已逝，别安给新经济政策。
- 工人阶级独立登上舞台是五四，不是鸦片战争后。
- 义和团是旧式农民战争最高峰（错，那是太平天国）。
- 控制通商口岸是经济掠夺，不是政治控制。边疆危机在甲午前，瓜分狂潮在甲午后。
- 郑观应设议院是君主立宪那一路；睁眼看世界在鸦片战争后。
- 裁绿营建新军、商法商律是清末新政，别安给洋务。
- 维新派突破了中体西用，但不敢根本否定封建君主制度。

# 分析题框架
:::def 为什么必须首先反帝反封建
① 半殖民地半封建，两对主要矛盾。② 两大任务，前者为后者扫清障碍，后者是最终目的。③ 帝国主义和封建势力不会自动退出，改良改变不了制度。④ 落到材料。
:::
:::def 早期探索为什么失败
① 农民阶级不代表新生产力。② 洋务维护封建统治，新生产力与封建关系不相容。③ 维新依靠无实权皇帝，自上而下走不通。④ 必须革命，探索新路。
:::
