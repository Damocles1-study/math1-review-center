# 过渡时期
新民主主义社会是过渡性形态，不是独立的社会形态，属于社会主义体系。

五种经济：国营（领导）、合作社、个体（绝对优势）、资本主义、国家资本主义。主要三种：社会主义、个体、资本主义。

土改前主要矛盾是人民大众同三座大山残余；土改后：工人阶级和资产阶级、社会主义和资本主义道路。

一化三改（一化主体，三改两翼），==建设和改造同时并举==。物质基础：国营经济。三条经验：同时并举；积极引导逐步过渡；和平方法（不是「一举过渡」）。

| 改造 | 原则 / 方法 | 形式 |
| 农业 | 自愿互利、典型示范、国家帮助 | 互助组 → 初级社（半社）→ 高级社 |
| 手工业 | 同上 | 供销合作组 → 供销社（半社）→ 合作社 |
| 工商业 | 和平赎买 | 初级国资（加工订货）→ 个别公私合营（半社）→ 全行业 |

赎买：资本家在一定年限内从经营所得获取部分利润。前两步四马分肥。国家资本主义的性质取决于所在国家性质。农业方针积极领导、稳步前进。

基本制度确立：最深刻最伟大的社会变革。

# 比方
- 过渡时期是一只鸟：工业化是身子，三改是两翼。
- 三条线同一列性质相同：第一列有社会主义因素，第二列半社会主义，第三列完全社会主义。
- 《论十大关系》是体检表，第一条重工业和轻工业、农业，总药方调动一切积极因素。「他们走过的弯路，你还想走？」
- 《正处》是家庭调解手册：先分敌人还是家里人，家里人用民主方法，按吵什么配办法。

# 潜台词
- 领导地位 ≠ 数量最多：国营领导，个体绝对优势。
- 1956 改造完成但工业化没完成：标志进入全面建设社会主义，不是工业化初步实现。
- 原则、方针、方式三个词各管各的。共用方式：区别对象、积极引导、逐步过渡。
- 「基本」完成：后期过急、过粗、过快、过于简单划一。
- 「开始」探索：只有起点没有完成。彻底摆脱苏联模式错；探索改革开放道路错。
- 基本矛盾「是什么」没变，性质和情况变了。问情况选又相适应又相矛盾，问性质选非对抗性。

# 错句和张冠李戴
- 合作社和国家资本主义是独立形态（错，过渡形式）。
- 统购统销是初级国资（错，初级里是统购包销）。全行业合营实行四马分肥（错，改定息）。赎买变国营，不是集体。
- 根本思想走自己的路；基本方针调动积极因素。
- 惩前毖后是延安整风方针；敌我矛盾用专政。
- 时代错位：三个面向、外资内资并举、信息化工业化，都不是 50 年代的话。古为今用、洋为中用才是。

# 分析题框架
:::def 基本制度确立的意义
① 最深刻最伟大变革，根本政治前提。② 劳动人民成为主人。③ 世界社会主义又一胜利。④ 适合中国特点的道路。⑤ 并举、逐步、和平。
:::
:::def 评价初步探索
① 四项成果。② 三句意义。③ 教训：从实际出发、发展生产力、民主法制、民主集中制。④ 两个历史时期不能相互否定。
:::
