# 一、总线：两条分界线
总线：多个部件==分时共享==的公共线，一次只能一个发、可以多个收。并行线间有干扰、时钟上不去；串行时钟可以极高，所以 PCIe 是串行。

数据线可传数据、命令、状态字（握手在控制线）；地址线位数决定寻址空间。单、双、三总线：越多越能隔离慢设备。

:::def 分界线一
**带宽** = 宽度 × 工作频率 × 通道数（理想上限，不看事务）。
**有效传输率** = 数据量 ÷ 一次事务总时间（地址、等待都算）。
:::
:::eg 算一遍：100MHz（10ns）、32 位、复用线，读 16 字节
地址 1 + 等待 2 + 数据 4 = 7 周期 = 70ns。有效 $16\text{B}\div70\text{ns}\approx228.6$MB/s。带宽是 400MB/s，算的只是最快那段。
:::
:::def 分界线二
给「时钟频率」要乘每周期次数；给「工作频率」或 MT/s ==不能再乘==。DDR3-1333、64 位、3 通道：$8\times1333\text{M}\times3\approx32$GB/s。
:::
再算：DDR4-2400，2400 已是 MT/s（时钟只有 1200MHz），单通道 $8\times2400=19.2$GB/s，双通道 38.4，不能再乘 2。

事务：申请 → 寻址 → 传输 → 结束。**突发传输**：只发一个首地址连传多个数据，省地址周期。地址数据复用省线数，但不提速。

同步：统一时钟，都按最慢的来。异步：握手，不互锁（可靠性最差）、半互锁、全互锁（最可靠最慢）。半同步：加 Wait。分离式：请求后放开总线，效率最高，控制最复杂。

# 二、I/O 接口与方式
接口是翻译官：地址译码、缓冲匹配速度、转换信号、传命令和状态。三类端口：数据（读写）、状态（CPU 读）、控制（CPU 写）。

统一编址：端口占内存地址，用访存指令。独立编址：IN/OUT。

I/O 指令在通用寄存器和端口之间传。

查询 → 中断 → DMA → 通道，是一步步把 CPU 解放出来。定时查询要多频繁：设备每 5ms 好一个数据，至少每 5ms 查一次，每秒 200 次，否则丢。
:::sk 410 140 | 占用率三算：都是 每秒次数 × 每次周期 ÷ 主频。次数各不相同
s.cells(6,6,[['方式','每秒次数','CPU 怎么参与'],['查询','题给频率','一直问'],['中断','传输率 ÷ 每次字节','每次字一次中断'],['DMA','传输率 ÷ 块大小','每块一次中断'],['通道','','专用处理器']],cw=[56,120,110],ch=22,size=11.5)
s.text(300,30,'50kB/s，32 位',11,'b');s.text(300,48,'12500 次/s',11,'b');s.text(300,66,'×1000 周期',11,'b');s.text(300,84,'÷1GHz=1.25%',11.5,'r')
s.text(6,134,'速度越高越要 DMA：中断太频繁，CPU 忙不过来，数据丢。',12,'k')
:::
:::eg 对比：1GHz、2MB/s、一次中断 100 周期
中断每次 4B：50 万次/秒，$5\times10^7$ 周期，占 5%。DMA 每块 4000B、每次 500 周期：500 次/秒，占 0.025%。给「18 条指令，CPI=5」时一次开销 90 周期，再加响应周期。
:::
中断隐指令三件事：关中断、保存断点、引出服务程序。通用寄存器是服务程序自己存的。多重中断在保存现场、设屏蔽字之后要==开中断==。

**屏蔽字**：屏蔽自己和优先级更低的；==能打断我的那些位写 0==。响应优先级硬件固定；处理优先级 OS 可改。

| 级别 | 能打断它的 | 屏蔽字（L3 L2 L1 L0） |
| L2 | 无 | 1111 |
| L0 | L2 | 1011 |
| L3 | L2、L0 | 1010 |
| L1 | L2、L0、L3 | 0010 |
正在跑 L0（1011 只开放 L2）时 L3、L1 同时来：都被屏蔽，等 L0 结束再按响应优先级。

DMAC 里有主存地址计数器、长度计数器（减到 0 发中断）、数据缓冲、请求触发器。传一个字：设备好 → 申请总线 → CPU 让出 → 送地址读写主存 → 地址 +1、计数 −1 → 放开总线。CPU 不访存时不受影响，还能做内部运算。

**DMA**：预处理（CPU）→ 传送（DMAC）→ 后处理（CPU 中断）。抢总线：CPU 停止访存、周期挪用（优先级==高于 CPU==）、交替访问。一个存取周期结束就能响应（中断要指令结束）。

# 三、I/O 软件四层
分层是为了换设备时只改最下面。**走一遍 read**：用户调 `read` → 系统调用进内核 → 设备独立层翻译逻辑块、查缓冲 → 驱动算柱面启动设备，进程阻塞 → 磁盘完成发中断 → 中断处理唤醒 → 数据拷到用户区返回。键盘是这条路反过来。
:::sk 400 136 | 从上到下四层。算柱面在驱动；键盘敲一下最先响应的是中断处理
for i,(t,d) in enumerate((('用户层','库函数、SPOOLing'),('设备独立性','逻辑名、权限、缓冲、分配'),('驱动','==算柱面磁头扇区==，启动设备'),('中断处理','保存状态，唤醒进程'))):
    d=d.replace('==','');c='r' if i==2 else 'k'
    s.box(30,8+i*30,110,26,c,1);s.text(85,26+i*30,t,12,c,'middle',rot=0);s.text(150,26+i*30,d,11.5,c)
s.arrow(14,12,14,122,'b');s.arrow(366,122,366,12,'g');s.text(372,28,'回',11,'g');s.text(4,134,'',1)
:::
接口：字符（get/put 不可寻址）、块（read/write/seek）、网络（socket）、`ioctl`。阻塞 vs 非阻塞。

缓冲为了匹配速度差、减少中断、提高并行。
:::def 缓冲时间（T 读入缓冲，M 送用户，C 处理）
单缓冲：稳态 $\max(T,C)+M$；n 块 $n(T+M)+C$。
双缓冲：稳态 $\max(T,C+M)$；n 块 $nT+M+C$。
==n 块总时间 ≠ 稳态 × n==。

:::
:::eg T=80，M=10，C=40，读 5 块
单缓冲：节拍 90，总 $5\times90+40=490$。双缓冲：节拍 80，总 $400+10+40=450$。
:::
循环缓冲是生产者消费者的翻版；缓冲池分空、输入、输出三队列。缓冲可能放唯一副本，高速缓存放副本。

设备分配：SDT → DCT → COCT → CHCT，都空闲才成功。LUT：逻辑名 → 物理设备，实现设备独立性。独占、分时共享、虚拟。安全分配（发一个请求就阻塞）vs 不安全分配（可能死锁）。

**SPOOLing**：独占变共享（虚拟设备）。输入井、输出井（磁盘）；缓冲（内存）；输入、输出进程。系统完成，==不用用户控制==。它破坏死锁的互斥条件。

# 四、网络开头
网络是互连的、自治的计算机集合。分类：WAN、MAN、LAN、PAN；广播式 vs 点对点。寄快递：应用写信，传输写房间号，网络写城市，链路写下一站，物理是卡车。每层加首部（链路层还加尾部）：400+20+20+18=458B 上线。
| 模型 | 层 |
| OSI | 物 链 网 传 会 表 应 |
| TCP/IP | 接口、网际、传输、应用 |
| 五层 | 物 链 网 传 应 |

传输层是第一个端到端。表示层：格式转换、加密压缩。会话层：会话管理、同步。OSI 先有模型后有协议，网络层有连接无连接都有；TCP/IP 网络层只有无连接。设备：集线器 1、交换机 2、路由器 3。

协议水平，服务垂直，接口相邻。上层 PDU 是下层 SDU。

:::sk 400 120 | 发送时延是把比特推上线，传播时延是比特在线上跑。k 数链路段
s.box(10,44,50,30,'k');s.text(35,63,'甲',12,'k','middle',rot=0);s.box(170,44,50,30,'k');s.text(195,63,'R',12,'k','middle',rot=0);s.box(330,44,50,30,'k');s.text(355,63,'乙',12,'k','middle',rot=0)
s.line(60,58,170,58);s.line(220,58,330,58)
for x in (66,76,86): s.box(x,48,8,20,'r',.9)
s.text(62,40,'发送=L/C',11,'r');s.text(100,76,'传播=d/v',11,'b');s.arrow(96,60,160,60,'b',1)
s.text(8,104,'T=(k+m−1)·r  k=2 段  m 分组数  r=每组一跳发送时延',12)
:::
- 时延带宽积 = 传播 × 带宽。
- RTT 一个来回。利用率：$D=D_0/(1-U)$，接近 1 时暴涨。
- 例：1000B、100Mb/s、2000km、$2\times10^8$m/s：发送 80μs，传播 10ms，时延带宽积 1Mb。
- 1 kb/s = $10^3$ b/s，1 KB = $2^{10}$ B。
- 报文交换 $k\cdot L/C$。
- 例：4000b 切 4 组，3 段，100Mb/s，$r=10$μs：分组 $(3+4-1)\times10=60$μs，报文 $3\times40=120$μs。电路交换打电话式，先建连接。
