# 三个代表与科学发展观
:::sk 420 112 | 每个理论回答一个问题，这张表最值钱
R=[('邓小平理论','什么是社会主义、怎样建设'),('三个代表','建设什么样的党、怎样建设党'),('科学发展观','实现什么样的发展、怎样发展')]
for i,(a,b) in enumerate(R):
    s.box(10,8+i*32,100,26,'r' if i==0 else 'k',1);s.text(60,25+i*32,a,11.5,'r' if i==0 else 'k','middle',rot=0);s.text(122,25+i*32,b,12.5,'b')
:::
- 三个代表：立党之本、执政之基、力量之源。关键与时俱进，核心先进性，本质执政为民。
- 第一要务发展。改革动力，发展目的，稳定前提。结合点改善人民生活。2001 入世。
- 科学发展观：第一要义发展；核心立场以人为本；基本要求全面协调可持续；根本方法统筹兼顾。
- 精神实质：解放思想、实事求是、与时俱进、求真务实。政治发展道路：党的领导、人民当家作主、依法治国有机统一。

# 比方
- 1978 的车换了司机：扳正方向盘（思想路线）、看车在哪（初级阶段）、定路线、车往哪开（本质）、换发动机（改革）、开窗（开放）、换燃料（市场）。三个仪表：三个有利于。
- 接力赛：邓问社会主义，江问党，胡问发展。

# 潜台词
- 兴国之要、立国之本、强国之路一一对应：经济建设、四项基本原则、改革开放。
- 计划和市场是手段可结合；计划经济和市场经济是体制，不能结合。十四大突破是不具有制度属性。
- 进一步 vs 创造性：三个代表创造性回答的只有党建。今天错的那道就在这里。
- 单选问结合点，只选改善人民生活；同段三句也对，但不对题。
- 精髓字数逐个加长：实事求是 → 解放思想、实事求是 → 再加与时俱进、求真务实。

秒杀两步：先看题干主语是哪个理论，再到那一列找帽子。干扰项几乎都是隔壁列的真话。
:::
# 错句和张冠李戴
- 新中国成立是进入社会主义标志（错，1956）。过渡时期是 1949–1956，不是初级阶段。
- 改革是基本制度的改革（错，改的是体制）。
- 邓小平理论是革命、建设、改革的指南（错，它不涉及革命）。
- 两科措辞不同：毛中特最根本是三者统一，人民当家作主是本质和核心；习概最根本是党的领导，本质特征。按题干科目答。

:::

:::
