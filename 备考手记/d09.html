一、行列式：判定方阵有没有「塌」

$$\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc$$

按行展开：$D=\sum a_{ij}A_{ij}$，$A_{ij}=(-1)^{i+j}M_{ij}$。异行展开为零。

六条性质（计算主干：化三角）

转置不变；互换两行变号，两行相同为 0；公因子可提，两行成比例为 0；某行是和可拆；$k$ 倍加到另一行不变；三角 = 对角线之积。

  • 行和相等：各列加到第一列提公因子，再各行减第一行。四阶例：$(a+3b)(a-b)^3$。
  • 代数余子式的组合：$A_{1j}$ 不依赖第一行，$A_{11}+A_{12}+A_{13}$ 就是把第一行换成 $1,1,1$ 的行列式，别逐个算。
  • 范德蒙：$\prod_{i\gt j}(x_i-x_j)$；$\begin{vmatrix}1&1&1\\1&2&3\\1&4&9\end{vmatrix}=2$。
  • 爪形：用对角元消第一列。
  • 分块三角：$\begin{vmatrix}A&C\\O&B\end{vmatrix}=\vert A\vert\vert B\vert$。
  • 克拉默只记结论：$D\neq0$ 唯一解；齐次有非零解 ⟺ $D=0$。

二、矩阵：一次变换

$AB$：$A$ 的行点乘 $B$ 的列。先穿袜子再穿鞋，不能换。

坑

$AB\neq BA$；$AB=O$ 推不出 $A=O$ 或 $B=O$；$AB=AC$ 不能约。$(A+B)^2$ 一般不是 $A^2+2AB+B^2$。 $(AB)^T=B^TA^T$，$(AB)^{-1}=B^{-1}A^{-1}$，顺序都反。 $\vert AB\vert=\vert A\vert\vert B\vert$，$\vert kA\vert=k^n\vert A\vert$，$\vert A+B\vert$ 没有公式。

列 × 行：两行成比例，$A=\alpha\beta^T$，$A^n=(\beta^T\alpha)^{n-1}A$，$\beta^T\alpha$ 是个数。

凑逆：$A^2+A-3E=O$ 求 $(A-E)^{-1}$：$(A-E)(A+2E)=A^2+A-2E=E$，答案 $A+2E$。

伴随矩阵

$AA^*=A^*A=\vert A\vert E$（$A^*$ 里元素转置放！） $A^{-1}=\frac{A^*}{\vert A\vert}$，$\vert A^*\vert=\vert A\vert^{n-1}$，$(kA)^*=k^{n-1}A^*$，$(A^*)^*=\vert A\vert^{n-2}A$。 二阶：主对调，副变号。

3 阶 $\vert A\vert=2$，$\vert3A^{-1}-A^*\vert$：$A^*=2A^{-1}$，合并得 $A^{-1}$，值 $\frac12$。

三、初等变换：左行右列

$(A\mid E)\xrightarrow{\text{行变换}}(E\mid A^{-1})$。例算：$A=\begin{pmatrix}1&0&1\\2&1&0\\0&1&1\end{pmatrix}$，$A^{-1}=\frac13\begin{pmatrix}1&1&-1\\-2&1&2\\2&-1&1\end{pmatrix}$。

算完乘回去验算！我第一遍第二行写错一个符号。

矩阵方程：$AX=B$，$X=A^{-1}B$；$XA=B$，$X=BA^{-1}$。含 $X$ 先移到一边，提公因子补 $E$：$AX=A+2X$ ⟹ $(A-2E)X=A$。

分块：$\begin{pmatrix}O&A\\B&O\end{pmatrix}^{-1}=\begin{pmatrix}O&B^{-1}\\A^{-1}&O\end{pmatrix}$。

一、指令 = 干什么 + 对谁干

零、一、二、三地址：OP / OP A（另一个隐含 ACC）/ OP A1,A2 / OP A1,A2,A3。 定长译码快适合流水线（RISC）；变长省空间（CISC）。

扩展操作码：短码不能是长码的前缀。从地址多的开始：k 位有 $2^k$ 种，分走 a 条，剩 $2^k-a$ 个前缀，每个再扩 m 位。 16 位、地址 4 位：三地址 0000~1110 共 15 条；二地址 1111 0000~1111 1110 共 15 条……每层留一个 1111。

二、寻址：形式地址 A → 有效地址 EA

方式EA访存用途
立即无0常数
直接A1简单，范围小
间接(A)2扩大范围、指针
寄存器无0快

相对寻址的 PC

取指时 PC 已经加过这条指令的长度：$EA$ = 当前地址 + 指令长 + 位移（补码，要符号扩展）。 3000H，长 4，位移 −8：2FFCH。

A 有 n 位：直接范围 $2^n$；相对 $-2^{n-1}\sim2^{n-1}-1$。

三、读汇编（只读不写）

mov dest,src。[ ] 才访存，lea 里的 [ ] 不访存（常用来做乘加）。 cmp a,b 做 a−b 只改标志，下一条就是条件转移：jg jl（有符号）、ja jb（无符号）。

四、栈帧（今天最重要）

参数从右向左压。调用者保存 eax ecx edx；被调用者保存 ebx esi edi。递归 n 层 n 个栈帧。这就是第二天那张递归工作栈的真实样子。

从机器码读地址：call 相对寻址，偏移 = 目标 − 下一条地址。00401020H、长 5、目标 00401000H：FFFFFFDBH，小端写 E8 DB FF FF FF。 函数长度 = 末条地址 + 末条长度 − 首条地址。

五、链接与 RISC

编译 → 汇编（.o，地址从 0 开始）→ 链接（符号解析 + 重定位）。静态库进文件；动态运行时才链接。 节：.text / .rodata / .data / .bss（不占文件空间）。
