一、特征值：只被拉伸、不被转动的方向

$A\xi=\lambda\xi$，$\xi\neq0$。转地球仪，只有地轴方向不变。

求法：$\vert\lambda E-A\vert=0$ 求 $\lambda$；对每个 $\lambda$ 解 $(\lambda E-A)x=0$。现成的因式别展开。 全部特征向量要写「$k\neq0$」或「不全为 0」，这是扣分点。

例：$A=\begin{pmatrix}2&0&0\\1&2&-1\\1&0&1\end{pmatrix}$

$(\lambda-2)^2(\lambda-1)=0$。$\lambda=2$：$\xi_1=(1,0,1)^T,\xi_2=(0,1,0)^T$；$\lambda=1$：$\xi_3=(0,1,1)^T$。

性质

$\sum\lambda_i=\mathrm{tr}A$，$\prod\lambda_i=\vert A\vert$。可逆 ⟺ 没有 0 特征值。不同 $\lambda$ 的特征向量无关；$k$ 重根的无关向量 $\le k$ 个。三角阵看对角元。

矩阵特征值特征向量
$kA,A^m,f(A)$$k\lambda,\lambda^m,f(\lambda)$$\xi$
$A^{-1}$$\frac1\lambda$$\xi$
$A^*$$\frac{\vert A\vert}{\lambda}$$\xi$
$A^T$$\lambda$一般不同
$P^{-1}AP$$\lambda$$P^{-1}\xi$

例：特征值 $1,2,3$，$\vert A\vert=6$；$A^*+E$ 的特征值 $7,4,3$，行列式 84；$A^2-2A$ 的特征值 $-1,0,3$，行列式 0。

秩 1 矩阵：$A=\alpha\beta^T$，特征值 $\beta^T\alpha$ 和 $0$（$n-1$ 重）。全 1 的 3 阶矩阵：$3,0,0$。

二、相似：同一套家具，两张坐标图

$P^{-1}AP=B$。不变量：特征值、行列式、迹、秩（只是必要条件）。

对角化

可对角化 ⟺ $n$ 个无关特征向量。判定：特征值互异 ⟹ 可以；$k$ 重根要求 $n-r(\lambda E-A)=k$。 $P=(\xi_1,\dots,\xi_n)$，$P^{-1}AP=\Lambda$，列的次序和 $\Lambda$ 对应。$A^m=P\Lambda^mP^{-1}$。

上面那个 $A$：$r(2E-A)=1$，$3-1=2$ 够数，可对角化。$P=\begin{pmatrix}1&0&0\\0&1&1\\1&0&1\end{pmatrix}$，$A^n=\begin{pmatrix}2^n&0&0\\2^n-1&2^n&1-2^n\\2^n-1&0&1\end{pmatrix}$。代 $n=1$ 回到 $A$，能验算。

三、实对称：最听话

实对称矩阵

特征值全实；不同特征值的特征向量正交；一定可对角化，且有正交矩阵 $Q$，$Q^TAQ=\Lambda$。 步骤：特征值 → 特征向量 → 同一特征值内施密特 → 单位化 → 排成 $Q$。

例：$A=\begin{pmatrix}0&1&1\\1&0&1\\1&1&0\end{pmatrix}$

$(\lambda-2)(\lambda+1)^2$。$\xi_1=(1,1,1)^T$；$\lambda=-1$：$\xi_2=(-1,1,0)^T,\xi_3=(-1,0,1)^T$。 $\beta_3=\xi_3-\frac12\xi_2=\frac12(-1,-1,2)^T$。单位化：$\frac{1}{\sqrt3}(1,1,1)$，$\frac{1}{\sqrt2}(-1,1,0)$，$\frac{1}{\sqrt6}(-1,-1,2)$。

反求矩阵：特征值 $1,1,4$，$\lambda=4$ 向量 $\xi=(1,1,1)^T$。写成 $E+$ 秩 1 ：$A=E+\xi\xi^T$（$\xi^T\xi=3$，$\xi$ 方向 $1+3=4$ ✓）。

术式408 第 23–25 话：中断、异常与内核态；OS 骨架；进程与线程
实用 3 小时 30 分（今天轻松一点，概念题多，读得快）进度 26/52 话（50%）

一、为什么要两种模式

银行柜台：程序是储户，OS 是柜员。储户进不了金库，要办事就按铃。

内核态与用户态

内核态：所有指令都能执行。用户态：只能非特权指令。 特权：开关中断、I/O、改 PSW、改基址/界限、设时钟、加载页表基址。 用户→内核只有一条路：中断或异常（含 trap）。内核→用户：改 PSW（iret）。

用户态能：访存、算术、读时钟、trap（用户态才用得上）。

二、中断 vs 异常

外中断只在指令结束后响应；异常是指令执行中当场处理。 缺页是异常（故障），不是中断。

三、硬件做什么，OS 做什么

为什么硬件先关中断：断点还没存好又来一个就乱了。为什么 PC、PSW 由硬件存：服务程序一开始 PC 就变了。

中断 vs 子程序：子程序只存 PC；中断还要存 PSW 并切内核态。 时钟中断服务程序：更新系统时间、当前进程已用时间、减时间片，用完就调度。

四、系统调用

程序接口。传参（寄存器）→ trap → 内核执行服务例程 → 返回。 发起在用户态，执行在内核态。缺页发生在用户态、处理在内核态。进程切换连「发生」都只能在内核态。 printf 是库函数（内部 write）；sin() 不进内核；Shell 是用户程序。

五、OS 骨架

接口：命令接口（人）、程序接口（程序）。 四特征：并发、共享（互为前提）、虚拟（时分、空分）、异步。并发 ≠ 并行，多任务不一定要多 CPU。

发展：单道批处理 → 多道（CPU、设备利用率高，吞吐大，开销变大，无交互）→ 分时（交互）→ 实时（讲截止）。

结构特点
宏内核快，模块耦合
微内核可靠，服务在用户态，切换多；基本功能：进程、低级内存、中断、通信
外核管分配

引导：ROM→BIOS 自检→MBR（磁盘第一个扇区，引导代码 + 分区表）→活动分区引导→加载 OS 到 RAM。 虚拟机：第一类裸金属（Hypervisor 直接跑硬件）；第二类寄居（跑在宿主 OS 上）。虚拟内核态实为用户态。

六、进程

菜谱和做菜：程序静态，进程动态。进程 = PCB + 程序段 + 数据段，PCB 是唯一标志。

  • 不能：阻塞 → 运行、就绪 → 阻塞。
  • 原语：创建、撤销、阻塞、唤醒（内核态，不可中断）。
  • 创建：申请 PID、PCB → 分配资源 → 初始化 → 入就绪队列。登录、调度、服务、fork。
  • 设备分配不会创建进程。

七、线程

进程线程
单位资源分配CPU 调度
共享代码、数据、堆、打开的文件
私有PC、寄存器、栈、TCB

同进程切换线程不切页表。

类型OS 知道？阻塞

模型：多对一（不能并行）、一对一（Linux）、多对多。
