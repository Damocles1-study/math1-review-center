01多元微分家族卡 5 + 触发器 3

家族卡概念关系图:可微 · 偏导 · 连续 · 方向导数(单向箭头)▶
结论(全部单向,反向均不成立)偏导数连续 $\Rightarrow$ 可微 $\Rightarrow$ 连续;可微 $\Rightarrow$ 偏导存在;可微 $\Rightarrow$ 任意方向的方向导数存在且 $\frac{\partial f}{\partial\boldsymbol l}=\nabla f\cdot\boldsymbol l^\circ$。
易混点(反例集,选择题弹药)① 偏导存在 $\nRightarrow$ 连续:$f=\frac{xy}{x^2+y^2}$(补 0)在原点偏导存在但不连续;② 连续+偏导存在 $\nRightarrow$ 可微:$f=\frac{xy}{\sqrt{x^2+y^2}}$(DEMO 错题页题 4);③ 方向导数沿所有方向存在 $\nRightarrow$ 可微(如 $f=\sqrt{x^2+y^2}$ 在原点沿各方向导数存在?——注意它沿方向 $\boldsymbol l$ 的单侧方向导数为 1,但偏导 $f_x(0,0)$ 是双侧极限,不存在,更谈不上可微)。一元里「可导=可微」,多元里断开——这是出题点本身。
真题出处概念选择题几乎每两年一考。待错题页反链。
家族卡复合函数链式法则:画树定项,抽象函数记号 $f_1',f_2'$▶
结论$z=f(u,v)$,$u=u(x,y)$,$v=v(x,y)$:$$\frac{\partial z}{\partial x}=f_1'\cdot\frac{\partial u}{\partial x}+f_2'\cdot\frac{\partial v}{\partial x}$$画变量树:$z\to(u,v)\to(x,y)$,每条从 $z$ 到 $x$ 的路径贡献一项,路径上每段相乘。
何时用抽象函数 $f(xy,\,x+y)$ 求二阶偏导是数一固定题型。关键意识:$f_1'$ 本身仍是 $u,v$ 的函数,再对 $x$ 求导时要再走一遍链式:$\frac{\partial f_1'}{\partial x}=f_{11}''u_x+f_{12}''v_x$。
易混点① 二阶时漏掉 $f_1'$ 自己的链式(只对显式部分求导)是最高频错误;② $f_{12}''=f_{21}''$ 需要「二阶混合偏导连续」——题目说 $f$ 二阶连续可偏导即可合并,抽象题一般都给;③ $\frac{\partial z}{\partial x}$ 与 $\frac{dz}{dx}$ 区分:若 $z=f(x,y(x))$ 是一元复合,用全导数。
真题出处待错题页反链。
家族卡隐函数求导:公式法 · 微分法 · 方程组情形▶
结论单方程 $F(x,y,z)=0$ 确定 $z=z(x,y)$:$$\frac{\partial z}{\partial x}=-\frac{F_x}{F_z},\qquad \frac{\partial z}{\partial y}=-\frac{F_y}{F_z}\quad(F_z\ne0)$$方程组(2 个方程定 2 个隐函数):对每个方程两边同时求(偏)导,联立解线性方程组;或全微分法一次到位。
何时用求二阶隐函数偏导时,对一阶结果继续求导,并且把其中出现的 $z_x$ 再用一阶公式回代。全微分形式不变性:对方程两边直接取 $d$,整理成 $dz=A\,dx+B\,dy$,一次拿到两个偏导——变量地位对称时最省事。
易混点公式里的负号最容易丢;$F_x$ 是把 $x,y,z$ 全当独立变量对 $x$ 求偏导(不做复合),这与「对方程两边求导时 $z$ 是 $x$ 的函数」是两套操作,别混在一次计算里。
真题出处待错题页反链。
家族卡多元极值:无条件判别式 + 条件极值拉格朗日 + 闭域最值▶
结论①无条件:解 $f_x=f_y=0$ 得驻点;记 $A=f_{xx},B=f_{xy},C=f_{yy}$:$AC-B^2\gt0$ 是极值($A\gt0$ 极小,$A\lt0$ 极大);$AC-B^2\lt0$ 不是极值;$=0$ 判别法失效(回定义,沿路径试)。②条件极值:$L=f+\lambda\varphi$,对 $x,y,\lambda$ 求偏导联立。③有界闭域最值=内部驻点值 ∪ 边界最值(边界代入化为一元或拉格朗日),比大小。
何时用应用题(距离最近点、面积最大)几乎都是条件极值;「最值存在性」由闭域连续函数保证,故拉格朗日解出的候选点直接比大小,不必验二阶。
易混点① 偏导不存在的点也可能是极值点(判别式只筛驻点);② 条件极值别忘了目标函数可先等价简化(距离平方代替距离);③ $AC-B^2=0$ 时不能下任何结论——「不是极值」是 $\lt0$ 的专利。
真题出处待错题页反链。
家族卡可微判定标准流程(分段函数在分段点)▶
流程① 按定义算 $f_x(x_0,y_0)$、$f_y(x_0,y_0)$(一元极限);不存在 → 不可微,结束。② 存在 → 验可微定义:$$\lim_{(h,k)\to(0,0)}\frac{f(x_0+h,y_0+k)-f(x_0,y_0)-f_xh-f_yk}{\sqrt{h^2+k^2}}\overset{?}{=}0$$③ 极限为 0 → 可微;找到一条路径极限非 0 或不同路径不同值 → 不可微。
何时用「判断在 $(0,0)$ 处是否可微」的选择/解答题;常配合极坐标 $h=r\cos\theta,k=r\sin\theta$:若结果与 $\theta$ 无关且 $\to0$ 则可微,与 $\theta$ 有关则不可微。
易混点「验证式里减的是 $f_xh+f_yk$」——先得把两个偏导数算出来再验,顺序不能反;沿坐标轴、$y=x$、$y=kx$ 都为 0 仍不够(还有 $y=x^2$ 等路径),证可微必须放缩出与路径无关的界,证不可微才用找路径。
真题出处DEMO 错题页题 4 即此流程。待反链。
触发器见抽象函数二阶偏导 → 画树;$f_1'$ 还要再走链式▶
触发动作见 $z=f(xy,\frac xy)$ 类:第一步在纸上画树标好 $u=xy$、$v=\frac xy$;一阶写完,对每个 $f_i'$ 继续视为 $f_i'(u,v)$ 求导。最后合并 $f_{12}''$ 与 $f_{21}''$。
易混点符号纪律:全程用 $f_1',f_2',f_{11}''$ 记号,别写 $\frac{\partial f}{\partial x}$——$f$ 的自变量是 $u,v$ 不是 $x$,记号混了必错。检验:二阶结果里 $f_{11}'',f_{12}'',f_{22}'',f_1',f_2'$ 五类项都该出现(除非系数恰好为零)。
真题出处待错题页反链。
触发器见「方向导数最大值 / 变化最快方向」→ 梯度▶
结论可微点处 $\frac{\partial f}{\partial\boldsymbol l}=\nabla f\cdot\boldsymbol l^\circ=|\nabla f|\cos\varphi$:最大方向 $=\nabla f$ 方向,最大值 $=|\nabla f|$;最小方向反向,值 $=-|\nabla f|$;与梯度垂直方向导数为 0(等值线切向)。
触发动作题目问「沿哪个方向增长最快/最大方向导数是多少」→ 算 $\nabla f=(f_x,f_y,f_z)$ 代点、取模。就这两步,别绕。
易混点方向导数公式要求方向向量单位化;「方向导数存在」不需要可微(定义是单侧极限),但「用梯度点乘公式」需要可微——概念题会考这个缝。
真题出处数一小题高频。待错题页反链。
触发器见「在约束下证不等式」→ 条件极值求最值再放缩▶
触发动作要证「当 $g(x,y)=c$ 时 $f(x,y)\le M$」型 → 把它读成「$f$ 在约束 $g=c$ 下的最大值是 $M$」:拉格朗日求出候选点,算出最值即完成证明。均值不等式题、周长面积不等式常可这样机械化。
易混点开域/无界域上要先说明最值存在(如「$f$ 连续,远处趋于 $0$ 或 $\infty$」),否则候选点比大小的逻辑不闭合——这半句话是采分点。

02二重积分家族卡 4 + 总表 1 + 触发器 3

家族卡对称性三板斧:奇偶 · 轮换 · 重心(算之前先看)▶
结论①奇偶:$D$ 关于 $y$ 轴对称时,被积函数对 $x$ 为奇 → 积分为 0;为偶 → 取一半区域乘 2(关于 $x$ 轴对称同理看 $y$);②轮换:$D$ 关于 $y=x$ 对称 → $\iint_D f(x,y)=\iint_D f(y,x)$,常用 $\iint f=\frac12\iint[f(x,y)+f(y,x)]$ 化简;③重心公式反用:$\iint_D x\,dA=\bar x\cdot S(D)$,区域重心已知(圆、三角形)时秒杀一次项。
何时用动笔前的固定检查:把被积函数拆成奇部+偶部,先消掉能消的项,再对剩余部分选坐标系。
易混点奇偶性要求「区域对称」和「函数奇偶」同时成立,只有函数奇没有区域对称=白搭;轮换对称是关于 $y=x$ 的对称,不是任意区域都有。
真题出处待错题页反链。
家族卡直角坐标定限与换序:穿线法,画图是硬规矩▶
结论先 $y$ 后 $x$(竖线穿域):$\iint_D=\int_a^b dx\int_{y_1(x)}^{y_2(x)}dy$,竖线从下边界进、上边界出;换序 = 用横线重新穿一遍域。区域是「弓形/三角形被曲线分割」时可能要分块,换序常能把两块合成一块。
何时用累次积分算不动(内层无初等原函数)或题目直接给累次积分要求换序时。流程:累次限 → 画出 $D$ → 换方向重新定限。
易混点换序不是「上下限互换抄一遍」,必须过区域图;内外限含义:外限是常数,内限是外变量的函数——写出「内限含内变量」立刻知道错了。
真题出处DEMO 错题页题 3。待反链。
家族卡极坐标:何时换 · 怎么定限 · 三种极点位置▶
结论$x=r\cos\theta,\ y=r\sin\theta$,$dx\,dy=r\,dr\,d\theta$(别丢 $r$)。定限:先定 $\theta$ 扫过的范围,再沿每条射线看 $r$ 进出:极点在域内 → $r$ 从 0 到边界;在域边界上 → $r$ 从 0 到边界曲线(如圆 $x^2+y^2=2ax$ → $r=2a\cos\theta$,$\theta\in[-\frac\pi2,\frac\pi2]$);在域外 → $r$ 从内边界到外边界。
何时用域是圆/环/扇形,或被积函数含 $x^2+y^2$、$\frac yx$;两个信号占一个就值得换。
易混点偏心圆 $r=2a\cos\theta$ 的 $\theta$ 范围是 $[-\frac\pi2,\frac\pi2]$ 不是 $[0,2\pi]$(超范围 $r$ 变负);丢雅可比 $r$ 是全国统一错误;$\theta$ 的范围由区域几何定,别默认 $[0,2\pi]$。
真题出处待错题页反链。
家族卡进阶技巧包:一般换元 · 含参积分 · 分段被积函数▶
结论①一般换元:$\iint_D f\,dxdy=\iint_{D'} f\cdot|J|\,dudv$,$J=\frac{\partial(x,y)}{\partial(u,v)}$(记得取绝对值;反向雅可比互为倒数);② 被积函数含 $\max/\min/|\cdot|$/取整 → 沿分界线把 $D$ 切开分块积;③ 已知 $\iint_D f=A$ 当常数用:$f(x,y)=g(x,y)+\lambda\iint_D f$ 型方程,两边再积一次解出 $\lambda$ 相关量。
何时用域是平行四边形/由 $xy=c,\ y=kx$ 围成 → 换元 $u=xy,v=\frac yx$ 类;含 $|y-x^2|$ → 按 $y=x^2$ 切两块。
易混点换元后区域也要换(新变量的范围重新描述);$|J|$ 忘取绝对值符号会整体反号;分段函数切块后每块的被积表达式不同,别抄串。

对比总表二重积分计算决策树▶
第 1 步看对称性:区域对称?被积函数拆奇偶 → 消项/减半;$y=x$ 对称 → 轮换平均
第 2 步选坐标系:圆/环/扇 或含 $x^2+y^2$ → 极坐标;否则直角坐标
第 3 步定限:画图 + 穿线法;分块域考虑换一个穿线方向合并
卡住时内层积不出 → 换序;域形状怪 → 换元(雅可比);含 $\max/|\cdot|$ → 切块;一次项 → 重心公式
易混点顺序就是「对称性 → 坐标系 → 定限」,跳过第 1 步直接硬算是时间黑洞。
触发器见 $e^{\pm y^2}$、$\sin(y^2)$、$\frac{\sin y}{y}$、$\frac1{\ln y}$ → 这个方向积不出,换序▶
触发动作这几个函数没有初等原函数,谁的累次积分先碰它谁死——见到它们出现在内层,无条件画域换序,让「积不出的变量」放到外层,内层先把好积的变量积掉(通常恰好产生一个因子把它救活,如 $y\sin(y^2)$)。
易混点换序后依然要它自己积的话,检查是不是漏了对称性或换元;$\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt\pi}2$ 是唯一「广义积分特例」,平方转极坐标得来,数一可以直接引用。
真题出处待错题页反链。
触发器见圆域/含 $x^2+y^2$ → 极坐标;见 $x^2+4y^2$ → 广义极坐标▶
触发动作标准信号直接换极坐标。椭圆域 $\frac{x^2}{a^2}+\frac{y^2}{b^2}\le1$ → 广义极坐标 $x=ar\cos\theta,\ y=br\sin\theta$,雅可比为 $abr$,椭圆变单位圆。
易混点广义极坐标下 $x^2+y^2$ 不再等于 $r^2$(变成 $a^2r^2\cos^2\theta+b^2r^2\sin^2\theta$)——它只把「椭圆边界」变好,被积函数可能变丑,权衡后再换。
真题出处待错题页反链。
触发器见对称区域 → 动笔前固定三问▶
触发动作① 区域关于坐标轴对称吗?→ 拆被积函数奇偶部;② 关于 $y=x$ 对称吗?→ $f(x,y)$ 与 $f(y,x)$ 平均(经典:$\iint_D\frac{af(x)+bf(y)}{f(x)+f(y)}dA=\frac{a+b}2S(D)$);③ 有一次项 $x$ 或 $y$ 吗?→ 重心公式。三问过完再选坐标系。
易混点轮换平均那道经典题的前提是区域关于 $y=x$ 对称(正方形 $[a,b]^2$、圆心在 $y=x$ 上的圆),别对任意区域套。
