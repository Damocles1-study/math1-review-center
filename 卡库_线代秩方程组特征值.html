01秩与方程组家族卡 9 + 触发器 7

家族卡秩的不等式家族(全员报数)▶
结论$$r(A+B)\le r(A)+r(B)\qquad r(AB)\le\min\{r(A),r(B)\}$$$$r(AB)\ge r(A)+r(B)-n\ \text{($A$ 列数 $=B$ 行数 $=n$)}\qquad AB=O\Rightarrow r(A)+r(B)\le n$$$$r(A)=r(A^T)=r(A^TA)=r(AA^T)\qquad r(kA)=r(A)\,(k\ne0)$$初等变换、乘可逆阵不改变秩:$P,Q$ 可逆 $\Rightarrow r(PAQ)=r(A)$。
何时用抽象矩阵秩的选择题、证明题的弹药库;$AB=O$ 那条是「隐藏信息挖掘」的第一现场(见触发器)。
易混点$r(AB)$ 与 $r(BA)$ 一般不相等;$r(A^TA)=r(A)$ 是实矩阵的专利;Sylvester 下界那条里 $n$ 是 $A$ 的列数,别代成行数。
真题出处待错题页反链。
家族卡线性方程组解的结构(判定 + 通解模板)▶
结论$A$ 为 $m\times n$:①齐次 $Ax=0$:基础解系含 $n-r(A)$ 个向量;只有零解 $\iff r(A)=n$。②非齐次 $Ax=b$:$$r(A)\lt r(A\,|\,b)\Rightarrow\text{无解};\quad r(A)=r(A\,|\,b)=n\Rightarrow\text{唯一解};\quad r(A)=r(A\,|\,b)\lt n\Rightarrow\text{无穷多解}$$通解 $=$ 特解 $+$ 齐次通解:$x=\eta^*+k_1\xi_1+\cdots+k_{n-r}\xi_{n-r}$。
何时用解性质题:$\eta_1,\eta_2$ 都是 $Ax=b$ 的解 $\Rightarrow\eta_1-\eta_2$ 是 $Ax=0$ 的解;$k_1\eta_1+k_2\eta_2$ 是 $Ax=b$ 的解 $\iff k_1+k_2=1$。「$Ax=b$ 的 $s$ 个解的组合仍是解」全靠系数和判定。
易混点基础解系个数是 $n-r$($n$ 是未知数个数=列数,不是行数);「$Ax=b$ 有无穷多解」$\Rightarrow$「$Ax=0$ 有非零解」,反向不成立($b$ 可能让它无解);非齐次解集不构成向量空间(不含零向量)。
真题出处待错题页反链。
家族卡线性相关/无关判定工具箱▶
结论(按优先级)① 拼成矩阵求秩:$r=$ 个数 $\iff$ 无关;② 方阵 → 行列式:$|A|\ne0\iff$ 无关;③ 定义法(抽象题):设 $k_1\alpha_1+\cdots+k_s\alpha_s=0$,想办法(左乘矩阵/代特征值)证 $k_i$ 全零。速判:个数 $\gt$ 维数必相关;含零向量必相关;部分相关 $\Rightarrow$ 整体相关;整体无关 $\Rightarrow$ 部分无关;无关组每个向量添加分量后仍无关。
何时用抽象题固定招:向量组 $A\alpha_1,A\alpha_2$ 相关性 → 左乘;$\alpha,A\alpha,A^2\alpha$ 相关性 → 利用 $A$ 的特征值/零化多项式;不同特征值的特征向量无关(直接引用)。
易混点「$\alpha_1,\dots,\alpha_s$ 线性相关」只保证至少一个可被其余表出,不是每个都行;「两向量相关=成比例」只对两个向量成立;相关性与排列顺序无关、与是否含零向量强相关。

家族卡伴随矩阵与逆矩阵公式束$AA^*=|A|E$▶
结论(源头只有一条:$AA^*=A^*A=|A|E$)$$A^{-1}=\frac{A^*}{|A|}\qquad A^*=|A|A^{-1}\qquad |A^*|=|A|^{n-1}\qquad (A^*)^*=|A|^{n-2}A\ (n\ge2)$$$$r(A^*)=\begin{cases}n,&r(A)=n\\ 1,&r(A)=n-1\\ 0,&r(A)\le n-2\end{cases}$$$(AB)^{-1}=B^{-1}A^{-1}$,$(AB)^T=B^TA^T$,$(AB)^*=B^*A^*$(全反序)。
何时用一切含 $A^*$ 的等式,先左/右乘 $A$ 或用 $A^*=|A|A^{-1}$ 消掉 $A^*$ 回到 $A$ 的世界;$r(A^*)$ 三段论是选择题老熟人。
易混点$A^*$ 的第 $(i,j)$ 元是 $A$ 的第 $(j,i)$ 元的代数余子式(转置着放);$|kA|=k^n|A|$(每行都提 $k$),别写成 $k|A|$;$A^*$ 存在不要求 $A$ 可逆(任何方阵都有伴随)。

触发器见 $AB=O$ → 立刻写出两条隐藏信息▶
触发动作① $B$ 的每一列都是 $Ax=0$ 的解(列视角);② $r(A)+r(B)\le n$。若再知 $B\ne O$,则 $Ax=0$ 有非零解 $\Rightarrow r(A)\lt n\Rightarrow|A|=0$。这三步是含参数题(「已知 $AB=O$,$B\ne O$,求 $a$」)的标准开局。
易混点$AB=O$ 推不出 $A=O$ 或 $B=O$(矩阵没有零因子性质);同样 $A^2=O$ 推不出 $A=O$,但能推出 $r(A)\le\frac n2$ 与特征值全零。

触发器见含参数方程组 → 系数行列式定分岔,逐参代回▶
触发动作方阵系数 → 先算 $|A|$(含参行列式):$|A|\ne0$ 的参数值 → 唯一解(克拉默);$|A|=0$ 的每个参数值逐个代回增广矩阵作初等行变换,比较 $r(A)$ 与 $r(A|b)$ 分「无解/无穷多解」。非方阵直接行变换讨论。

家族卡极大无关组 · 行最简形一次交付三样东西只能行变换▶
结论把向量按列拼成矩阵,化行最简形,则:① 台阶数 $=r$;② 主元列对应的原向量构成一个极大无关组;③ 非主元列的数字竖着读就是该向量被极大无关组表示的系数。由此得满秩分解 $A=GH$:$G=$ 主元列原样,$H=$ 最简形的非零行。
何时用求极大无关组、求表示式、求满秩分解(ch2 用 $A=GH$ 降幂求 $A^n$ 的来料)。一次消元三样全出,别分三次算。
易混点绝对不能行列变换混用:列变换会改变列向量之间的线性关系,读出来的表示系数全错(求秩时可以混用,求关系时不行);极大无关组不唯一但个数唯一。
真题出处精读版 ch3 §五(配步进器)。
家族卡$n-r(A)$ 的四个名字 · 与「一物三名」▶
结论同一个数 $n-r(A)$ 有四个名字:自由变量个数 = 解空间维数 = 基础解系向量个数 = 线性无关解的个数。同一串数 $[x_1,\cdots,x_n]^T$ 也有三个名字:① $\beta$ 被表示的组合系数 ② (数一)在基下的坐标 ③ 方程组的解。
基础解系三条件:①是解 ②线性无关 ③个数 $=n-r(A)$。
何时用题问"基础解系含几个""解空间维数""最多几个无关解"——三问一个答案。选择题考基础解系时,火力 90% 打在②③上(①通常题目直接给)。
易混点$n$ 是列数(未知量个数),不是行数,两个方程组的 $n$ 可以不同;问 $Ax=b$ 的解里最多几个无关 → 答 $n-r+1$(多的那个 1 是"平移量"$\eta^*$),问 $Ax=0$ → 答 $n-r$。
真题出处精读版 ch4 §一。
家族卡同解三判据 + 公共解三法先分清求交集还是判相等▶
结论 · 齐次同解(三选一)① $r\left(\begin{bmatrix}A\\B\end{bmatrix}\right)=r(A)=r(B)$(三秩相同,最常用);② $A$ 与 $B$ 的行向量组等价;③ 存在 $P,Q$ 使 $B=PA,\ A=QB$(题给矩阵乘积/分块拼接时用)。
非齐次同解(须先设两边均有解):$r\left(\left[\begin{smallmatrix}A&\beta\\B&\gamma\end{smallmatrix}\right]\right)=r\left(\begin{bmatrix}A\\B\end{bmatrix}\right)=r(A)=r(B)$。
公共解三法:两组都给系数矩阵 → 联立摞起来解;一组给基础解系另一组给矩阵 → 把通解代入(★最省力);两组都给基础解系 → 令两边组合相等配平。
何时用题里出现两个方程组:问"都满足的解" → 公共解(交集);问"解完全相同" → 同解(相等)。公共解集 $=V_A\cap V_B$,维数 $=n-r\left(\begin{bmatrix}A\\B\end{bmatrix}\right)$。
易混点非齐次四条等价说法的前提是两边均有解(两个都无解时秩关系会乱);同解题何时可单向验证:仅当一组的方程包含另一组时(加方程型);两组方程完全不同就必须双向,代入求出参数后还要再验一次行最简形一致。
真题出处精读版 ch4 §五§六。
家族卡(数一)三张平面的八种位置关系α 判方向 · β 判位置▶
结论 · 四条生成元($i\ne j$,$\alpha_i$ 为 $A$ 的行=法向量,$\beta_i$ 为 $\bar A$ 的行):$\alpha_i,\alpha_j$ 相关 $\iff$ 平行或重合;无关 $\iff$ 相交;$\beta_i,\beta_j$ 相关 $\iff$ 重合;无关 $\iff$ 不重合。
有解 4 种:$r=r(\bar A)=3$ 交于一点;$=2$ 且任两 $\beta$ 无关 → 交于一直线;$=2$ 且有两 $\beta$ 相关 → 两面重合第三面相交;$=1$ 三面重合。
无解 4 种:$r(A)=2,r(\bar A)=3$ 且任两 $\alpha$ 无关 → 三棱柱;有两 $\alpha$ 相关 → 两面平行第三面相交;$r(A)=1,r(\bar A)=2$ 且任两 $\beta$ 无关 → 三面平行不重合;有两 $\beta$ 相关 → 两面重合第三面平行。
何时用数一给图求参数(如三面交于一线求 $a,b$)。八行不用背:先由 $r(A),r(\bar A)$ 定有解/无解,再按下面这句挑字母现推。
易混点要分"斜不斜"用 $\alpha$,要分"贴不贴"用 $\beta$——$r(A)=2$ 的两种无解情形分的是平行还是相交(方向问题,用 $\alpha$);$r(A)=1$ 时方向已全部平行,只剩重合与否(位置问题,用 $\beta$)。$\beta$ 相关必推出 $\alpha$ 相关,反之不然。
真题出处精读版 ch4 §七(配三平面实验台,可输入系数真解真画)。
触发器见"解的线性组合" → 只数系数和▶
触发动作$\eta_i$ 都是 $Ax=b$ 的解时,$A\left(\sum c_i\eta_i\right)=\left(\sum c_i\right)b$,于是:$\sum c_i=0$ ⟹ 是 $Ax=0$ 的解;$\sum c_i=1$ ⟹ 是 $Ax=b$ 的解(可当特解)。给一堆解要凑基础解系时,配系数把和凑成 0;要凑特解,把和凑成 1(如 $\frac12(\eta_1+\eta_2)$)。
易混点系数和只判"落在哪个集合",不判线性无关——造出两个齐次解后仍须单独验证无关且个数 $=n-r$,才配称基础解系。判据管归属,不管资格。

触发器见"存在两个不同的解" → 无穷多解 → $|A|=0$▶
触发动作线性方程组的解只有 0 / 1 / ∞ 三种个数,所以"有两个不同解""解不唯一""解集含至少两个元素"全部等价于无穷多解 ⟹ $r(A)=r([A,b])\lt n$ ⟹ 方阵时 $|A|=0$。第一刀砍在行列式上,先把参数候选值挖出来。
易混点$|A|=0$ 只保证"不唯一",不保证有解——解出的每个参数候选值都必须逐个代回增广矩阵验有解性,把变成"无解"的那个舍去。漏掉这一步会算出根本不存在的通解,整题全崩。

触发器见抽象条件 → 翻译成解向量(五条对照)▶
触发动作抽象型题没有套路,只有这一张翻译表:
① 向量关系式 $\alpha_1=2\alpha_2+\alpha_3$ → 移项配 0,系数排成列 $[1,-2,-1,0]^T$ 就是 $Ax=0$ 的解;
② $\beta=\alpha_1+2\alpha_2+3\alpha_3+4\alpha_4$ → $[1,2,3,4]^T$ 是 $Ax=\beta$ 的特解;

易混点翻译①时系数为 0 的分量必须补上(解向量维数 $=$ 向量个数);④只说"是解"不够,要数够个数才能说"任一解都能被它们表示"。

触发器秩算不出来时 → 夹逼定秩▶
触发动作系数矩阵含一堆字母、$r(A)$ 算不出时,上下两头夹:
上界从"已知有几个线性无关解"来($k$ 个无关解 ⟹ $n-r\ge k$ ⟹ $r\le n-k$),或从形状来($r\le\min\{m,n\}$);
下界从"能一眼看出无关的那几行/列"来(挑字母最少的两行比是否成比例),或从已知乘积来(如 $r(AB)=2\Rightarrow r(A)\ge2$)。
两头相等即定死。同一手法还用于 $r(A^*)$:$A$ 有非零 $n-1$ 阶子式 ⟹ $r(A^*)\ge1$,$A^*A=O$ ⟹ $r(A^*)\le1$,夹出 $=1$。
易混点只做上界不做下界是高发错:由两个无关解得 $r\le2$ 就断言 $r=2$——万一 $r=1$,基础解系要多一个,答案整段错。

触发器见方程组"拼接/乘积"形式 → 提左乘因子▶
触发动作两个方程组的系数阵能写成 $\begin{bmatrix}\ast\\ \ast\end{bmatrix}=M\begin{bmatrix}A\\B\end{bmatrix}$ 时:$M$ 可逆 ⟹ 同解($M$ 不可逆则不一定)。判 $M$ 可逆用分块消元 $\begin{bmatrix}E&X\\E&Y\end{bmatrix}\to\begin{bmatrix}E&X\\O&Y-X\end{bmatrix}$。
口诀:左乘换方程(保解集),右乘换基(保秩)——右乘版本是"新组 $=$ 旧组 $\times C$,$C$ 可逆 ⟺ 仍是基础解系"。
易混点题问"不一定同解"时,只需说明左乘因子不可逆即可,不必真造反例;初等行变换就是左乘初等矩阵——这条原理与"求解只能行变换"是同一件事的两个粒度。
真题出处精读版 强 5.6(与 基 4.5 右乘版对读)。
家族卡等价矩阵 vs 等价向量组 · 五条判据总表▶
结论 ·「等价」两义矩阵等价:要同型,只看秩($A\cong B\iff$ 同型且 $r(A)=r(B)$);向量组等价:要同维,须三秩相同($r(\text{I})=r(\text{II})=r(\text{I},\text{II})$)。秩相等对向量组等价远远不够。
五条判据总表:① $Ax=0$ 只有零解 ⟹ $r(A)=n$,推不出 $Ax=b$ 有解;② $Ax=0$ 有非零解 ⟹ $r(A)\lt n$,同样推不出;③ $A$ 行满秩 ⟹ $Ax=b$ 必有解;④ $Ax=b$ 唯一解 ⟹ $Ax=0$ 只有零解;⑤ $Ax=b$ 无穷多解 ⟹ $Ax=0$ 有非零解。④⑤ 不能倒推。
何时用选择题看箭头方向先秒杀一半:"齐次 ⟹ 非齐次"一律错(信息量不够,丢的是 $r([A,b])$),"非齐次 ⟹ 齐次"方向对再看内容。
易混点口诀:行满秩管"有没有解",列满秩管"唯不唯一";$r(A)=m$ 时增广矩阵是给每个行向量加一个分量,仍无关,故必有解。
真题出处精读版 ch4 §八 · ch3 §八。

家族卡特征值基本功:定义 · 两恒等式 · 函数搬运表▶
结论$A\alpha=\lambda\alpha$($\alpha\ne0$);求法 $|\lambda E-A|=0$。两恒等式:$\sum\lambda_i=\text{tr}(A)$,$\prod\lambda_i=|A|$。搬运表($\alpha$ 不变):$$A\to\lambda;\quad A^k\to\lambda^k;\quad f(A)\to f(\lambda);\quad A^{-1}\to\frac1\lambda;\quad A^*\to\frac{|A|}{\lambda};\quad P^{-1}AP\to\lambda\ (\text{向量变}P^{-1}\alpha)$$不同特征值对应的特征向量线性无关。
何时用「$A$ 满足 $A^2-3A+2E=O$,求 $A^{-1}$ 的特征值」类:特征值只能取零化多项式的根,再逐个搬运。
易混点① $A^T$ 与 $A$ 特征值相同但特征向量一般不同;② 零化多项式的根是特征值的候选集,不保证每个根都真是特征值(要结合 tr、秩等确认);③ $\lambda=0$ 是特征值 $\iff|A|=0$。

家族卡相似对角化条件链(判定固定动作)▶
结论$A$ 可对角化 $\iff$ 有 $n$ 个线性无关特征向量 $\iff$ 对每个 $k_i$ 重特征值 $\lambda_i$ 都有 $n-r(\lambda_iE-A)=k_i$。充分条件:$n$ 个特征值互异;实对称矩阵必可(且可正交对角化)。$P=(\alpha_1,\dots,\alpha_n)$,$P^{-1}AP=\Lambda$,$\Lambda$ 对角元顺序与 $P$ 列顺序一一对应。
何时用判定题固定动作:求特征值 → 单根跳过 → 对每个重根算 $r(\lambda E-A)$ 验重数;求 $A^k$:$A^k=P\Lambda^kP^{-1}$。
易混点「相似」与「可对角化」是两回事:$A\sim B$ 不要求谁可对角化;可对角化失败的唯一原因是某个重根的特征向量不够数;$k$ 重特征值的无关特征向量个数 $\le k$(几何重数≤代数重数),只可能少不可能多。

家族卡实对称矩阵专属性质包▶
结论① 特征值全为实数;②不同特征值的特征向量相互正交;③ 必可正交对角化:存在正交阵 $Q$($Q^TQ=E$,$Q^{-1}=Q^T$)使 $Q^TAQ=\Lambda$;④ $r(A)=$ 非零特征值个数(重数计)。
何时用「已知部分特征值和特征向量,反求其余特征向量/反求 $A$」:未知特征向量与已知的全部正交 → 解正交方程组直接得到;这是实对称独有的补全手段。
易混点正交对角化流程中,同一特征值的多个特征向量还要施密特正交化(不同特征值的自动正交,不用做);$Q$ 的列必须单位化,否则 $Q^{-1}\ne Q^T$;普通矩阵不同特征值的特征向量只保证无关、不保证正交。

家族卡二次型标准化三法 + 惯性定理▶
结论$f=x^TAx$($A$ 取实对称写法):①正交变换法 $x=Qy$:$f=\sum\lambda_iy_i^2$,系数就是特征值——保长度、保几何形状,涉及「距离/曲面类型/在 $\|x\|=1$ 上的最值」必须用它;②配方法(可逆线性变换):系数一般不是特征值,但正负个数不变;③ 惯性定理:无论怎样的可逆变换,正、负惯性指数 $(p,q)$ 不变;规范形 $z_1^2+\cdots+z_p^2-\cdots-z_{p+q}^2$ 唯一。
何时用标准形只问正负个数 → 配方/求特征值符号即可;要写变换矩阵或有几何背景 → 正交变换法全流程。
易混点二次型矩阵必须写成对称的(交叉项系数减半分两边);配方时若没有平方项、只有交叉项,先做 $x_1=y_1+y_2,x_2=y_1-y_2$ 造出平方项;正交变换下标准形系数=特征值,配方法下不是——选择题拿这个设坑。

家族卡正定判定家族(等价条件全家福)▶
结论$A$ 实对称,以下等价:① $\forall x\ne0,\ x^TAx\gt0$;② 特征值全 $\gt0$;③ 各阶顺序主子式全 $\gt0$;④ 正惯性指数 $p=n$;⑤ 存在可逆 $D$ 使 $A=D^TD$;⑥ $A$ 与 $E$ 合同。必要条件(验坑用):$a_{ii}\gt0$、$|A|\gt0$。
何时用数字题用顺序主子式最快;抽象题(如证 $A^TA+kE$ 正定)用定义:算 $x^T(\cdot)x=\|Ax\|^2+k\|x\|^2\gt0$;含参讨论正定 → 顺序主子式列不等式组。
易混点顺序主子式判别法只适用于实对称矩阵;「特征值全 $\gt0$」别弱化成「$|A|\gt0$」($|A|\gt0$ 可能是两负相乘);$A,B$ 正定 $\Rightarrow A+B$ 正定(定义直接加),但 $AB$ 未必(可能不对称)。

对比总表等价 · 相似 · 合同:三关系一张表▶
关系定义充要判据不变量
等价$B=PAQ$($P,Q$ 可逆)同型 + $r(A)=r(B)$秩
相似$B=P^{-1}AP$(一般矩阵无简单充要;实对称:特征值相同即相似)特征多项式、特征值、tr、行列式、秩
合同$B=C^TAC$($C$ 可逆)(实对称)正负惯性指数相同$(p,q)$、秩
用法判断题流程:先比不变量排除(tr 不同必不相似;$(p,q)$ 不同必不合同);实对称阵:相似 $\Rightarrow$ 合同 $\Rightarrow$ 等价,一路单向。正交变换 $Q^TAQ$ 同时是相似和合同——正交对角化两头通吃的原因。
易混点「特征值相同 $\Rightarrow$ 相似」对一般矩阵不成立(如 $\begin{pmatrix}0&1\\0&0\end{pmatrix}$ 与 $O$),对实对称成立;相似必等价,合同必等价,相似与合同互不包含(非对称时)。
触发器见抽象矩阵等式求特征值 → 凑 $A\alpha=\lambda\alpha$ / 零化多项式▶
触发动作① 给向量等式(如 $A\alpha=2\alpha+\beta$?不行——必须凑成「$A\cdot$某向量$=$数$\cdot$同一向量」);② 给矩阵等式 $f(A)=O$ → 特征值 $\in\{f(\lambda)=0\text{ 的根}\}$;③ 给 $A$ 每行和为 $c$ → $A(1,1,\dots,1)^T=c(1,\dots,1)^T$,即 $c$ 是特征值——「行和相等」是隐藏最深的送分暗号。
易混点由 $f(A)=O$ 判定具体哪些根真被取到:用 $\text{tr}(A)$、$r(A)$、$|A|$ 反推重数分配(如 $A^2=A$、$r(A)=r$ ⇒ 特征值 1 有 $r$ 个、0 有 $n-r$ 个)。

触发器见 $\|x\|=1$ 上求 $x^TAx$ 最值 → 最大/最小特征值▶
触发动作$\max_{\|x\|=1}x^TAx=\lambda_{\max}$,$\min=\lambda_{\min}$,取到的 $x$ 是对应的单位特征向量。原理:正交变换 $x=Qy$ 保 $\|x\|=\|y\|$,化成 $\sum\lambda_iy_i^2$ 一眼定界。不限长度时 $x^TAx$ 的正负性由特征值符号(惯性指数)定。
易混点约束是 $\|x\|=1$ 才有此结论;若约束是别的二次型($y^TBy=1$)那是广义特征值问题,考研不涉及——见到就说明读错题了。

触发器见「$A$ 与 $B$ 相似吗」选择题 → 四道闸门顺序过▶
触发动作① 比 tr;② 比 $|A|$;③ 比特征值(特征多项式);④ 都同 → 若都可对角化于同一 $\Lambda$ 则相似;有重根且不对称时比 $r(\lambda E-A)$ 与 $r(\lambda E-B)$(几何重数)。任何一道闸不同即不相似,选完收工。
