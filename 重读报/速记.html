全部 37 期的「本期只记」和易错，一页过完。每次套卷前翻一遍。

第 1 期 · 函数与极限

  1. \displaystyle\lim_{x\to x_0}f(x) 存在 ⟺ 左、右极限都存在且相等。
  2. e^{1/x} 和 \arctan\frac1x 在 x=0 两侧的极限不同，见到必须分左右。
  3. 局部保号性：极限 >0，则附近的函数值也 >0。
  4. \alpha=o(\beta) 的意思是 \alpha/\beta\to0：\alpha 比 \beta 更快趋于 0。
易错

  • 反向保号时等号不能丢：f(x)\gt0 只能推出 A\ge0。比如 x\to0 时 x^2\gt0（x\neq 0），极限却是 0。

第 2 期 · 极限运算与连续

  1. 连续 ⟺ \lim\limits_{x\to x_0}f(x)=f(x_0)。初等函数在定义区间内都连续，可以直接代入。
  2. 间断点：左右极限都存在是第一类（相等叫可去，不等叫跳跃）；至少一侧不存在是第二类。
  3. 闭区间上连续：有最值、能取到最大最小之间的一切值；两端异号必有零点。
易错

  • 前提是两个极限都存在。\lim_{x\to\infty}(\sqrt{x^2+x}-x) 不能拆成 \infty-\infty；\lim\frac{f}{g} 中分母极限为 0 时也不能用商法则。

第 3 期 · 求极限（第一套工具）

  1. 等价替换只能换乘除因子，不能换加减中的一项。
  2. 替换表：\sin x,\tan x,\arcsin x,\arctan x,\ln(1+x),e^x-1\sim x；1-\cos x\sim\frac{x^2}{2}；(1+x)^a-1\sim ax。
  3. 1^\infty 型：\lim u^v=e^{\lim(u-1)v}。
  4. 数列递推：先证单调有界，再对递推式两边取极限。
易错

  • 加减中间的项不能单独替换。\tan x-\sin x 若各换成 x，得到 0，是错的。正确做法是先写成乘积。

第 4 期 · 导数与微分

  1. f'(x_0)=\lim\limits_{\Delta x\to0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}；分段点必须用定义。
  2. 可导 ⟹ 连续，反过来不行（\vert x\vert 在 0 处）。
  3. 可导 ⟺ 左导数、右导数存在且相等。
  4. 一元函数：可微 ⟺ 可导，dy=f'(x_0)\,dx。
易错

  • \lim\limits_{h\to0}\frac{f(a+h)-f(a-h)}{2h} 存在不能推出 f'(a) 存在：f=\vert x\vert，a=0 时这个极限为 0，但 f'(0) 不存在。判定可导，定义里必须有一个定点 f(a)，且动点能从两侧趋近。

第 5 期 · 求导法则

  1. 复合函数：一层一层乘。[f(g(x))]'=f'(g(x))g'(x)。
  2. 隐函数：两边对 x 求导，y 看作 x 的函数。
  3. 参数方程：\frac{dy}{dx}=\frac{y'_t}{x'_t}；二阶是 \frac{d}{dt}\bigl(\frac{dy}{dx}\bigr)\Big/x'_t，不是 y''_t/x''_t。
  4. 幂指函数：先取对数，或者写成 e^{v\ln u}。
易错

  • 二阶导不是 \frac{y''(t)}{x''(t)}。一阶导 \frac{dy}{dx} 仍是 t 的函数，再对 x 求导要用链式法则，因此必须再除一个 x'(t)。

第 6 期 · 中值定理与洛必达

  1. 费马：可导的极值点处导数为 0。
  2. 罗尔：闭连开导 + 两端相等 ⟹ 存在 f'(\xi)=0。
  3. 拉格朗日：f(b)-f(a)=f'(\xi)(b-a)。
  4. 洛必达三步：验型 → 求导 → 看新极限是否存在；新极限不存在时法则失效，不能说原极限不存在。
易错

  • 洛必达是「若新极限存在，则旧极限等于它」。新极限不存在时，不能得出旧极限不存在。如 \lim\limits_{x\to\infty}\frac{x+\sin x}{x}=1，求导后 1+\cos x 振荡。

第 7 期 · 泰勒公式

  1. e^x,\ \sin x,\ \cos x,\ \ln(1+x),\ (1+x)^a 五个展开式必须默写。
  2. 展开到第几项：分子、分母展成同阶，抵消后还剩非零项为止。
  3. 求 f^{(n)}(0)：x^n 的系数乘 n!。
  4. 佩亚诺余项用于极限，拉格朗日余项用于证明。

第 8 期 · 函数图像

  1. f'\gt0 单调增；f' 变号的点才是极值点。
  2. f''\gt0 下凸（∪），f''\lt0 上凸（∩）；f'' 变号的点才是拐点。
  3. 拐点是曲线上的点 (x_0,f(x_0))，极值点只是 x_0。
  4. 斜渐近线：a=\lim\frac{f(x)}{x}，b=\lim[f(x)-ax]。
易错

  • f''(x_0)=0 不一定是拐点：y=x^4 在 0 处 y''=0，但 y'' 不变号。此外，拐点要写成曲线上的点。

第 9 期 · 不等式、根、辅助函数

  1. 证不等式：令 F= 左 - 右，用单调性或最值。
  2. 根的个数：分离参数，画 g(x) 的图，数交点。
  3. 辅助函数口诀：f'+gf 乘 e^{\int g}；xf'+nf 乘 x^{n-1}；xf'-f 除 x^2。
  4. 两个中值 \xi,\eta：分段用两次拉格朗日。

第 10 期 · 不定积分

  1. 先想凑微分，再想换元，然后分部，分式最后拆项。
  2. 分部口诀：「反对幂指三」，靠前的留作 u，靠后的放进 d。
  3. 根号换元：\sqrt{a^2-x^2} 用 x=a\sin t；\sqrt{a^2+x^2} 用 x=a\tan t；\sqrt{x^2-a^2} 用 x=a\sec t。
  4. 不定积分结果必须带 +C。

第 11 期 · 定积分

  1. 牛顿—莱布尼茨：\int_a^bf=F(b)-F(a)。
  2. 变限积分求导：\frac{d}{dx}\int_{a}^{\varphi(x)}f(t)\,dt=f(\varphi(x))\varphi'(x)。
  3. 奇函数在对称区间积分为 0；偶函数等于两倍半区间。
  4. 和式极限：\lim\limits_{n\to\infty}\frac1n\sum f(\frac kn)=\int_0^1f(x)\,dx。
易错

  • 被积函数里含求导变量 x 时不能直接用公式。比如 \int_0^xxf(t)\,dt，要先把 x 提出去；\int_0^xf(x-t)\,dt 要先换元 u=x-t。

第 12 期 · 反常积分与几何应用

  1. \int_1^{+\infty}\frac{dx}{x^p}：p\gt1 收敛。\int_0^1\frac{dx}{x^p}：p\lt1 收敛。
  2. 瑕点在区间内部时必须拆开算，一处发散整个发散。
  3. 绕 x 轴：V=\pi\int y^2dx；绕 y 轴（柱壳）：V=2\pi\int x\vert y\vert dx。
  4. 极坐标面积：S=\frac12\int r^2d\theta。
易错

  • \int_{-1}^{1}\frac{dx}{x^3} 不能用「奇函数积分为 0」，因为 x=0 是瑕点，\int_0^1\frac{dx}{x^3} 发散，所以整个发散。对称性只适用于已知收敛的积分。

第 13 期 · 一阶微分方程

  1. 可分离：y'=f(x)g(y)，分开两边积分。
  2. 齐次：y'=\varphi(\frac{y}{x})，令 u=\frac{y}{x}。
  3. 一阶线性：y'+P(x)y=Q(x)，通解公式 y=e^{-\int P}\bigl(\int Qe^{\int P}dx+C\bigr)。
  4. 解完代初值确定 C；公式里的 \int 不用再加常数。
易错

  • 先把 y' 的系数化为 1，再读 P,Q。xy'+y=\sin x 要先除以 x。

第 14 期 · 二阶微分方程

  1. 通解 = 齐次通解 + 非齐次特解。
  2. 两不等实根 C_1e^{r_1x}+C_2e^{r_2x}；重根 (C_1+C_2x)e^{rx}；复根 e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)。
  3. f=P_m(x)e^{\lambda x}：设 y^*=x^kQ_m(x)e^{\lambda x}，k 是 \lambda 作为特征根的重数。
  4. 欧拉方程令 x=e^t，变常系数。

第 15 期 · 行列式

  1. 互换两行变号；一行的 k 倍加到另一行，值不变。
  2. 三角形行列式 = 对角线之积。
  3. 按行展开：某行元素分别乘自己的代数余子式，和为 D；乘别行的代数余子式，和为 0。
  4. 见到 A_{11}+A_{12}+A_{13} 这种组合：把系数填进那一行，算新行列式。

第 16 期 · 矩阵

  1. AB\neq BA；AB=O 推不出 A=O 或 B=O。
  2. AA^*=A^*A=\vert A\vert E，一切伴随公式都由此推出。
  3. \vert kA\vert=k^n\vert A\vert，\vert A^*\vert=\vert A\vert^{n-1}，\vert A^{-1}\vert=\vert A\vert^{-1}。
  4. 左乘行变换，右乘列变换。(A\mid E)\to(E\mid A^{-1})。

第 17 期 · 秩与线性方程组

  1. 秩 = 行阶梯形的非零行数 = 最高阶非零子式的阶数。
  2. Ax=b：r(A)\neq r(A\mid b) 无解；=n 唯一解；\lt n 无穷多解。
  3. Ax=0 解空间的「维数」是 n-r(A)。
  4. 通解 = 特解 + 齐次通解。

第 18 期 · 向量组

  1. \beta 能由 \alpha_1,\dots,\alpha_n 表示 ⟺ Ax=\beta 有解 ⟺ r(A)=r(A\mid\beta)。
  2. \alpha_1,\dots,\alpha_n 线性相关 ⟺ Ax=0 有非零解 ⟺ r(A)\lt n。
  3. 向量组的秩 = 极大无关组的个数 = 排成矩阵的秩。
  4. 过渡矩阵：(\beta_1,\dots,\beta_n)=(\alpha_1,\dots,\alpha_n)C。
易错

  • 矩阵等价：同型且秩相同。向量组等价：能互相线性表示。向量组等价则秩相同，秩相同却不一定等价。

    C=AB 时，C 的列是 A 的列的组合；若 B 可逆，C 与 A 的列向量组等价。

第 19 期 · 特征值与特征向量

  1. A\xi=\lambda\xi（\xi\neq0）；\vert\lambda E-A\vert=0 求 \lambda，(\lambda E-A)x=0 求 \xi。
  2. \sum\lambda_i=\mathrm{tr}A，\prod\lambda_i=\vert A\vert。
  3. f(A) 的特征值是 f(\lambda)，特征向量不变。
  4. 不同特征值对应的特征向量线性无关。
易错

  • 全部特征向量要写「不全为 0」或「k\neq0」。特征向量不能是零向量，这是扣分点。

第 20 期 · 相似与对角化

  1. P^{-1}AP=B：相似矩阵有相同的特征值、行列式、迹、秩。
  2. 可对角化 ⟺ 有 n 个线性无关特征向量 ⟺ 每个 k 重根 \lambda 都有 r(\lambda E-A)=n-k。
  3. P 的列是特征向量，顺序与对角阵上的 \lambda 对应。
  4. 实对称：特征值全实，不同特征值的向量正交，一定可正交对角化。
易错

  • P 的列顺序和对角矩阵必须一致。写 \mathrm{diag}(2,2,1)，就必须把 \lambda=1 的向量放在第三列。

第 21 期 · 二次型

  1. f=x^TAx，A 实对称：x_i^2 系数放对角线，x_ix_j 系数折半放对称位置。
  2. 正交变换 x=Qy：标准形系数就是特征值。
  3. 惯性定理：正、负惯性指数不随变换方法改变。
  4. 正定 ⟺ 特征值全正 ⟺ 顺序主子式全正。
  5. 合同 ⟺ 正负惯性指数相同（实对称）。

第 22 期 · 向量与空间解析几何

  1. 点积判垂直：a\cdot b=0。叉积判平行：a\times b=0，\vert a\times b\vert 是平行四边形面积。
  2. 平面 Ax+By+Cz+D=0，法向量 (A,B,C)。
  3. 直线 \frac{x-x_0}{l}=\frac{y-y_0}{m}=\frac{z-z_0}{n}，方向向量 (l,m,n)。
  4. yOz 面上 f(y,z)=0 绕 z 轴转：y\to\pm\sqrt{x^2+y^2}。

第 23 期 · 多元函数微分

  1. 连续偏导 ⟹ 可微 ⟹ 连续，可微 ⟹ 偏导存在。偏导存在推不出连续。
  2. 判可微：\lim\frac{\Delta z-f_x\Delta x-f_y\Delta y}{\rho}=0。
  3. 抽象复合：用 f_1',f_2' 记号；f_{12}''=f_{21}''（二阶连续时）。
  4. 隐函数：z_x=-\frac{F_x}{F_z}，z_y=-\frac{F_y}{F_z}。

第 24 期 · 多元微分的应用

  1. 无条件极值：f_x=f_y=0 求驻点，AC-B^2\gt0 有极值，A\gt0 极小，A\lt0 极大。
  2. 条件极值：L=f+\lambda\varphi，对所有变量和 \lambda 求偏导令其为 0。
  3. 方向导数 = 梯度 · 单位方向向量；最大值 = 梯度的模。
  4. 曲面法向量 (F_x,F_y,F_z)；曲线切向量 (x',y',z')。

第 25 期 · 二重积分

  1. 第一步永远是画积分区域。
  2. 有 x^2+y^2 或圆形区域：极坐标，d\sigma=r\,dr\,d\theta，别漏 r。
  3. 内层积不出（e^{y^2},\frac{\sin y}{y}）：交换次序。
  4. D 关于 y 轴对称：f 对 x 奇则积分为 0，偶则两倍。轮换对称可互换 x,y。

第 26 期 · 三重积分

  1. 只含 z：截面法，\int dz\iint_{D_z}。
  2. 柱坐标：dV=r\,dr\,d\theta\,dz。
  3. 球坐标：dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta，\varphi 从 z 轴往下量。
  4. 形心：\bar z=\frac{\iiint z\,dV}{V}。

第 27 期 · 第一类曲线、曲面积分

  1. 第一类曲线：ds=\sqrt{x'^2+y'^2}\,dt，下限 \lt 上限。
  2. 第一类曲面：dS=\sqrt{1+z_x^2+z_y^2}\,d\sigma。
  3. 积分在曲线/曲面上进行，可以把方程代入被积函数。
  4. 对称性（奇零偶倍）和轮换对称同样适用。
易错

  • 第一类积分和后两期的第二类积分，长得很像。判断依据：第一类写 ds,dS，没有方向；第二类写 dx,dy,dydz，有方向。

第 28 期 · 第二类曲线积分与格林公式

  1. 第二类：\int_LP\,dx+Q\,dy，代入参数，下限对应起点。
  2. 格林：\oint_{L^+}Pdx+Qdy=\iint_D(Q_x-P_y)\,d\sigma，正向 = 区域在左手边。
  3. 不封闭就补线，有奇点就挖洞。
  4. Q_x=P_y（单连通）⟹ 与路径无关，Pdx+Qdy 是全微分。

第 29 期 · 第二类曲面积分、高斯、斯托克斯

  1. 投影法：\iint_\Sigma R\,dxdy=\pm\iint_{D_{xy}}R(x,y,z(x,y))\,d\sigma，上侧取 +，下侧取 -。
  2. 高斯：\oiint_{\text{外侧}}Pdydz+Qdzdx+Rdxdy=\iiint_\Omega(P_x+Q_y+R_z)\,dV。
  3. 不封闭：补平面（上底/下底），方向使整体朝外。
  4. 斯托克斯：曲线积分 = 旋度通过曲面的通量。

第 30 期 · 常数项级数

  1. 必要条件：\sum u_n 收敛 ⟹ u_n\to0。u_n\not\to0 直接发散。
  2. \sum\frac{1}{n^p}：p\gt1 收敛。\sum q^n：\vert q\vert\lt1 收敛。
  3. 正项：比较（等价无穷小阶数）；有阶乘、幂指用比值或根值。
  4. 交错：莱布尼茨。任意项：先看绝对收敛。
易错

  • 去掉绝对值再看，只对「绝对收敛」成立。\sum u_n 收敛推不出 \sum u_n^2 收敛（任意项时）：u_n=\frac{(-1)^n}{\sqrt n}，\sum u_n^2=\sum\frac{1}{n} 发散。

第 31 期 · 幂级数与傅里叶级数

  1. R=\lim\vert\frac{a_n}{a_{n+1}}\vert；端点单独代入判敛。
  2. 求和：分母有 n 先求导，分子有 n 先积分，化成 \frac{1}{1-x}。
  3. 展开：化成 \frac{1}{1-t}，e^t，\ln(1+t) 等已知式。
  4. 傅里叶：奇函数只有 b_n，偶函数只有 a_n。狄利克雷：间断点处收敛到左右极限平均值。
易错

  • 正弦级数在 x=0,l 处和为 0（f 在那里不为零也一样，因为奇延拓后左右极限互为相反数）。余弦级数在 x=0,l 处和就是 f(0),f(l)。

第 32 期 · 事件与概率

  1. P(A\cup B)=P(A)+P(B)-P(AB)；P(A-B)=P(A)-P(AB)。
  2. P(B\vert A)=\frac{P(AB)}{P(A)}；P(AB)=P(A)P(B\vert A)。
  3. 全概率：P(B)=\sum P(A_i)P(B\vert A_i)；贝叶斯：P(A_i\vert B)=\frac{P(A_i)P(B\vert A_i)}{P(B)}。
  4. 独立：P(AB)=P(A)P(B)。互斥不是独立。
易错

  • 「互斥」和「独立」是两回事。P(A),P(B)\gt0 时，互斥则 P(AB)=0\neq P(A)P(B)，一定不独立。

第 33 期 · 一维随机变量

  1. F(x)=P(X\le x)：单调不减，右连续，F(-\infty)=0，F(+\infty)=1。
  2. f\ge0，\int_{-\infty}^{+\infty}f\,dx=1，P(a\lt X\le b)=\int_a^bf\,dx，F'=f。
  3. N(\mu,\sigma^2)：标准化 \frac{X-\mu}{\sigma}\sim N(0,1)，\Phi(-x)=1-\Phi(x)。
  4. Y=g(X)：F_Y(y)=P(g(X)\le y)，求导得 f_Y。

第 34 期 · 二维随机变量

  1. P((X,Y)\in D)=\iint_Df\,dx\,dy。第一步画密度非零的区域。
  2. 边缘：f_X(x)=\int f\,dy。条件：f_{Y\vert X}=\frac{f}{f_X}。
  3. 独立 ⟺ f(x,y)=f_X(x)f_Y(y)。必要条件：非零区域是矩形。
  4. Z=X+Y：f_Z(z)=\int f(x,z-x)\,dx；\max：F_{\max}=F_XF_Y；\min：F_{\min}=1-(1-F_X)(1-F_Y)。

第 35 期 · 数字特征

  1. E[g(X)]=\int g(x)f(x)\,dx，不需要先求 g(X) 的分布。
  2. D(X)=E(X^2)-(EX)^2。D(X\pm Y)=DX+DY\pm2\mathrm{Cov}(X,Y)。
  3. \mathrm{Cov}(X,Y)=E(XY)-EX\cdot EY，\rho=\frac{\mathrm{Cov}}{\sqrt{DX}\sqrt{DY}}。
  4. 独立 ⟹ 不相关，反之不成立；二维正态中两者等价。

第 36 期 · 极限定理与抽样分布

  1. 切比雪夫：P(\vert X-EX\vert\ge\varepsilon)\le\frac{DX}{\varepsilon^2}。
  2. 中心极限：独立同分布，\sum X_i\approx N(n\mu,n\sigma^2)。
  3. \chi^2(n)：n 个标准正态的平方和。t(n)=\frac{N(0,1)}{\sqrt{\chi^2(n)/n}}。F(m,n)=\frac{\chi^2(m)/m}{\chi^2(n)/n}。
  4. 正态总体：\bar X\sim N(\mu,\frac{\sigma^2}{n})；\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)；\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)。
