## 任务

为数学一重读报真题套卷重制 **<年份> 年整卷**：文字题面＋逐步精解。工作目录 `11408相关/数学一/复盘中心/重读报/`。
先读：`README.md` 末节「套卷精解」、`_build/rich_build.py` 开头的语法、样板 `_build/rich/2021.txt`、全局卡 `_build/rich/kp.txt`、草图库 `_build/sk.py`、本年旧精研卡 `_build/deep/<年份>.txt`、`assets/exam/y<年份>.js`（题数、分值、选择题答案、归属第几期）。
每题：
1. `@stem`（选择题加 `@A`–`@D`）：把题面图 `assets/exam/img/<年份>/qNN.webp` 逐字转成文字＋LaTeX。用 PIL 放大读，上下标、积分限、分式、绝对值、矩阵逐个复核；题目带图的用 `::sk` 重画或表格。填空题写 `@ans`。
2. 解析素材：原书解析图 `assets/exam/img/<年份>/sNN.webp` ＋ 旧精研卡，在此基础上**加工**，不照抄、不省步。

**块与标记**（语法以 `_build/rich_build.py` 开头为准）：
- `::read` 每题必写：逐句「原句 >> 看到它想到什么 / 该画什么 / 这句话的固定含义 / 能排除什么」，用 `{{圈|}}`、`{{波|}}` 圈画。
- `::sk` 草图（**先读文末「统一规定」第二节**，旧口径「凡是会画的都画」已作废）：只画考场上真会画的（函数图像、积分区域、空间几何体/曲面、数轴与区间、概率密度/分布函数图、矩阵分块示意、极限的「抵消账本」等），画法看 `_build/sk.py` 与样板；坐标要算对，渲染后肉眼核对位置。
- `::think` 思路；`::fast` 秒杀/快法（选填必写：特值、排除、奇偶对称、几何意义、结论秒杀、选项代入，用 `{{秒|}}`）。
- `::steps` 每一步，**不许跳步**，读者要能看懂每个环节；考场上可省的步骤行首加 `~`（灰底），行内可省用 `{{省|}}`。
- `::paper` 考场卷面：解答题必写，照三层铁律——「解/证」开头、分问小标题、中间式编号、`⛳N` 采分点、用定理先点名、条件先验证、末行回扣题干；选填不写卷面
- `::note` 扣分点（`{{扣|}}`）、适用边界、提速心算、跨章联系。
- `::vary` 举一反三：普通题 2 条、必吃透题 3 条，每条带答案（「变式 >> 答案」），要有真正改条件后的变化，不是换数字。
- `@tpl`：凡是能沉淀成跨年固定套路的都标上。先用 `kp.txt` 里已有的；没有就在本年文件顶部 `@tpl Txxx | 看到什么→先做什么` 新建（汇总时会提到全局）。定义、定理、公式、方法用 `[[id]]` 做弹窗，缺的在本年顶部 `@kp` 定义（写「是什么＋怎么用＋最小例子」）。
**正确性第一**：每题答案都要程序独立复算，写进 `_build/rich/chk/<年份>.py` 并跑通（sympy 符号或数值积分/求极限/解方程，概率题可蒙特卡洛）。复算与原解析冲突时，第一反应是自己转录错了，回去放大看原图/原文。
**验收**：`python3 _build/rich_build.py <年份>` 必须 ✓ 通过；然后把中心目录（不含 `_build`）rsync 到你自己的 scratchpad，写个 `serve.py` 监听 `127.0.0.1:<端口>`，在 `新威考研-资料/.claude/launch.json` 追加一条配置后用 `preview_start` 打开 `真题套卷.html#y=<年份>`，交卷（顶栏「交卷」→ 弹窗确认）后逐题抽查：无 `.katex-error`、草图位置对、宽 375 时 `scrollX` 为 0。
**约束**：只写 `_build/rich/<年份>.txt`、`_build/rich/chk/<年份>.py`（构建生成的 `assets/exam/rich/` 文件不用管）。**不要改** `engine.js`、`exam.css`、`rich_build.py`、`kp.txt`、`sk.py`、页面 HTML——别的会话正同时写别的年份；发现构建脚本 bug 或需要新语法，写进最终报告。**不要 git commit**，主会话最后统一提交。题量大，按题推进、随写随构建，别攒到最后。

## 统一规定（2026-11-12 起，所有年份都照此写；与上文冲突的以这里为准）

用户原话：「我现在不是无限时间」「图是要我确实能在草稿纸上想到和能画出的」。距初试不到 40 天，一张卷的复盘只有卷首给的限时（60–150 分钟）。精解是给他在这段时间里读完并记住的，不是越多越好。

### 一、篇幅预算（超了就删重复话，不删步骤）

| 题型 | 每题正文上限（不含草图代码） |
|---|---|
| 选择、填空 | 1200 字 |
| 解答 | 2600 字 |

- `::steps` 照旧不许跳步，这是用户要的；可省的步骤照旧标 `~`。省的是别处：
- `::read` 只写「不写就会漏掉」的句子，一题最多 3 行。「求极限」「设函数可导」这类看了等于没看的不写。
- `::think` 最多 4 条，只写怎么选路，不预演计算。
- `::note` 最多 3 条：一个扣分点、一个边界或易错、一个提速。没有就少写。
- `::vary` 普通题 2 条，精研卡点名「必吃透」的题 3 条。每条必须改了条件后做法真的变了。
- 同一句话只说一次：read 里说过的，think、steps、note 里不再重复。
- 旧精研卡的「本质」那一行（`_build/deep/<年份>.txt`）是交卷后做对的题唯一显示的东西，写精解时顺手核一遍：≤ 50 字，一句话说清「看到什么 → 做什么 → 答案」。

### 二、草图：只画考场上真会画的（`::sk 宽 高 画|列|看 | 图注`，不标用途构建报错）

- **画**＝考场草稿纸上 1 分钟内徒手画得出、并且画了能帮着得出答案。只用默画得出的形状：直线、圆、抛物线、钟形、指数衰减、折线、数轴、韦恩图、积分区域（直角坐标或极坐标）、标准密度曲线和它下面的阴影、概率树、简单的柱/锥/球投影。图上要标的点不超过 4 个，坐标都能口算。图注第一句写画法：「先画……，再标……」。
- **列**＝草稿上列的式子或表（抵消账本、逐轮表、地址切分）。纯表格优先直接用 `| 表 | 格 |` 写进 `::steps`，不必做成图。
- **看**＝只为看懂、考场不会画的示意图。页面上标着「看懂就行 · 考场不画」，用户点「精简」就整类隐藏。**一张卷最多 4 张**，只在「不看图就讲不清」时用。
- **不许再画的**：要算好多个点才描得出的非标准函数曲线（如 $y=x+\sin\frac1x$、某个被积函数的精确形状）、三维曲面的立体渲染、推理链 / 流程框图、比喻图（杠杆、眼镜、同台演出）。这些改成一句话。
- **不再要求每题一张图**。没有值得画的就不画，别凑数。
- 画完自问一句：合上页面，用户能不能在草稿纸上照着图注自己画出来？不能就改成「看」或删掉。

### 三、知识点卡要写全（页面会把它们汇到每题顶上「这题要用到的」）

- 本题用到的每个公式、定理、常用结论都要有 `[[id]]` 或 `@tpl` 指到一张卡，用户靠它重复记忆。
- 卡的内容写全：是什么、公式全文、什么时候用、一个最小例子。不许写「见教材」「略」。
- 先在 `kp.txt` 里搜，能复用就复用。

### 四、样式与写法

- 不写 emoji（块标题的图标页面已不显示；正文里也别加）。采分点照旧写 `⛳N`，页面会画成红笔圈的「+N 分」。
- 页面现在是手写笔记样式（引擎 v5，见 README「套卷引擎」）：解析是一页带红页边线的纸，交卷后只有失分、标记过、看过提示、必吃透的题默认摊开。写的时候按「用户只读摊开的这些题」来安排详略。

### 六、精修已完成年份（2026-11-12 用户点名：删废话、删无用图、每题写「复盘」）

样板：数学 `_build/rich/2021.txt` 第 1–12 题（已精修）。其余年份、其余题照此做，一年一个会话：

1. **每题第一块加 `::rev`**，固定四行，必须具体到这道题，不许写套话：
   `- **该花** 几分钟；超时说明走了哪条弯路` / `- **卡点** 具体错在哪一步、会错成哪个选项或哪个数` / `- **错了说明** 哪个知识点或习惯没到位` / `- **带走** 一句下次能直接用的做法`。

5. 改完 `python3 _build/rich_build.py <年份>` 通过，再跑 `_build/rich/chk/<年份>.py`。
