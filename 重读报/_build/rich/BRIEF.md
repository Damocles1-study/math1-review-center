# 套卷精解 · 分年会话任务书

> 主会话派活时会告诉你 <年份> 和 <端口>。

## 背景

用户 zyx 备考 2027 考研（初试 2026-12-19/20，时间很紧），数学一走「重读报」中心（`11408相关/数学一/复盘中心/重读报/`，独立 git 仓库 math1-review-center，公开）。其中在线真题套卷 `真题套卷.html` 原先题面和解析都是 PDF 裁图，用户反馈：看不清、解析太省、精研太浅，要求改成文字题面＋详细且正确的逐步精解：读题时每句话想到什么、要画什么草图（像人在纸上用笔画的，圈画批注）、每一步都讲清，考场可省的步骤用灰色标、秒杀/特值用橙色标，知识点方法点开弹出，并有跨年固定套路（如「求极限先代入，不行再等价/泰勒/洛必达，看到 e^{1/x} 先分左右极限」）。主会话已做好：引擎与样式（`assets/exam/engine.js`、`exam.css`）、编译器 `_build/rich_build.py`、手绘草图库 `_build/sk.py`、全局卡 `_build/rich/kp.txt`、样板 `_build/rich/2021.txt`（第 1、2、3、11、17 题，已浏览器验收）。现在按年份分给多个会话并行写，每个会话只负责一年。项目规范见根目录 `新威考研-资料/CLAUDE.md`（大题三层铁律等）。

## 任务

为数学一重读报真题套卷重制 **<年份> 年整卷**：文字题面＋逐步精解。工作目录 `11408相关/数学一/复盘中心/重读报/`。
先读：`README.md` 末节「套卷精解」、`_build/rich_build.py` 开头的语法、样板 `_build/rich/2021.txt`、全局卡 `_build/rich/kp.txt`、草图库 `_build/sk.py`、本年旧精研卡 `_build/deep/<年份>.txt`、`assets/exam/y<年份>.js`（题数、分值、选择题答案、归属第几期）。
每题：
1. `@stem`（选择题加 `@A`–`@D`）：把题面图 `assets/exam/img/<年份>/qNN.webp` 逐字转成文字＋LaTeX。用 PIL 放大读，上下标、积分限、分式、绝对值、矩阵逐个复核；题目带图的用 `::sk` 重画或表格。填空题写 `@ans`。
2. 解析素材：原书解析图 `assets/exam/img/<年份>/sNN.webp` ＋ 旧精研卡，在此基础上**加工**，不照抄、不省步。

**块与标记**（语法以 `_build/rich_build.py` 开头为准）：
- `::read` 每题必写：逐句「原句 >> 看到它想到什么 / 该画什么 / 这句话的固定含义 / 能排除什么」，用 `{{圈|}}`、`{{波|}}` 圈画。
- `::sk` 草图：凡是人在草稿纸上会画的都画（函数图像、积分区域、空间几何体/曲面、数轴与区间、概率密度/分布函数图、矩阵分块示意、极限的「抵消账本」等），画法看 `_build/sk.py` 与样板；坐标要算对，渲染后肉眼核对位置。
- `::think` 思路；`::fast` 秒杀/快法（选填必写：特值、排除、奇偶对称、几何意义、结论秒杀、选项代入，用 `{{秒|}}`）。
- `::steps` 每一步，**不许跳步**，读者要能看懂每个环节；考场上可省的步骤行首加 `~`（灰底），行内可省用 `{{省|}}`。
- `::paper` 考场卷面：解答题必写，照三层铁律——「解/证」开头、分问小标题、中间式编号、`⛳N` 采分点、用定理先点名、条件先验证、末行回扣题干；选填不写卷面
- `::note` 扣分点（`{{扣|}}`）、适用边界、提速心算、跨章联系。
- `::vary` 举一反三：每题 ≥3 条（重点题 ≥4 条），每条带答案（「变式 >> 答案」），要有真正改条件后的变化，不是换数字。
- `@tpl`：凡是能沉淀成跨年固定套路的都标上。先用 `kp.txt` 里已有的；没有就在本年文件顶部 `@tpl Txxx | 看到什么→先做什么` 新建（汇总时会提到全局）。定义、定理、公式、方法用 `[[id]]` 做弹窗，缺的在本年顶部 `@kp` 定义（写「是什么＋怎么用＋最小例子」）。
**正确性第一**：每题答案都要程序独立复算，写进 `_build/rich/chk/<年份>.py` 并跑通（sympy 符号或数值积分/求极限/解方程，概率题可蒙特卡洛）。复算与原解析冲突时，第一反应是自己转录错了，回去放大看原图/原文。
**验收**：`python3 _build/rich_build.py <年份>` 必须 ✓ 通过；然后把中心目录（不含 `_build`）rsync 到你自己的 scratchpad，写个 `serve.py` 监听 `127.0.0.1:<端口>`，在 `新威考研-资料/.claude/launch.json` 追加一条配置后用 `preview_start` 打开 `真题套卷.html#y=<年份>`，交卷（顶栏「交卷」→ 弹窗确认）后逐题抽查：无 `.katex-error`、草图位置对、宽 375 时 `scrollX` 为 0。
**约束**：只写 `_build/rich/<年份>.txt`、`_build/rich/chk/<年份>.py`（构建生成的 `assets/exam/rich/` 文件不用管）。**不要改** `engine.js`、`exam.css`、`rich_build.py`、`kp.txt`、`sk.py`、页面 HTML——别的会话正同时写别的年份；发现构建脚本 bug 或需要新语法，写进最终报告。**不要 git commit**，主会话最后统一提交。题量大，按题推进、随写随构建，别攒到最后。
**完成标准**：本年全部题都有文字题面和完整精解，构建通过、复算全过、浏览器抽查过；最终报告写：题数、草图数、新建的 @tpl/@kp 清单（id＋名字）、抓出的原解析错误、没把握的地方。
