#1
@stem
曲线 $y=\dfrac{x^2+x}{x^2-1}$ 的渐近线的条数为（　）.
@A $0$
@B $1$
@C $2$
@D $3$
@ans C
@tpl T渐近线三查
::rev
- **该花** 1 分钟。约分、看两个间断点、看无穷远，三眼的事。
- **卡点** 看到分母 $x^2-1$ 有两个零点就数出两条铅直渐近线，加上水平的选了 D。
- **错了说明** 「分母为 0 的点」和「函数趋于无穷的点」没分开：公因式约掉的点是可去间断点。
- **带走** 有理函数数渐近线：先约分，铅直只数约分后分母的零点；有水平就没有斜。
::read
「$y=\frac{x^2+x}{x^2-1}$」 >> 分子分母都能分解：$\frac{x(x+1)}{(x-1)(x+1)}$，{{圈|有公因式 $x+1$}} ⟹ $x=-1$ 处要单独看极限，不能直接算成铅直渐近线
「渐近线的条数」 >> 三类逐一查（[[T渐近线三查]]）；分子分母同次 ⟹ 有水平渐近线，同侧就不会再有斜渐近线
::fast
{{秒|约分后一眼}}：$y=\frac{x}{x-1}=1+\frac1{x-1}$（$x\ne-1$），就是反比例函数平移：一条铅直 $x=1$、一条水平 $y=1$，共 2 条。
::steps
分解并约分：$y=\dfrac{x(x+1)}{(x-1)(x+1)}=\dfrac{x}{x-1}$（$x\ne\pm1$）。
**铅直**：间断点只有 $x=1$ 和 $x=-1$。
  $x\to1$：$\frac{x}{x-1}\to\infty$ ⟹ $x=1$ 是铅直渐近线。
  $x\to-1$：$\frac{x}{x-1}\to\frac{-1}{-2}=\frac12$，是有限数 ⟹ $x=-1$ 是可去间断点，==不是==渐近线。
**水平**：$x\to\pm\infty$ 时 $\frac{x}{x-1}\to1$ ⟹ $y=1$ 是水平渐近线（两侧是同一条）。
**斜**：两侧都已有水平渐近线，$k=\lim\frac yx=0$ ⟹ 没有斜渐近线（[[渐近线]]）。
共 $1+1=2$ 条，选 **C**。
::note
- {{扣|把 $x=-1$ 也算进去}}：铅直渐近线的定义是 $\lim y=\infty$，不是「分母为 0」。
- 对照 2014 第 1 题（四条曲线里挑有渐近线的）、2023 第 1 题（求斜渐近线的截距）：那两题的坑在斜渐近线的 $b$，本题的坑在铅直。
::vary
$y=\dfrac{x^2+x}{x-1}$ 有几条渐近线 >> 不能约分；铅直 $x=1$；分子高一次 ⟹ 无水平、有斜 $y=x+2$（$\frac{x^2+x}{x-1}=x+2+\frac2{x-1}$）⟹ 2 条
$y=\dfrac{x^2+x}{x^2-1}e^{1/x}$ 有几条渐近线 >> 多一个间断点 $x=0$：$x\to0^+$ 时 $\frac{x}{x-1}e^{1/x}\to-\infty$（指数压过 $x$）⟹ $x=0$ 也是铅直；加上 $x=1$、$y=1$ 共 3 条

#2
@stem
设函数 $f(x)=(e^x-1)(e^{2x}-2)\cdots(e^{nx}-n)$，其中 $n$ 为正整数，则 $f'(0)=$（　）.
@A $(-1)^{n-1}(n-1)!$
@B $(-1)^n(n-1)!$
@C $(-1)^{n-1}n!$
@D $(-1)^nn!$
@ans A
@tpl T零因子求导
::rev
- **该花** 1 分钟。$n=2$ 代进去算一个数就能选。
- **卡点** 数符号：其余因子是 $(1-2)(1-3)\cdots(1-n)$，共 $n-1$ 个负数，不是 $n$ 个；多数一个就选 B。
- **错了说明** 没看出第一个因子在 0 处为 0，去硬套 $n$ 项乘积求导。
- **带走** 连乘求某点导数：先代点找零因子，答案 = 零因子的导数 × 其余因子的值。
::read
「$(e^x-1)(e^{2x}-2)\cdots(e^{nx}-n)$，求 $f'(0)$」 >> 代 $x=0$：第一个因子 $e^0-1=0$，{{圈|其余因子是 $1-k\ne0$}} ⟹ 只有「对第一个因子求导」那一项活下来（[[T零因子求导]]）
选项 >> 只差符号的幂次和 $(n-1)!$ 还是 $n!$ ⟹ 取 $n=2$ 就能分开
::fast
{{秒|取 $n=2$}}：$f=(e^x-1)(e^{2x}-2)$，$f'(0)=e^0\cdot(1-2)=-1$。四个选项在 $n=2$ 时依次是 $-1,\ 1,\ -2,\ 2$ ⟹ 选 A。
::steps
$f(0)=(1-1)(1-2)\cdots(1-n)=0$。
用[[导数定义]]：$f'(0)=\lim\limits_{x\to0}\dfrac{f(x)-f(0)}{x}=\lim\limits_{x\to0}\dfrac{e^x-1}{x}\cdot(e^{2x}-2)(e^{3x}-3)\cdots(e^{nx}-n)$。
  $\lim\limits_{x\to0}\frac{e^x-1}{x}=1$；其余因子连续，直接代 0：$(1-2)(1-3)\cdots(1-n)$。
$(1-2)(1-3)\cdots(1-n)=(-1)(-2)\cdots(-(n-1))$：共 $n-1$ 个因子，绝对值之积 $(n-1)!$ ⟹ $(-1)^{n-1}(n-1)!$。
$f'(0)=(-1)^{n-1}(n-1)!$，选 **A**。
~乘积法则的看法：$f'$ 是 $n$ 项之和，每项对一个因子求导；不对第一个因子求导的项都还带着 $e^x-1$，在 0 处为 0。
::note
- {{扣|因子个数数成 $n$}}：从 $k=2$ 到 $k=n$ 是 $n-1$ 个。拿 $n=2$ 验一下符号最稳。
- 这个结论不要求其余因子可导，只要连续——所以含 $|x|$ 的因子也照用。
::vary
$g(x)=(x-1)(x-2)\cdots(x-n)$，求 $g'(1)$ >> 零因子是 $x-1$：$g'(1)=(1-2)(1-3)\cdots(1-n)=(-1)^{n-1}(n-1)!$，与本题相同
$f(x)=x(x+1)(x+2)\cdots(x+n)$，求 $f'(0)$ >> $1\cdot2\cdots n=n!$（其余因子全正，没有符号问题）
$f(x)=(e^x-1)^2(e^{2x}-2)\cdots(e^{nx}-n)$，求 $f'(0)$、$f''(0)$ >> 零因子是二重的：$f\sim x^2\cdot c$，$c=(-1)^{n-1}(n-1)!$ ⟹ $f'(0)=0$，$f''(0)=2c$

#3
@stem
如果函数 $f(x,y)$ 在点 $(0,0)$ 处连续，那么下列命题正确的是（　）.
@A 若极限 $\lim\limits_{\substack{x\to0\\y\to0}}\dfrac{f(x,y)}{|x|+|y|}$ 存在，则 $f(x,y)$ 在点 $(0,0)$ 处可微
@B 若极限 $\lim\limits_{\substack{x\to0\\y\to0}}\dfrac{f(x,y)}{x^2+y^2}$ 存在，则 $f(x,y)$ 在点 $(0,0)$ 处可微
@C 若 $f(x,y)$ 在点 $(0,0)$ 处可微，则极限 $\lim\limits_{\substack{x\to0\\y\to0}}\dfrac{f(x,y)}{|x|+|y|}$ 存在
@D 若 $f(x,y)$ 在点 $(0,0)$ 处可微，则极限 $\lim\limits_{\substack{x\to0\\y\to0}}\dfrac{f(x,y)}{x^2+y^2}$ 存在
@ans B
@tpl T可微看阶, T举反例
::rev
- **该花** 2 分钟。$f=x$ 砸掉 C、D，$f=|x|+|y|$ 砸掉 A，剩 B。
- **卡点** 觉得 A 的分母「也趋于 0」所以和 B 一样；没注意 $|x|+|y|$ 只是一阶，$f$ 可以是尖顶。
- **错了说明** 可微定义里的 $o(\rho)$ 没有当成「比一阶小」来用。
- **带走** 「$\frac{f}{\rho^k}$ 极限存在」判可微只看 $k$：$k=2$ 可微，$k=1$ 不保证；反方向用 $f=x$ 否掉。
::read
「$\lim\frac{f(x,y)}{x^2+y^2}$ 存在」 >> 分母 → 0 ⟹ 分子 → 0，连续 ⟹ $f(0,0)=0$；且 $f$ 是 $\rho^2$ 级，{{圈|比 $\rho$ 高阶}} ⟹ 正好是可微定义里的 $o(\rho)$（[[T可微看阶]]、[[可微定义]]）
「$\frac{f}{|x|+|y|}$」 >> $|x|+|y|$ 与 $\rho$ 同阶，只能说 $f$ 是一阶量；$f=|x|+|y|$ 本身就满足，它在原点是尖的
「若可微，则极限存在」（C、D） >> 可微的函数太多了，{{波|拿 $f=x$ 试}}（[[T举反例]]）
::fast
{{秒|两个反例}}：$f=x$ 可微，但 $\frac{x}{|x|+|y|}$ 沿 $x$ 轴正、负方向分别趋于 $1,-1$，$\frac{x}{x^2+y^2}$ 沿 $x$ 轴趋于 $\infty$ ⟹ C、D 错。$f=|x|+|y|$ 使 A 的极限为 1，但 $f(x,0)=|x|$ 在 0 处不可导 ⟹ A 错。选 B。
::steps
**B 成立**。设 $\lim\dfrac{f(x,y)}{x^2+y^2}=A$。
  分母 → 0、极限存在 ⟹ $\lim f(x,y)=0$；$f$ 在 $(0,0)$ 连续 ⟹ $f(0,0)=0$。
  记 $\rho=\sqrt{x^2+y^2}$：$\dfrac{f(x,y)-f(0,0)-0\cdot x-0\cdot y}{\rho}=\dfrac{f(x,y)}{\rho^2}\cdot\rho\to A\cdot0=0$。
  这正是[[可微定义]]（取 $f_x(0,0)=f_y(0,0)=0$）⟹ $f$ 在 $(0,0)$ 可微。
**A 不成立**。取 $f=|x|+|y|$：连续，$\frac{f}{|x|+|y|}\equiv1$，极限存在；但 $\frac{f(x,0)-f(0,0)}{x}=\frac{|x|}{x}$ 无极限 ⟹ $f_x(0,0)$ 不存在 ⟹ 不可微。
**C 不成立**。取 $f=x$（可微）：沿 $y=0$，$\frac{x}{|x|}$ 在 $x\to0^+$ 为 1、$x\to0^-$ 为 $-1$ ⟹ 极限不存在。
**D 不成立**。取 $f=x$：沿 $y=0$，$\frac{x}{x^2}=\frac1x\to\infty$。
选 **B**。
::note
- {{扣|B 里漏掉「连续 ⟹ $f(0,0)=0$」}}：极限只管去心邻域（[[极限与函数值]]），$f(0,0)$ 的值是题干第一句「连续」给的。
- B 的结论其实更强：两个偏导都是 0，$(0,0)$ 是驻点。
::vary
把 B 的分母换成 $\sqrt{x^2+y^2}$，极限存在能推出可微吗 >> 不能：$f=\sqrt{x^2+y^2}$（圆锥）极限为 1，但在原点不可微。若极限值是 ==0== 就能推出可微
若 $\lim\frac{f(x,y)-2x+y}{x^2+y^2}$ 存在且 $f$ 连续，求 $df|_{(0,0)}$ >> $f(0,0)=0$，$f=2x-y+o(\rho)$ ⟹ $df=2dx-dy$
若 $\lim\frac{f(x,y)}{(x^2+y^2)^2}=1$，$(0,0)$ 是不是极值点 >> 由保号性，去心邻域内 $f\gt0=f(0,0)$ ⟹ 极小值点

#4
@stem
设 $I_k=\displaystyle\int_0^{k\pi}e^{x^2}\sin x\,dx\ (k=1,2,3)$，则有（　）.
@A $I_1\lt I_2\lt I_3$
@B $I_3\lt I_2\lt I_1$
@C $I_2\lt I_3\lt I_1$
@D $I_2\lt I_1\lt I_3$
@ans D
@tpl T拱形比大小
::rev
- **该花** 2 分钟。画三拱：正、负（更大）、正（再更大），顺序直接读出来。
- **卡点** 只看出 $I_2\lt I_1$、$I_2\lt I_3$，定不了 $I_1$ 与 $I_3$，在 C、D 里蒙。
- **错了说明** 不知道「隔一个比」要把后一拱平移到前一拱上去比。
- **带走** 上限不同的同一个积分比大小：作差只剩一段；两段符号相反时平移到同一区间比被积函数。
::read
「$I_k=\int_0^{k\pi}e^{x^2}\sin x\,dx$」 >> 被积函数相同、只是上限多出一拱 ⟹ {{圈|作差}}：$I_{k+1}-I_k$ 就是第 $k+1$ 拱上的积分，符号由 $\sin x$ 定（[[T拱形比大小]]）
「$e^{x^2}$」 >> 正的、递增得很快 ⟹ 每一拱都比前一拱「高」，后一拱的面积压过前一拱
::sk 380 190 画 | 先画 $\sin x$ 的三拱（正、负、正），再按 $e^{x^2}$ 越往右越高把每一拱拉长：第二拱（负）比第一拱大，第三拱（正）比第二拱大
import math
ox,oy=36,96;X=lambda x:ox+x*34;Y=lambda y:oy-y*46
s.axes(ox,oy,20,372,186,8,xl='x',yl='')
amp=[0.45,1.0,1.75]
for k in range(3):
    s.plot(lambda x,k=k:amp[k]*math.sin(x),k*math.pi+0.02,(k+1)*math.pi-0.02,X,Y,n=9,c='k')
s.text(X(math.pi),oy+14,'π',11,'k','middle');s.text(X(2*math.pi),oy-6,'2π',11,'k','middle');s.text(X(3*math.pi),oy+14,'3π',11,'k','middle')
s.text(X(1.57),Y(0.45)-6,'＋ 小',11,'b','middle');s.text(X(4.71),Y(-1.0)+16,'− 中',11,'r','middle');s.text(X(7.85),Y(1.75)-6,'＋ 大',11,'b','middle')
s.text(X(3.3),Y(1.55),'I₂ = 小 − 中 ＜ 0 ＜ I₁',11,'r','start')
::fast
{{秒|看图记账}}：记三拱的面积为 小、中、大（小＜中＜大）。$I_1=$ 小，$I_2=$ 小 − 中 ＜ 0，$I_3=$ 小 − 中 + 大 ＞ 小 ⟹ $I_2\lt I_1\lt I_3$，选 D。
::steps
**$I_2$ 与 $I_1$**：$I_2-I_1=\displaystyle\int_\pi^{2\pi}e^{x^2}\sin x\,dx$。在 $(\pi,2\pi)$ 上 $\sin x\lt0$、$e^{x^2}\gt0$ ⟹ 积分 $\lt0$ ⟹ $I_2\lt I_1$（[[定积分保序]]）。
**$I_3$ 与 $I_1$**：$I_3-I_1=\displaystyle\int_\pi^{2\pi}e^{x^2}\sin x\,dx+\int_{2\pi}^{3\pi}e^{x^2}\sin x\,dx$，一负一正，要比绝对值。
  第二个积分令 $x=t+\pi$（$t:\pi\to2\pi$），$\sin(t+\pi)=-\sin t$：$\displaystyle\int_{2\pi}^{3\pi}e^{x^2}\sin x\,dx=-\int_\pi^{2\pi}e^{(t+\pi)^2}\sin t\,dt$。
  合并到同一区间：$I_3-I_1=\displaystyle\int_\pi^{2\pi}\left[e^{x^2}-e^{(x+\pi)^2}\right]\sin x\,dx$。
  在 $(\pi,2\pi)$ 上：方括号 $\lt0$（$(x+\pi)^2\gt x^2$），$\sin x\lt0$ ⟹ 被积函数 $\gt0$ ⟹ $I_3\gt I_1$。
合起来 $I_2\lt I_1\lt I_3$，选 **D**。
::note
- {{扣|由「$I_3-I_2\gt0$」就断定 $I_3$ 最大}}：那只说明 $I_3\gt I_2$，$I_3$ 与 $I_1$ 必须单独比。
- 对照 2018 第 4 题、2022 第 4 题：那两题三个积分区间相同，只比被积函数；本题是区间不同、被积函数相同，要作差。
::vary
把 $e^{x^2}$ 换成 $e^{-x}$，比较 $I_1,I_2,I_3$ >> 递减 ⟹ 后一拱更小：$I_2=$ 大 − 中 ＞ 0，$I_3=$ 大 − 中 + 小 ⟹ $I_2\lt I_3\lt I_1$（原题的 C）
$I_k=\int_0^{k\pi}e^{x^2}\cos x\,dx$，比较 $I_1$ 与 $0$ >> $[0,\frac\pi2]$ 正、$[\frac\pi2,\pi]$ 负且权重更大 ⟹ $I_1\lt0$（把后半段用 $x=\pi-t$ 折回来比）

#5
@stem
设 $\alpha_1=\begin{pmatrix}0\\0\\c_1\end{pmatrix}$，$\alpha_2=\begin{pmatrix}0\\1\\c_2\end{pmatrix}$，$\alpha_3=\begin{pmatrix}1\\-1\\c_3\end{pmatrix}$，$\alpha_4=\begin{pmatrix}-1\\1\\c_4\end{pmatrix}$，其中 $c_1,c_2,c_3,c_4$ 为任意常数，则下列向量组线性相关的为（　）.
@A $\alpha_1,\alpha_2,\alpha_3$
@B $\alpha_1,\alpha_2,\alpha_4$
@C $\alpha_1,\alpha_3,\alpha_4$
@D $\alpha_2,\alpha_3,\alpha_4$
@ans C
@tpl T含参秩
::rev
- **该花** 1 分半。看前两个分量：$\alpha_3$ 与 $\alpha_4$ 正好相反，加起来只剩第三分量。
- **卡点** 四个三阶行列式挨个算，算错一个符号就选错。
- **错了说明** 没先观察「不含参数的那两行」。
- **带走** 3 个三维向量含任意常数判相关：行列式对任意常数恒为 0 才算；先看不含参数的行有没有成比例。
::read
「$c_1,c_2,c_3,c_4$ 为任意常数」 >> 要的是{{圈|对任何 $c$ 都相关}} ⟹ 3 个三维向量的行列式恒等于 0，结果里不能留下 $c$
「$\alpha_3=(1,-1,c_3)^T$，$\alpha_4=(-1,1,c_4)^T$」 >> 前两个分量正好相反 ⟹ $\alpha_3+\alpha_4=(0,0,c_3+c_4)^T$，和 $\alpha_1=(0,0,c_1)^T$ 同一个方向
::fast
{{秒|前两行}}：$\alpha_1,\alpha_3,\alpha_4$ 的前两个分量是 $(0,0),(1,-1),(-1,1)$，行列式前两行是 $(0,1,-1)$ 与 $(0,-1,1)$，成比例 ⟹ 行列式为 0，与 $c$ 无关，选 C。
::steps
3 个三维向量线性相关 ⟺ 以它们为列的行列式 $=0$。
**C**：$|\alpha_1,\alpha_3,\alpha_4|=\begin{vmatrix}0&1&-1\\0&-1&1\\c_1&c_3&c_4\end{vmatrix}$，第一行与第二行成比例（差一个负号）⟹ 行列式 $=0$，对任意 $c_1,c_3,c_4$ 成立 ⟹ 恒相关。
~其余三个按第一列（或含零多的列）展开（[[行列式展开]]）：
~  **A**：$\begin{vmatrix}0&0&1\\0&1&-1\\c_1&c_2&c_3\end{vmatrix}=-c_1$；**B**：$\begin{vmatrix}0&0&-1\\0&1&1\\c_1&c_2&c_4\end{vmatrix}=c_1$；**D**：$\begin{vmatrix}0&1&-1\\1&-1&1\\c_2&c_3&c_4\end{vmatrix}=-(c_3+c_4)$。
~  它们只在 $c_1=0$ 或 $c_3+c_4=0$ 时为 0，不是恒为 0。
选 **C**。
::note
- 原书方法一写「$\alpha_3+\alpha_4$ 与 $\alpha_1$ 成比例」，在 $c_1=0$、$c_3+c_4\ne0$ 时并不成比例（此时 $\alpha_1$ 是零向量，含零向量的组照样相关）。结论对，说法有小漏洞，用行列式说最干净。
- 对照 2015 第 5 题、2022 第 7 题：那两题是「参数取何值」要逐个回代；本题是「任意常数」，要的是恒成立。
::vary
若问「线性无关的充要条件」，A 组是什么 >> $|\alpha_1,\alpha_2,\alpha_3|=-c_1\ne0$ ⟺ $c_1\ne0$
$\alpha_1,\alpha_2,\alpha_3,\alpha_4$ 四个向量整体相关吗 >> 4 个三维向量必相关（个数大于维数），与 $c$ 无关

#6
@stem
设 $A$ 为 3 阶矩阵，$P$ 为 3 阶可逆矩阵，且 $P^{-1}AP=\begin{pmatrix}1&0&0\\0&1&0\\0&0&2\end{pmatrix}$. 若 $P=(\alpha_1,\alpha_2,\alpha_3)$，$Q=(\alpha_1+\alpha_2,\alpha_2,\alpha_3)$，则 $Q^{-1}AQ=$（　）.
@A $\begin{pmatrix}1&0&0\\0&2&0\\0&0&1\end{pmatrix}$
@B $\begin{pmatrix}1&0&0\\0&1&0\\0&0&2\end{pmatrix}$
@C $\begin{pmatrix}2&0&0\\0&1&0\\0&0&2\end{pmatrix}$
@D $\begin{pmatrix}2&0&0\\0&2&0\\0&0&1\end{pmatrix}$
@ans B
@tpl T构造P相似, T行左列右
::rev
- **该花** 1 分钟。$\alpha_1,\alpha_2$ 同属特征值 1，和还是属于 1，对角阵不变。
- **卡点** 以为「列变了对角阵就得变」，或把 $\alpha_1+\alpha_2$ 的特征值算成 $1+1=2$ 选 C。
- **错了说明** 没把 $P^{-1}AP=\Lambda$ 读成「$P$ 的第 $i$ 列是 $\lambda_i$ 的特征向量」。
- **带走** $P^{-1}AP=\Lambda$ 换列：新列仍是特征向量就照位置写特征值；同一特征值的特征向量相加还属于它。
::read
「$P^{-1}AP=\mathrm{diag}(1,1,2)$，$P=(\alpha_1,\alpha_2,\alpha_3)$」 >> 读成 $AP=P\Lambda$：{{圈|$A\alpha_1=\alpha_1$，$A\alpha_2=\alpha_2$，$A\alpha_3=2\alpha_3$}}（[[相似对角化]]）
「$Q=(\alpha_1+\alpha_2,\alpha_2,\alpha_3)$」 >> 第一列换成 $\alpha_1+\alpha_2$：两个都属于特征值 1 ⟹ 和仍属于 1；$Q$ 的三列对应特征值 $1,1,2$
::fast
{{秒|逐列读特征值}}：$A(\alpha_1+\alpha_2)=\alpha_1+\alpha_2$ ⟹ $Q$ 的三列依次属于 $1,1,2$ ⟹ $Q^{-1}AQ=\mathrm{diag}(1,1,2)$，选 B。
::steps
由 $P^{-1}AP=\Lambda=\mathrm{diag}(1,1,2)$ 得 $AP=P\Lambda$，按列写：$A\alpha_1=\alpha_1$，$A\alpha_2=\alpha_2$，$A\alpha_3=2\alpha_3$。
算 $AQ$ 的每一列（[[T构造P相似]]）：$A(\alpha_1+\alpha_2)=\alpha_1+\alpha_2$，$A\alpha_2=\alpha_2$，$A\alpha_3=2\alpha_3$。
  即 $AQ=(\alpha_1+\alpha_2,\ \alpha_2,\ 2\alpha_3)=Q\begin{pmatrix}1&0&0\\0&1&0\\0&0&2\end{pmatrix}$。
$Q$ 可逆：$Q=P\begin{pmatrix}1&0&0\\1&1&0\\0&0&1\end{pmatrix}$（第 2 列加到第 1 列，列变换右乘，[[T行左列右]]），右边两个矩阵都可逆。
两边左乘 $Q^{-1}$：$Q^{-1}AQ=\mathrm{diag}(1,1,2)$，选 **B**。
~硬算也行：记 $C=\begin{pmatrix}1&0&0\\1&1&0\\0&0&1\end{pmatrix}$，$Q^{-1}AQ=C^{-1}\Lambda C$；$\Lambda$ 左上 $2\times2$ 块是单位阵，与 $C$ 的左上块可交换 ⟹ 仍是 $\Lambda$。
::note
- {{扣|把「特征向量相加」当成「特征值相加」}}：$A(\alpha_1+\alpha_2)=1\cdot(\alpha_1+\alpha_2)$，特征值还是 1。
- 边界：不同特征值的特征向量相加（如 $\alpha_1+\alpha_3$）==不再是特征向量==，那时 $Q^{-1}AQ$ 不是对角阵。
- 对照 2020 第 21 题：同一招「写 $AQ=Q\cdot(\ast)$，不求逆」。
::vary
若 $Q=(\alpha_1+\alpha_3,\alpha_2,\alpha_3)$，求 $Q^{-1}AQ$ >> $A(\alpha_1+\alpha_3)=\alpha_1+2\alpha_3=(\alpha_1+\alpha_3)+\alpha_3$ ⟹ 第一列是 $(1,0,1)^T$：$\begin{pmatrix}1&0&0\\0&1&0\\1&0&2\end{pmatrix}$，不是对角阵
若 $Q=(\alpha_3,\alpha_1,2\alpha_2)$，求 $Q^{-1}AQ$ >> 换列序、乘非零倍数都还是特征向量：$\mathrm{diag}(2,1,1)$

- **错了说明** 没用常识校验：$Y$ 的均值只有 $\frac14$，比 $X$ 小得多，$X\lt Y$ 应该是小概率。
- **带走** 两个独立指数比大小：对较小的那个积分，另一个用尾概率 $e^{-\lambda y}$；答案用均值大小验方向。
::read
「参数为 1 与参数为 4 的指数分布」 >> 密度 $e^{-x}$、$4e^{-4y}$；均值 $1$ 与 $\frac14$ ⟹ {{圈|$Y$ 通常比 $X$ 小}}，$P\{X\lt Y\}$ 应小于 $\frac12$，C、D 先排除（[[指数分布]]）

::fast
{{秒|结论}}：$P\{X\lt Y\}=\dfrac{\lambda_X}{\lambda_X+\lambda_Y}=\dfrac{1}{1+4}=\dfrac15$。
::steps
$f_X(x)=e^{-x}\ (x\gt0)$，$f_Y(y)=4e^{-4y}\ (y\gt0)$；独立 ⟹ $f(x,y)=4e^{-x-4y}$（$x\gt0,y\gt0$），其余为 0（[[独立性]]）。
$P\{X\lt Y\}=\displaystyle\iint_{x\lt y}f(x,y)\,dxdy=\int_0^{+\infty}e^{-x}dx\int_x^{+\infty}4e^{-4y}dy$。
内层：$\displaystyle\int_x^{+\infty}4e^{-4y}dy=\left[-e^{-4y}\right]_x^{+\infty}=e^{-4x}$（就是 $P\{Y\gt x\}$）。
外层：$\displaystyle\int_0^{+\infty}e^{-x}\cdot e^{-4x}dx=\int_0^{+\infty}e^{-5x}dx=\frac15$。
选 **A**。
::note
- {{扣|积分区域写成 $y\lt x$}}：$X\lt Y$ 是直线 $y=x$ 的上方，固定 $x$ 时 $y$ 从 $x$ 到 $+\infty$。

::vary

- **错了说明** 没把「两段」翻译成一个等式 $X+Y=1$。

::read
「长度为 1 的木棒截成两段」 >> 设两段长 $X$、$Y$：{{圈|$X+Y=1$}}，即 $Y=-X+1$，严格线性、斜率为负（[[T线性关系相关系数]]）

$DY=D(1-X)=(-1)^2DX=DX$（[[方差性质]]）。

::vary

木棒截成三段，长度为 $X,Y,Z$，求 $\rho_{XY}$ >> $D(X+Y+Z)=0$ ⟹ $3D+6\,\mathrm{Cov}=0$ ⟹ $\mathrm{Cov}=-\frac D2$，$\rho=-\frac12$（原题的 C）
$Y=X^2$，$X\sim U(-1,1)$，求 $\rho_{XY}$ >> $E(XY)=EX^3=0$，$EX=0$ ⟹ $\rho=0$：完全由 $X$ 决定却不相关，相关系数只管线性

::rev
- **该花** 1 分半。解齐次方程两个根，代入第二个方程比系数。

- **带走** 一个函数满足两个方程：解齐次的那个得通解，代入另一个比较各指数的系数。

{{秒|猜特解再验}}：$f=e^x$ 代第二个方程：$e^x+e^x=2e^x$ ✓；代第一个：$e^x+e^x-2e^x=0$ ✓。两个都满足，填 $e^x$。
::steps
第一个方程是二阶常系数齐次方程，[[特征方程]] $r^2+r-2=0$，即 $(r-1)(r+2)=0$，$r_1=1$，$r_2=-2$。
通解 $f(x)=C_1e^x+C_2e^{-2x}$。
求导：$f''(x)=C_1e^x+4C_2e^{-2x}$。

比较 $e^x$ 与 $e^{-2x}$ 的系数（两者线性无关）：$2C_1=2$，$5C_2=0$ ⟹ $C_1=1$，$C_2=0$。
$f(x)=e^x$。

- {{扣|特征方程写成 $r^2+r+2=0$ 或根的符号弄反}}：$-2f$ 对应常数项 $-2$；写完把 $e^x$ 代回去验一次只要 5 秒。

::vary
$f''+f'-2f=0$ 且 $f'+f=2e^x$，求 $f$ >> 代通解：$2C_1e^x-C_2e^{-2x}=2e^x$ ⟹ $f=e^x$（同样定死）

@tpl T曲面代入
::rev

- **卡点** 漏掉 $\sqrt3$ 填 $\frac1{12}$；或二重积分先对 $y$ 积，多算一步还容易错。

::read

$z_x=-1$，$z_y=-1$ ⟹ $dS=\sqrt{1+z_x^2+z_y^2}\,dxdy=\sqrt3\,dxdy$。
$\displaystyle\iint_\Sigma y^2dS=\sqrt3\iint_Dy^2\,dxdy$。
先对 $x$ 积（$y$ 固定，$x$ 从 0 到 $1-y$）：$\displaystyle\sqrt3\int_0^1y^2dy\int_0^{1-y}dx=\sqrt3\int_0^1y^2(1-y)\,dy$。
$\displaystyle\int_0^1(y^2-y^3)dy=\frac13-\frac14=\frac1{12}$。
原式 $=\dfrac{\sqrt3}{12}$。
~验算（[[轮换对称]]）：$\iint_\Sigma x^2dS=\iint_\Sigma y^2dS=\iint_\Sigma z^2dS$；$\Sigma$ 的面积 $=\sqrt3\cdot\frac12=\frac{\sqrt3}2$，三角形上 $y^2$ 的平均值 $\frac16$ ⟹ $\frac{\sqrt3}2\cdot\frac16=\frac{\sqrt3}{12}$ ✓。
::note
- {{扣|漏 $\sqrt3$}}：$dS$ 是斜面上的面积，投影到 $xOy$ 面会缩小 $\cos\gamma=\frac1{\sqrt3}$ 倍，所以要乘回 $\sqrt3$。
- 对照 2018 第 12 题一类「球面与平面交线」的轮换对称题：那里对称性用来化简被积函数；本题对称性只用来验算。
::vary
同一个 $\Sigma$，求 $\iint_\Sigma(x+y+z)^2dS$ >> 在 $\Sigma$ 上 $x+y+z=1$（[[T曲面代入]]）⟹ 就是面积 $\frac{\sqrt3}2$
同一个 $\Sigma$，求 $\iint_\Sigma xy\,dS$ >> $\sqrt3\int_0^1y\,dy\int_0^{1-y}x\,dx=\frac{\sqrt3}2\int_0^1y(1-y)^2dy=\frac{\sqrt3}{24}$

（本题满分 10 分）求幂级数 $\displaystyle\sum_{n=0}^{\infty}\frac{4n^2+4n+3}{2n+1}x^{2n}$ 的收敛域及和函数.
@tpl T求导积分两型, T凑已知展开
::rev
- **该花** 10 分钟。收敛域 2 分钟，拆项 1 分钟，两个级数各 3 分钟。
- **卡点** 不拆项，对整个系数硬凑；或第二个级数除以 $x$ 之后忘了 $x=0$，和函数少一行。
- **错了说明** 「分子次数高于分母先做除法」没想到；和函数在特殊点要单独写没成习惯。
- **带走** 系数是 $n$ 的假分式：先除成「整式 + 真分式」，整式部分先积后导，真分式部分先导后积，$x=0$ 单列。
::read
「$\frac{4n^2+4n+3}{2n+1}$」 >> 分子二次、分母一次 ⟹ {{圈|先做除法}}：$4n^2+4n+3=(2n+1)^2+2$ ⟹ 系数 $=(2n+1)+\frac{2}{2n+1}$（[[T求导积分两型]]）
「$x^{2n}$」 >> 只有偶次幂（缺项）⟹ 求收敛半径用比值法直接对通项做，别套 $\lim\left|\frac{a_n}{a_{n+1}}\right|$；配 $(2n+1)$ 正好是 $x^{2n+1}$ 的导数
「收敛域及和函数」 >> 两问：端点要单独判；和函数最后要写清定义域，$x=0$ 处单独给值
::steps
**收敛域**。记 $u_n(x)=\dfrac{4n^2+4n+3}{2n+1}x^{2n}$。$x\ne0$ 时
$$\lim_{n\to\infty}\left|\frac{u_{n+1}(x)}{u_n(x)}\right|=\lim_{n\to\infty}\frac{4(n+1)^2+4(n+1)+3}{4n^2+4n+3}\cdot\frac{2n+1}{2n+3}\cdot x^2=x^2.$$
  $x^2\lt1$ 时收敛，$x^2\gt1$ 时发散 ⟹ 收敛半径 $R=1$（[[幂级数收敛域]]）。
  端点 $x=\pm1$：通项 $\dfrac{4n^2+4n+3}{2n+1}\to\infty\ne0$ ⟹ 发散（[[级数必要条件]]）。收敛域 $(-1,1)$。
**拆项**。$\dfrac{4n^2+4n+3}{2n+1}=\dfrac{(2n+1)^2+2}{2n+1}=(2n+1)+\dfrac{2}{2n+1}$。
  $S(x)=\underbrace{\sum_{n=0}^\infty(2n+1)x^{2n}}_{S_1(x)}+\underbrace{\sum_{n=0}^\infty\frac{2}{2n+1}x^{2n}}_{S_2(x)}$，$|x|\lt1$（两个级数的收敛半径都是 1）。
**$S_1$（先积后导）**。$(2n+1)x^{2n}=\left(x^{2n+1}\right)'$，在 $(-1,1)$ 内逐项求导：
$$S_1(x)=\left(\sum_{n=0}^\infty x^{2n+1}\right)'=\left(\frac{x}{1-x^2}\right)'=\frac{(1-x^2)+2x^2}{(1-x^2)^2}=\frac{1+x^2}{(1-x^2)^2}.$$
  其中 $\sum x^{2n+1}=x\sum(x^2)^n=\frac{x}{1-x^2}$（[[几何级数]]，公比 $x^2$）。
**$S_2$（先导后积）**。$x\ne0$ 时 $S_2(x)=\dfrac2x\displaystyle\sum_{n=0}^\infty\frac{x^{2n+1}}{2n+1}$。记 $T(x)=\displaystyle\sum_{n=0}^\infty\frac{x^{2n+1}}{2n+1}$，$T(0)=0$：
  $T'(x)=\displaystyle\sum_{n=0}^\infty x^{2n}=\frac1{1-x^2}$ ⟹ $T(x)=\displaystyle\int_0^x\frac{dt}{1-t^2}=\frac12\ln\frac{1+x}{1-x}$。

@tpl T正态线性组合, T最大似然

::steps
**(I)** $X,Y$ 独立且都服从正态分布 ⟹ $Z=X-Y$ 服从正态分布（[[正态分布]]）。
  $EZ=EX-EY=\mu-\mu=0$；$DZ=DX+(-1)^2DY=\sigma^2+2\sigma^2=3\sigma^2$。
  $Z\sim N(0,3\sigma^2)$。正态密度 $\frac1{\sqrt{2\pi}s}e^{-\frac{(z-m)^2}{2s^2}}$ 中代 $m=0$、$s^2=3\sigma^2$：
$$f(z;\sigma^2)=\frac{1}{\sqrt{2\pi}\cdot\sqrt3\sigma}e^{-\frac{z^2}{2\cdot3\sigma^2}}=\frac1{\sqrt{6\pi}\,\sigma}e^{-\frac{z^2}{6\sigma^2}},\quad-\infty\lt z\lt+\infty.$$

$$L(\theta)=\prod_{i=1}^nf(z_i;\theta)=(6\pi\theta)^{-\frac n2}\exp\left(-\frac{1}{6\theta}\sum_{i=1}^nz_i^2\right).$$

**(III)** $E(Z_i^2)=DZ_i+(EZ_i)^2=3\sigma^2+0=3\sigma^2$。
  $E\widehat{\sigma^2}=\dfrac1{3n}\displaystyle\sum_{i=1}^nE(Z_i^2)=\dfrac1{3n}\cdot n\cdot3\sigma^2=\sigma^2$ ⟹ 无偏。

解　(I) 因 $X$ 与 $Y$ 相互独立且均服从正态分布，故 $Z=X-Y$ 服从正态分布，且
$$EZ=EX-EY=0,\qquad DZ=DX+DY=3\sigma^2,$$ ⛳2
即 $Z\sim N(0,3\sigma^2)$，所以 $f(z;\sigma^2)=\dfrac{1}{\sqrt{6\pi}\,\sigma}e^{-\frac{z^2}{6\sigma^2}}\ (-\infty\lt z\lt+\infty)$. ⛳1
(II) 设 $z_1,z_2,\cdots,z_n$ 为样本观测值，似然函数为
$$L(\sigma^2)=\prod_{i=1}^nf(z_i;\sigma^2)=(6\pi\sigma^2)^{-\frac n2}e^{-\frac{1}{6\sigma^2}\sum\limits_{i=1}^nz_i^2},\qquad(1)$$ ⛳2
$$\ln L(\sigma^2)=-\frac n2\ln(6\pi)-\frac n2\ln\sigma^2-\frac1{6\sigma^2}\sum_{i=1}^nz_i^2.$$ ⛳1
令 $\dfrac{d\ln L(\sigma^2)}{d(\sigma^2)}=-\dfrac{n}{2\sigma^2}+\dfrac{1}{6(\sigma^2)^2}\displaystyle\sum_{i=1}^nz_i^2=0$，解得 $\sigma^2=\dfrac{1}{3n}\displaystyle\sum_{i=1}^nz_i^2$，
故 $\sigma^2$ 的最大似然估计量为 $\widehat{\sigma^2}=\dfrac1{3n}\displaystyle\sum_{i=1}^nZ_i^2$. ⛳3
(III) 因 $E(Z_i^2)=DZ_i+(EZ_i)^2=3\sigma^2\ (i=1,2,\cdots,n)$，故
$$E\left(\widehat{\sigma^2}\right)=\frac1{3n}\sum_{i=1}^nE(Z_i^2)=\frac1{3n}\cdot3n\sigma^2=\sigma^2,$$
所以 $\widehat{\sigma^2}$ 为 $\sigma^2$ 的无偏估计量. 证毕. ⛳2
