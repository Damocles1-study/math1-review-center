设函数 $f(x)$ 在 $(-\infty,+\infty)$ 上连续，其 2 阶导函数 $f''(x)$ 的图形如右图所示，则曲线 $y=f(x)$ 的拐点个数为（　）.
（图：$y$ 轴左侧是一段开口向上、在某点 $x=x_1\lt0$ 处与 $x$ 轴相切的曲线，向右一直在 $x$ 轴上方；$y$ 轴右侧的曲线从 $x$ 轴下方很低处升起，在某点 $x=x_2\gt0$ 处穿过 $x$ 轴后保持在上方；$x=0$ 处 $f''$ 无定义。见下方第一张草图，原图在「看原卷题面」。）
@A 0
@B 1
@C 2
@D 3
@ans C
@tpl T凹凸拐点表
::read
「$f(x)$ 在 $(-\infty,+\infty)$ 上连续」 >> {{圈|连续}} 是拐点的前提：凹凸分界点要在曲线上；$f''$ 不存在的点也可能是拐点（[[凹凸性]]）
「$f''(x)$ 的图形」 >> 给的是二阶导，不是 $f$ ⟹ 拐点只看一件事：{{波|$f''$ 在哪儿变号}}（[[T凹凸拐点表]]）
「左侧曲线与 $x$ 轴相切」 >> 切点处 $f''=0$，但两侧都 $\ge0$，{{圈|不变号}} ⟹ 不是拐点
「$x=0$ 处 $f''$ 无定义」 >> 候选点：左边 $f''\gt0$、右边贴近 0 处 $f''\lt0$ ⟹ 变号，且 $f$ 在 0 连续 ⟹ 是拐点
「右侧穿过 $x$ 轴」 >> $x_2$ 处由负变正 ⟹ 拐点
「选项 0～3」 >> 候选点一共 3 个（$x_1$、$0$、$x_2$），命题人押的错误就是 D：把相切点也算上

::think
1. 拐点 = 连续曲线上凹凸改变的点 ⟹ 找 $f''=0$ 或 $f''$ 不存在的点，再看两侧是否变号。
2. 从图上读：$f''=0$ 的点有 $x_1$（相切）、$x_2$（穿过）；$f''$ 不存在的点有 $x=0$。
3. 逐个判变号：$x_1$ 两侧都正 ✗；$0$ 左正右负 ✓；$x_2$ 左负右正 ✓ ⟹ 2 个，选 C。
::fast
{{秒|数「$f''$ 的图像穿过 $x$ 轴或在断开处换边」的次数}}：0 处从上方跳到下方算一次，$x_2$ 处穿过算一次，相切点不算 ⟹ 2，选 C。
::steps
拐点的必要条件：$f''(x_0)=0$ 或 $f''(x_0)$ 不存在；充分条件：$f$ 在 $x_0$ 连续，且 $f''$ 在 $x_0$ 两侧异号（[[凹凸性]]）。
从图上找全部候选点：$f''$ 与 $x$ 轴的交点 $x_1\lt0$、$x_2\gt0$，以及 $f''$ 无定义的 $x=0$，共 3 个。
$x=x_1$：曲线在此与 $x$ 轴相切，左右两侧 $f''\gt0$，曲线两侧都是凹的，不变号 ⟹ $(x_1,f(x_1))$ **不是**拐点。
$x=0$：左侧（$x_1\lt x\lt0$）$f''\gt0$，右侧（$0\lt x\lt x_2$）$f''\lt0$，两侧异号；题设 $f$ 在 $(-\infty,+\infty)$ 上连续，在 0 处连续 ⟹ $(0,f(0))$ **是**拐点。
  $f''(0)$ 不存在并不妨碍：拐点要求的是 $f$ 连续 + 凹凸改变，不要求 $f''$ 存在。
$x=x_2$：左侧 $f''\lt0$，右侧 $f''\gt0$，异号 ⟹ $(x_2,f(x_2))$ **是**拐点。
共 2 个拐点，选 **C**。
::note
- {{扣|把相切点 $x_1$ 也算成拐点选 D}}：$f''=0$ 只是必要条件，切点处 $f''$ 不变号，曲线在 $x_1$ 两边都向上弯。$x_1$ 其实是 $f'$ 的「驻点但非极值点」：$f'$ 在那儿单调增、只是瞬间停一下。
- {{扣|$f''$ 不存在就跳过 $x=0$ 选 B}}：二阶导不存在的点照样能是拐点，最经典的是 $y=\sqrt[3]{x}$ 在原点。
- 同一张图换个问法：问 $f'$ 的极值点个数——看 $f''$（即 $(f')'$）变号的点，答案也是 2，只是这时 0 点要求 $f'$ 在 0 处连续（$f$ 可导）。
- 若题设去掉「$f$ 连续」：$x=0$ 处 $f$ 可能断开，就不能算拐点了——所以第一句话不是废话。
::vary
同一张图问 $f(x)$ 的极值点个数（假设 $f'$ 的图像未给出） >> 判断不了：极值点看 $f'$ 变号，只给 $f''$ 不知道 $f'$ 的零点在哪
若左侧那段改成在 $x_1$ 处穿过 $x$ 轴（左负右正），其余不变，拐点个数 >> 3：$x_1$ 也变号了，加上 $0$ 与 $x_2$
曲线 $y=(x-1)^2(x-3)^3$ 的拐点个数 >> $y''=4(x-3)(5x^2-18x+15)$，三个单根 $3$、$\frac{9\pm\sqrt6}{5}$ 处都变号 ⟹ 3 个拐点
$y=x^{1/3}$ 在原点是拐点吗 >> 是：$y''=-\frac29x^{-5/3}$ 在 0 不存在且两侧异号，曲线连续

@stem
设 $y=\dfrac12e^{2x}+\left(x-\dfrac13\right)e^x$ 是二阶常系数非齐次线性微分方程 $y''+ay'+by=ce^x$ 的一个特解，则（　）.
@A $a=-3,\ b=2,\ c=-1$
@B $a=3,\ b=2,\ c=-1$
@C $a=-3,\ b=2,\ c=1$
@D $a=3,\ b=2,\ c=1$
@ans A
@tpl T特解认根
::read
「$y''+ay'+by=ce^x$」 >> 右端只有 $e^x$ ⟹ 特解里 {{圈|$\frac12e^{2x}$}} 这一项右端根本造不出来 ⟹ 它是齐次解 ⟹ $2$ 是特征根（[[T特解认根]]）
「$\left(x-\frac13\right)e^x=xe^x-\frac13e^x$」 >> 拆开：$-\frac13e^x$ 也是「纯 $e^x$」形式；$xe^x$ 带了个 $x$ ⟹ {{波|共振}}：$1$ 是特征单根，非齐次特解是 $xe^x$ 的倍数
「一个特解」 >> 特解 = 齐次解 + 非齐次特解，齐次部分的系数 $\frac12$、$-\frac13$ 无所谓，任何常数都行
「选项里 $a$ 正负、$c$ 正负」 >> $b=2$ 全都一样；先由根定 $a$（两根之和取负），再由 $xe^x$ 定 $c$ 的符号
::sk 380 120 | 把特解拆账：哪一项来自齐次解、哪一项是非齐次的
s.cells(14,14,[['特解里的项','它是谁','给出什么'],['½e^{2x}','齐次解','!r=2 是特征根'],['−⅓eˣ','齐次解','!r=1 是特征根'],['x eˣ','非齐次特解','!代入定 c']],cw=[110,100,130],ch=22,size=11)
s.text(14,114,'两根 1、2 ⟹ (r−1)(r−2)=r²−3r+2 ⟹ a=−3, b=2',11,'r')
::think
1. $\frac12e^{2x}$、$-\frac13e^x$ 都是齐次方程的解 ⟹ 特征根 $r_1=1$、$r_2=2$。
2. 特征方程 $(r-1)(r-2)=r^2-3r+2=0$ ⟹ $a=-3$，$b=2$。
3. $y^*=xe^x$ 是 $y''-3y'+2y=ce^x$ 的解：代入得 $c=-1$ ⟹ A。
::fast
{{秒|只算 $c$}}：$a=-3,b=2$ 后，令 $y^*=xe^x$，$y^{*\prime}=(x+1)e^x$，$y^{*\prime\prime}=(x+2)e^x$，代入 $(x+2)-3(x+1)+2x=-1$ ⟹ $c=-1$。A、C 中只有 A 的 $c=-1$。
另一个口诀：$f=ce^{\lambda x}$、$\lambda$ 是单根时，特解 $Axe^{\lambda x}$ 的系数 $A=\frac{c}{2\lambda+a}$；这里 $A=1$、$2\cdot1-3=-1$ ⟹ $c=-1$。
::steps
把特解拆开：$y=\frac12e^{2x}-\frac13e^x+xe^x$。
右端 $ce^x$ 不含 $e^{2x}$，所以 $\frac12e^{2x}$ 只能来自齐次通解 ⟹ $e^{2x}$ 是齐次方程 $y''+ay'+by=0$ 的解 ⟹ $r=2$ 是特征根（[[特征方程]]）。
$xe^x$ 出现在特解里，说明右端 $e^x$ 与齐次解「撞车」⟹ $r=1$ 是特征根（且是单根，否则会是 $x^2e^x$）。
  同时 $-\frac13e^x$ 是 $1$ 为特征根带来的齐次部分，与这个判断一致。
两个特征根 1、2 ⟹ 特征方程 $(r-1)(r-2)=r^2-3r+2=0$，对照 $r^2+ar+b=0$：$a=-3$，$b=2$。
剩下的非齐次特解 $y^*=xe^x$ 满足 $y''-3y'+2y=ce^x$：
$y^{*\prime}=e^x+xe^x=(x+1)e^x$，$y^{*\prime\prime}=e^x+(x+1)e^x=(x+2)e^x$。
代入：$(x+2)e^x-3(x+1)e^x+2xe^x=(x+2-3x-3+2x)e^x=-e^x$ ⟹ $c=-1$。
所以 $a=-3,\ b=2,\ c=-1$，选 **A**。
~验算：把整个 $y$ 代进去也行，齐次部分代入得 0，只剩 $xe^x$ 那块给出 $-e^x$ ✓。
::note
- {{扣|把 $\left(x-\frac13\right)e^x$ 整块当成非齐次特解去代}}：能做出来（齐次部分代入为 0 不影响），但会误以为 $-\frac13$ 必须由 $c$ 决定，算到一半自相矛盾。先拆开再认。
- 为什么 $1$ 一定是**单**根：若 1 是二重根，特征方程是 $(r-1)^2$，就不可能再有根 2；且特解会是 $x^2e^x$ 型。
- 选项设计：B、D 的 $a=3$ 对应根 $-1,-2$（把两根之和的符号弄反）；C 是 $c$ 符号错。
- 跨章：同类「给解反推方程」见 2016 第 3 题（一阶线性两解作差，[[T两解反推方程]]）。
::vary
特解改为 $y=e^{2x}+xe^{-x}$，方程 $y''+ay'+by=ce^{-x}$，求 $a,b,c$ >> 根 $2,-1$：$(r-2)(r+1)=r^2-r-2$ ⟹ $a=-1,b=-2$；$y^*=xe^{-x}$，$y^{*\prime}=(1-x)e^{-x}$，$y^{*\prime\prime}=(x-2)e^{-x}$，代入 $(x-2)-(1-x)-2x=-3$ ⟹ $c=-3$
若题目改成「$y=\frac12e^{2x}+x^2e^x$ 是 $y''+ay'+by=ce^x$ 的特解」，还能成立吗 >> 不能：$x^2e^x$ 要求 1 是二重根，但 $e^{2x}$ 又要求 2 是根，三阶才行，二阶方程矛盾
本题方程的通解 >> $y=C_1e^x+C_2e^{2x}+xe^x$
$y''-3y'+2y=e^{x}$ 的特解系数 >> $y^*=Axe^x$，$A=\frac{1}{2\cdot1-3}=-1$ ⟹ $y^*=-xe^x$

@stem
若级数 $\displaystyle\sum_{n=1}^\infty a_n$ 条件收敛，则 $x=\sqrt3$ 与 $x=3$ 依次为幂级数 $\displaystyle\sum_{n=1}^\infty na_n(x-1)^n$ 的（　）.
@A 收敛点，收敛点
@B 收敛点，发散点
@C 发散点，收敛点
@D 发散点，发散点
@ans B
@tpl T条件收敛定半径
::read
「$\sum a_n$ 条件收敛」 >> 看成幂级数 $\sum a_nt^n$ 在 $t=1$ 处条件收敛 ⟹ {{圈|$t=1$ 恰是端点}} ⟹ 收敛半径 $R=1$（[[T条件收敛定半径]]）
「$\sum na_n(x-1)^n$」 >> 系数多乘 $n$、中心平移到 1：{{波|都不改收敛半径}} ⟹ 仍是 $R=1$，收敛区间 $(0,2)$
「$x=\sqrt3$」 >> $|\sqrt3-1|\approx0.73\lt1$ ⟹ 在区间内部 ⟹ 绝对收敛
「$x=3$」 >> $|3-1|=2\gt1$ ⟹ 在区间外 ⟹ 发散
::sk 380 110 | 数轴：$\sum na_n(x-1)^n$ 以 1 为中心、半径 1，收敛区间 $(0,2)$；$\sqrt3\approx1.73$ 在里面，3 在外面

1. $\sum a_n$ 条件收敛 ⟹ $\sum a_nt^n$ 在 $t=1$ 收敛、但不绝对收敛 ⟹ $t=1$ 不在收敛区间内部、也不在外部 ⟹ $R=1$。
2. $\sum na_nt^n$ 是逐项求导再乘 $t$，半径不变，$R=1$；令 $t=x-1$，收敛区间 $|x-1|\lt1$ 即 $(0,2)$。
3. $\sqrt3\in(0,2)$ 收敛；$3\notin[0,2]$ 发散 ⟹ B。
::fast
{{秒|条件收敛 ⟹ 端点 ⟹ $R=1$；乘 $n$ 不改半径}}，只看 $|x-1|$ 与 1 的大小：$\sqrt3-1\lt1$，$3-1\gt1$ ⟹ B。
::steps
考虑幂级数 $\sum_{n=1}^\infty a_nt^n$。由题设，它在 $t=1$ 处收敛 ⟹ 由[[阿贝尔定理]]，收敛半径 $R\ge1$。
又它在 $t=1$ 处**不**绝对收敛；若 $R\gt1$，则 $t=1$ 在收敛区间内部，内部必绝对收敛，矛盾 ⟹ $R\le1$。故 $R=1$。
$\sum na_nt^n=t\sum na_nt^{n-1}=t\left(\sum a_nt^n\right)'$：逐项求导不改变收敛半径，乘 $t$ 也不改变 ⟹ $\sum na_nt^n$ 的收敛半径也是 1（[[幂级数收敛域]]）。
  也可以直接用比值：$\lim\left|\frac{(n+1)a_{n+1}}{na_n}\right|=\lim\left|\frac{a_{n+1}}{a_n}\right|$（若后者存在），乘 $n$ 不改变极限。
令 $t=x-1$：$\sum na_n(x-1)^n$ 在 $|x-1|\lt1$ 即 $0\lt x\lt2$ 时绝对收敛，在 $|x-1|\gt1$ 时发散。
$x=\sqrt3$：$|\sqrt3-1|=\sqrt3-1\approx0.732\lt1$ ⟹ 收敛点。
$x=3$：$|3-1|=2\gt1$ ⟹ 发散点。选 **B**。
::note
- {{扣|以为乘 $n$ 会把收敛半径变小}}：乘 $n$、除 $n$、乘 $n^k$ 都不改半径（$\sqrt[n]{n}\to1$），只改端点。
- {{扣|把「条件收敛」读成「收敛」，只得到 $R\ge1$}}：那样 $x=3$ 就判不了。「条件」两个字恰好把 $R$ 卡死在 1。
- 端点 $x=0,2$ 本题判不了：$x=2$ 处是 $\sum na_n$，一般发散（如 $a_n=\frac{(-1)^n}{n}$ 时 $\sum(-1)^n$ 发散）；不考，别多想。
- 跨章：同一思路的「在 $x_0$ 处收敛、在 $x_1$ 处发散 ⟹ 夹出 $R$」见[[阿贝尔定理]]的逆否形式。
::vary
若 $\sum a_n$ 绝对收敛，能确定 $\sum na_n(x-1)^n$ 的收敛半径吗 >> 不能：只知 $R\ge1$，如 $a_n=\frac1{n^2}$ 时 $R=1$，$a_n=\frac1{n!}$ 时 $R=\infty$
若 $\sum a_n(x+1)^n$ 在 $x=1$ 处条件收敛，求 $\sum a_nx^n$ 的收敛半径 >> $t=x+1=2$ 是端点 ⟹ $R=2$
若 $\sum a_nx^n$ 在 $x=-2$ 处条件收敛，问 $\sum\frac{a_n}{n}x^n$ 在 $x=3$ 处 >> $R=2$，除以 $n$ 不改半径，$|3|\gt2$ ⟹ 发散
已知 $\sum a_n$ 条件收敛，$\sum a_n(x-1)^n$ 在 $x=2$ 处 >> 条件收敛（就是 $\sum a_n$ 本身）

$$\frac12|f(x_0)|\cdot|x_0-X_0|=\frac{f^2(x_0)}{2f'(x_0)}=4,$$
由 $x_0$ 的任意性，$y=f(x)$ 满足 ⛳3
$$y'=\frac{y^2}{8},\qquad y(0)=2.\qquad(2)$$

由 $y(0)=2$ 得 $C=-\dfrac12$，故
$$f(x)=\frac{8}{4-x},\qquad x\in I\ \left(I\subset(-\infty,4)\right).$$ ⛳3
