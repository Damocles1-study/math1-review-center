#1
@stem
曲线 $y=x\ln\left(e+\dfrac{1}{x-1}\right)$ 的斜渐近线方程为（　）.
@A $y=x+e$
@B $y=x+\dfrac1e$
@C $y=x$
@D $y=x-\dfrac1e$
@ans B
@tpl T渐近线三查, T极限
::rev
- **该花** 1 分半。$k=1$ 一眼出，只算 $b=\lim x\left[\ln\left(e+\frac1{x-1}\right)-1\right]$。
- **卡点** 没先提出 $e$，把 $\ln(e+u)$ 直接当 $u$，得 $b=1$（无此选项）或错选 A。
- **错了说明** $\ln(e+u)=1+\ln\left(1+\frac ue\right)\sim1+\frac ue$ 这一步拆不出来。
- **带走** $\ln(a+\text{小量})$ 先提出 $a$：$\ln a+\ln\left(1+\frac{\text{小量}}a\right)$，再用等价。
::read
「斜渐近线」 >> [[渐近线]]的固定两步：$k=\lim\frac yx$，$b=\lim(y-kx)$。四个选项斜率都是 1 ⟹ {{圈|只差 $b$}}，题目真正考的是第二个极限
「$x\ln(\cdots)$」 >> $\frac yx=\ln\left(e+\frac1{x-1}\right)\to\ln e=1$，$k=1$ 一眼出
「$\ln\left(e+\frac1{x-1}\right)$」 >> 要和 $x$ 相减，先把 $e$ 提出来：$\ln e+\ln\left(1+\frac{1}{e(x-1)}\right)=1+\ln(1+\square)$，这样才能用 $\ln(1+u)\sim u$
「没说 $x\to+\infty$ 还是 $-\infty$」 >> 两侧都要看；这里两侧结果相同（{{波|$\frac{x}{x-1}\to1$ 不分正负}}）
::sk 340 205 看 | 两支曲线：右支从 $x=1$ 的铅直渐近线上冲下来，往右贴着 $y=x+\frac1e$；左支从左下贴着同一条直线，在 $x=1-\frac1e$ 处掉下去
ox,oy=125,125;X=lambda x:ox+x*36;Y=lambda y:oy-y*22
F=lambda u:u*math.log(math.e+1/(u-1))
s.axes(ox,oy,10,332,200,10)
s.line(X(-3),Y(-3+1/math.e),X(4.6),Y(4.6+1/math.e),'r',1.1,dash='5 4')
s.line(X(1),Y(5.1),X(1),Y(-3.2),'g',1,dash='3 3')
s.line(X(1-1/math.e),Y(1.2),X(1-1/math.e),Y(-3.2),'g',1,dash='3 3')
s.curve([(X(u),Y(F(u))) for u in (1.02,1.05,1.12,1.3,1.7,2.4,3.3,4.5)])
s.curve([(X(u),Y(F(u))) for u in (-3,-2,-1,0,0.35,0.5,0.58,0.615,0.626,0.629)])
s.text(X(3.1),Y(2.6),'y = x + 1/e',12,'r')
s.text(X(1)+4,Y(-2.6),'x=1',11,'g')
s.text(X(1-1/math.e)-6,Y(-2.9),'x=1−1/e',11,'g','end')
s.text(X(1.25),Y(5.0),'x→1⁺ 冲上天',11)
::fast
{{秒|$x$ 很大时 $\frac{1}{x-1}\approx\frac1x$，$\ln\left(e+\frac1x\right)\approx1+\frac{1}{ex}$}}，乘 $x$ 得 $x+\frac1e$ ⟹ B。
（$\ln(e+h)\approx\ln e+\frac{h}{e}$ 就是 $\ln$ 在 $e$ 处的一阶泰勒，导数 $\frac1e$。）
::steps
斜率：$k=\lim_{x\to\infty}\frac yx=\lim_{x\to\infty}\ln\left(e+\frac1{x-1}\right)=\ln e=1$。
截距写成：$b=\lim_{x\to\infty}(y-x)=\lim_{x\to\infty}x\left[\ln\left(e+\frac1{x-1}\right)-1\right]$。
提出 $e$：$\ln\left(e+\frac1{x-1}\right)=\ln\left[e\left(1+\frac{1}{e(x-1)}\right)\right]=1+\ln\left(1+\frac{1}{e(x-1)}\right)$，于是方括号 $=\ln\left(1+\frac{1}{e(x-1)}\right)$。
  ==不提 $e$ 直接写 $\ln(e+u)\sim u$ 是错的==：$\ln(1+u)\sim u$ 要求括号里是「1 + 无穷小」。
换等价：$\frac{1}{e(x-1)}\to0$，所以 $\ln\left(1+\frac{1}{e(x-1)}\right)\sim\frac{1}{e(x-1)}$。
$b=\lim_{x\to\infty}\frac{x}{e(x-1)}=\frac1e$。
~$x\to+\infty$ 与 $x\to-\infty$ 两侧，$\frac{x}{x-1}$ 都 → 1，结果一样，所以两侧是同一条斜渐近线。
斜渐近线 $y=x+\frac1e$，选 **B**。
::note
- {{扣|把 $\ln(e+u)$ 直接换成 $u$}}：得 $b=\lim\frac{x}{x-1}=1$，没有这个选项——命题人设的就是这一步。
- 顺手看完整的[[T渐近线三查|三查]]：定义域要求 $e+\frac1{x-1}>0$，即 $x>1$ 或 $x\lt1-\frac1e$；$x\to1^+$ 时 $y\to+\infty$、$x\to\left(1-\frac1e\right)^-$ 时 $y\to-\infty$ ⟹ 两条铅直渐近线 $x=1$、$x=1-\frac1e$（草图里两条灰虚线）；$y\to\pm\infty$ ⟹ 无水平渐近线。
::vary
问这条曲线一共有几条渐近线 >> 3 条：斜 $y=x+\frac1e$，铅直 $x=1$ 与 $x=1-\frac1e$
把曲线改成 $y=x\ln\left(2+\frac1x\right)$ >> $k=\ln2\ne1$，$b=\lim x\left[\ln(2+\frac1x)-\ln2\right]=\lim x\cdot\frac{1}{2x}=\frac12$，斜渐近线 $y=x\ln2+\frac12$

#2
@stem
若微分方程 $y''+ay'+by=0$ 的解在 $(-\infty,+\infty)$ 上有界，则（　）.
@A $a\lt0,\ b>0$
@B $a>0,\ b>0$
@C $a=0,\ b>0$
@D $a=0,\ b\lt0$
@ans C
@tpl T有界解
::rev
- **该花** 40 秒。两头都不许爆 ⟹ 特征根是纯虚数 ⟹ $a=0,b\gt0$。
- **卡点** 记成「$a\gt0,b\gt0$ 解趋于 0」选 B：那只管 $x\to+\infty$，往左会爆。
- **错了说明** 没注意区间是整条实轴；$e^{rx}$ 只要实部非零必有一端无界。
- **带走** 整轴有界 ⟺ 根为共轭纯虚数；只要求 $x\to+\infty$ 趋于 0 ⟺ 实部全负。
::read
「$y''+ay'+by=0$」 >> 二阶常系数齐次 ⟹ 写[[特征方程]] $r^2+ar+b=0$，解的样子全由两个根决定
「解在 $(-\infty,+\infty)$ 上有界」 >> {{圈|两头都不许爆}}：$e^{rx}$ 只要 $r$ 有非零实部，必有一端趋于无穷 ⟹ 实部只能是 0
「实部为 0」 >> 两根之和 $=-a=0$ ⟹ $a=0$；还得是虚根（不能是 $r=0$ 的重根）⟹ $b>0$
::fast
{{秒|代选项看通解}}：C 是 $y=C_1\cos\sqrt b x+C_2\sin\sqrt b x$，显然有界，直接选 C。
排除另外三个：D 有正实根 $\sqrt{-b}$，$e^{\sqrt{-b}x}$ 往右爆；A、B 两根实部同号且非零，必有一端爆。
::steps
特征方程 $r^2+ar+b=0$，两根 $r_1+r_2=-a$，$r_1r_2=b$（韦达定理）。
解有界要求每个基本解都有界（取 $C_1=1,C_2=0$ 等），所以每个根对应的 $e^{rx}$ 或 $e^{\alpha x}\cos\beta x$ 在 $x\to\pm\infty$ 两端都不能爆。
  $e^{\alpha x}$：$\alpha>0$ 时 $x\to+\infty$ 爆；$\alpha\lt0$ 时 $x\to-\infty$ 爆。所以实部 $\alpha$ 必须为 0。
实根情形：实部为 0 只能是 $r=0$。若 $r=0$ 是单根，另一根 $-a$ 也要为 0，矛盾；若是重根，解里有 $C_1+C_2x$，$x$ 无界。所以不能是实根。
复根情形：$r=\alpha\pm\beta i$，$\alpha=-\frac a2=0$ ⟹ $a=0$；有复根要求判别式 $a^2-4b\lt0$，即 $b>0$。
此时 $y=C_1\cos\sqrt b x+C_2\sin\sqrt b x$，$|y|\le|C_1|+|C_2|$，确实有界。选 **C**。
::note
- {{扣|选 B}}：$a>0,b>0$ 时解满足 $\lim_{x\to+\infty}y=0$（「稳定」），很多人记的是这个结论；但题目问的是整条实轴，往左 $e^{-\frac a2x}$ 爆掉。
- 「有界」看全部解，只要有一个基本解无界就不成立。
::vary
把「在 $(-\infty,+\infty)$ 上有界」改成「在 $[0,+\infty)$ 上有界」 >> 实部 $\le0$ 且实部为 0 的根不重：B、C 都满足（还有 $a>0,b=0$ 时 $y=C_1+C_2e^{-ax}$ 也有界）
改成「当 $x\to+\infty$ 时所有解都趋于 0」 >> 两根实部都 $\lt0$ ⟺ $a>0,b>0$，选 B

#3
@stem
已知 $y=f(x)$ 由 $\begin{cases}x=2t+|t|,\\ y=|t|\sin t\end{cases}$ 确定，则（　）.
@A $f(x)$ 连续，$f'(0)$ 不存在
@B $f'(0)$ 存在，$f'(x)$ 在 $x=0$ 处不连续
@C $f'(x)$ 连续，$f''(0)$ 不存在
@D $f''(0)$ 存在，$f''(x)$ 在 $x=0$ 处不连续
@ans C
@tpl T分段点, T泰勒读系数
::rev
- **该花** 2 分钟。分 $t\ge0$、$t\lt0$ 消去 $t$，两段各展开到 $x^2$ 比系数。
- **卡点** 直接用参数方程求导公式 $\frac{y'(t)}{x'(t)}$：$|t|$ 在 0 不可导，公式失效，误判 $f'(0)$ 不存在选 A。
- **错了说明** 绝对值就是分段，分段点只能两侧分别算；选项层层递进没按顺序查。
- **带走** 右段 $\frac{x^2}9$、左段 $-x^2$：常数项管连续，一次项管 $f'(0)$，二次项系数不等 ⟹ $f''(0)$ 不存在。
::read
「$|t|$」 >> {{圈|绝对值 = 分段}}：$t\ge0$ 与 $t\lt0$ 是两套式子；$t=0$ 对应 $x=0$，问的又全是 $x=0$ 处 ⟹ 分段点 ⟹ [[T分段点|回定义]]
「$x=2t+|t|$」 >> $t\ge0$：$x=3t$；$t\lt0$：$x=t$。两段都是增函数，$x$ 与 $t$ 一一对应，所以 $y$ 确实是 $x$ 的函数，而且能直接消去 $t$
「四个选项层层递进」 >> 连续 → $f'(0)$ → $f'$ 连续 → $f''(0)$ → $f''$ 连续。从低到高一级级查，查到第一个不成立的就停
::fast
{{秒|两段各展开到 $x^2$}}：右段 $\frac x3\sin\frac x3=\frac{x^2}{9}+o(x^2)$，左段 $-x\sin x=-x^2+o(x^2)$。
两段都没有常数项和一次项 ⟹ 连续、$f'(0)=0$；$x^2$ 系数 $\frac19\ne-1$ ⟹ 左右二阶导 $\frac29\ne-2$ ⟹ $f''(0)$ 不存在。剩下「$f'$ 连续」看两段导函数在 0 处都 → 0，成立 ⟹ C。（[[T泰勒读系数]]：$f''=2!\times$ 系数。）
::steps
消参：$t\ge0$ 时 $x=3t$，$t=\frac x3$，$y=t\sin t=\frac x3\sin\frac x3$（$x\ge0$）；$t\lt0$ 时 $x=t$，$y=-t\sin t=-x\sin x$（$x\lt0$）。
  所以 $f(x)=\begin{cases}\frac x3\sin\frac x3,&x\ge0\\-x\sin x,&x\lt0\end{cases}$，$f(0)=0$。
~连续：两段在 $x\to0$ 时都 → 0 $=f(0)$。（下一步可导就自动连续，这步可省。）
$f'(0)$：右导数 $\lim_{x\to0^+}\frac{\frac x3\sin\frac x3}{x}=\lim\frac13\sin\frac x3=0$；左导数 $\lim_{x\to0^-}\frac{-x\sin x}{x}=\lim(-\sin x)=0$。左右相等，$f'(0)=0$，A 错。
$f'(x)$（$x\ne0$）：$x>0$ 时 $f'(x)=\frac13\sin\frac x3+\frac x9\cos\frac x3$；$x\lt0$ 时 $f'(x)=-\sin x-x\cos x$。
  两式在 $x\to0$ 时都 → 0 $=f'(0)$ ⟹ $f'(x)$ 在 0 处连续，B 错。
$f''(0)$ 回定义：右侧 $\lim_{x\to0^+}\frac{f'(x)-0}{x}=\lim\left(\frac{\sin\frac x3}{3x}+\frac19\cos\frac x3\right)=\frac19+\frac19=\frac29$。
  左侧 $\lim_{x\to0^-}\frac{-\sin x-x\cos x}{x}=-1-1=-2$。
$\frac29\ne-2$ ⟹ $f''(0)$ 不存在，D 错；选 **C**。
::note
- {{扣|直接用 $\frac{dy}{dx}=\frac{y'(t)}{x'(t)}$}}：$|t|$ 在 $t=0$ 不可导，$x'(0)$、$y'(0)$ 都不存在，这个公式在分段点失效。
- 绝对值让左右两侧是两个不同的函数——==分段点就分两侧各算一遍==，2021 第 1 题同样是分段点回定义。
- 提速：两侧泰勒系数逐项比，常数项、一次项、二次项分别管连续、$f'(0)$、$f''(0)$。
::vary
把 $x=2t+|t|$ 换成 $x=t$（即 $y=|x|\sin x$） >> 右 $x\sin x\approx x^2$、左 $-x\sin x\approx-x^2$，$f''(0^\pm)=\pm2$，仍是 C
把 $y$ 换成 $|t|\sin^2t$ >> 两段都是三阶小量：右 $\frac{x^3}{27}$、左 $-x^3$；$f''(0)=0$ 存在且 $f''$ 在 0 连续，$f'''(0)$ 不存在
把 $y$ 换成 $|t|$ >> 右 $\frac x3$、左 $-x$，左右导数 $\frac13\ne-1$，$f'(0)$ 不存在，选 A

#4
@stem
已知 $a_n\lt b_n\ (n=1,2,\cdots)$. 若级数 $\sum\limits_{n=1}^{\infty}a_n$ 与 $\sum\limits_{n=1}^{\infty}b_n$ 均收敛，则「$\sum\limits_{n=1}^{\infty}a_n$ 绝对收敛」是「$\sum\limits_{n=1}^{\infty}b_n$ 绝对收敛」的（　）.
@A 充分必要条件
@B 充分不必要条件
@C 必要不充分条件
@D 既不充分也不必要条件
@ans A
@tpl T绝对收敛互推
::rev
- **该花** 1 分半。$\sum(b_n-a_n)$ 是收敛的正项级数，即绝对收敛。
- **卡点** 凭「小的绝对收敛推不出大的」的比较直觉选 B 或 C。
- **错了说明** 没看出 $b_n-a_n\gt0$ 藏着一个绝对收敛级数；不会用 $|b_n|\le|a_n|+(b_n-a_n)$。
- **带走** 两个级数之差绝对收敛 ⟹ 二者同为绝对收敛或同不是；充要题两个方向各写一行三角不等式。
::read
「$a_n\lt b_n$」 >> $b_n-a_n>0$：一个{{圈|正项}}级数藏在这里
「$\sum a_n$、$\sum b_n$ 均收敛」 >> 两个收敛级数可以相减 ⟹ $\sum(b_n-a_n)$ 收敛 ⟹ 正项且收敛 = [[绝对收敛]]
「$a_n$ 绝对收敛 ⟺? $b_n$ 绝对收敛」 >> 想把 $|b_n|$ 和 $|a_n|$ 连起来 ⟹ 三角不等式：$b_n=a_n+(b_n-a_n)$
::fast
{{秒|绝对收敛级数加减绝对收敛级数仍绝对收敛}}：$b_n=a_n+d_n$、$a_n=b_n-d_n$，$\sum d_n$ 绝对收敛 ⟹ $a_n$、$b_n$ 要么都绝对收敛，要么都不 ⟹ A。
::steps
令 $d_n=b_n-a_n$。由 $a_n\lt b_n$ 得 $d_n>0$。
由收敛级数的性质，$\sum d_n=\sum b_n-\sum a_n$ 收敛；$d_n>0$，所以 $\sum|d_n|=\sum d_n$ 收敛，$\sum d_n$ 绝对收敛。
充分性：设 $\sum|a_n|$ 收敛。$|b_n|=|a_n+d_n|\le|a_n|+d_n$，右边是两个收敛正项级数之和，由比较判别法 $\sum|b_n|$ 收敛。
必要性：设 $\sum|b_n|$ 收敛。$|a_n|=|b_n-d_n|\le|b_n|+d_n$，同理 $\sum|a_n|$ 收敛。
两个方向都成立，是充分必要条件，选 **A**。
::note
- 直觉陷阱：「小的绝对收敛推不出大的」——但这里不是比大小，是「差」本身绝对收敛，两边地位完全对称。
- 两个前提缺一不可：去掉「$\sum b_n$ 收敛」，$a_n=\frac{(-1)^n}{n^2}$、$b_n=1$ 就是反例。
::vary
去掉「$\sum b_n$ 收敛」，只说 $\sum a_n$ 收敛，问 $\sum|a_n|$ 收敛能否推出 $\sum b_n$ 收敛 >> 不能：$a_n=\frac{1}{n^2}$、$b_n=1$
把「$a_n\lt b_n$」去掉（$a_n,b_n$ 大小随意，都收敛） >> 两个方向都推不出：$a_n=\frac{(-1)^n}{n}$（条件收敛）、$b_n=\frac1{n^2}$（绝对收敛），选 D
若 $a_n\le c_n\le b_n$ 且 $\sum a_n,\sum b_n$ 都收敛，$\sum c_n$ 呢 >> 收敛：$0\le c_n-a_n\le b_n-a_n$，比较判别法得 $\sum(c_n-a_n)$ 收敛

#5
@stem
已知 $n$ 阶矩阵 $A,B,C$ 满足 $ABC=O$，$E$ 为 $n$ 阶单位矩阵. 记矩阵 $\begin{pmatrix}O&A\\BC&E\end{pmatrix}$，$\begin{pmatrix}AB&C\\O&E\end{pmatrix}$，$\begin{pmatrix}E&AB\\AB&O\end{pmatrix}$ 的秩分别为 $r_1,r_2,r_3$，则（　）.
@A $r_1\le r_2\le r_3$
@B $r_1\le r_3\le r_2$
@C $r_3\le r_1\le r_2$
@D $r_2\le r_1\le r_3$
@ans B
@tpl T分块消元, T分块秩
::rev
- **该花** 2 分半。三个矩阵都用 $E$ 块消元，化成 $n+r(\cdot)$。
- **卡点** 块行变换的乘数写在右边，$ABC=O$ 用不上；或以为 $r((AB)^2)=r(AB)$。
- **错了说明** 分块消元「行变换左乘、列变换右乘」不熟；$r(M^2)\le r(M)$ 没想到。
- **带走** 含 $E$ 的分块矩阵：用 $E$ 把同行同列消成 $O$，秩＝$n$＋剩下那块的秩；本题剩 $O$、$AB$、$(AB)^2$。
::read
「三个 $2n$ 阶分块矩阵，每个都含一个 $E$」 >> {{圈|$E$ 是可逆的主元}}，用它把同行同列的块全消掉（[[T分块消元]]），每个都会变成 $\mathrm{diag}(E,\ast)$，秩 $=n+r(\ast)$
「$ABC=O$」 >> 消元时会冒出 $A\cdot BC$，这里直接变 $O$——只在 $r_1$ 里用得上
「比较三个秩」 >> 化成 $n+r(\cdot)$ 后，比 $r(O)=0$、$r(AB)$、$r((AB)^2)$ 三个数；$r((AB)^2)\le r(AB)$（[[秩的性质]]：$r(PQ)\le r(P)$）
::fast
{{秒|取特例}}：$A=E$、$C=O$、$B$ 取幂零矩阵 $\begin{pmatrix}0&1\\0&0\end{pmatrix}$（$n=2$，满足 $ABC=O$）。则 $r_1=2$（$A=E$，$BC=O$）、$r_2=2+r(B)=3$、$r_3=2+r(B^2)=2$ ⟹ $r_1=r_3\lt r_2$，只有 B 符合。
::steps
$r_1$：第一块行减去 $A$ 乘第二块行（左乘 $\begin{pmatrix}E&-A\\O&E\end{pmatrix}$）：$\begin{pmatrix}O-A\cdot BC&A-A\cdot E\\BC&E\end{pmatrix}=\begin{pmatrix}-ABC&O\\BC&E\end{pmatrix}=\begin{pmatrix}O&O\\BC&E\end{pmatrix}$。

「经过点 $(1,2)$」 >> 初值 $y(1)=2$ 定常数
「$f(x)=\int_1^xy(t)dt$ 的最大值」 >> [[T变限积分最值|变限积分]]：$f'(x)=y(x)$，最大值点就是 $y$ 由正变负的零点
::steps
切线方程：在 $P(x,y)$ 处 $Y-y=y'(x)(X-x)$。令 $X=0$，得截距 $Y=y-xy'$。
$P$ 到 $y$ 轴距离为 $|x|=x$（$x>0$）。由题意 $y-xy'=x$，整理为 $y'-\frac1xy=-1$。
用通解公式（[[一阶线性公式]]）：$P(x)=-\frac1x$，$e^{-\int P\,dx}=e^{\ln x}=x$，$e^{\int P\,dx}=\frac1x$。
  $y=x\left[\int(-1)\cdot\frac1x\,dx+C\right]=x(C-\ln x)$。
~验算：$y'=C-\ln x-1$，$y-xy'=x(C-\ln x)-x(C-\ln x-1)=x$ ✓。
代 $y(1)=2$：$1\cdot(C-0)=2$，$C=2$ ⟹ $y(x)=x(2-\ln x)$，$x>0$。
(Ⅱ) 由[[变限积分求导]]，$f'(x)=y(x)=x(2-\ln x)$。
$x>0$，所以 $f'(x)$ 与 $2-\ln x$ 同号：$0\lt x\lt e^2$ 时 $f'>0$，$x>e^2$ 时 $f'\lt0$。
$f$ 在 $(0,e^2]$ 上单调增加、在 $[e^2,+\infty)$ 上单调减少 ⟹ 最大值为 $f(e^2)$。
求原函数：$\int t(2-\ln t)dt=t^2-\int t\ln t\,dt$；分部 $\int t\ln t\,dt=\frac{t^2}{2}\ln t-\int\frac{t^2}{2}\cdot\frac1t dt=\frac{t^2}{2}\ln t-\frac{t^2}{4}$。
  所以 $\int t(2-\ln t)dt=\frac54t^2-\frac{t^2}{2}\ln t+C$。
代限：$t=e^2$ 时 $\frac54e^4-\frac{e^4}{2}\cdot2=\frac{e^4}{4}$；$t=1$ 时 $\frac54$。$f(e^2)=\frac{e^4}{4}-\frac54=\frac{e^4-5}{4}$。
::paper
解　(Ⅰ) 曲线在点 $P(x,y)$ 处的切线方程为 $Y-y=y'(X-x)$，令 $X=0$，得切线在 $y$ 轴上的截距为 $y-xy'$. ⛳1
由题意（$x>0$）$y-xy'=x$，即
$$y'-\frac1xy=-1.\qquad(1)$$ ⛳2
由一阶线性微分方程的通解公式，
$$y=e^{\int\frac1xdx}\left[\int(-1)e^{-\int\frac1xdx}dx+C\right]=x\left(C-\ln x\right).$$ ⛳2
由 $y(1)=2$ 得 $C=2$，故 $y(x)=x(2-\ln x)$，$x>0$. ⛳1
(Ⅱ) $f'(x)=y(x)=x(2-\ln x)$，$x>0$. 令 $f'(x)=0$ 得 $x=e^2$. 当 $0\lt x\lt e^2$ 时 $f'(x)>0$，当 $x>e^2$ 时 $f'(x)\lt0$，故 $f(x)$ 在 $(0,e^2]$ 上单调增加，在 $[e^2,+\infty)$ 上单调减少，$f(x)$ 在 $(0,+\infty)$ 上的最大值为 $f(e^2)$. ⛳2
$$f(e^2)=\int_1^{e^2}t(2-\ln t)dt=\left[\frac54t^2-\frac{t^2}{2}\ln t\right]_1^{e^2}=\frac{e^4}{4}-\frac54=\frac{e^4-5}{4}.$$ ⛳2
所以 $f(x)$ 在 $(0,+\infty)$ 上的最大值为 $\dfrac{e^4-5}{4}$.
::note
- {{扣|截距写成 $x-\frac{y}{y'}$}}：那是切线在 **$x$ 轴**上的截距。$y$ 轴截距令 $X=0$，$x$ 轴截距令 $Y=0$。
- {{扣|只求驻点、不说单调性}}：「最大值」必须交代 $e^2$ 左增右减（或「唯一驻点且是极大值点」），否则只能算极值。
- {{扣|通解公式里符号弄反}}：标准形是 $y'+P(x)y=Q(x)$，这里 $P=-\frac1x$，$e^{-\int P}=x$。写完代回原方程验一下最稳（steps 里的验算行）。
::vary
(Ⅱ) 改问 $f(x)$ 在 $(0,+\infty)$ 上有没有最小值 >> $x\to0^+$ 时 $f\to\int_1^0y=-\int_0^1t(2-\ln t)dt=-\frac54$（取不到），$x\to+\infty$ 时 $f\to-\infty$ ⟹ 无最小值

解　(Ⅰ) 记 $D=\{(x,y)\mid x^2+y^2\le1\}$. 因 $D$ 关于 $y$ 轴对称，$x\cdot\frac2\pi(x^2+y^2)$ 与 $xy\cdot\frac2\pi(x^2+y^2)$ 均为 $x$ 的奇函数，故 ⛳2
$$EX=\iint_Dx\cdot\frac2\pi(x^2+y^2)dxdy=0,\qquad E(XY)=\iint_Dxy\cdot\frac2\pi(x^2+y^2)dxdy=0,$$
从而 $\mathrm{Cov}(X,Y)=E(XY)-EX\cdot EY=0$. ⛳2
(Ⅱ) 当 $|x|\le1$ 时，
$$f_X(x)=\int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}}\frac2\pi(x^2+y^2)dy=\frac{4}{3\pi}(2x^2+1)\sqrt{1-x^2},$$
当 $|x|>1$ 时 $f_X(x)=0$；同理 $f_Y(y)=\frac{4}{3\pi}(2y^2+1)\sqrt{1-y^2}$（$|y|\le1$），其他为 0. ⛳2
在区域 $\{(x,y)\mid x^2+y^2>1,\ |x|\lt1,\ |y|\lt1\}$ 上，$f(x,y)=0$ 而 $f_X(x)f_Y(y)>0$，即 $f(x,y)\ne f_X(x)f_Y(y)$，故 $X$ 与 $Y$ 不相互独立. ⛳2
(Ⅲ) $Z$ 的分布函数 $F_Z(z)=P\{X^2+Y^2\le z\}$. 当 $z\lt0$ 时 $F_Z(z)=0$；当 $z\ge1$ 时 $F_Z(z)=1$；当 $0\le z\lt1$ 时，
$$F_Z(z)=\iint_{x^2+y^2\le z}\frac2\pi(x^2+y^2)dxdy=\frac2\pi\int_0^{2\pi}d\theta\int_0^{\sqrt z}r^3dr=z^2.$$ ⛳3
故 $Z$ 的概率密度为 $f_Z(z)=\begin{cases}2z,&0\lt z\lt1,\\0,&\text{其他}.\end{cases}$ ⛳1
::note
- {{扣|(Ⅰ) 写「由对称性得 0」不说哪个对称、哪个奇函数}}：至少一句「$D$ 关于 $y$ 轴对称，被积函数是 $x$ 的奇函数」。
- {{扣|(Ⅱ) 只找一个点}}：密度可以在一个点上随意改动，严格的写法是指出一块**正面积区域**上 $f\ne f_Xf_Y$（或者证明 $f_Xf_Y\ne f$ 在圆盘内某个连续点成立，如原点：$f(0,0)=0$，$f_X(0)f_Y(0)=\frac{16}{9\pi^2}\ne0$）。
- 原点那个反例更「硬」：$(0,0)$ 在支撑内部，$f$、$f_X$、$f_Y$ 在那里都连续，一个点就足以说明。
