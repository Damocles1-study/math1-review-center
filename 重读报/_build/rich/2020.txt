#1
@stem
当 $x\to0^+$ 时，下列无穷小量中最高阶的是（　）.
@A $\displaystyle\int_0^x\left(e^{t^2}-1\right)dt$
@B $\displaystyle\int_0^x\ln\left(1+\sqrt{t^3}\right)dt$
@C $\displaystyle\int_0^{\sin x}\sin t^2\,dt$
@D $\displaystyle\int_0^{1-\cos x}\sqrt{\sin^3t}\,dt$
@ans D
@tpl T变限积分阶数
::rev
- **该花** 1 分钟。阶数＝（被积函数的阶＋1）×上限的阶：3、$\frac52$、3、5。
- **卡点** 只看被积函数，D 的 $t^{3/2}$ 阶最低，以为 D 最低阶；忘了上限 $1-\cos x$ 是 2 阶。
- **错了说明** 变限积分的阶要把上限的阶乘进去。
- **带走** $\int_0^{\varphi(x)}t^p\,dt$ 的阶是 $(p+1)\times\varphi$ 的阶；同阶的两个选项都不是答案。
::read
「$x\to0^+$，最高阶」 >> 四个都是[[变限积分求导|变限积分]]，比阶 ⟹ 每个都化成「$\sim Cx^k$」，比 $k$ 的大小
「被积函数 $e^{t^2}-1$、$\ln(1+\sqrt{t^3})$、$\sin t^2$、$\sqrt{\sin^3t}$」 >> 全部换[[等价无穷小]]：$t^2$、$t^{3/2}$、$t^2$、$t^{3/2}$
「上限 $x$、$x$、$\sin x$、$1-\cos x$」 >> {{圈|上限也要换等价}}：$x$、$x$、$x$、$\frac{x^2}{2}$——D 的上限是 2 阶，这是全题唯一的机关
「$x\to0^+$」 >> 只看右侧，B、D 里的 $\sqrt{t^3}$ 才有意义（$t\ge0$）
::sk 350 150 画 | 草稿上列一张「阶数账本」：被积函数的阶加 1，再乘上限的阶
s.cells(10,10,[['','被积 ~','+1','上限 ~','阶'],['A','t²','3','x','3'],['B','t^{3/2}','5/2','x','5/2'],['C','t²','3','sin x ~ x','3'],['D','t^{3/2}','5/2','!1−cos x ~ x²/2','!5']],cw=[30,70,44,130,50],ch=25,size=12)
s.circle(300,123,16,'r',ry=11)
::fast
{{秒|阶数 = (被积阶 + 1) × 上限阶}}：A $3\times1$，B $\frac52\times1$，C $3\times1$，D $\frac52\times2=5$ ⟹ D。
A、C 同阶（都是 3），选择题里同阶的两个一定都不是答案——这一眼就能排除 A、C。
::steps
A：$e^{t^2}-1\sim t^2$，$\int_0^xt^2dt=\frac{x^3}{3}$ ⟹ 3 阶。
B：$\ln(1+\sqrt{t^3})\sim\sqrt{t^3}=t^{3/2}$，$\int_0^xt^{3/2}dt=\frac25x^{5/2}$ ⟹ $\frac52$ 阶。
C：$\sin t^2\sim t^2$，$\int_0^{\sin x}t^2dt=\frac{\sin^3x}{3}\sim\frac{x^3}{3}$ ⟹ 3 阶。
D：$\sqrt{\sin^3t}\sim t^{3/2}$，$\int_0^{1-\cos x}t^{3/2}dt=\frac25(1-\cos x)^{5/2}$；而 $1-\cos x\sim\frac{x^2}{2}$，所以 $\sim\frac25\cdot\frac{x^5}{2^{5/2}}$ ⟹ 5 阶。
~严格一点：「被积函数换等价后再积分」的依据是洛必达——$\lim\frac{\int_0^{u}g(t)dt}{\int_0^{u}t^kdt}=\lim\frac{g(u)u'}{u^ku'}=1$。考场上直接用。
比较：$5>3>\frac52$，最高阶是 D，选 **D**。
::note
- {{扣|只看被积函数}}：D 的被积函数 $t^{3/2}$ 阶数最低，只看它会以为 D 最低阶，正好选反。
- 洛必达验证 D：$\frac{d}{dx}\int_0^{1-\cos x}\sqrt{\sin^3t}dt=\sqrt{\sin^3(1-\cos x)}\cdot\sin x\sim\left(\frac{x^2}{2}\right)^{3/2}\cdot x\sim x^4$，求导后 4 阶，原函数 5 阶 ✓。
::vary
$\int_0^{x^2}\sin t\,dt$ 是几阶 >> 被积 $t$（1 阶），$+1$ 得 2，上限 $x^2$（2 阶），$2\times2=4$ 阶
已知 $\int_0^{x}(e^{t^k}-1)dt$ 与 $x^5$ 同阶，求 $k$ >> $(k+1)\times1=5$ ⟹ $k=4$

#2
@stem
设函数 $f(x)$ 在区间 $(-1,1)$ 内有定义，且 $\lim\limits_{x\to0}f(x)=0$，则（　）.
@A 当 $\lim\limits_{x\to0}\dfrac{f(x)}{\sqrt{|x|}}=0$ 时，$f(x)$ 在 $x=0$ 处可导
@B 当 $\lim\limits_{x\to0}\dfrac{f(x)}{x^2}=0$ 时，$f(x)$ 在 $x=0$ 处可导
@C 当 $f(x)$ 在 $x=0$ 处可导时，$\lim\limits_{x\to0}\dfrac{f(x)}{\sqrt{|x|}}=0$
@D 当 $f(x)$ 在 $x=0$ 处可导时，$\lim\limits_{x\to0}\dfrac{f(x)}{x^2}=0$
@ans C
@tpl T举反例, T分段点
::rev
- **该花** 1 分半。A、B 用「只把 $f(0)$ 抬到 1」的函数打掉，D 用 $f=x$ 打掉。
- **卡点** 把 $\lim f(x)=0$ 当成 $f(0)=0$，于是觉得 B 对。
- **错了说明** 极限不管该点的函数值；可导的定义里有 $f(0)$，条件没给就推不出可导。
- **带走** 「由极限推可导」先看有没有给函数值；「由可导推极限」直接写 $f(x)=f'(0)x+o(x)$ 代进去。
::read
「$\lim\limits_{x\to0}f(x)=0$」 >> {{圈|只给了极限，没说 $f(0)=0$}}——极限不管 $x=0$ 那一点本身。这是全题的机关
「A、B：某个比值极限为 0 ⟹ 可导」 >> 可导要回[[导数定义]] $\lim\frac{f(x)-f(0)}{x}$，里面有 $f(0)$；条件里根本没有 $f(0)$ ⟹ 多半推不出
「C、D：可导 ⟹ 某个比值 → 0」 >> 可导 ⟹ 连续 ⟹ $f(0)=\lim f=0$，于是 $f(x)=f'(0)x+o(x)$，就看除以 $\sqrt{|x|}$、$x^2$ 谁还能趋于 0
::fast
{{秒|[[T举反例|举反例]]}}：$f(x)=\begin{cases}0,&x\ne0\\1,&x=0\end{cases}$ 打掉 A、B（条件全满足但不连续）；$f(x)=x$ 打掉 D（$\frac{x}{x^2}=\frac1x\to\infty$）⟹ 只剩 C。
::steps
A、B：取 $f(x)=0\ (x\ne0)$，$f(0)=1$。$\lim f(x)=0$ ✓；$x\ne0$ 时 $\frac{f(x)}{\sqrt{|x|}}=0$、$\frac{f(x)}{x^2}=0$，两个极限都是 0 ✓。但 $\lim f(x)=0\ne1=f(0)$，不连续，更不可导 ⟹ A、B 都错。
D：取 $f(x)=x$，在 0 处可导，但 $\frac{f(x)}{x^2}=\frac1x$ 的极限不存在 ⟹ D 错。
C 正面证：$f$ 在 0 处可导 ⟹ 连续 ⟹ $f(0)=\lim\limits_{x\to0}f(x)=0$。
于是 $\dfrac{f(x)}{\sqrt{|x|}}=\dfrac{f(x)-f(0)}{x}\cdot\dfrac{x}{\sqrt{|x|}}$。
  第一个因子 $\to f'(0)$（有限数），第二个因子 $\frac{x}{\sqrt{|x|}}$ 的绝对值是 $\sqrt{|x|}\to0$。
有界 × 无穷小 = 无穷小 ⟹ 极限为 0，C 对，选 **C**。
::note
- {{扣|把「$\lim f(x)=0$」当成「$f(0)=0$」}}：这是本题全部的分。极限只看去心邻域。
- 若题目补上 $f(0)=0$：B 就对了（$\frac{f(x)-0}{x}=\frac{f(x)}{x^2}\cdot x\to0$，且 $f'(0)=0$）；A 仍错，反例 $f(x)=|x|^{3/4}$：$\frac{f}{\sqrt{|x|}}=|x|^{1/4}\to0$，但 $\frac{f(x)}{x}$ 趋于 $\pm\infty$。
- 判断「比值 → 0 能不能推可导」：分母比 $x$ **高阶**（如 $x^2$）才有希望，比 $x$ **低阶**（如 $\sqrt{|x|}$）不行。
::vary
把 A 改成「$\lim\frac{f(x)}{x}=0$ 时可导」（仍不给 $f(0)$） >> 仍错，同一个反例（$f(0)=1$）
把 C 的 $\sqrt{|x|}$ 换成 $x$ >> $\lim\frac{f(x)}{x}=f'(0)$，不一定是 0（$f=x$ 时为 1），错
「$f$ 在 0 处可导且 $f'(0)=0$」能推出 $\lim\frac{f(x)}{x^2}=0$ 吗 >> 不能：$f=x^2$ 时为 1；$f=|x|^{3/2}$ 时 $\frac{f}{x^2}\to\infty$

#3
@stem
设函数 $f(x,y)$ 在点 $(0,0)$ 处可微，$f(0,0)=0$，$\boldsymbol n=\left(\dfrac{\partial f}{\partial x},\dfrac{\partial f}{\partial y},-1\right)\Big|_{(0,0)}$，非零向量 $\boldsymbol\alpha$ 与 $\boldsymbol n$ 垂直，则（　）.
@A $\lim\limits_{(x,y)\to(0,0)}\dfrac{|\boldsymbol n\cdot(x,y,f(x,y))|}{\sqrt{x^2+y^2}}$ 存在
@B $\lim\limits_{(x,y)\to(0,0)}\dfrac{|\boldsymbol n\times(x,y,f(x,y))|}{\sqrt{x^2+y^2}}$ 存在
@C $\lim\limits_{(x,y)\to(0,0)}\dfrac{|\boldsymbol\alpha\cdot(x,y,f(x,y))|}{\sqrt{x^2+y^2}}$ 存在
@D $\lim\limits_{(x,y)\to(0,0)}\dfrac{|\boldsymbol\alpha\times(x,y,f(x,y))|}{\sqrt{x^2+y^2}}$ 存在
@ans A
@tpl T举反例
::rev
- **该花** 1 分半。$\boldsymbol n\cdot(x,y,f)=f_xx+f_yy-f$，正是可微定义的余项。
- **卡点** 没把点积展开，被叉积、$\boldsymbol\alpha$ 的记号吓住。
- **错了说明** 可微定义 $f-f_xx-f_yy=o(\rho)$ 没有背到能认出变形。
- **带走** 见「可微」＋分母 $\sqrt{x^2+y^2}$，先把可微定义写出来再对选项。
::read
「$f$ 在 $(0,0)$ 可微，$f(0,0)=0$」 >> 立刻写[[可微定义]]：$f(x,y)=f_xx+f_yy+o(\rho)$，$\rho=\sqrt{x^2+y^2}$
「$\boldsymbol n=(f_x,f_y,-1)$」 >> 这是切平面 $z=f_xx+f_yy$ 的{{圈|法向量}}
「$\boldsymbol n\cdot(x,y,f)$」 >> 展开就是 $f_xx+f_yy-f(x,y)$——{{波|正好是可微定义里那个余项（差个负号）}}
「分母 $\sqrt{x^2+y^2}$」 >> 就是 $\rho$ ⟹ A 是「余项 / $\rho$」，即可微定义原文
「$\boldsymbol\alpha\perp\boldsymbol n$」 >> $\boldsymbol\alpha$ 平行于切平面，是一个切向量；C、D 是迷惑项
::fast
{{秒|$\boldsymbol n\cdot(x,y,f)=f_xx+f_yy-f$ 就是可微定义的余项（反号）}} ⟹ A 的极限是 0，存在。
B、C、D 用 $f\equiv0$（或 $f=x$）一代就出现「随方向变化」的极限，不存在。
::steps
由可微：$f(x,y)=f(0,0)+f_x(0,0)x+f_y(0,0)y+o(\rho)=f_xx+f_yy+o(\rho)$。
A：$\boldsymbol n\cdot(x,y,f(x,y))=f_xx+f_yy-f(x,y)=-o(\rho)$，所以 $\dfrac{|\boldsymbol n\cdot(x,y,f)|}{\rho}\to0$，极限存在（为 0），A 对。
C：取 $f\equiv0$，则 $\boldsymbol n=(0,0,-1)$，取 $\boldsymbol\alpha=(1,0,0)\perp\boldsymbol n$。$\boldsymbol\alpha\cdot(x,y,0)=x$，$\frac{|x|}{\sqrt{x^2+y^2}}$ 沿 $y=0$ 为 1、沿 $x=0$ 为 0，极限不存在 ⟹ C 错。
D：同上 $f\equiv0$、$\boldsymbol\alpha=(1,0,0)$：$\boldsymbol\alpha\times(x,y,0)=(0,0,y)$，$\frac{|y|}{\rho}$ 同样随方向变化 ⟹ D 错。
B：取 $f(x,y)=x$，$\boldsymbol n=(1,0,-1)$，$\boldsymbol n\times(x,y,x)=\begin{vmatrix}\boldsymbol i&\boldsymbol j&\boldsymbol k\\1&0&-1\\x&y&x\end{vmatrix}=(y,-2x,y)$。
  模长 $\sqrt{4x^2+2y^2}$，除以 $\rho$：沿 $y=0$ 为 2，沿 $x=0$ 为 $\sqrt2$，极限不存在 ⟹ B 错。
~注意 B 若取 $f\equiv0$：$\boldsymbol n\times(x,y,0)=(y,-x,0)$，模长恰为 $\rho$，比值恒为 1，极限存在——所以 $f\equiv0$ 打不掉 B，要换 $f=x$。
选 **A**。
::note
- 本题把「可微定义」写成了向量形式。点积 ↔ 投影到法向（落差），叉积 ↔ 投影到切平面（与 $\rho$ 同阶，比值随方向变）。
- {{扣|找反例时只试 $f\equiv0$}}：B 恰好在 $f\equiv0$ 时比值恒为 1，会误以为 B 也对。反例要能「打穿」，换一个不对称的。
- 几何：$\frac{|\boldsymbol n\cdot P|}{|\boldsymbol n|}$ 是曲面上点 $P$ 到切平面的距离，A 说的是「这个距离比 $\rho$ 高阶」。
::vary
把条件「可微」降成「两个偏导存在」，A 还对吗 >> 不一定：$f=\frac{xy}{\sqrt{x^2+y^2}}$（$f(0,0)=0$）偏导都为 0，$\frac{|f|}{\rho}=\frac{|xy|}{x^2+y^2}$ 随方向变，极限不存在
把 A 的分母换成 $x^2+y^2$ >> 不一定存在：$f=x^2+y^2+x^3$ 可以，但 $f=(x^2+y^2)^{3/4}$ 时 $\frac{\rho^{3/2}}{\rho^2}\to\infty$

#4
@stem
设 $R$ 为幂级数 $\displaystyle\sum_{n=1}^\infty a_nx^n$ 的收敛半径，$r$ 是实数，则（　）.
@A 当 $\displaystyle\sum_{n=1}^\infty a_{2n}r^{2n}$ 发散时，$|r|\ge R$
@B 当 $\displaystyle\sum_{n=1}^\infty a_{2n}r^{2n}$ 收敛时，$|r|\le R$
@C 当 $|r|\ge R$ 时，$\displaystyle\sum_{n=1}^\infty a_{2n}r^{2n}$ 发散
@D 当 $|r|\le R$ 时，$\displaystyle\sum_{n=1}^\infty a_{2n}r^{2n}$ 收敛
@ans A
@tpl T举反例
::rev
- **该花** 1 分钟。$|r|\lt R$ ⟹ 绝对收敛 ⟹ 偶数项子级数收敛；A 是它的逆否命题。
- **卡点** 选 D：以为 $|r|\le R$ 也能保证收敛（边界点不确定）。
- **错了说明** 阿贝尔定理只管开区间内外，$|x|=R$ 处什么都可能。
- **带走** 幂级数题里带等号的「$\le R$ 收敛」「$\ge R$ 发散」基本都错；确定的结论只有开区间内绝对收敛。
::read
「$R$ 是 $\sum a_nx^n$ 的收敛半径」 >> [[阿贝尔定理]]：$|x|<R$ ==绝对==收敛，$|x|>R$ 发散，$|x|=R$ 不确定
「$\sum a_{2n}r^{2n}$」 >> 这是原级数在 $x=r$ 处的{{圈|偶数项子级数}}。原级数绝对收敛 ⟹ 子级数也绝对收敛；但原级数发散时子级数可能收敛（奇数项全被扔了）
「四个选项：A、B 是『子级数怎样 ⟹ $r$ 在哪』，C、D 是『$r$ 在哪 ⟹ 子级数怎样』」 >> 唯一能确定的是：$|r|<R$ ⟹ 子级数收敛。它的逆否命题就是 A
::fast
{{秒|A 是「$|r|<R$ ⟹ 收敛」的逆否命题}}，直接选 A。
反例：$a_n=1$（$R=1$）在 $r=1$ 处子级数 $\sum1$ 发散 ⟹ 打掉 D；只有奇数项的级数（$a_{2n}=0$）子级数恒为 0 ⟹ 打掉 B、C。
::steps
若 $|r|<R$：由阿贝尔定理 $\sum|a_nr^n|$ 收敛，而 $|a_{2n}r^{2n}|$ 是其中一部分项，部分和有界 ⟹ $\sum a_{2n}r^{2n}$ 绝对收敛。
取逆否：$\sum a_{2n}r^{2n}$ 发散 ⟹ $|r|\ge R$，A 对。
B、C 反例：$a_n=\begin{cases}1,&n\text{ 奇}\\0,&n\text{ 偶}\end{cases}$，$\sum a_nx^n=x+x^3+x^5+\cdots$ 的 $R=1$。取 $r=2$：子级数每项都是 0，收敛，但 $|r|=2>R$ ⟹ B 错；$|r|\ge R$ 时子级数收敛（不是发散）⟹ C 错。
D 反例：$a_n=1$，$R=1$，取 $r=1$：$\sum a_{2n}r^{2n}=\sum1$ 发散，但 $|r|\le R$ ⟹ D 错。
选 **A**。
::note
- 「绝对收敛」是关键：只有绝对收敛的级数才能随便抽子级数仍收敛。条件收敛的级数抽出一部分可能发散（如 $\sum\frac{(-1)^n}{n}$ 只取正项）。
- 本题的教训：幂级数在 $|x|=R$ 处收敛性永远不能确定，选项里把边界写成「$\le$」「$\ge$」的结论（D、C）基本都是错的。
::vary
已知 $\sum a_nx^n$ 在 $x=-2$ 收敛、在 $x=3$ 发散，求 $R$ 的范围 >> 收敛 ⟹ $2\le R$；发散 ⟹ $R\le3$；故 $2\le R\le3$
已知 $\sum a_n(x-1)^n$ 在 $x=-1$ 条件收敛，求 $R$ >> $x=-1$ 到中心 1 的距离是 2；条件收敛只能发生在边界 ⟹ $R=2$

#5
@stem
若矩阵 $A$ 经过初等列变换化成 $B$，则（　）.
@A 存在矩阵 $P$，使得 $PA=B$
@B 存在矩阵 $P$，使得 $BP=A$
@C 存在矩阵 $P$，使得 $PB=A$
@D 方程组 $AX=0$ 与 $BX=0$ 同解
@ans B
@tpl T行左列右
::rev
- **该花** 30 秒。列变换＝右乘可逆阵：$AQ=B$ ⟹ $A=BQ^{-1}$。
- **卡点** 把列变换记成左乘选 A；或认为列变换后方程组同解选 D。
- **错了说明** 行变换左乘、列变换右乘；只有行变换保持 $AX=0$ 同解。
- **带走** 行左列右；同解是行变换的性质。
::read
「初等{{圈|列}}变换」 >> [[T行左列右|行左列右]]：列变换 = 右乘若干个初等矩阵 ⟹ $AQ=B$，$Q$ 可逆
「存在矩阵 $P$，$PA=B$ / $PB=A$」 >> $P$ 在左边 = 行变换，和「列变换」对不上 ⟹ A、C 先存疑
「$BP=A$」 >> 由 $AQ=B$ 两边右乘 $Q^{-1}$：$BQ^{-1}=A$，取 $P=Q^{-1}$ 正好
「$AX=0$ 与 $BX=0$ 同解」 >> 同解是**行**变换才保证的性质（行变换 = 方程组的同解变形）。列变换会打乱未知数 ⟹ D 存疑
::fast
{{秒|列变换 = 右乘}}：$AQ=B$ ⟹ $A=BQ^{-1}$，$P$ 在 $B$ 的**右边** ⟹ B。四个选项里只有 B 的 $P$ 在右边。
::steps
初等列变换相当于右乘初等矩阵。设 $A$ 经过若干次初等列变换化成 $B$，对应初等矩阵 $E_1,\dots,E_k$，则 $AE_1E_2\cdots E_k=B$。
记 $Q=E_1E_2\cdots E_k$，初等矩阵都可逆 ⟹ $Q$ 可逆，且 $AQ=B$。
两边右乘 $Q^{-1}$：$A=BQ^{-1}$。取 $P=Q^{-1}$，就有 $BP=A$ ⟹ B 对。
A、C、D 用同一个反例：$A=\begin{pmatrix}1&0\\0&0\end{pmatrix}$，交换两列得 $B=\begin{pmatrix}0&1\\0&0\end{pmatrix}$。
  A：任意 $P$，$PA$ 的第 2 列 $=P\cdot\boldsymbol 0=\boldsymbol 0$，而 $B$ 的第 2 列不是 $\boldsymbol 0$ ⟹ 不存在 $P$，A 错。
  C：$PB$ 的第 1 列 $=\boldsymbol 0$，而 $A$ 的第 1 列不是 $\boldsymbol 0$ ⟹ C 错。
  D：$AX=0$ 即 $x_1=0$，解为 $(0,k)^T$；$BX=0$ 即 $x_2=0$，解为 $(k,0)^T$，不同解 ⟹ D 错。
选 **B**。
::note
- {{扣|把「列变换」记成左乘}}：一句话记牢——**谁变换就在谁那一侧乘**：行在左、列在右。

于是不论哪种情况，$f(x)$ 与 $f'(x)$ 都是「指数衰减 × 多项式或三角函数」的组合 ⟹ $\lim\limits_{x\to+\infty}f(x)=0$，$\lim\limits_{x\to+\infty}f'(x)=0$，且 $\int_0^{+\infty}f$ 收敛。
方程两边从 0 到 $+\infty$ 积分：$\displaystyle\int_0^{+\infty}f''dx+a\int_0^{+\infty}f'dx+\int_0^{+\infty}f\,dx=0$。
$\int_0^{+\infty}f''dx=f'(+\infty)-f'(0)=0-n=-n$；$\int_0^{+\infty}f'dx=f(+\infty)-f(0)=0-m=-m$。
代入：$-n-am+\int_0^{+\infty}f\,dx=0$ ⟹ $\displaystyle\int_0^{+\infty}f(x)\,dx=n+am$。
::note
- {{扣|直接写 $f(+\infty)=0$ 不给理由}}：填空题无所谓，大题要写「特征根实部为负」这一句，否则「两边积分」的每一项是否收敛都没交代。
- 若 $a<0$：根实部为正，$f$ 发散（一般情形），积分不存在。$a=0$：$f=m\cos x+n\sin x$ 不衰减，积分也不存在。
::vary
求 $\int_0^{+\infty}f'(x)dx$ >> $f(+\infty)-f(0)=-m$
方程改成 $f''+af'+bf=0$（$a>0,b>0$） >> 两边积分：$-n-am+b\int f=0$ ⟹ $\int_0^{+\infty}f=\frac{n+am}{b}$
方程改成 $f''+3f'+2f=0$，$f(0)=1$，$f'(0)=0$，求 $\int_0^{+\infty}f$，再用解出的 $f$ 核对 >> 公式 $\frac{0+3\cdot1}{2}=\frac32$；$f=2e^{-x}-e^{-2x}$，$\int=2-\frac12=\frac32$ ✓

「第 1、2 行：$(a,0,-1,1)$、$(0,a,1,-1)$」 >> 后两列正好相反 ⟹ {{圈|$r_1+r_2$}} 后两列变 0

::fast
{{秒|特征值}}：原矩阵 $=aE+M$，$M=\begin{pmatrix}O&C\\C&O\end{pmatrix}$，$C=\begin{pmatrix}-1&1\\1&-1\end{pmatrix}$ 的特征值是 $0,-2$ ⟹ $M$ 的特征值是 $\pm0,\pm2$，即 $0,0,2,-2$ ⟹ 行列式 $=a\cdot a\cdot(a+2)(a-2)=a^4-4a^2$。

第 2 行加到第 1 行，第 4 行加到第 3 行（行列式不变）：
$$D=\begin{vmatrix}a&a&0&0\\0&a&1&-1\\0&0&a&a\\1&-1&0&a\end{vmatrix}.$$
第 1 列的 $-1$ 倍加到第 2 列，第 3 列的 $-1$ 倍加到第 4 列：
$$D=\begin{vmatrix}a&0&0&0\\0&a&1&-2\\0&0&a&0\\1&-2&0&a\end{vmatrix}.$$

3 阶行列式按第 2 行展开：$=a\begin{vmatrix}a&-2\\-2&a\end{vmatrix}=a(a^2-4)$。

设 $X$ 服从区间 $\left(-\dfrac\pi2,\dfrac\pi2\right)$ 上的均匀分布，$Y=\sin X$，则 $\mathrm{Cov}(X,Y)=$ ________.
@ans $\dfrac2\pi$
@tpl T函数期望
::rev
- **该花** 1 分半。$EX=0$，$\mathrm{Cov}=E(X\sin X)=\frac2\pi\int_0^{\pi/2}x\sin x\,dx=\frac2\pi$。
- **卡点** 密度写成 $\frac1{2\pi}$ 或 $\frac2\pi$；分部积分 $\int x\sin x$ 符号错。
- **错了说明** 均匀分布密度＝1÷区间长度（这里是 $\frac1\pi$）；偶函数对称区间取 2 倍半边。
- **带走** $Y=g(X)$ 的协方差：$E[Xg(X)]-EX\cdot Eg(X)$，直接用 $X$ 的密度积分。
::read
「$X\sim U(-\frac\pi2,\frac\pi2)$」 >> 密度 $\frac1\pi$；区间关于 0 对称 ⟹ $EX=0$
「$Y=\sin X$」 >> $Y$ 是 $X$ 的函数，求期望不用先求 $Y$ 的分布（[[T函数期望]]）
「$\mathrm{Cov}(X,Y)$」 >> [[协方差]] $=E(XY)-EX\cdot EY$；$EX=0$ ⟹ {{圈|只要算 $E(X\sin X)$}}
「$x\sin x$」 >> [[奇偶性|奇 × 奇 = 偶]] ⟹ 对称区间上 = 2 倍半边积分
::fast
{{秒|$\int_0^{\pi/2}x\sin x\,dx=[\sin x-x\cos x]_0^{\pi/2}=1$}} ⟹ $\mathrm{Cov}=\frac2\pi\times1=\frac2\pi$。
::steps
$X$ 的密度 $f(x)=\frac1\pi$，$-\frac\pi2<x<\frac\pi2$。$EX=0$（区间对称）。
$\mathrm{Cov}(X,Y)=E(XY)-EX\cdot EY=E(X\sin X)$。
$E(X\sin X)=\displaystyle\int_{-\pi/2}^{\pi/2}x\sin x\cdot\frac1\pi\,dx=\frac2\pi\int_0^{\pi/2}x\sin x\,dx$（$x\sin x$ 是偶函数）。
分部积分：$\int x\sin x\,dx=-x\cos x+\int\cos x\,dx=-x\cos x+\sin x$。
$\int_0^{\pi/2}x\sin x\,dx=\left[-x\cos x+\sin x\right]_0^{\pi/2}=(0+1)-(0+0)=1$。
所以 $\mathrm{Cov}(X,Y)=\frac2\pi$。
::note
- 符号核对：$\sin$ 在区间上单调增，$X$、$Y$ 正相关 ⟹ 协方差应为正 ✓。
- 另一个常考版本：$Y=\cos X$ ⟹ $x\cos x$ 是奇函数，协方差为 0，但 $Y$ 由 $X$ 完全决定，**不相关 ≠ 独立**。
::vary

对 $C_\varepsilon$ 围成的椭圆域 $D_\varepsilon$ 用格林：$\oint_{C_\varepsilon}(4x-y)dx+(x+y)dy=\iint_{D_\varepsilon}\big[1-(-1)\big]dxdy=2\cdot S_{D_\varepsilon}$。

$I=\dfrac1{\varepsilon^2}\cdot2\cdot\dfrac{\pi\varepsilon^2}{2}=\pi$。
::paper
解　记 $P=\dfrac{4x-y}{4x^2+y^2}$，$Q=\dfrac{x+y}{4x^2+y^2}$. 当 $(x,y)\ne(0,0)$ 时，
$$\frac{\partial Q}{\partial x}=\frac{y^2-4x^2-8xy}{(4x^2+y^2)^2}=\frac{\partial P}{\partial y}.\qquad(1)$$ ⛳3
取 $L_\varepsilon:4x^2+y^2=\varepsilon^2$，逆时针方向，$0<\varepsilon<1$，则 $L_\varepsilon$ 位于 $L$ 内部. 记 $L$ 与 $L_\varepsilon$ 所围区域为 $D_1$，由格林公式及 (1)，
$$\oint_L P\,dx+Q\,dy-\oint_{L_\varepsilon}P\,dx+Q\,dy=\iint_{D_1}\Big(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\Big)dxdy=0.$$ ⛳3
于是
$$I=\oint_{L_\varepsilon}\frac{(4x-y)\,dx+(x+y)\,dy}{4x^2+y^2}=\frac1{\varepsilon^2}\oint_{L_\varepsilon}(4x-y)\,dx+(x+y)\,dy.$$ ⛳1
记 $D_\varepsilon:4x^2+y^2\le\varepsilon^2$，再由格林公式，
$$I=\frac1{\varepsilon^2}\iint_{D_\varepsilon}2\,dxdy=\frac{2}{\varepsilon^2}\cdot\frac{\pi\varepsilon^2}{2}=\pi.$$ ⛳3
::note
- {{扣|直接对圆盘用格林得 0}}：原点是奇点，$P$、$Q$ 在圆盘上偏导不连续，格林公式的条件不满足。这是最常见的 0 分写法。
- {{扣|挖圆 $x^2+y^2=\varepsilon^2$}}：方法没错，但分母不是常数，要用极坐标硬积 $\int_0^{2\pi}\frac{\cdots}{4\cos^2\theta+\sin^2\theta}d\theta$，很难算完。
- 卷面上「$\varepsilon$ 足够小使 $L_\varepsilon$ 在 $L$ 内部」必须写，它是用格林的前提。
::vary
若 $L$ 改为 $(x-2)^2+y^2=1$（逆时针） >> 不包含原点，环内 $Q_x=P_y$，直接格林得 $I=0$
把 $P$、$Q$ 的分子改成 $-y$、$x$（分母不变） >> $\frac1{\varepsilon^2}\oint x\,dy-y\,dx=\frac1{\varepsilon^2}\cdot2\cdot\frac{\pi\varepsilon^2}{2}=\pi$（仍需先验 $Q_x=P_y$ 成立）
问 $\oint_L$ 与路径的关系 >> 绕原点一圈（逆时针）的任意分段光滑闭曲线积分都等于 $\pi$；不绕原点的都等于 0

「证明 $Y\sim N(0,1)$」 >> 由联合分布函数取 $x\to+\infty$ 得边缘，或直接对 $Y$ 全概率

（Ⅰ）$F(x,y)=P\{X_1\le x,Y\le y\}$。由全概率公式：
$$F(x,y)=P\{X_3=0\}P\{X_1\le x,Y\le y\mid X_3=0\}+P\{X_3=1\}P\{X_1\le x,Y\le y\mid X_3=1\}.$$
$X_3=0$ 时 $Y=X_2$：$P\{X_1\le x,Y\le y\mid X_3=0\}=P\{X_1\le x,X_2\le y\mid X_3=0\}$。
  $(X_1,X_2)$ 与 $X_3$ 独立 ⟹ 条件可去：$=P\{X_1\le x,X_2\le y\}=P\{X_1\le x\}P\{X_2\le y\}=\Phi(x)\Phi(y)$。
$X_3=1$ 时 $Y=X_1$：$P\{X_1\le x,X_1\le y\mid X_3=1\}=P\{X_1\le\min\{x,y\}\}=\Phi(\min\{x,y\})$。
代入：$F(x,y)=\frac12\Phi(x)\Phi(y)+\frac12\Phi(\min\{x,y\})$。
写成分段：$F(x,y)=\begin{cases}\frac12\Phi(x)+\frac12\Phi(x)\Phi(y),&x\lt y,\\[2pt]\frac12\Phi(y)+\frac12\Phi(x)\Phi(y),&x\ge y.\end{cases}$
（Ⅱ）$Y$ 的分布函数 $F_Y(y)=\lim\limits_{x\to+\infty}F(x,y)$。$x\to+\infty$ 时 $\Phi(x)\to1$，且 $x>y$ 后 $\min\{x,y\}=y$。
$F_Y(y)=\frac12\cdot1\cdot\Phi(y)+\frac12\Phi(y)=\Phi(y)$ ⟹ $Y\sim N(0,1)$。
~直接法：$P\{Y\le y\}=\frac12P\{X_2\le y\}+\frac12P\{X_1\le y\}=\Phi(y)$，一行写完。
::paper
解　（Ⅰ）由全概率公式及 $X_1,X_2,X_3$ 相互独立，
$$\begin{aligned}F(x,y)&=P\{X_1\le x,Y\le y\}\\&=P\{X_3=0\}P\{X_1\le x,X_2\le y\mid X_3=0\}+P\{X_3=1\}P\{X_1\le x,X_1\le y\mid X_3=1\}\end{aligned}$$ ⛳3
$$=\frac12P\{X_1\le x\}P\{X_2\le y\}+\frac12P\{X_1\le\min\{x,y\}\}$$ ⛳2
$$=\frac12\Phi(x)\Phi(y)+\frac12\Phi(\min\{x,y\}).$$ ⛳2
（Ⅱ）证　$Y$ 的分布函数为
$$F_Y(y)=\lim_{x\to+\infty}F(x,y)=\frac12\Phi(y)+\frac12\Phi(y)=\Phi(y),$$ ⛳3
故 $Y$ 服从标准正态分布. ⛳1
::note
- {{扣|$X_3=1$ 那支写成 $\Phi(x)\Phi(y)$}}：把 $X_1$ 当成两个独立变量，最常见的错误。同一个 $X_1$ 两个条件只能取交集 $\{X_1\le\min\}$。
- {{扣|不说明「独立所以条件可去」}}：$P\{X_1\le x,X_2\le y\mid X_3=0\}=P\{X_1\le x,X_2\le y\}$ 用的是 $(X_1,X_2)$ 与 $X_3$ 独立，要点名。
- $(X_1,Y)$ 不是二维正态（$F$ 里有 $\min$，在 $x=y$ 这条线上有概率质量 $\frac12$），但两个边缘都是标准正态——经典的「边缘正态 ⇏ 联合正态」例子。
::vary
求 $\mathrm{Cov}(X_1,Y)$ >> $E(X_1Y)=\frac12E(X_1^2)+\frac12E(X_1X_2)=\frac12$，$EX_1=EY=0$ ⟹ $\frac12$
求 $P\{X_1=Y\}$ >> $X_3=1$ 时必相等，$X_3=0$ 时 $P\{X_1=X_2\}=0$ ⟹ $\frac12$
若 $P\{X_3=1\}=p$，$Y$ 还服从 $N(0,1)$ 吗 >> 是：$F_Y=p\Phi+(1-p)\Phi=\Phi$，与 $p$ 无关

#23
@stem
（本题满分 11 分）设某元件的使用寿命 $T$ 的分布函数为 $F(t)=\begin{cases}1-e^{-\left(\frac t\theta\right)^m},&t\ge0,\\0,&\text{其他},\end{cases}$ 其中 $\theta,m$ 为参数且大于零.
（Ⅰ）求概率 $P\{T>t\}$ 与 $P\{T>s+t\mid T>s\}$，其中 $s>0,t>0$；
（Ⅱ）任取 $n$ 个这种元件做寿命试验，测得它们的寿命分别为 $t_1,t_2,\cdots,t_n$，若 $m$ 已知，求 $\theta$ 的最大似然估计值 $\hat\theta$.
@tpl T最大似然
::rev
- **该花** 10 分钟。（Ⅰ）3 分钟，（Ⅱ）7 分钟。
- **卡点** 似然函数用分布函数 $F$ 连乘；对 $\theta$ 求导时 $\theta^{-m}$ 的符号错。
- **错了说明** 连续型的似然是密度连乘，要先对 $F$ 求导得密度。
- **带走** 条件概率直接用 $\frac{1-F(s+t)}{1-F(s)}$；MLE 四步后得 $\hat\theta=\left(\frac1n\sum t_i^m\right)^{1/m}$。
::read
「$F(t)=1-e^{-(t/\theta)^m}$」 >> 威布尔分布；$m=1$ 时就是[[指数分布]]（参数 $\frac1\theta$）
「$P\{T>t\}$」 >> $=1-F(t)$，直接读出来 $e^{-(t/\theta)^m}$
「$P\{T>s+t\mid T>s\}$」 >> [[条件概率]]：$\{T>s+t\}\subset\{T>s\}$ ⟹ 分子的交集就是 $\{T>s+t\}$
「$m$ 已知，求 $\theta$ 的最大似然估计」 >> [[T最大似然]] 四步；连续型要{{圈|先求密度}} $f=F'$
「$t_1,\dots,t_n$，估计值」 >> 用小写 $t_i$ 写成估计值；分布只在 $t\gt0$ 上有密度，样本值都为正
::steps
（Ⅰ）$t>0$ 时 $P\{T>t\}=1-F(t)=e^{-\left(\frac t\theta\right)^m}$。
$\{T>s+t\}\subset\{T>s\}$，所以 $P\{T>s+t,T>s\}=P\{T>s+t\}$。
$P\{T>s+t\mid T>s\}=\dfrac{P\{T>s+t\}}{P\{T>s\}}=\dfrac{e^{-\left(\frac{s+t}\theta\right)^m}}{e^{-\left(\frac s\theta\right)^m}}=e^{\left(\frac s\theta\right)^m-\left(\frac{s+t}\theta\right)^m}$。
（Ⅱ）密度：$t>0$ 时 $f(t)=F'(t)=e^{-\left(\frac t\theta\right)^m}\cdot m\left(\frac t\theta\right)^{m-1}\cdot\frac1\theta=\dfrac{m}{\theta^m}t^{m-1}e^{-\left(\frac t\theta\right)^m}$；$t\le0$ 时 $f(t)=0$。
似然函数（$t_i>0$）：$L(\theta)=\prod\limits_{i=1}^n\dfrac{m}{\theta^m}t_i^{m-1}e^{-\left(\frac{t_i}\theta\right)^m}=\dfrac{m^n}{\theta^{mn}}\Big(\prod\limits_{i=1}^nt_i\Big)^{m-1}e^{-\frac1{\theta^m}\sum\limits_{i=1}^nt_i^m}$。
取对数：$\ln L=n\ln m-mn\ln\theta+(m-1)\sum\limits_{i=1}^n\ln t_i-\theta^{-m}\sum\limits_{i=1}^nt_i^m$。
对 $\theta$ 求导：$\dfrac{d\ln L}{d\theta}=-\dfrac{mn}{\theta}+m\theta^{-m-1}\sum\limits_{i=1}^nt_i^m$。
  $\frac{d}{d\theta}\theta^{-m}=-m\theta^{-m-1}$，前面有负号，所以是 $+m\theta^{-m-1}\sum t_i^m$。
令其为 0：$\dfrac{mn}{\theta}=\dfrac{m}{\theta^{m+1}}\sum t_i^m$ ⟹ $\theta^m=\dfrac1n\sum\limits_{i=1}^nt_i^m$ ⟹ $\hat\theta=\Big(\dfrac1n\sum\limits_{i=1}^nt_i^m\Big)^{\frac1m}$。
~确认是最大值：$\theta$ 小于该值时导数 $>0$，大于时 $<0$，唯一驻点就是最大值点。
::paper
解　（Ⅰ）$P\{T>t\}=1-F(t)=e^{-\left(\frac t\theta\right)^m}$， ⛳2
$$P\{T>s+t\mid T>s\}=\frac{P\{T>s+t,\,T>s\}}{P\{T>s\}}=\frac{P\{T>s+t\}}{P\{T>s\}}=e^{\left(\frac s\theta\right)^m-\left(\frac{s+t}\theta\right)^m}.$$ ⛳3
（Ⅱ）$T$ 的概率密度为 $f(t)=\begin{cases}\dfrac{mt^{m-1}}{\theta^m}e^{-\left(\frac t\theta\right)^m},&t>0,\\0,&\text{其他}.\end{cases}$ ⛳1
似然函数为（$t_i>0$）
$$L(\theta)=\prod_{i=1}^n\frac{mt_i^{m-1}}{\theta^m}e^{-\left(\frac{t_i}\theta\right)^m}=\frac{m^n}{\theta^{mn}}\Big(\prod_{i=1}^nt_i\Big)^{m-1}e^{-\frac1{\theta^m}\sum_{i=1}^nt_i^m},$$ ⛳1
$$\ln L(\theta)=n\ln m-mn\ln\theta+(m-1)\sum_{i=1}^n\ln t_i-\frac1{\theta^m}\sum_{i=1}^nt_i^m.$$ ⛳1
令 $\dfrac{d\ln L}{d\theta}=-\dfrac{mn}{\theta}+\dfrac{m}{\theta^{m+1}}\sum\limits_{i=1}^nt_i^m=0$， ⛳1
得 $\theta$ 的最大似然估计值
$$\hat\theta=\Big(\frac1n\sum_{i=1}^nt_i^m\Big)^{\frac1m}.$$ ⛳2
::note
- {{扣|似然函数直接用分布函数 $F$ 连乘}}：连续型要用密度。
- {{扣|求导时 $\theta^{-m}$ 的导数符号}}：$-\theta^{-m}\sum t_i^m$ 求导是 $+m\theta^{-m-1}\sum t_i^m$，符号错了会解出负的 $\theta^m$。
- （Ⅰ）的潜台词：条件概率 $e^{(s/\theta)^m-((s+t)/\theta)^m}$ 一般**依赖 $s$**。只有 $m=1$ 时它等于 $e^{-t/\theta}=P\{T>t\}$（无记忆性）；$m>1$ 时随 $s$ 增大而减小（越用越容易坏），$m<1$ 时随 $s$ 增大而增大（「磨合期」）。
- 题目说「估计值」，用小写 $t_i$；若说「估计量」，要写成大写 $T_i$。
::vary
求 $\theta^m$ 的最大似然估计 >> 由不变性，$\widehat{\theta^m}=\frac1n\sum t_i^m$
$m=2$ 时求 $P\{T>s+t\mid T>s\}$，并说明它比 $P\{T>t\}$ 大还是小 >> $e^{-\frac{2st+t^2}{\theta^2}}\lt e^{-\frac{t^2}{\theta^2}}$，更小——用过 $s$ 时间的元件更容易在接下来 $t$ 时间内坏
