#1
@stem
下列曲线中有渐近线的是（　）.
@A $y=x+\sin x$
@B $y=x^2+\sin x$
@C $y=x+\sin\dfrac1x$
@D $y=x^2+\sin\dfrac1x$
@ans C
@tpl T渐近线三查
::read
「有渐近线」 >> 三类都要查：{{圈|铅直、水平、斜}}（[[T渐近线三查]]）。四条曲线都在整条实轴（或除 0 外）上有定义、没有往 $\infty$ 冲的点，铅直渐近线基本可以先放一边
「$\sin x$、$\sin\frac1x$」 >> 都是{{波|有界}}的「小尾巴」：$|\sin|\le1$，它们决定不了曲线往不往 $\infty$ 冲，只决定 $y-kx$ 有没有极限
「$x+\cdots$」与「$x^2+\cdots$」 >> 主项是 $x^2$ 的 B、D：$\frac yx\to\infty$，斜率都没有 ⟹ 不可能有斜渐近线，也没有水平渐近线；B、D 先划掉
「$\sin x$ vs $\sin\frac1x$」 >> $x\to\infty$ 时 $\sin x$ {{圈|来回振荡没有极限}}，$\sin\frac1x\to\sin0=0$ ⟹ A 的截距不存在，C 的截距是 0
::sk 380 215 看 | $y=x+\sin\frac1x$（黑）在两头贴向 $y=x$（红虚线）；$x\to0$ 时 $\sin\frac1x$ 只在 $[-1,1]$ 里抖，不冲向 ∞，所以没有铅直渐近线
ox,oy=190,108;X=lambda x:ox+x*40;Y=lambda y:oy-y*19
s.axes(ox,oy,14,368,205,8,xl='x',yl='y')
s.line(X(-4.2),Y(-4.2),X(4.2),Y(4.2),'r',1.2,dash='5 4')
s.plot(lambda x:x+math.sin(1/x),0.42,4.2,X,Y,n=14)
s.plot(lambda x:x+math.sin(1/x),-4.2,-0.42,X,Y,n=14)
s.line(X(-0.4),Y(0.6),X(0.4),Y(-0.6),'p',0.7,dash='2 3')
s.text(X(3.6),Y(2.4),'y=x',11,'r','middle')
s.text(X(1.2),Y(-2.2),'x→∞：sin(1/x)→0',10,'r')
s.text(X(-0.3),Y(3.2),'0 附近只在 ±1 内抖',10,'p','end')
s.arrow(X(-1.6),Y(2.9),X(-0.15),Y(0.9),'p',0.8)
::think
1. 主项是 $x^2$ 的 B、D：$\lim\frac yx=\infty$，没有斜渐近线；$y\to\infty$，没有水平渐近线；$x\to0$ 时 $\sin\frac1x$ 有界，没有铅直渐近线 ⟹ 排除。
2. A：$k=\lim\frac{x+\sin x}x=1$，但 $b=\lim(y-x)=\lim\sin x$ 不存在 ⟹ 无斜渐近线；也无水平、铅直 ⟹ 排除。
3. C：$k=\lim\frac{x+\sin\frac1x}{x}=1$，$b=\lim\sin\frac1x=0$ ⟹ 斜渐近线 $y=x$，选 C。
::fast
{{秒|「主项 + 有界尾巴」型}}：$y=kx+(\text{尾巴})$ 有斜渐近线 ⟺ 尾巴在 $x\to\infty$ 时有极限。$\sin x$ 没有、$\sin\frac1x\to0$ 有 ⟹ 只有 C。B、D 主项是 $x^2$，连斜率都没有。
::steps
渐近线三类：铅直（某点处 $y\to\infty$）、水平（$x\to\infty$ 时 $y\to$ 常数）、斜（$k=\lim\frac yx\ne0$、$b=\lim(y-kx)$ 都存在）（[[渐近线]]）。
**A** $y=x+\sin x$：在 $\mathbb R$ 上连续，无铅直渐近线；$x\to\pm\infty$ 时 $y\to\pm\infty$，无水平渐近线。
  $k=\lim\limits_{x\to\infty}\frac{x+\sin x}{x}=1+\lim\frac{\sin x}x=1$；$b=\lim\limits_{x\to\infty}(y-x)=\lim\sin x$ 不存在 ⟹ 无斜渐近线。A 没有任何渐近线。
**B** $y=x^2+\sin x$：连续，无铅直；$y\to+\infty$，无水平；$\frac yx=x+\frac{\sin x}x\to\infty$，无斜。没有渐近线。
**C** $y=x+\sin\frac1x$（$x\ne0$）：$x\to0$ 时 $|\sin\frac1x|\le1$，$y$ 有界，{{注|不是 ∞}} ⟹ $x=0$ 不是铅直渐近线。
  $k=\lim\limits_{x\to\infty}\frac{x+\sin\frac1x}{x}=1+\lim\frac{\sin\frac1x}{x}=1+0=1$。
  $b=\lim\limits_{x\to\infty}(y-x)=\lim\sin\frac1x=\sin0=0$ ⟹ 斜渐近线 $y=x$（$x\to\pm\infty$ 两侧都是）。
**D** $y=x^2+\sin\frac1x$：$x\to0$ 时有界，无铅直；$\frac yx\to\infty$，无斜；$y\to+\infty$，无水平。没有渐近线。
只有 C 有渐近线，选 **C**。
::note
- {{扣|看到 $\sin\frac1x$ 在 $x=0$ 无定义就以为有铅直渐近线}}：铅直渐近线要 $y\to\infty$，$\sin\frac1x$ 在 0 附近剧烈振荡但始终在 $[-1,1]$ 里，不算。
- {{扣|算出 A 的 $k=1$ 就以为有斜渐近线}}：斜渐近线要 $k$ 和 $b$ **两个**极限都存在，$b$ 往往才是关键。
- 提速：主项是 $x^n$（$n\ge2$）的曲线，水平、斜渐近线一律没有，只剩铅直可查。
- 跨章：$\sin x$ 与 $\sin\frac1x$ 一个在无穷远振荡、一个在 0 附近振荡，是「极限不存在」的两个标准反例（[[T举反例]]）。
::vary
$y=x\sin\frac1x$ 有哪些渐近线 >> $x\to\infty$ 时 $x\sin\frac1x\to1$ ⟹ 水平渐近线 $y=1$；0 附近有界，无铅直
$y=x+\arctan x$ 的斜渐近线 >> $k=1$，$b=\lim\arctan x=\pm\frac\pi2$ ⟹ 两条：$y=x+\frac\pi2$（$x\to+\infty$）与 $y=x-\frac\pi2$（$x\to-\infty$）
$y=x+\frac{\sin x}{x}$ 有斜渐近线吗 >> 有：$b=\lim\frac{\sin x}x=0$ ⟹ $y=x$；和 A 的区别是尾巴被 $\frac1x$ 压到 0
$y=\frac1x+\sin x$ 的渐近线 >> 铅直 $x=0$（$\frac1x\to\infty$）；无穷远 $\sin x$ 振荡，无水平、无斜

#2
@stem
设函数 $f(x)$ 具有 2 阶导数，$g(x)=f(0)(1-x)+f(1)x$，则在区间 $[0,1]$ 上（　）.
@A 当 $f'(x)\ge0$ 时，$f(x)\ge g(x)$
@B 当 $f'(x)\ge0$ 时，$f(x)\le g(x)$
@C 当 $f''(x)\ge0$ 时，$f(x)\ge g(x)$
@D 当 $f''(x)\ge0$ 时，$f(x)\le g(x)$
@ans D
@tpl T凹弦下方, T举反例
::read
「$g(x)=f(0)(1-x)+f(1)x$」 >> 一次函数，$g(0)=f(0)$、$g(1)=f(1)$ ⟹ {{圈|连接两端点的弦}}；这是本题唯一要「认」出来的东西
「在区间 $[0,1]$ 上」 >> 比较曲线与弦谁上谁下，正是凹凸性的几何意义（[[凹凸性]]）
「$f'\ge0$」 >> 只说单调递增，决定不了曲线与弦的位置——递增的曲线可以鼓起来（在弦上方），也可以凹下去（在弦下方）⟹ A、B 都能用反例打掉（[[T举反例]]）
「$f''\ge0$」 >> 凹（碗口朝上）⟹ 画一个碗，连两端，曲线在弦{{波|下方}}（[[T凹弦下方]]）⟹ D
::sk 360 200 画 | 碗形曲线（$f''\ge0$）与它的弦：中间每一处都是曲线在下、弦在上，$F=f-g\le0$
ox,oy=50,178;X=lambda x:ox+x*260;Y=lambda y:oy-y*190
s.axes(ox,oy,20,345,190,10,xl='x',yl='y')
f=lambda x:0.25+1.3*(x-0.4)**2
s.plot(f,-0.05,1.08,X,Y,n=10)
s.line(X(0),Y(f(0)),X(1),Y(f(1)),'r',1.3)
s.dot(X(0),Y(f(0)),2.6,'k');s.dot(X(1),Y(f(1)),2.6,'k')
s.text(X(0)+6,Y(f(0))-8,'(0, f(0))',10,'k');s.text(X(1)+6,Y(f(1))+4,'(1, f(1))',10,'k')
s.text(X(0.55),Y(f(0)+(f(1)-f(0))*0.55)-8,'弦 y=g(x)',11,'r','middle')
s.text(X(0.42),Y(f(0.42))+18,'y=f(x)，f″≥0',11,'k','middle')
for xx in (0.25,0.45,0.7):
    s.line(X(xx),Y(f(xx)),X(xx),Y(f(0)+(f(1)-f(0))*xx),'b',0.9,dash='2 3')
s.text(X(0.62),Y(0.2),'f−g≤0',10,'b','middle')
s.line(X(1),oy,X(1),Y(f(1)),'p',0.7,dash='2 3');s.text(X(1),oy+14,'1',10,'k','middle')
::think
1. 认出 $g$ 是弦。
2. $f''\ge0$ ⟹ 凹函数 ⟹ 曲线在弦下方 ⟹ $f\le g$，选 D。
3. 严格证：令 $F=f-g$，$F(0)=F(1)=0$，$F''=f''\ge0$，凹函数两端为 0，中间不超过 0。
::fast
{{秒|特例代入}}：取 $f(x)=x^2$（$f'\ge0$、$f''\ge0$ 都满足）：$g(x)=x$，在 $[0,1]$ 上 $x^2\le x$ ⟹ A、C 错（它们说 $f\ge g$）。
再取 $f(x)=\sqrt{x+1}$ 之类的上凸递增函数，$f'\ge0$ 但曲线在弦上方 ⟹ B 错。只剩 D。
::steps
$g$ 是一次函数，且 $g(0)=f(0)$、$g(1)=f(1)$ ⟹ $y=g(x)$ 是连接 $(0,f(0))$ 与 $(1,f(1))$ 的直线段（弦）。
令 $F(x)=f(x)-g(x)$，则 $F(0)=F(1)=0$，$F''(x)=f''(x)-0=f''(x)$（$g$ 是一次函数，二阶导为 0）。
**看 D**：设 $f''\ge0$，则 $F''\ge0$，$F'$ 单调不减。对任意 $x\in(0,1)$，由[[拉格朗日中值定理]]：
  $F(x)-F(0)=F'(\xi_1)x$，$\xi_1\in(0,x)$；$F(1)-F(x)=F'(\xi_2)(1-x)$，$\xi_2\in(x,1)$。
  因 $F(0)=F(1)=0$：$F(x)=F'(\xi_1)x$，$-F(x)=F'(\xi_2)(1-x)$。
  $\xi_1\lt\xi_2$ 且 $F'$ 不减 ⟹ $F'(\xi_1)\le F'(\xi_2)$ ⟹ $\frac{F(x)}{x}\le\frac{-F(x)}{1-x}$ ⟹ $F(x)\left(\frac1x+\frac1{1-x}\right)\le0$ ⟹ $F(x)\le0$。
  所以 $f(x)\le g(x)$，D 对；C 与 D 相反，取 $f=x^2$ 时 $x^2\ge x$ 在 $(0,1)$ 不成立 ⟹ C 错。
**看 A、B**：$f(x)=x^2$，$f'=2x\ge0$，$f\le g$ ⟹ A 错；$f(x)=2x-x^2$，$f'=2-2x\ge0$，$g(x)=x$，$f-g=x(1-x)\ge0$ ⟹ B 错。
选 **D**。
::note
- {{扣|看到 $f'\ge0$ 就选 A}}：单调性只管「从左到右往上走」，管不了「弯向哪边」。本题的 A、B 是专门给只记住「导数正 ⟹ 大」的人准备的。
- 图像记忆：$f''\ge0$ 是「碗」（凹，也叫下凸），碗里装水，水面（弦）在碗壁上方。教材叫法不统一，**卷面上一律写 $f''\ge0$ 而不写「凹/凸」**，免得叫法反了。
- 更一般的结论：$f''\ge0$ ⟹ $f(\lambda a+(1-\lambda)b)\le\lambda f(a)+(1-\lambda)f(b)$（琴生不等式），本题就是 $a=0,b=1,\lambda=1-x$。
- 证明题版本常要求写 $F''\ge0$ + 两次拉格朗日（如上），或者用「$F$ 在 $[0,1]$ 上的最大值只能在端点取」。
::vary
若改成 $f''(x)\le0$，则 >> 曲线在弦上方，$f(x)\ge g(x)$
若 $g$ 改成切线 $g(x)=f(0)+f'(0)x$，$f''\ge0$ 时 >> 凹函数在切线上方：$f(x)\ge g(x)$（泰勒：$f(x)=f(0)+f'(0)x+\frac{f''(\xi)}2x^2$）
证明：$f''\gt0$ 时 $f\left(\frac{a+b}2\right)\lt\frac{f(a)+f(b)}2$ >> $F=f-$弦，中点处 $F\lt0$；或在中点泰勒：$f(a)+f(b)=2f(m)+\frac{f''(\xi_1)+f''(\xi_2)}2\left(\frac{b-a}2\right)^2\gt2f(m)$
$f(x)=e^x$ 在 $[0,1]$ 上与弦比较 >> $e^x\le1+(e-1)x$（$f''\gt0$，曲线在弦下）

#3
@stem
设 $f(x,y)$ 是连续函数，则 $\displaystyle\int_0^1dy\int_{-\sqrt{1-y^2}}^{1-y}f(x,y)\,dx=$（　）.
@A $\displaystyle\int_0^1dx\int_0^{x-1}f(x,y)\,dy+\int_{-1}^0dx\int_0^{\sqrt{1-x^2}}f(x,y)\,dy$
@B $\displaystyle\int_0^1dx\int_0^{1-x}f(x,y)\,dy+\int_{-1}^0dx\int_{-\sqrt{1-x^2}}^0f(x,y)\,dy$
@C $\displaystyle\int_0^{\frac\pi2}d\theta\int_0^{\frac1{\cos\theta+\sin\theta}}f(r\cos\theta,r\sin\theta)\,dr+\int_{\frac\pi2}^{\pi}d\theta\int_0^1f(r\cos\theta,r\sin\theta)\,dr$
@D $\displaystyle\int_0^{\frac\pi2}d\theta\int_0^{\frac1{\cos\theta+\sin\theta}}f(r\cos\theta,r\sin\theta)\,r\,dr+\int_{\frac\pi2}^{\pi}d\theta\int_0^1f(r\cos\theta,r\sin\theta)\,r\,dr$
@ans D
@tpl T换序先画域, T极坐标直线边界
::read
「$\int_0^1dy$」 >> 外层：$y$ 从 0 到 1，区域夹在两条水平线 $y=0$、$y=1$ 之间
「$x$ 从 $-\sqrt{1-y^2}$ 到 $1-y$」 >> 左边界 $x=-\sqrt{1-y^2}$ ⟹ $x^2+y^2=1$ 的{{圈|左半圆}}；右边界 $x=1-y$ ⟹ 直线 $x+y=1$。**先画图**（[[T换序先画域]]）
「区域」 >> 左边是第二象限的四分之一圆盘，右边是第一象限里 $x+y\le1$ 的三角形，两块以 $y$ 轴为界
「A、B 是直角坐标换序」 >> 先对 $y$ 积：$x\in[0,1]$ 时 $y$ 从 0 到 $1-x$；$x\in[-1,0]$ 时 $y$ 从 0 到 $\sqrt{1-x^2}$。A 的上限写成 $x-1$（{{波|负的}}），B 的第二块写成下半圆——都错
「C、D 是极坐标」 >> 差别只在 {{圈|有没有 $r$}}：$dxdy=r\,drd\theta$，C 漏了 $r$ ⟹ 选 D
::sk 340 190 画 | 原积分的区域：左边四分之一圆 + 右边三角形。极坐标射线在第一象限碰到直线 $x+y=1$，在第二象限碰到圆 $r=1$
ox,oy=170,160;X=lambda x:ox+x*120;Y=lambda y:oy-y*120
s.axes(ox,oy,24,330,182,14,xl='x',yl='y')
arc=[(X(math.cos(t)),Y(math.sin(t))) for t in [math.pi/2+i*math.pi/16 for i in range(9)]]
s.poly(arc,'k',1.4)
s.line(X(0),Y(1),X(1),Y(0),'k',1.4)
s.hatch([(X(0),Y(0)),(X(0),Y(1))]+arc[1:]+[(X(-1),Y(0))],gap=7,c='p')
s.hatch([(X(0),Y(0)),(X(1),Y(0)),(X(0),Y(1))],gap=7,c='p')
t1=0.5;r1=1/(math.cos(t1)+math.sin(t1))
s.line(ox,oy,X(r1*math.cos(t1)),Y(r1*math.sin(t1)),'r',1.2);s.dot(X(r1*math.cos(t1)),Y(r1*math.sin(t1)),2.4,'r')
s.text(X(0.75),Y(0.5),'r=1/(cosθ+sinθ)',10,'r')
t2=2.3;s.line(ox,oy,X(math.cos(t2)),Y(math.sin(t2)),'b',1.2);s.dot(X(math.cos(t2)),Y(math.sin(t2)),2.4,'b')
s.text(X(-0.98),Y(0.9),'r=1',11,'b')
s.text(X(1),oy+14,'1',10,'k','middle');s.text(X(-1),oy+14,'−1',10,'k','middle');s.text(ox-6,Y(1)+4,'1',10,'k','end')
s.text(X(0.62),Y(0.12),'x+y=1',10,'k')
::think
1. 画出区域：$\{0\le y\le1,\ -\sqrt{1-y^2}\le x\le1-y\}$ = 第二象限单位四分之一圆 ∪ 第一象限三角形。
2. 直角坐标换序：两块分别 $\int_0^1dx\int_0^{1-x}$、$\int_{-1}^0dx\int_0^{\sqrt{1-x^2}}$ ⟹ A（上限 $x-1$）、B（下半圆）都不对。
3. 极坐标：$\theta\in[0,\frac\pi2]$ 时射线出口是直线 $r=\frac1{\cos\theta+\sin\theta}$；$\theta\in[\frac\pi2,\pi]$ 时出口是圆 $r=1$；面积元 $r\,dr\,d\theta$ ⟹ D。
::fast
{{秒|只看 $r$}}：C、D 的上下限一模一样，区别只有 $r\,dr$ 与 $dr$；极坐标面积元必带 $r$ ⟹ C 错。
A 的 $\int_0^{x-1}$ 在 $x\in(0,1)$ 时上限为负（从 0 积到负数），B 的 $-\sqrt{1-x^2}$ 到 0 是下半圆，与 $y\ge0$ 矛盾 ⟹ 选 D。
::steps
外层 $0\le y\le1$；内层 $x$ 从左边界 $x=-\sqrt{1-y^2}$（即 $x^2+y^2=1$，$x\le0$）走到右边界 $x=1-y$（直线 $x+y=1$）。
  区域 $D=D_1\cup D_2$：$D_1=\{-1\le x\le0,\ 0\le y\le\sqrt{1-x^2}\}$（第二象限四分之一圆），$D_2=\{0\le x\le1,\ 0\le y\le1-x\}$（三角形）。
**直角坐标先 $y$ 后 $x$**：$x\in[-1,0]$ 时 $y$ 从 0 到 $\sqrt{1-x^2}$；$x\in[0,1]$ 时 $y$ 从 0 到 $1-x$。
  正确写法是 $\int_0^1dx\int_0^{1-x}f\,dy+\int_{-1}^0dx\int_0^{\sqrt{1-x^2}}f\,dy$。
  A 第一项上限 $x-1\le0$，错；B 第二项是 $y\in[-\sqrt{1-x^2},0]$（下半圆），错。
**极坐标**（[[极坐标二重积分]]）：$x=r\cos\theta$，$y=r\sin\theta$，$dx\,dy=r\,dr\,d\theta$。
  $\theta\in[0,\frac\pi2]$：射线从原点出发，出口是直线 $x+y=1$，即 $r\cos\theta+r\sin\theta=1$ ⟹ $r=\frac1{\cos\theta+\sin\theta}$（[[T极坐标直线边界]]）。
  $\theta\in[\frac\pi2,\pi]$：出口是单位圆，$r=1$。
  所以原积分等于
$$\int_0^{\frac\pi2}d\theta\int_0^{\frac1{\cos\theta+\sin\theta}}f(r\cos\theta,r\sin\theta)\,r\,dr$$
$$+\int_{\frac\pi2}^\pi d\theta\int_0^1f(r\cos\theta,r\sin\theta)\,r\,dr.$$
与 D 完全一致；C 少了因子 $r$。选 **D**。
~验算：取 $f\equiv1$，原积分 = 区域面积 $=\frac\pi4+\frac12$；D 中第一项 $=\int_0^{\pi/2}\frac{d\theta}{2(\cos\theta+\sin\theta)^2}=\frac12$，第二项 $=\frac\pi2\cdot\frac12=\frac\pi4$ ✓。
::note
- {{扣|极坐标漏写 $r$}}：这是本题唯一的「陷阱选项」C；考场上写极坐标的第一个动作就是先写 $r\,dr$。

::read
「分子是 $\int_1^x$ 的变上限积分」 >> 求导就能去掉积分号（[[变限积分求导]]）⟹ 这题注定要{{圈|洛必达}}
「分母 $x^2\ln(1+\frac1x)$」 >> $x\to+\infty$ 时 $\ln(1+\frac1x)\sim\frac1x$（[[等价无穷小]]）⟹ 分母 $\sim x$。{{波|先把分母换成 $x$ 再洛必达}}，否则对 $x^2\ln(1+\frac1x)$ 求导又臭又长（[[T极限]]：先定型、先化简，再选工具）

「满屏 $\frac1x$」 >> 洛必达之后的式子令 $t=\frac1x$ 化成 $t\to0^+$ 的泰勒（[[T倒代换]]）
::sk 360 134 列 | 洛必达后的「抵消账本」：$x^2(e^{1/x}-1)$ 展开后第一项是 $x$，正好被 $-x$ 消掉，剩下的常数 $\frac12$ 就是答案
s.cells(8,10,[['','主项','常数项','更小'],['x²(e^{1/x}−1)','x','!1/2','o(1)'],['−x','−x','0',''],['相加','!0','!1/2','→ 0']],cw=[110,70,80,70],ch=24,size=11)
s.text(8,126,'e^{1/x}=1+1/x+1/(2x²)+o(1/x²)，乘 x² 再减 x',10,'p')

1. 定型：分母 $x^2\ln(1+\frac1x)\sim x\to+\infty$；被积函数 $\to\frac12$，分子 $\to+\infty$ ⟹ $\frac\infty\infty$。
2. 分母等价替换成 $x$，再洛必达：原式 $=\lim\frac{\int_1^x[\cdots]dt}{x}=\lim[x^2(e^{1/x}-1)-x]$。
3. 令 $t=\frac1x$：$\lim_{t\to0^+}\frac{e^t-1-t}{t^2}=\frac12$。
::steps
分母：$x\to+\infty$ 时 $\frac1x\to0$，$\ln\left(1+\frac1x\right)\sim\frac1x$ ⟹ $x^2\ln\left(1+\frac1x\right)\sim x^2\cdot\frac1x=x$。
  乘积因子可以等价替换：原式 $=\lim\limits_{x\to+\infty}\frac{\int_1^x[\cdots]dt}{x}\cdot\frac{x}{x^2\ln(1+\frac1x)}$，后一个因子 $\to1$。
所以原式 $=\lim\limits_{x\to+\infty}\dfrac{\int_1^x\left[t^2\left(e^{\frac1t}-1\right)-t\right]dt}{x}$。
定型：分母 $x\to+\infty$；被积函数 $g(t)=t^2(e^{1/t}-1)-t\to\frac12$（下面算的就是这个），所以 $t$ 足够大时 $g(t)\gt\frac14$，分子 $\to+\infty$ ⟹ $\frac\infty\infty$ 型。
  {{省|严格说洛必达的 $\frac{\cdot}{\infty}$ 型只要求分母 → ∞}}，分子是否 → ∞ 不影响使用；写出来更稳。
洛必达，分子用[[变限积分求导]]：原式 $=\lim\limits_{x\to+\infty}\dfrac{x^2\left(e^{\frac1x}-1\right)-x}{1}$。
令 $t=\frac1x$，$x\to+\infty$ ⟹ $t\to0^+$：$x^2(e^{1/x}-1)-x=\dfrac{e^t-1}{t^2}-\dfrac1t=\dfrac{e^t-1-t}{t^2}$。
泰勒（[[泰勒常用]]）：$e^t=1+t+\frac{t^2}2+o(t^2)$ ⟹ $e^t-1-t=\frac{t^2}{2}+o(t^2)$ ⟹ $\lim\limits_{t\to0^+}\dfrac{e^t-1-t}{t^2}=\dfrac12$。
  ~或再洛必达一次：$\lim\frac{e^t-1}{2t}=\frac12$。
原式 $=\dfrac12$。
::paper
解　当 $x\to+\infty$ 时，$\ln\left(1+\dfrac1x\right)\sim\dfrac1x$，故 $x^2\ln\left(1+\dfrac1x\right)\sim x$，于是 ⛳2
$$\text{原式}=\lim_{x\to+\infty}\frac{\int_1^x\left[t^2\left(e^{\frac1t}-1\right)-t\right]dt}{x}.\qquad(1)$$
由于 $\lim\limits_{t\to+\infty}\left[t^2\left(e^{\frac1t}-1\right)-t\right]=\dfrac12\gt0$（见 (2) 式），(1) 式分子、分母都趋于 $+\infty$. 由洛必达法则，⛳3
$$\text{原式}=\lim_{x\to+\infty}\left[x^2\left(e^{\frac1x}-1\right)-x\right].$$
令 $t=\dfrac1x$，则 ⛳2
$$\text{原式}=\lim_{t\to0^+}\frac{e^t-1-t}{t^2}=\lim_{t\to0^+}\frac{\frac{t^2}{2}+o(t^2)}{t^2}=\frac12.\qquad(2)$$ ⛳3
::note
- {{扣|直接对原分母洛必达}}：$\left[x^2\ln(1+\frac1x)\right]'=2x\ln(1+\frac1x)-\frac{x}{x+1}$，后面还得再化，极易出错；先等价替换再洛必达是本题的「标准动作」。

{{秒|换个变量看}}：$P\{X^2\le s\}=P\{X\le\sqrt s\}=1-e^{-s/\theta}$（$s\ge0$）⟹ $X^2\sim E(\frac1\theta)$，均值 $\theta$ ⟹ $E(X^2)=\theta$ 一步得到；$\hat\theta_n$ 就是指数分布的样本均值，(Ⅲ) 也一眼看穿。
::steps
**(Ⅰ)** 密度：$f(x;\theta)=F'(x;\theta)=\begin{cases}\frac{2x}{\theta}e^{-\frac{x^2}\theta},&x\gt0,\\0,&x\le0.\end{cases}$
$E(X)=\int_0^{+\infty}x\cdot\frac{2x}{\theta}e^{-\frac{x^2}\theta}dx$。令 $t=\frac{x^2}\theta$，$x=\sqrt{\theta t}$，$dx=\frac{\sqrt\theta}{2\sqrt t}dt$，$\frac{2x^2}{\theta}=2t$：
  $E(X)=\int_0^{+\infty}2t\,e^{-t}\cdot\frac{\sqrt\theta}{2\sqrt t}dt=\sqrt\theta\int_0^{+\infty}t^{\frac12}e^{-t}dt=\sqrt\theta\,\Gamma\!\left(\tfrac32\right)=\sqrt\theta\cdot\frac{\sqrt\pi}2=\frac{\sqrt{\pi\theta}}2$（[[伽马函数]]）。
$E(X^2)=\int_0^{+\infty}x^2\cdot\frac{2x}{\theta}e^{-\frac{x^2}\theta}dx$，同一换元 $\frac{2x\,dx}{\theta}=dt$、$x^2=\theta t$：
  $E(X^2)=\int_0^{+\infty}\theta t\,e^{-t}dt=\theta\,\Gamma(2)=\theta$。
**(Ⅱ)** 设 $x_1,\dots,x_n$ 为样本观测值，似然函数
  $L(\theta)=\prod_{i=1}^nf(x_i;\theta)=\dfrac{2^n\,x_1x_2\cdots x_n}{\theta^n}e^{-\frac1\theta\sum x_i^2}$（$x_1,\dots,x_n\gt0$；否则 $L=0$）。
  $\ln L(\theta)=n\ln2+\sum_{i=1}^n\ln x_i-n\ln\theta-\frac1\theta\sum_{i=1}^nx_i^2$。
  $\frac{d\ln L}{d\theta}=-\frac n\theta+\frac{1}{\theta^2}\sum x_i^2=\frac{1}{\theta^2}\left(\sum x_i^2-n\theta\right)=0$ ⟹ $\theta=\frac1n\sum x_i^2$。
  ~极大的确认：$\theta\lt\frac1n\sum x_i^2$ 时导数 $\gt0$，之后 $\lt0$ ⟹ 唯一驻点是最大值点。
  最大似然估计量：$\hat\theta_n=\dfrac1n\sum_{i=1}^nX_i^2$（[[最大似然估计]]）。
**(Ⅲ)** $X_1,\dots,X_n$ 独立同分布 ⟹ $X_1^2,\dots,X_n^2$ 独立同分布，且 $E(X_i^2)=\theta$ 存在。
  由辛钦大数定律，$\hat\theta_n=\frac1n\sum X_i^2\xrightarrow{P}E(X_i^2)=\theta$，即对任意 $\varepsilon\gt0$，$\lim\limits_{n\to\infty}P\{|\hat\theta_n-\theta|\ge\varepsilon\}=0$。
  所以存在 $a=\theta$。

解　(Ⅰ) 总体 $X$ 的概率密度为 $f(x;\theta)=\begin{cases}\dfrac{2x}\theta e^{-\frac{x^2}\theta},&x\gt0,\\0,&x\le0.\end{cases}$ 令 $t=\dfrac{x^2}\theta$，
$$E(X)=\int_0^{+\infty}\frac{2x^2}{\theta}e^{-\frac{x^2}\theta}dx=\sqrt\theta\int_0^{+\infty}t^{\frac12}e^{-t}dt=\sqrt\theta\,\Gamma\left(\frac32\right)=\frac{\sqrt{\pi\theta}}{2},$$ ⛳2
$$E(X^2)=\int_0^{+\infty}\frac{2x^3}{\theta}e^{-\frac{x^2}\theta}dx=\theta\int_0^{+\infty}te^{-t}dt=\theta.$$ ⛳2
(Ⅱ) 设 $x_1,x_2,\cdots,x_n$ 为样本观测值，当 $x_1,\cdots,x_n\gt0$ 时，似然函数为
$$L(\theta)=\frac{2^nx_1x_2\cdots x_n}{\theta^n}e^{-\frac1\theta\sum\limits_{i=1}^nx_i^2},$$ ⛳2
$$\ln L(\theta)=n\ln2+\sum_{i=1}^n\ln x_i-n\ln\theta-\frac1\theta\sum_{i=1}^nx_i^2.$$
令 $\dfrac{d\ln L(\theta)}{d\theta}=-\dfrac n\theta+\dfrac1{\theta^2}\sum\limits_{i=1}^nx_i^2=0$，得 $\theta=\dfrac1n\sum\limits_{i=1}^nx_i^2$. ⛳2
所以 $\theta$ 的最大似然估计量为 $\hat\theta_n=\dfrac1n\sum\limits_{i=1}^nX_i^2$. ⛳1
(Ⅲ) 因为 $X_1^2,X_2^2,\cdots,X_n^2$ 独立同分布，且 $E(X_i^2)=\theta$，由辛钦大数定律，$\hat\theta_n=\dfrac1n\sum\limits_{i=1}^nX_i^2$ 依概率收敛于 $\theta$，即对任意 $\varepsilon\gt0$，$\lim\limits_{n\to\infty}P\{|\hat\theta_n-\theta|\ge\varepsilon\}=0$. 故存在 $a=\theta$. ⛳2
::note
- {{扣|(Ⅲ) 只写「存在 $a=\theta$」不写依据}}：必须点名「辛钦大数定律」并验证它的条件（独立同分布、期望存在）。用切比雪夫不等式也行：$D\hat\theta_n=\frac{D(X^2)}{n}=\frac{\theta^2}n\to0$。
- {{扣|似然函数不写 $x_i\gt0$ 的前提}}：密度在 $x\le0$ 处为 0，似然要注明取值范围。
- {{扣|估计量写成小写 $\frac1n\sum x_i^2$}}：「估计量」要用大写的随机变量 $X_i$，小写是估计值。
- (Ⅰ) 若不熟 $\Gamma$ 函数，$E(X^2)$ 可以分部积分：$\int_0^{+\infty}x^2\,d\left(-e^{-x^2/\theta}\right)=\int_0^{+\infty}2xe^{-x^2/\theta}dx=\theta$；$E(X)$ 也可分部后化成正态型积分 $\int_0^{+\infty}e^{-x^2/\theta}dx=\frac{\sqrt{\pi\theta}}2$。
::vary
$\hat\theta_n$ 是 $\theta$ 的无偏估计吗？求 $D(\hat\theta_n)$ >> $E\hat\theta_n=E(X^2)=\theta$ 无偏；$X^2$ 服从均值 $\theta$ 的指数分布，$D(X^2)=\theta^2$ ⟹ $D\hat\theta_n=\frac{\theta^2}n$
求 $\theta$ 的矩估计量 >> $\bar X=E(X)=\frac{\sqrt{\pi\theta}}2$ ⟹ $\hat\theta=\frac{4\bar X^2}{\pi}$
$X$ 的中位数 >> $1-e^{-m^2/\theta}=\frac12$ ⟹ $m=\sqrt{\theta\ln2}$
若总体是 $U(0,\theta)$，$\hat\theta=\max X_i$ 是否依概率收敛到 $\theta$ >> 是：$P\{\theta-\max X_i\ge\varepsilon\}=\left(1-\frac\varepsilon\theta\right)^n\to0$
