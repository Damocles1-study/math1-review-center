#1
@stem
若函数 $f(x)=\begin{cases}\dfrac{1-\cos\sqrt x}{ax},&x>0,\\ b,&x\le0\end{cases}$ 在 $x=0$ 处连续，则（　）.
@A $ab=\dfrac12$
@B $ab=-\dfrac12$
@C $ab=0$
@D $ab=2$
@ans A
@tpl T分段点, T极限
::read
「分段函数……在 $x=0$ 处连续」 >> $x=0$ 是分段点 ⟹ [[T分段点]]：右极限 = 左极限 = 函数值
「$x\le0$ 时 $f=b$」 >> {{圈|左边是常数}} ⟹ 左极限 $=f(0)=b$，左边不用算
「$\frac{1-\cos\sqrt x}{ax}$，$x>0$」 >> 只在右侧有定义（根号要求 $x\ge0$），所以只要右极限；$\frac00$ 型、乘除结构 ⟹ [[等价无穷小]]：$1-\cos u\sim\frac{u^2}{2}$，$u=\sqrt x$
「选项全是 $ab=$ 某数」 >> 提示右极限会算出 $\frac{1}{2a}$ 这种「含 $a$ 的分式」，和 $b$ 一乘就消掉
::think
1. 连续的定义：$\lim_{x\to0^+}f(x)=\lim_{x\to0^-}f(x)=f(0)$（[[T分段点]]）。
2. 左边常数 $b$，$f(0)=b$；右边用等价无穷小算出 $\frac{1}{2a}$。
3. 令二者相等，整理成选项的形式。
::fast
{{秒|$1-\cos\sqrt x\sim\frac{x}{2}$ ⟹ 右极限 $\frac{x/2}{ax}=\frac1{2a}$，令 $=b$ ⟹ $ab=\frac12$}}，一步选 A。
::steps
~左极限与函数值：$x\le0$ 时 $f(x)=b$，所以 $\lim_{x\to0^-}f(x)=b$，$f(0)=b$。
右极限是 $\frac00$ 型：$x\to0^+$ 时 $\sqrt x\to0$，$1-\cos\sqrt x\to0$，分母 $ax\to0$。
用[[等价无穷小]] $1-\cos u\sim\frac{u^2}{2}$（$u\to0$），这里 $u=\sqrt x$，$u^2=x$：$1-\cos\sqrt x\sim\frac x2$。
  $u^2=(\sqrt x)^2=x$，因为 $x>0$，不用加绝对值。
$\lim_{x\to0^+}\dfrac{1-\cos\sqrt x}{ax}=\lim_{x\to0^+}\dfrac{x/2}{ax}=\dfrac1{2a}$。
  题目默认 $a\ne0$（否则 $x>0$ 那段的分母恒为 0，函数没定义）。
连续 ⟹ $\frac1{2a}=b$ ⟹ $ab=\frac12$，选 **A**。
::note
- {{扣|写成 $1-\cos\sqrt x\sim\frac{(\sqrt x)^2}{2}$ 后又误写成 $\frac{x^2}{2}$}}：根号平方是 $x$ 不是 $x^2$，会得到右极限为 0、错选 C。
- 本题右侧只有 $x>0$ 才有意义，所以只需右极限；若分段函数两侧都是表达式，两侧都要算。
- 跨章：同一个等价 $1-\cos u\sim\frac{u^2}2$ 在 2018 第 1 题（$\cos\sqrt{|x|}$ 判可导）又出现了一次，那里还要看左右导数。
::vary
把 $x\le0$ 那段改成 $f(x)=b+x$，其余不变 >> 左极限仍为 $b$，答案不变：$ab=\frac12$
左段为 $b$ 且已连续，问 $f$ 在 0 处可导吗 >> 左导数 $=0$；右边用 $1-\cos u=\frac{u^2}2-\frac{u^4}{24}+o(u^4)$ 得 $f(x)-\frac1{2a}=-\frac{x}{24a}+o(x)$，右导数 $=-\frac1{24a}\ne0$ ⟹ 不可导
把分子换成 $e^{\sqrt x}-1-\sqrt x$ >> $\sim\frac{x}{2}$，右极限仍是 $\frac1{2a}$，答案仍为 $ab=\frac12$
把分子换成 $\ln(1+\sqrt x)$ >> $\sim\sqrt x$，$\frac{\sqrt x}{ax}\to\infty$，不论 $a,b$ 取何值都不连续

#2
@stem
设函数 $f(x)$ 可导，且 $f(x)f'(x)>0$，则（　）.
@A $f(1)>f(-1)$
@B $f(1)\lt f(-1)$
@C $\lvert f(1)\rvert>\lvert f(-1)\rvert$
@D $\lvert f(1)\rvert\lt\lvert f(-1)\rvert$
@ans C
@tpl T认导数, T举反例
::read
「$f(x)$ 可导」 >> 可导 ⟹ 连续，能用单调性的导数判别法
「$f(x)f'(x)>0$」 >> {{圈|$ff'=\big(\frac12f^2\big)'$}} ⟹ $f^2$ 严格单调递增（[[T认导数]]）
「$f(x)f'(x)>0$」 >> 另一层：$f$ 处处不为 0 ⟹ $f$ 连续又不变号 ⟹ 要么恒正、要么恒负；且 $f'$ 与 $f$ 同号
「A、B 比 $f$；C、D 比 $\lvert f\rvert$」 >> 不知道 $f$ 的符号，比 $f$ 本身的选项多半推不出 ⟹ 拿 $f=e^x$、$f=-e^x$ 两个例子去砸（[[T举反例]]）
::sk 320 160 画 | 两种情形：$f$ 恒正时 $f$ 增，恒负时 $f$ 减；但两种情形下 $\lvert f\rvert$ 都在变大（离 $x$ 轴越来越远）
ox,oy=160,80;X=lambda x:ox+x*90;Y=lambda y:oy-y*22
s.axes(ox,oy,20,312,150,10,xl='x',yl='')
s.plot(lambda x:math.exp(x),-1.4,1.25,X,Y,n=8,c='b')
s.plot(lambda x:-math.exp(x),-1.4,1.25,X,Y,n=8,c='r')
for xx in (-1,1):
    s.line(X(xx),Y(-math.exp(xx)),X(xx),Y(math.exp(xx)),'p',0.9,dash='3 3')
s.text(X(-1)-5,oy+14,'−1',11,'k','middle');s.text(X(1)+8,oy+14,'1',11,'k','middle')
s.text(X(1.05),Y(3.1),'f>0：f 增',11,'b')
s.text(X(1.05),Y(-3.1)+10,'f<0：f 减',11,'r')
s.text(X(-1.55),Y(1.6),'|f| 都在变大',12,'k')
::think
1. 先把条件翻译：$ff'>0$ ⟺ $(f^2)'>0$ ⟹ $f^2$ 在整条数轴上严格增。
2. $f^2(1)>f^2(-1)$，两边开方（都非负）⟹ $\lvert f(1)\rvert>\lvert f(-1)\rvert$，就是 C。
3. 再用两个反例说明 A、B 都不一定成立。
::fast
{{秒|$f=e^x$ 满足 $ff'=e^{2x}>0$：$f(1)>f(-1)$，否掉 B、D；$f=-e^x$ 也满足：$f(1)\lt f(-1)$，否掉 A}} ⟹ 只剩 C。
::steps
令 $F(x)=f^2(x)$，则 $F'(x)=2f(x)f'(x)>0$，所以 $F$ 在 $(-\infty,+\infty)$ 上严格单调递增。
  这一步用的是「导数恒正 ⟹ 严格增」（拉格朗日中值定理的推论），$F$ 可导因为 $f$ 可导。
于是 $F(1)>F(-1)$，即 $f^2(1)>f^2(-1)$。
两边都非负，开平方保持大小：$\sqrt{f^2(1)}>\sqrt{f^2(-1)}$，即 $\lvert f(1)\rvert>\lvert f(-1)\rvert$，C 正确。
~A 不一定：$f(x)=-e^x$，$ff'=(-e^x)(-e^x)=e^{2x}>0$，但 $f(1)=-e\lt-e^{-1}=f(-1)$。
~B 不一定：$f(x)=e^x$，$ff'=e^{2x}>0$，但 $f(1)=e>e^{-1}=f(-1)$。D 与 C 矛盾，错。选 **C**。
::note
- 原书方法一按 $f>0$、$f\lt0$ 两种情形讨论——之所以只有这两种，是因为 $ff'>0$ 推出 $f\ne0$，再由 $f$ 连续推出 $f$ 不变号（[[介值定理]]）。卷面要写这句理由，不能凭感觉说「分两种情况」。
- {{扣|由 $ff'>0$ 直接说「$f'>0$」}}：没有 $f>0$ 的前提，$f'$ 的符号不定。
- 提速：凡条件是「两个东西乘起来的符号」，先想它是不是某个整体的导数（[[T认导数]]）。
::vary
条件改成 $f'(x)-f(x)>0$，比较 $e^{-1}f(1)$ 与 $ef(-1)$ >> $(e^{-x}f)'=e^{-x}(f'-f)>0$，$e^{-x}f$ 增 ⟹ $e^{-1}f(1)>ef(-1)$
条件改成 $xf'(x)+f(x)>0$，比较 $f(1)$ 与 $-f(-1)$ >> $(xf)'>0$，$xf$ 增 ⟹ $1\cdot f(1)>(-1)f(-1)$，即 $f(1)>-f(-1)$
条件改成 $f(x)f'(x)\lt0$ >> $f^2$ 递减 ⟹ $\lvert f(1)\rvert\lt\lvert f(-1)\rvert$，选 D 那种
条件改成 $\frac{f'(x)}{f(x)}>1$（$f>0$），比较 $f(1)$ 与 $e^2f(-1)$ >> $(\ln f-x)'>0$ ⟹ $\ln f(1)-1>\ln f(-1)+1$ ⟹ $f(1)>e^2f(-1)$

#3
@stem
函数 $f(x,y,z)=x^2y+z^2$ 在点 $(1,2,0)$ 处沿向量 $\boldsymbol n=(1,2,2)$ 的方向导数为（　）.
@A $12$
@B $6$
@C $4$
@D $2$
@ans D
@tpl T最大方向导数
::read
「沿向量 $\boldsymbol n=(1,2,2)$ 的方向导数」 >> [[梯度与方向导数]]：$\frac{\partial f}{\partial\boldsymbol n}=\nabla f\cdot\boldsymbol e$，{{圈|$\boldsymbol e$ 必须是单位向量}}
「$(1,2,2)$」 >> 模 $=\sqrt{1+4+4}=3$，正好是整数，单位化后 $\frac13(1,2,2)$——命题人特意挑的
「$f=x^2y+z^2$」 >> 多项式，处处可微，方向导数可以用梯度点乘算
「选项 6 和 2 差 3 倍」 >> 6 = 没单位化，是专门给漏步的人准备的
::think
1. 求梯度：$\nabla f=(2xy,\ x^2,\ 2z)$，代点 $(1,2,0)$ 得 $(4,1,0)$。
2. 单位化方向：$\boldsymbol e=\frac{\boldsymbol n}{\lvert\boldsymbol n\rvert}=\left(\frac13,\frac23,\frac23\right)$。
3. 点乘（[[T最大方向导数]] 第 3 条）。
::fast
{{秒|$\nabla f\cdot\boldsymbol n=4+2+0=6$，再除以 $\lvert\boldsymbol n\rvert=3$ 得 2}}，选 D。
::steps
偏导：$f_x=2xy$，$f_y=x^2$，$f_z=2z$。
代入 $(1,2,0)$：$f_x=2\cdot1\cdot2=4$，$f_y=1$，$f_z=0$，所以 $\nabla f(1,2,0)=(4,1,0)$。
$\lvert\boldsymbol n\rvert=\sqrt{1^2+2^2+2^2}=3$，方向余弦 $\cos\alpha=\frac13$，$\cos\beta=\frac23$，$\cos\gamma=\frac23$。
$\dfrac{\partial f}{\partial\boldsymbol n}\Big|_{(1,2,0)}=4\cdot\dfrac13+1\cdot\dfrac23+0\cdot\dfrac23=\dfrac{4+2}{3}=2$，选 **D**。
::note
- {{扣|不单位化}}：得 6，正好是选项 B。方向导数只与方向有关，与向量长短无关——把 $\boldsymbol n$ 换成 $(2,4,4)$ 结果不能变，这就是必须单位化的原因。
- 本题梯度的模 $\sqrt{17}\approx4.12$ 是最大方向导数；沿 $\boldsymbol n$ 的 2 比它小，符合「投影不超过斜边」。
::vary
沿 $\boldsymbol n=(2,4,4)$ 呢 >> 仍是 2（单位化后同一个方向）
求该点处方向导数的最大值及方向 >> 最大值 $\lvert\nabla f\rvert=\sqrt{17}$，方向 $\frac{1}{\sqrt{17}}(4,1,0)$
沿哪些方向的方向导数为 0 >> 与 $(4,1,0)$ 垂直的单位向量 $(a,b,c)$：$4a+b=0$，如 $\frac{1}{\sqrt{17}}(1,-4,0)$ 或 $(0,0,1)$
在点 $(1,2,1)$ 沿 $\boldsymbol n$ 呢 >> $\nabla f=(4,1,2)$，$\frac{4+2+4}{3}=\frac{10}3$

@stem

@A $E-\alpha\alpha^T$ 不可逆
@B $E+\alpha\alpha^T$ 不可逆

::vary

$P(A|B)>P(A)$ 与题干条件的关系 >> 等价（也化为 $P(AB)>P(A)P(B)$）

（Ⅲ）设 $z_1,\dots,z_n$ 为样本值（均 $>0$），似然函数 $L(\sigma)=\displaystyle\prod_{i=1}^n\frac{2}{\sqrt{2\pi}\sigma}e^{-\frac{z_i^2}{2\sigma^2}}=\Big(\frac{2}{\pi}\Big)^{\frac n2}\sigma^{-n}e^{-\frac{1}{2\sigma^2}\sum z_i^2}$。
  $\frac{2}{\sqrt{2\pi}}=\sqrt{\frac{2}{\pi}}$，$n$ 个相乘得 $(\frac2\pi)^{n/2}$。
$\ln L=\dfrac n2\ln\dfrac2\pi-n\ln\sigma-\dfrac{1}{2\sigma^2}\displaystyle\sum z_i^2$。
$\dfrac{d\ln L}{d\sigma}=-\dfrac n\sigma+\dfrac{1}{\sigma^3}\sum z_i^2=0$ ⟹ $\sigma^2=\dfrac1n\sum z_i^2$ ⟹ $\sigma=\sqrt{\dfrac1n\sum z_i^2}$。
  导数 $=\frac{1}{\sigma^3}(\sum z_i^2-n\sigma^2)$，在此点左正右负，是最大值点。
最大似然估计量 $\hat\sigma=\sqrt{\dfrac1n\displaystyle\sum_{i=1}^nZ_i^2}$。
