#1
@stem
若反常积分 $\displaystyle\int_0^{+\infty}\frac{1}{x^a(1+x)^b}\,dx$ 收敛，则（　）.
@A $a\lt1$ 且 $b>1$
@B $a>1$ 且 $b>1$
@C $a\lt1$ 且 $a+b>1$
@D $a>1$ 且 $a+b>1$
@ans C
@tpl T反常两端拆
::read
「$\int_0^{+\infty}$」 >> 上限是 $+\infty$——{{圈|无穷限}}；下限 0 处要看被积函数是不是无界
「$\frac{1}{x^a(1+x)^b}$」 >> $a>0$ 时在 $x=0$ 处分母为 0 ⟹ {{圈|0 也是瑕点}}。两端都有问题 ⟹ [[T反常两端拆]]：拆成 $\int_0^1+\int_1^{+\infty}$
「$x\to0^+$」 >> $(1+x)^b\to1$，被积函数 $\sim\frac1{x^a}$ ⟹ [[p积分]] 在 0 端要 $a\lt1$
「$x\to+\infty$」 >> $(1+x)^b\sim x^b$，被积函数 $\sim\frac1{x^{a+b}}$ ⟹ 无穷端要 $a+b>1$
「选项里有 $a>1$」 >> 0 端立刻发散 ⟹ B、D 直接排除；A 只管了 $b$ 没管 $a+b$
::sk 330 170 | 被积函数（图按 $a=\frac12,b=1$ 画）：0 处往上冲（瑕点，看 $x^a$），无穷远贴着 $x$ 轴拖尾（看 $x^{a+b}$）——两头各判一次
ox,oy=36,140;X=lambda x:ox+x*52;Y=lambda y:oy-y*40
s.axes(ox,oy,20,320,150,10,xl='x',yl='y')
f=lambda x:1/(x**0.5*(1+x))
s.plot(f,0.09,5.4,X,Y,n=14)
s.line(X(1),oy,X(1),Y(f(1)),'g',0.9,dash='3 3');s.text(X(1),oy+14,'1',10,'k','middle')
s.text(X(0.15)+8,Y(2.9),'x→0⁺：≈ 1/x^{a}',11,'r');s.text(X(0.15)+8,Y(2.9)+15,'要 a<1',11,'r')
s.text(X(2.6),Y(0.75),'x→+∞：≈ 1/x^{a+b}',11,'b');s.text(X(2.6),Y(0.75)+15,'要 a+b>1',11,'b')
s.bend(X(0.6),Y(1.8),X(0.2),Y(2.4),k=-10,c='r',w=0.9)
s.bend(X(3.4),Y(0.4),X(4.4),Y(0.22),k=8,c='b',w=0.9)
::think
1. 两端都是「问题点」，必须拆开：$\int_0^{+\infty}=\int_0^1+\int_1^{+\infty}$，两段都收敛才收敛。
2. 每段用比较判别法的极限形式，把被积函数换成同阶的 $\frac1{x^p}$。
3. 0 端得 $a\lt1$，无穷端得 $a+b>1$，两条同时成立 ⟹ C。
::fast
{{秒|0 端 $\sim x^{-a}$ 要 $a\lt1$ ⟹ 排除 B、D；A 的 $a\lt1,b>1$ 是 C 的特例（推出 $a+b>1$ 但不必要）}}，选 C。
反例确认 A 不必要：$a=\frac12,b=1$ ⟹ $\int_0^{+\infty}\frac{dx}{\sqrt x(1+x)}=\pi$ 收敛，但 $b>1$ 不成立。
::steps
拆开：$\displaystyle\int_0^{+\infty}\frac{dx}{x^a(1+x)^b}=\int_0^1\frac{dx}{x^a(1+x)^b}+\int_1^{+\infty}\frac{dx}{x^a(1+x)^b}$，原积分收敛 ⟺ 两段都收敛。
0 端：$\displaystyle\lim_{x\to0^+}\frac{\frac{1}{x^a(1+x)^b}}{\frac1{x^a}}=\lim_{x\to0^+}\frac1{(1+x)^b}=1$，由[[p积分|比较判别法极限形式]]，$\int_0^1$ 与 $\int_0^1\frac{dx}{x^a}$ 同敛散 ⟹ 收敛 ⟺ $a\lt1$。
  $a\le0$ 时 $x=0$ 根本不是瑕点，$\int_0^1$ 是正常积分，也满足 $a\lt1$，结论不变。
无穷端：$\displaystyle\lim_{x\to+\infty}\frac{\frac{1}{x^a(1+x)^b}}{\frac1{x^{a+b}}}=\lim_{x\to+\infty}\left(\frac{x}{1+x}\right)^b=1$ ⟹ $\int_1^{+\infty}$ 与 $\int_1^{+\infty}\frac{dx}{x^{a+b}}$ 同敛散 ⟹ 收敛 ⟺ $a+b>1$。
两条同时成立：$a\lt1$ 且 $a+b>1$，选 **C**。
~排除其余：B、D 含 $a>1$，0 端发散；A 比 C 多要求 $b>1$，是充分不必要（$a=\frac12$、$b=1$ 收敛）。
::note
- {{扣|只看无穷端（$a+b>1$）就选 D}}：忘了 0 也是瑕点，0 端要的是 $a\lt1$，正好与无穷端方向相反。
- 两个 $p$ 积分的方向别记反：**0 附近 $p\lt1$ 收敛（升得不够快）**，**无穷远 $p>1$ 收敛（降得够快）**；$p=1$ 两头都发散。
- 题目问的是「收敛则（必要条件）」，C 是充要条件，自然也是必要条件；A 不是必要条件，所以不选。
- 跨章：同样的「两端拆」在 2019 年第 1 题级数比较、各年反常积分题里都出现；遇到 $\int_0^{+\infty}\frac{\ln x}{\cdots}$ 时 0 端多一个 $\ln x$，它比任何正幂都慢，判法不变。
::vary
改为 $\int_0^{+\infty}\frac{dx}{x^a(1+x^2)^b}$ >> 0 端 $a\lt1$；无穷端 $\sim x^{-(a+2b)}$ 要 $a+2b>1$
改为 $\int_0^{1}\frac{dx}{x^a(1-x)^b}$ >> 两个瑕点 0 与 1：要 $a\lt1$ 且 $b\lt1$
改为 $\int_1^{+\infty}\frac{dx}{x^a(x-1)^b}$ >> 1 端 $\sim(x-1)^{-b}$ 要 $b\lt1$；无穷端要 $a+b>1$
$\int_0^{+\infty}\frac{\ln(1+x)}{x^p}dx$ 何时收敛 >> 0 端 $\sim x^{1-p}$ 要 $p\lt2$；无穷端 $\frac{\ln x}{x^p}$ 要 $p>1$ ⟹ $1\lt p\lt2$

@stem
已知函数 $f(x)=\begin{cases}2(x-1),&x\lt1,\\ \ln x,&x\ge1,\end{cases}$ 则 $f(x)$ 的一个原函数是（　）.
@A $F(x)=\begin{cases}(x-1)^2,&x\lt1,\\ x(\ln x-1),&x\ge1\end{cases}$
@B $F(x)=\begin{cases}(x-1)^2,&x\lt1,\\ x(\ln x+1)-1,&x\ge1\end{cases}$
@C $F(x)=\begin{cases}(x-1)^2,&x\lt1,\\ x(\ln x+1)+1,&x\ge1\end{cases}$
@D $F(x)=\begin{cases}(x-1)^2,&x\lt1,\\ x(\ln x-1)+1,&x\ge1\end{cases}$
@ans D
@tpl T分段原函数
::read
「分段函数 $f(x)$」 >> 先看 $f$ 在分界点 $x=1$ 处连不连续：$2(1-1)=0=\ln1$ ⟹ $f$ 连续 ⟹ 原函数一定存在（[[原函数连续]]）
「一个原函数」 >> [[T分段原函数]]：两段各积一次，常数靠「$F$ 在 $x=1$ 处连续」定
「四个选项左段全是 $(x-1)^2$」 >> {{圈|左段不用管}}，$x=1$ 处左边的值是 0；只看右段
「右段只有 $\ln x\pm1$ 与 $\pm1$ 的区别」 >> 两步淘汰：① $(\cdots)'=\ln x$ 吗？② $x=1$ 处等于 0 吗？
::sk 320 200 | 实线是原函数 $F$：左边抛物线 $(x-1)^2$、右边 $x(\ln x-1)+1$，在 $(1,0)$ 处接上；虚线是 $f$ 本身（左边直线、右边 $\ln x$）
ox,oy=60,120;X=lambda x:ox+x*75;Y=lambda y:oy-y*30
s.axes(ox,oy,14,312,196,12,xl='x',yl='y')

s.line(X(0),Y(-2),X(1),Y(0),'b',1.0,dash='4 3')

1. 右段原函数：$\int\ln x\,dx=x\ln x-x+C=x(\ln x-1)+C$——先排除导数不对的 B、C。
2. 剩 A、D 只差常数：用 $F$ 在 $x=1$ 处连续定 $C$。
3. 左段在 1 处的值 $(1-1)^2=0$，右段 $1\cdot(0-1)+C=C-1$ ⟹ $C=1$ ⟹ D。
::fast
{{秒|代 $x=1$：右段必须等于 0。A 得 $-1$，B 得 $0$，C 得 $2$，D 得 $0$ ⟹ 剩 B、D；B 的导数 $\ln x+2\ne\ln x$}}，选 D。
::steps
左段：$x\lt1$ 时 $\int2(x-1)dx=(x-1)^2+C_1$，选项都取 $C_1=0$。
右段：[[分部积分]] $\int\ln x\,dx=x\ln x-\int x\cdot\frac1xdx=x\ln x-x+C_2=x(\ln x-1)+C_2$。
  验算：$[x(\ln x-1)]'=(\ln x-1)+x\cdot\frac1x=\ln x$ ✓。
原函数必须在 $x=1$ 处连续（它在 $x=1$ 处可导）：$\lim_{x\to1^-}(x-1)^2=0$，右段在 $x=1$ 处 $=1\cdot(\ln1-1)+C_2=C_2-1$。
令 $C_2-1=0$ ⟹ $C_2=1$，所以 $F(x)=\begin{cases}(x-1)^2,&x\lt1\\x(\ln x-1)+1,&x\ge1\end{cases}$，选 **D**。
~再验 $F'(1)=f(1)$：左导数 $\lim_{x\to1^-}\frac{(x-1)^2-0}{x-1}=0$，右导数 $=\ln1=0$，都等于 $f(1)=0$ ✓。
::note
- {{扣|只验导数不验连续就选 A}}：A 的右段导数也是 $\ln x$，但在 $x=1$ 处为 $-1$，与左边的 0 断开，有跳跃的函数不可导，不是原函数。
- 为什么连续就够了：$F$ 在 $x=1$ 两侧可导且导数在 1 处的单侧极限都是 0，又连续，由导数极限定理 $F'(1)=0=f(1)$。卷面上可直接用「原函数必连续」定常数。
- 若 $f$ 在分界点有跳跃间断点（比如右段改成 $\ln x+1$），则任何「原函数」在该点都不可导——$f$ 没有原函数，四个选项都不对。
::vary

$f(x)=|x|$，求过原点的原函数 >> $F=\frac{x|x|}{2}$

@stem
若 $y=(1+x^2)^2-\sqrt{1+x^2}$，$y=(1+x^2)^2+\sqrt{1+x^2}$ 是微分方程 $y'+p(x)y=q(x)$ 的两个解，则 $q(x)=$（　）.
@A $3x(1+x^2)$
@B $-3x(1+x^2)$
@C $\dfrac{x}{1+x^2}$
@D $-\dfrac{x}{1+x^2}$
@ans A
@tpl T两解反推方程
::read
「两个解……$y'+p(x)y=q(x)$」 >> 一阶**线性**非齐次方程 ⟹ [[线性方程解的结构]]：差是齐次解，平均还是非齐次解（[[T两解反推方程]]）
「$(1+x^2)^2\mp\sqrt{1+x^2}$」 >> {{圈|两解只差 $\sqrt{1+x^2}$ 前的符号}} ⟹ 差 $=2\sqrt{1+x^2}$ 是齐次解，平均 $=(1+x^2)^2$ 是特解
「求 $q(x)$」 >> 先由齐次解求 $p$，再把特解 $(1+x^2)^2$ 代回求 $q$
「C、D 是 $\pm\frac{x}{1+x^2}$」 >> 这是 $p$ 的长相，命题人拿 $p$ 冒充 $q$；A、B 只差符号
::sk 400 190 | 两个解（实线）上下对称地夹着中间那条 $(1+x^2)^2$（虚线）：中间线是非齐次的特解，上下的距离 $2\sqrt{1+x^2}$ 是齐次解
ox,oy=140,170;X=lambda x:ox+x*95;Y=lambda y:oy-y*23
s.axes(ox,oy,20,262,180,8,xl='x',yl='y')
s.plot(lambda x:(1+x*x)**2-math.sqrt(1+x*x),-1.1,1.1,X,Y,n=10)
s.plot(lambda x:(1+x*x)**2+math.sqrt(1+x*x),-1.1,1.1,X,Y,n=10)
s.plot(lambda x:(1+x*x)**2,-1.1,1.1,X,Y,n=10,c='b',dash='4 3')
s.arrow(X(0.55),Y((1.3025)**2-math.sqrt(1.3025))+1,X(0.55),Y((1.3025)**2+math.sqrt(1.3025))-1,'r',1.0)
s.text(X(1.1)+8,Y(6.37)+4,'y₂',11);s.text(X(1.1)+8,Y(3.4)+4,'y₁',11)
s.text(X(1.1)+8,Y(4.88)+4,'平均 (1+x²)²：特解',11,'b')
s.text(X(1.1)+8,Y(2.1),'红箭头 = 差 2√(1+x²)',11,'r');s.text(X(1.1)+8,Y(2.1)+15,'= 齐次解',11,'r')
::think
1. $y_2-y_1=2\sqrt{1+x^2}$ 满足 $y'+py=0$ ⟹ $p=-\frac{y'}{y}=-\frac{x}{1+x^2}$。
2. $\frac{y_1+y_2}2=(1+x^2)^2$ 满足原方程 ⟹ $q=[(1+x^2)^2]'+p(1+x^2)^2$。
3. $=4x(1+x^2)-x(1+x^2)=3x(1+x^2)$ ⟹ A。
::fast
{{秒|代 $x=1$ 看符号：$p(1)=-\frac12$，特解 $u=(1+x^2)^2$ 在 1 处 $u=4$、$u'=8$ ⟹ $q(1)=8-2=6>0$}}；A 在 1 处为 6，B 为 $-6$，C 为 $\frac12$，选 A。
::steps
记 $y_1=(1+x^2)^2-\sqrt{1+x^2}$，$y_2=(1+x^2)^2+\sqrt{1+x^2}$。由[[线性方程解的结构]]，$y_2-y_1=2\sqrt{1+x^2}$ 是齐次方程 $y'+p(x)y=0$ 的解。
  验证：$(y_2'+py_2)-(y_1'+py_1)=q-q=0$，即 $(y_2-y_1)'+p(y_2-y_1)=0$。
代入齐次方程：$\left(2\sqrt{1+x^2}\right)'+p\cdot2\sqrt{1+x^2}=0$，$\left(2\sqrt{1+x^2}\right)'=\frac{2x}{\sqrt{1+x^2}}$。
⟹ $p(x)=-\dfrac{2x/\sqrt{1+x^2}}{2\sqrt{1+x^2}}=-\dfrac{x}{1+x^2}$。
$\frac{y_1+y_2}2=(1+x^2)^2$ 也是原方程的解（系数和 $\frac12+\frac12=1$）。代入：$q(x)=[(1+x^2)^2]'+p(x)(1+x^2)^2$。
$[(1+x^2)^2]'=2(1+x^2)\cdot2x=4x(1+x^2)$；$p(1+x^2)^2=-\frac{x}{1+x^2}(1+x^2)^2=-x(1+x^2)$。
$q(x)=4x(1+x^2)-x(1+x^2)=3x(1+x^2)$，选 **A**。
~验算：把 $y_1$ 代回，$y_1'=4x(1+x^2)-\frac{x}{\sqrt{1+x^2}}$，$py_1=-x(1+x^2)+\frac{x}{\sqrt{1+x^2}}$，相加正好 $3x(1+x^2)$ ✓。
::note
- {{扣|求出 $p=-\frac{x}{1+x^2}$ 就选 D}}：题目问的是 $q$，命题人专门把 $p$ 放进选项。
- 不要「把两个解分别代入、联立解 $p,q$」：能做，但要解二元一次方程组且根式满天飞；差和平均把根式一次消干净。
- 用 $y_1+y_2$ 代入也行，但它满足的是 $y'+py=2q$（系数和为 2），一不留神少除 2。
- 跨章：二阶线性方程同理，2013、2019 年都考过「给三个特解写通解」。
::vary
已知 $y'+py=q$ 有解 $e^x$ 与 $e^x+x$，求 $p,q$ >> 差 $x$：$1+px=0$ ⟹ $p=-\frac1x$；$q=e^x-\frac{e^x}x$
$y_1=x$，$y_2=x+e^{-x^2}$ 是 $y'+py=q$ 的解，求通解 >> $p=2x$，$q=1+2x^2$；通解 $y=x+Ce^{-x^2}$
二阶：$y''+py'+qy=f$ 有解 $x,\ x+e^x,\ x+e^{2x}$，写通解 >> 齐次解 $e^x,e^{2x}$ 无关：$y=C_1e^x+C_2e^{2x}+x$
若只知 $y_1$、$y_2$ 是解，$\lambda y_1+\mu y_2$ 何时是齐次解 >> $\lambda+\mu=0$；何时是非齐次解：$\lambda+\mu=1$

@stem

@tpl T分段点, T阶梯夹逼

「$x\le0$ 时 $f=x$」 >> 左边是直线：左极限 0、左导数 1，{{圈|$f(0)=0$}}

（Ⅰ）特征方程 $\lambda^2+2\lambda+k=0$，判别式 $\Delta=4-4k>0$（因 $k\lt1$），特征根 $\lambda_{1,2}=-1\pm\sqrt{1-k}$。

由于 $\lambda_i\lt0$，$\displaystyle\int_0^{+\infty}e^{\lambda_ix}dx=-\frac1{\lambda_i}$（$i=1,2$）收敛，所以
$$\int_0^{+\infty}y(x)dx=-\frac{C_1}{\lambda_1}-\frac{C_2}{\lambda_2}$$
收敛. ⛳2
（Ⅱ）解　由（Ⅰ），$\displaystyle\lim_{x\to+\infty}y(x)=0$，$\displaystyle\lim_{x\to+\infty}y'(x)=\lim_{x\to+\infty}\left(C_1\lambda_1e^{\lambda_1x}+C_2\lambda_2e^{\lambda_2x}\right)=0$. ⛳1

$$\left[y'(x)\right]_0^{+\infty}+2\left[y(x)\right]_0^{+\infty}+k\int_0^{+\infty}y(x)dx=0,\qquad(1)$$ ⛳2

$$\int_0^{+\infty}y(x)dx=\frac{y'(0)+2y(0)}{k}=\frac3k.$$ ⛳2

$f$ 可导 ⟹ 连续，在 $x_{n+1}=f(x_n)$ 两边令 $n\to\infty$：$A=f(A)$。

$g(0)=0-f(0)=-1\lt0$。
由拉格朗日中值定理，$f(2)-f(0)=2f'(\eta)$，$\eta\in(0,2)$，而 $f'(\eta)\lt\frac12$ ⟹ $f(2)\lt f(0)+1=2$ ⟹ $g(2)=2-f(2)>0$。
$g$ 严格单增且 $g(0)\lt0=g(A)\lt g(2)$ ⟹ $0\lt A\lt2$，即 $0\lt\lim_{n\to\infty}x_n\lt2$。

因为 $\displaystyle\sum_{n=1}^\infty\left(\frac12\right)^{n-1}|x_2-x_1|$ 收敛，由比较判别法，$\displaystyle\sum_{n=1}^\infty|x_{n+1}-x_n|$ 收敛，即级数 $\displaystyle\sum_{n=1}^\infty(x_{n+1}-x_n)$ 绝对收敛. ⛳2
