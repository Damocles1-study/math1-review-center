#1
@stem
下列函数中，在 $x=0$ 处不可导的是（　）.
@A $f(x)=|x|\sin|x|$
@B $f(x)=|x|\sin\sqrt{|x|}$
@C $f(x)=\cos|x|$
@D $f(x)=\cos\sqrt{|x|}$
@ans D
@tpl T绝对值可导, T分段点
::read
「在 $x=0$ 处不可导」 >> 四个函数全带绝对值，$x=0$ 正好是绝对值的「拐弯处」⟹ 只能[[导数定义|回定义]]，或者看 $f(x)-f(0)$ 的主项
「$\cos|x|$」 >> $\cos$ 是偶函数，$\cos|x|=\cos x$ ⟹ {{圈|绝对值是假的}}，C 处处可导，先划掉
「$|x|\sin|x|$、$|x|\sin\sqrt{|x|}$」 >> 前面已经乘了一个 $|x|$，后面的 sin 又趋于 0 ⟹ 整体比 $|x|$ 高阶 ⟹ 除以 $x$ 趋于 0，可导
「$\cos\sqrt{|x|}$」 >> $1-\cos u\sim\frac{u^2}{2}$，$u=\sqrt{|x|}$ ⟹ $f(x)-1\approx-\frac{|x|}{2}$ ⟹ {{波|主项就是 $|x|$ 本身}} ⟹ 尖点
::think
1. 四个函数都在 0 处有定义且连续，问题只在可导 ⟹ 写 $\frac{f(x)-f(0)}{x}$ 看极限。
2. 不想写四次定义 ⟹ 先用[[等价无穷小]]看 $f(x)-f(0)$ 的主项是 $|x|$ 的几次方（[[T绝对值可导]]）。
3. 主项恰好是 $c|x|$ 的那个就是答案。
::fast
{{秒|C 里 $\cos|x|=\cos x$ 先划掉；A、B 前面带 $|x|$ 再乘一个无穷小，比 $|x|$ 高阶，可导}} ⟹ 只剩 D。
再验一眼：$\cos\sqrt{|x|}-1\sim-\frac{|x|}{2}$，$\frac{-|x|/2}{x}$ 左右极限 $\pm\frac12$ 不等 ⟹ D 不可导。
::steps
C：$\cos$ 是偶函数，$\cos|x|=\cos x$，在 0 处可导，$f'(0)=-\sin0=0$。
A：$\dfrac{f(x)-f(0)}{x}=\dfrac{|x|\sin|x|}{x}$。$|\sin|x||\le|x|$ ⟹ $\left|\dfrac{|x|\sin|x|}{x}\right|\le|x|\to0$，所以 $f'(0)=0$，可导。
B：$\dfrac{|x|\sin\sqrt{|x|}}{x}$ 的绝对值 $=|\sin\sqrt{|x|}|\le\sqrt{|x|}\to0$，所以 $f'(0)=0$，可导。
  ==夹逼的写法==：$\frac{|x|}{x}=\pm1$ 是有界量，乘上趋于 0 的 $\sin\sqrt{|x|}$，整体趋于 0。
D：$f(0)=1$，$\dfrac{f(x)-f(0)}{x}=\dfrac{\cos\sqrt{|x|}-1}{x}$，由 $1-\cos u\sim\frac{u^2}2$（$u=\sqrt{|x|}\to0$）得分子 $\sim-\frac{|x|}{2}$。
右导数：$x\to0^+$ 时 $|x|=x$，极限 $=-\frac12$；左导数：$x\to0^-$ 时 $|x|=-x$，极限 $=\frac{-(-x)/2}{x}=+\frac12$。
左右导数不相等 ⟹ D 在 0 处不可导，选 **D**。
::note
- 判法一句话：$f(x)-f(0)$ 的主项是「$|x|$ 的一次」⟹ 尖点，不可导；比 $|x|$ 高阶 ⟹ 可导且导数为 0。
- {{扣|D 里写成 $\cos\sqrt{|x|}\approx1-\frac{x}{2}$}}：丢了绝对值，会得出「导数 $-\frac12$，可导」的错结论。
- A 其实连二阶导都不存在（$|x|\sin|x|\approx x|x|$，$x|x|$ 的导数 $2|x|$ 在 0 处又是尖点），但本题只问一阶。
::vary
$f(x)=|x|^{3/2}$ 在 0 处可导吗 >> 可导，$\frac{|x|^{3/2}}{x}\to0$，$f'(0)=0$
$f(x)=\sin|x|$ 在 0 处呢 >> 不可导：$\sin|x|\sim|x|$，主项是 $|x|$ 一次，左右导数 $-1$、$+1$
$f(x)=|x|\varphi(x)$，$\varphi$ 连续，什么时候在 0 处可导 >> 当且仅当 $\varphi(0)=0$（右导 $\varphi(0)$、左导 $-\varphi(0)$）
$f(x)=\cos\sqrt[3]{x^2}$ 在 0 处呢 >> $1-\cos x^{2/3}\sim\frac{x^{4/3}}{2}$，$\frac{x^{4/3}}{x}=x^{1/3}\to0$，可导

@stem
过点 $(1,0,0)$，$(0,1,0)$，且与曲面 $z=x^2+y^2$ 相切的平面为（　）.
@A $z=0$ 与 $x+y-z=1$
@B $z=0$ 与 $2x+2y-z=2$
@C $x=y$ 与 $x+y-z=1$
@D $x=y$ 与 $2x+2y-z=2$
@ans B
@tpl T切平面过点
::read
「与曲面 $z=x^2+y^2$ 相切的平面」 >> 切点不知道 ⟹ 设切点 $(x_0,y_0,x_0^2+y_0^2)$，[[切平面]]法向量 $(2x_0,2y_0,-1)$
「过点 $(1,0,0)$，$(0,1,0)$」 >> 两个点 ⟹ 两个方程，正好解两个未知数 $x_0,y_0$
「$z=x^2+y^2$」 >> 旋转抛物面，开口向上；它的切平面法向量的 $z$ 分量是 $-1$，{{圈|永远不会是竖直的平面}} ⟹ $x=y$（竖直平面）不可能是切平面，C、D 出局
「选项每个给两张平面」 >> 提醒你==切点有两个==，只找到一个就会被 A 骗
::think
1. 设切点、写切平面（[[T切平面过点]]），把两个已知点代进去 ⟹ 解出所有切点。
2. 每个切点对应一张切平面，全部写出来再对选项。
::fast
{{秒|竖直平面 $x=y$ 不可能与 $z=x^2+y^2$ 相切（抛物面的法向量 $z$ 分量恒为 $-1$）⟹ 排除 C、D}}。
A 与 B 只差第二张：$2x+2y-z=2$ 的法向量 $(2,2,-1)$ 对应切点 $x_0=y_0=1$，切点 $(1,1,2)$ 代入 $2+2-2=2$ ✓；而 $x+y-z=1$ 法向量 $(1,1,-1)$ 对应切点 $(\frac12,\frac12,\frac12)$，代入得 $\frac12\ne1$，不在曲面上相切 ⟹ B。
::steps
设切点 $(x_0,y_0,z_0)$，$z_0=x_0^2+y_0^2$。$z_x'=2x$，$z_y'=2y$ ⟹ 法向量 $(2x_0,2y_0,-1)$。
切平面：$z-z_0=2x_0(x-x_0)+2y_0(y-y_0)$，整理成 $z=2x_0x+2y_0y-(x_0^2+y_0^2)$。
  展开：$z=2x_0x+2y_0y-2x_0^2-2y_0^2+z_0$，而 $z_0=x_0^2+y_0^2$，所以常数项是 $-(x_0^2+y_0^2)$。
代 $(1,0,0)$：$0=2x_0-(x_0^2+y_0^2)$。 ……(1)
代 $(0,1,0)$：$0=2y_0-(x_0^2+y_0^2)$。 ……(2)
(1)−(2)：$x_0=y_0$；代回 (1)：$2x_0=2x_0^2$ ⟹ $x_0=0$ 或 $x_0=1$。
$x_0=y_0=0$：切平面 $z=0$；$x_0=y_0=1$：切平面 $z=2x+2y-2$，即 $2x+2y-z=2$。选 **B**。
::note
- {{扣|只解出一个切点}}：方程 $2x_0=2x_0^2$ 两边约掉 $x_0$ 就丢了 $x_0=0$。==约分前先问能不能为 0==。
- 几何看：两点 $(1,0,0)$、$(0,1,0)$ 连成的直线在 $xOy$ 面上，过一条直线向一个凸曲面能作两张切平面，所以答案必然是一对。
::vary
把曲面换成 $z=x^2+y^2+1$（其余不变） >> 切平面 $z=2x_0x+2y_0y-(x_0^2+y_0^2)+1$，代两点仍得 $x_0=y_0$，且 $2x_0^2-2x_0-1=0$ ⟹ $x_0=\frac{1\pm\sqrt3}{2}$，仍是两张切平面，只是不再有 $z=0$
只给一个点 $(1,0,0)$ >> 切点满足一个方程 $2x_0=x_0^2+y_0^2$（一个圆），切平面有无穷多张
求曲面 $z=x^2+y^2$ 上切平面平行于 $2x+2y-z=0$ 的点 >> 法向量成比例 $(2x_0,2y_0,-1)\parallel(2,2,-1)$ ⟹ $(1,1,2)$

@stem
$\displaystyle\sum_{n=0}^{\infty}(-1)^n\frac{2n+3}{(2n+1)!}=$（　）.
@A $\sin1+\cos1$
@B $2\sin1+\cos1$
@C $2\sin1+2\cos1$
@D $2\sin1+3\cos1$
@ans B
@tpl T级数凑阶乘
::read
「$(-1)^n$，分母 $(2n+1)!$」 >> 交错 + 奇数阶乘 ⟹ 脑子里立刻跳出 $\sin1=\sum\frac{(-1)^n}{(2n+1)!}$（[[正余弦级数]]）
「分子 $2n+3$」 >> 不是常数 ⟹ {{圈|拆}}：$2n+3=(2n+1)+2$，$(2n+1)$ 正好和分母约掉一截，变成 $(2n)!$ ⟹ 出现 $\cos1$
「选项全是 $a\sin1+b\cos1$」 >> 只要分别算出两个系数
::think
1. 分母 $(2n+1)!$ 的级数要往 $\sin$ 上靠，分子多出来的 $2n+1$ 约掉一个因子后变成 $(2n)!$，往 $\cos$ 上靠。
2. 拆完两块各自对号入座。
::fast
{{秒|代 $n=0$ 看首项：$\frac{3}{1!}=3$；$\sin1+\cos1$ 系数和才 2}}——这不是严格排除法。更快的是心算：$2n+3=(2n+1)+2$ ⟹ $\cos1+2\sin1$，选 B。
数值验：$\cos1+2\sin1\approx0.540+1.683=2.223$，级数前三项 $3-\frac56+\frac7{120}=2.225$ ✓。
::steps
拆分子：$\dfrac{2n+3}{(2n+1)!}=\dfrac{2n+1}{(2n+1)!}+\dfrac{2}{(2n+1)!}=\dfrac{1}{(2n)!}+\dfrac{2}{(2n+1)!}$。
  $(2n+1)!=(2n+1)\cdot(2n)!$，约掉 $2n+1$ 得 $\frac1{(2n)!}$。
原式 $=\displaystyle\sum_{n=0}^\infty\frac{(-1)^n}{(2n)!}+2\sum_{n=0}^\infty\frac{(-1)^n}{(2n+1)!}$。
  两个级数都绝对收敛，可以拆开分别求和。
由 $\cos x=\sum\frac{(-1)^nx^{2n}}{(2n)!}$、$\sin x=\sum\frac{(-1)^nx^{2n+1}}{(2n+1)!}$，代 $x=1$：原式 $=\cos1+2\sin1$，选 **B**。
::note
- 认法口诀：**奇数阶乘配 sin，偶数阶乘配 cos，不带 $(-1)^n$ 配 $e$**（或 $\mathrm{sh},\mathrm{ch}$，数一不常考）。
- 拆分子的固定动作：让分子里出现分母阶乘的「最后一个因子」，就能约掉一截。
::vary
$\sum_{n=0}^\infty\frac{(-1)^n(2n+2)}{(2n+1)!}$ >> $=\sum\frac{(-1)^n}{(2n)!}+\sum\frac{(-1)^n}{(2n+1)!}=\cos1+\sin1$
$\sum_{n=0}^\infty\frac{n+1}{n!}$ >> $=\sum\frac{n}{n!}+\sum\frac1{n!}=e+e=2e$（$n\ge1$ 时 $\frac{n}{n!}=\frac1{(n-1)!}$）
$\sum_{n=0}^\infty\frac{(-1)^n n^2}{(2n)!}$ 的思路 >> 不好直接拆，改用幂级数：$S(x)=\sum\frac{(-1)^nx^{2n}}{(2n)!}=\cos x$，$n^2$ 对应对 $x$ 求导再乘 $x$ 两次后除以 4：$\frac14(x\frac{d}{dx})^2\cos x$ 在 $x=1$ 的值 $=\frac14(-\cos1-\sin1)$

@stem
设 $M=\displaystyle\int_{-\frac\pi2}^{\frac\pi2}\frac{(1+x)^2}{1+x^2}dx$，$N=\displaystyle\int_{-\frac\pi2}^{\frac\pi2}\frac{1+x}{e^x}dx$，$K=\displaystyle\int_{-\frac\pi2}^{\frac\pi2}\left(1+\sqrt{\cos x}\right)dx$，则（　）.
@A $M>N>K$
@B $M>K>N$
@C $K>M>N$
@D $K>N>M$
@ans C
@tpl T积分比大小
::read
「三个积分都在 $[-\frac\pi2,\frac\pi2]$」 >> 对称区间 ⟹ 先拆[[奇偶性]]
「$\frac{(1+x)^2}{1+x^2}$」 >> 展开分子 $1+2x+x^2$，正好是「分母 + $2x$」⟹ $1+\frac{2x}{1+x^2}$，后一块是奇函数，积分为 0 ⟹ {{圈|$M=\pi$}}
「$\frac{1+x}{e^x}$」 >> 看到 $1+x$ 和 $e^x$ 并列 ⟹ 立刻想 $e^x\ge1+x$ ⟹ 被积函数 $\le1$
「$1+\sqrt{\cos x}$」 >> $\sqrt{\cos x}\ge0$ ⟹ 被积函数 $\ge1$
==三个都在和「1」比== >> 中间量就是 $\int_{-\pi/2}^{\pi/2}1\,dx=\pi$
::sk 330 170 看 | 三条被积函数和水平线 $y=1$：蓝 $1+\frac{2x}{1+x^2}$ 绕着 1 上下对称地摆，红 $\frac{1+x}{e^x}$ 整条在 1 下面（只在 0 处碰到），绿 $1+\sqrt{\cos x}$ 整条在 1 上面

::think
1. 对称区间 ⟹ 先把 $M$ 里的奇函数部分去掉，$M$ 直接算出 $\pi$。
2. 剩下两个不好算 ⟹ 和 $\pi$（被积函数为 1）逐点比较（[[T积分比大小]]、[[定积分保序]]）。
::fast
{{秒|$M=\pi$；$e^x\ge1+x$ ⟹ $N<\pi$；$\sqrt{\cos x}\ge0$ ⟹ $K>\pi$}} ⟹ $K>M>N$，C。三行心算，不用积出 $N$ 和 $K$。
::steps
$M$：$\dfrac{(1+x)^2}{1+x^2}=\dfrac{1+x^2+2x}{1+x^2}=1+\dfrac{2x}{1+x^2}$。
$\frac{2x}{1+x^2}$ 是奇函数，在对称区间上积分为 0 ⟹ $M=\int_{-\pi/2}^{\pi/2}1\,dx=\pi$。
$N$：对一切 $x$ 有 $e^x\ge1+x$，且只在 $x=0$ 处取等 ⟹ $\frac{1+x}{e^x}\le1$，只在 $x=0$ 取等。
  $e^x\ge1+x$ 的来历：$g(x)=e^x-1-x$，$g'(x)=e^x-1$，$x=0$ 处取最小值 $g(0)=0$。
  $x<-1$ 时 $1+x<0$，$\frac{1+x}{e^x}<0<1$，同样成立。
两边连续、不恒等 ⟹ $N<\int_{-\pi/2}^{\pi/2}1\,dx=\pi$。
$K$：$\cos x\ge0$ 在区间上成立，$\sqrt{\cos x}\ge0$ 且只在端点为 0 ⟹ $K>\pi$。
~真算也行：$N=\left[-(2+x)e^{-x}\right]_{-\pi/2}^{\pi/2}=(2-\frac\pi2)e^{\pi/2}-(2+\frac\pi2)e^{-\pi/2}\approx1.32$，$K=\pi+\int\sqrt{\cos x}\,dx\approx5.54$；考场上没必要。
所以 $K>\pi=M>N$，选 **C**。
::note
- 不必真的算 $N$（$N\approx1.32$）、$K$（$\approx5.54$），比大小题==找中间量==永远比硬算快。
- {{扣|写「$e^x\ge1+x$ ⟹ $N\le\pi$」而不说严格}}：选择题无所谓，填空/证明题要补一句「连续且不恒等，故严格不等」。
::vary
把 $N$ 换成 $\int_{-\pi/2}^{\pi/2}\frac{1+\sin x}{e^{\sin x}}dx$ >> 令 $u=\sin x$ 逐点仍有 $\frac{1+u}{e^u}\le1$，所以仍 $<\pi$
$M'=\int_{-\pi/2}^{\pi/2}\frac{(1-x)^2}{1+x^2}dx$ 与 $M$ 比 >> 也是 $1-\frac{2x}{1+x^2}$，奇部分抵消，$M'=\pi=M$
比较 $\int_0^1\frac{x}{1+x}dx$ 与 $\int_0^1\ln(1+x)dx$ >> $x\in(0,1]$ 时 $\frac{x}{1+x}<\ln(1+x)$（$\ln(1+x)$ 的下界），前者小
把 $K$ 换成 $\int_{-\pi/2}^{\pi/2}(1-\sqrt{\cos x})dx$ >> 被积函数 $\le1$，$K'<\pi$；再和 $N$ 比就得真算：$K'\approx0.74<N\approx1.32$

「$y'+y=f(x)$」 >> [[一阶线性公式|一阶线性]]，$P=1$，积分因子 $e^x$：$(e^xy)'=e^xf(x)$（[[T一阶线性]]）
「（Ⅰ）$f(x)=x$」 >> $\int xe^xdx$ 分部一次，送分
「（Ⅱ）存在唯一的以 $T$ 为周期的解」 >> 通解里有一个任意常数 $C$ ⟹ 「唯一」就是说 {{圈|恰好有一个 $C$ 让解成为周期函数}}
「周期解」 >> 要证的是 $y(x+T)=y(x)$ 对**一切** $x$ 成立 ⟹ 研究差 $w(x)=y(x+T)-y(x)$：它满足==齐次方程== $w'+w=0$，所以 $w=w(0)e^{-x}$ ⟹ 只要在一个点 $x=0$ 处为 0 就处处为 0
::think
（Ⅰ）积分因子 $e^x$ 直接套公式。
（Ⅱ）
1. 写通解 $y=e^{-x}\left(C+\int_0^xe^tf(t)dt\right)$，所有解都在这里面，每个 $C$ 一个解。
2. 关键观察：$y(x+T)$ 也是原方程的解（因为 $f(x+T)=f(x)$），两个解的差 $w=y(x+T)-y(x)$ 满足 $w'+w=0$ ⟹ $w=w(0)e^{-x}$（[[T周期解唯一]]）。
3. 所以 $y$ 以 $T$ 为周期 ⟺ $w(0)=0$ ⟺ $y(T)=y(0)$——一个关于 $C$ 的一次方程，系数 $e^{-T}-1\ne0$ ⟹ 恰有一解 ⟹ 存在且唯一。
::steps
（Ⅰ）$f(x)=x$：两边乘 $e^x$，$(e^xy)'=xe^x$ ⟹ $e^xy=\int xe^xdx=xe^x-e^x+C$ ⟹ $y=x-1+Ce^{-x}$（$C$ 为任意常数）。
  $\int xe^xdx=xe^x-\int e^xdx=xe^x-e^x+C$。
（Ⅱ）通解：$(e^xy)'=e^xf(x)$，从 0 积到 $x$：$e^xy(x)-y(0)=\int_0^xe^tf(t)dt$ ⟹ $y(x)=e^{-x}\left(C+\int_0^xe^tf(t)dt\right)$，$C=y(0)$。
  每个解对应唯一的 $C=y(0)$，所以「唯一的周期解」等价于「唯一的 $C$」。
任取一个解 $y$，令 $w(x)=y(x+T)-y(x)$。因为 $f(x+T)=f(x)$：$y'(x+T)+y(x+T)=f(x+T)=f(x)$。
  这说明 $y(x+T)$ 也是原方程的解。
两式相减：$w'(x)+w(x)=f(x)-f(x)=0$ ⟹ $(e^xw)'=0$ ⟹ $w(x)=w(0)e^{-x}$。
于是：$y$ 以 $T$ 为周期 ⟺ $w\equiv0$ ⟺ $w(0)=0$ ⟺ $y(T)=y(0)$。
  「⟸」用的就是 $w(x)=w(0)e^{-x}$：一点为 0 则处处为 0。
$y(T)=y(0)$ 写开：$e^{-T}\left(C+\int_0^Te^tf(t)dt\right)=C$ ⟹ $C(1-e^{-T})=e^{-T}\int_0^Te^tf(t)dt$。
$T>0$ ⟹ $1-e^{-T}\ne0$ ⟹ $C=\dfrac{\int_0^Te^tf(t)dt}{e^T-1}$，存在且只有这一个。
所以方程存在唯一的以 $T$ 为周期的解 $y=e^{-x}\left(\dfrac{\int_0^Te^tf(t)dt}{e^T-1}+\int_0^xe^tf(t)dt\right)$。
::paper
解　（Ⅰ）当 $f(x)=x$ 时，方程的通解为
$$y=e^{-\int dx}\left(\int xe^{\int dx}dx+C\right)=e^{-x}(xe^x-e^x+C)=x-1+Ce^{-x},\ C\text{ 为任意常数}.$$ ⛳3
证　（Ⅱ）方程的任一解可写为
$$y(x)=e^{-x}\left(C+\int_0^xe^tf(t)dt\right),\quad C=y(0).\qquad(1)$$ ⛳2
设 $y(x)$ 为方程的解，令 $w(x)=y(x+T)-y(x)$. 由 $f(x+T)=f(x)$ 得 $y'(x+T)+y(x+T)=f(x)$，与原方程相减得 $w'(x)+w(x)=0$，故
$$w(x)=w(0)e^{-x}.\qquad(2)$$ ⛳2
由 (2)，$y(x)$ 以 $T$ 为周期 $\iff w(x)\equiv0\iff w(0)=0\iff y(T)=y(0)$. ⛳1
由 (1)，$y(T)=y(0)$ 即 $e^{-T}\left(C+\int_0^Te^tf(t)dt\right)=C$，因 $e^{-T}\ne1$，解得唯一的
$$C=\frac{1}{e^T-1}\int_0^Te^tf(t)dt.$$ ⛳1
所以方程存在唯一的以 $T$ 为周期的解. 证毕. ⛳1
::note
- 原书的做法是把 $y(x+T)-y(x)$ 硬算出来再拆积分、换元 $t=u+T$，篇幅是上面的两倍；「差满足齐次方程」这一步把周期性的验证压缩到一个点，==是本题真正的考点==。
- {{扣|只证存在不证唯一}}（或反之）：唯一性来自「每个解对应唯一的 $C$」+「$C$ 的方程只有一个根」，两句都要写。
- {{扣|直接说 $y(T)=y(0)$ 就是周期}}：一个点相等推出处处相等，必须有 (2) 式那一步。
- 跨章：这正是「一阶线性 + 周期性」的通法；二阶常系数 $y''+ay'+by=f$ 的周期解问题也是看齐次方程有没有周期解（[[T有界解]]）。
::vary

解　（Ⅰ）设 $x_1,\cdots,x_n$ 为样本值，似然函数为
$$L(\sigma)=\prod_{i=1}^n\frac{1}{2\sigma}e^{-\frac{|x_i|}{\sigma}}=\frac{1}{2^n\sigma^n}e^{-\frac1\sigma\sum_{i=1}^n|x_i|},$$ ⛳1
$\ln L(\sigma)=-n\ln2-n\ln\sigma-\dfrac1\sigma\displaystyle\sum_{i=1}^n|x_i|$. ⛳1
令 $\dfrac{d\ln L}{d\sigma}=-\dfrac n\sigma+\dfrac{1}{\sigma^2}\displaystyle\sum_{i=1}^n|x_i|=0$，得 $\sigma=\dfrac1n\displaystyle\sum_{i=1}^n|x_i|$，所以 $\sigma$ 的最大似然估计量为 $\hat\sigma=\dfrac1n\displaystyle\sum_{i=1}^n|X_i|$. ⛳2
（Ⅱ）$E|X|=\displaystyle\int_{-\infty}^{+\infty}\frac{|x|}{2\sigma}e^{-\frac{|x|}{\sigma}}dx=\frac1\sigma\int_0^{+\infty}xe^{-\frac x\sigma}dx=\sigma$， ⛳2
$E(X^2)=\dfrac1\sigma\displaystyle\int_0^{+\infty}x^2e^{-\frac x\sigma}dx=2\sigma^2$，故 $D|X|=2\sigma^2-\sigma^2=\sigma^2$. ⛳2
所以 $E(\hat\sigma)=\dfrac1n\displaystyle\sum_{i=1}^nE|X_i|=\sigma$，$D(\hat\sigma)=\dfrac{1}{n^2}\displaystyle\sum_{i=1}^nD|X_i|=\dfrac{\sigma^2}{n}$. ⛳3
::note
- {{扣|估计量写成小写 $\frac1n\sum|x_i|$}}：小写是估计值，题目要的是估计量，用大写 $X_i$。
- {{扣|把 $D|X|$ 当成 $DX$}}：$DX=EX^2-(EX)^2=2\sigma^2-0=2\sigma^2$，而 $D|X|=\sigma^2$，差一倍。
- 提速：认出 $|X|\sim E(\frac1\sigma)$（均值 $\sigma$），指数分布的 $E=\sigma$、$D=\sigma^2$ 直接写，两行搞定（复算脚本用 sympy 核对过）。
- 跨章：$\Gamma$ 积分 $\int_0^\infty t^ne^{-t}dt=n!$ 是概率里算矩的万能钥匙。
::vary
求 $\sigma$ 的矩估计 >> $EX=0$ 没用，改用二阶矩 $EX^2=2\sigma^2$：$\hat\sigma_{\text{矩}}=\sqrt{\frac1{2n}\sum X_i^2}$（或用 $E|X|=\sigma$ 得 $\frac1n\sum|X_i|$）
$\hat\sigma^2$ 是 $\sigma^2$ 的无偏估计吗 >> 不是：$E\hat\sigma^2=D\hat\sigma+(E\hat\sigma)^2=\sigma^2+\frac{\sigma^2}n>\sigma^2$
$\hat\sigma$ 是否为 $\sigma$ 的一致（相合）估计 >> 是：由大数定律 $\frac1n\sum|X_i|\to E|X|=\sigma$（或 $D\hat\sigma\to0$ 加无偏）
