当 $x\to0$ 时，$f(x)=e^x-\dfrac{1+ax}{1+bx}$ 是 $x$ 的三阶无穷小，则（　）.
@A $a=\dfrac12$，$b=-\dfrac12$
@B $a=-\dfrac12$，$b=\dfrac12$
@C $a=1$，$b=0$
@D $a=\dfrac32$，$b=\dfrac12$
@ans A
@tpl T同阶无穷小
::rev
- **该花** 3 分钟。
- **卡点** 分式 $\frac{1+ax}{1+bx}$ 不知道怎么展开。
- **错了说明** $\frac1{1+u}=1-u+u^2-\cdots$ 没用起来。
- **带走** 「$k$ 阶无穷小求参数」：两边都展到 $x^k$，低于 $k$ 次的系数全为 0，$x^k$ 的系数不为 0。
::read
「三阶无穷小」 >> [[T同阶无穷小|展开到 $x^3$]]：$x,x^2$ 的系数为 0，$x^3$ 的系数不为 0
$\frac{1+ax}{1+bx}$ >> 用 $\frac{1}{1+bx}=1-bx+b^2x^2-b^3x^3+\cdots$ 乘出来
::think
两个未知数，正好由 $x$、$x^2$ 两个系数为 0 定出来；最后还要验 $x^3$ 的系数不为 0（否则就是四阶以上了）。
::fast
{{秒|代选项}}：$e^x=1+x+\frac{x^2}2+\cdots$。$\frac{1+ax}{1+bx}=1+(a-b)x-b(a-b)x^2+\cdots$，一次系数要 $a-b=1$（排除 B），二次要 $-b=\frac12$ ⟹ 只有 A。
::steps
$\dfrac{1+ax}{1+bx}=(1+ax)\bigl(1-bx+b^2x^2-b^3x^3+o(x^3)\bigr)=1+(a-b)x-b(a-b)x^2+b^2(a-b)x^3+o(x^3)$。
$e^x=1+x+\dfrac{x^2}2+\dfrac{x^3}6+o(x^3)$（[[R.mclaurin|麦克劳林展开]]）。
$f(x)=\bigl[1-(a-b)\bigr]x+\Bigl[\dfrac12+b(a-b)\Bigr]x^2+\Bigl[\dfrac16-b^2(a-b)\Bigr]x^3+o(x^3)$。
三阶无穷小：$1-(a-b)=0$，$\frac12+b(a-b)=0$ ⟹ $a-b=1$，$b=-\frac12$，$a=\frac12$。
检验 $x^3$ 系数：$\dfrac16-\dfrac14\cdot1=-\dfrac1{12}\ne0$，确是三阶。选 A。
::note
C（$a=1,b=0$）是 $e^x-1-x\sim\frac{x^2}2$，只有二阶——给只凑了一次项的人准备的。
**口诀**：几阶无穷小，就展到几阶；低阶全清零，本阶不为零。
::vary
$e^x-\frac{1+ax}{1+bx}$ 的等价无穷小（$a,b$ 取本题的值）？ >> $-\frac{1}{12}x^3$。
$\cos x-\frac{1+ax^2}{1+bx^2}$ 为 $x^4$ 的高阶无穷小，求 $a,b$？ >> $a=-\frac5{12}$，$b=\frac1{12}$。

方程 $x^3-3x+k=0$ 有三个不同实根的充要条件是（　）.
@A $k\gt2$
@B $-2\lt k\lt2$
@C $k\lt-2$
@D $-2\le k\le2$
@ans B
::rev
- **该花** 2 分钟。
- **卡点** 端点 $k=\pm2$ 拿不准。
- **错了说明** 等号时有重根，「不同」的根只剩两个。
- **带走** 三次方程根的个数：看极大值 $\gt0$、极小值 $\lt0$ 同时成立。
::read
「三个不同实根」 >> [[R.extjudge|求极值]]，极大值在 $x$ 轴上方、极小值在下方
::think
画 $g(x)=x^3-3x+k$ 的草图：先升、后降、再升。三次穿过 $x$ 轴 ⟺ 极大值 $\gt0$ 且极小值 $\lt0$。
::fast
{{秒|上下平移}}：$x^3-3x$ 的极大值 2、极小值 $-2$，加 $k$ 后要跨过 0：$-2\lt k\lt2$，选 B。
::steps
$g(x)=x^3-3x+k$，$g'(x)=3x^2-3=0$ ⟹ $x=\pm1$。
$x=-1$ 为极大值点，$g(-1)=2+k$；$x=1$ 为极小值点，$g(1)=-2+k$。
$x\to-\infty$ 时 $g\to-\infty$，$x\to+\infty$ 时 $g\to+\infty$，$g$ 在 $(-\infty,-1)$、$(-1,1)$、$(1,+\infty)$ 上各自单调。
三个不同实根 ⟺ 三段各有一个零点 ⟺ $2+k\gt0$ 且 $-2+k\lt0$ ⟺ $-2\lt k\lt2$。选 B。
::note
$k=2$ 时 $g(1)=0$，$x=1$ 是重根，只有两个不同实根；$k=-2$ 时 $x=-1$ 是重根。D 错在等号。
**口诀**：三次三根，极大正、极小负。
::vary
$k=2$ 时有几个不同实根？ >> 2 个：$x^3-3x+2=(x-1)^2(x+2)$，$x=1$ 二重、$x=-2$。
$x^3-3x+k=0$ 只有一个实根的条件？ >> $k\gt2$ 或 $k\lt-2$。

@stem
设 $f(x,y)$ 在点 $(0,0)$ 处连续，且 $\displaystyle\lim_{(x,y)\to(0,0)}\frac{f(x,y)}{\vert x\vert+\vert y\vert}=1$，则（　）.
@A $f_x'(0,0)$ 存在
@B $f(x,y)$ 在 $(0,0)$ 处可微
@C $(0,0)$ 是 $f(x,y)$ 的极小值点
@D $(0,0)$ 不是 $f(x,y)$ 的极值点
@ans C
@tpl T极限反推
::rev
- **该花** 3 分钟。
- **卡点** 以为极值点一定要偏导为 0，看到偏导不存在就选 D。
- **错了说明** 极值的定义只比函数值，不要求可导。
- **带走** 极限条件 ⟹ 先反推 $f(0,0)$，再用保号性比较附近的函数值。
::read
「连续」＋分母 $\to0$、极限有限 >> [[T极限反推|分子 $\to0$]] ⟹ $f(0,0)=0$
极限为 1 $\gt0$ >> [[R.limprop|保号性]]：附近 $\frac{f}{\vert x\vert+\vert y\vert}\gt0$ ⟹ $f\gt0=f(0,0)$
::think
打个比方：$f$ 在原点附近长得像一个「倒立的四棱锥」$\vert x\vert+\vert y\vert$——尖底朝下，最低点在原点，但尖底处没有切平面，所以偏导不存在、不可微，却仍是极小值点。
::fast
{{秒|像谁}}：$f\approx\vert x\vert+\vert y\vert$，原点是尖底：极小值，偏导不存在。选 C。
::steps
由极限存在且分母 $\to0$，得 $\lim f(x,y)=0$，又 $f$ 在原点连续，所以 $f(0,0)=0$。
由保号性，存在去心邻域使 $\dfrac{f(x,y)}{\vert x\vert+\vert y\vert}\gt\dfrac12\gt0$，即 $f(x,y)\gt0=f(0,0)$ ⟹ $(0,0)$ 是极小值点。C 对，D 错。
偏导：$\dfrac{f(x,0)-f(0,0)}{x}=\dfrac{f(x,0)}{\vert x\vert}\cdot\dfrac{\vert x\vert}{x}$，前一个因子 $\to1$，后一个在 $x\to0^\pm$ 时为 $\pm1$ ⟹ 左右极限 $\mp1$ 不等，$f_x'(0,0)$ 不存在。A 错。
偏导不存在 ⟹ 不可微，B 错。选 C。
::note
**口诀**：极值只比高低，不问光滑；尖底也是谷底。
::vary
把分母换成 $x^2+y^2$，偏导存在吗？ >> 存在且为 0，可微，仍是极小值点。
把极限换成 $-1$？ >> 极大值点。

设级数 $\displaystyle\sum_{n=1}^\infty a_n$ 条件收敛，则（　）.
@A $\displaystyle\sum_{n=1}^\infty a_n^2$ 收敛
@B $\displaystyle\sum_{n=1}^\infty a_{2n}$ 收敛
@C $\displaystyle\sum_{n=1}^\infty\frac{a_n+\vert a_n\vert}{2}$ 发散
@D $\displaystyle\sum_{n=1}^\infty(-1)^na_n$ 收敛
@ans C
@tpl T级数反例
::rev
- **该花** 3 分钟。
- **卡点** C 不知道怎么证。
- **错了说明** 「收敛 + 收敛 = 收敛」的反证用法没想到。
- **带走** 条件收敛 = 正部、负部各自都发散，只是相互抵消。
::read
「条件收敛」 >> [[R.absconv|$\sum a_n$ 收敛但 $\sum\vert a_n\vert$ 发散]]
$\frac{a_n+\vert a_n\vert}2$ >> 正部：$a_n\gt0$ 时是 $a_n$，否则是 0
::think
用最常见的条件收敛级数 $\frac{(-1)^n}{n}$、$\frac{(-1)^n}{\sqrt n}$ 去试 A、B、D；C 用反证：若正部收敛，$\vert a_n\vert=2\cdot$正部 $-a_n$ 也收敛，矛盾。
::fast
{{秒|拿 $\frac{(-1)^n}{n}$ 试}}：B 变成 $\sum\frac1{2n}$ 发散，D 变成 $\sum\frac1n$ 发散；A 用 $\frac{(-1)^n}{\sqrt n}$ 平方得 $\sum\frac1n$ 发散。只剩 C。
::steps
C：若 $\sum\dfrac{a_n+\vert a_n\vert}2$ 收敛，则 $\vert a_n\vert=2\cdot\dfrac{a_n+\vert a_n\vert}2-a_n$，$\sum\vert a_n\vert$ 为两个收敛级数之差，收敛，与「条件收敛」矛盾。故 C 中级数发散。
A 的反例：$a_n=\frac{(-1)^n}{\sqrt n}$ 条件收敛，$\sum a_n^2=\sum\frac1n$ 发散。
B 的反例：$a_n=\frac{(-1)^n}{n}$，$\sum a_{2n}=\sum\frac1{2n}$ 发散。
D 的反例：$a_n=\frac{(-1)^n}{n}$，$\sum(-1)^na_n=\sum\frac1n$ 发散。
∴ 选 C。
::note
同理 $\sum\frac{a_n-\vert a_n\vert}2$（负部）也发散。
**口诀**：条件收敛，正负两部各自发散，靠抵消才收敛。
::vary
$\sum a_n$ 绝对收敛时，$\sum a_n^2$？ >> 必收敛（$\vert a_n\vert\lt1$ 后 $a_n^2\le\vert a_n\vert$）。
$\sum a_n$ 条件收敛，$\sum(a_n+a_{n+1})$？ >> 收敛（两个收敛级数相加）。

设向量组 $\alpha_1,\alpha_2,\alpha_3$ 线性无关，则下列向量组中线性无关的是（　）.
@A $\alpha_1-\alpha_2,\ \alpha_2-\alpha_3,\ \alpha_3-\alpha_1$
@B $\alpha_1+\alpha_2,\ \alpha_2+\alpha_3,\ \alpha_3-\alpha_1$
@C $\alpha_1+\alpha_2,\ \alpha_2+\alpha_3,\ \alpha_3+\alpha_1$
@D $\alpha_1,\ \alpha_1+\alpha_2,\ 2\alpha_1+\alpha_2$
@ans C
::rev
- **该花** 2 分钟。
- **卡点** 一个个去找线性组合，费时间。
- **错了说明** 「新组 = 旧组 × 系数矩阵 $C$，无关 ⟺ $\vert C\vert\ne0$」没用。
- **带走** 用旧向量组表示新向量组时，只算系数矩阵的行列式。
::read
新向量都由 $\alpha_1,\alpha_2,\alpha_3$ 表示 >> $(\beta_1,\beta_2,\beta_3)=(\alpha_1,\alpha_2,\alpha_3)C$，[[R.linthm|无关 ⟺ $\vert C\vert\ne0$]]
::think
A、B、D 都能一眼看出组合：A 三个加起来为 0；B 是 $\beta_1-\beta_2+\beta_3=0$；D 是 $\beta_3=\beta_1+\beta_2$。C 的系数矩阵行列式为 2。
::fast
{{秒|看系数行列式}}：C 的 $C=\begin{pmatrix}1&0&1\\1&1&0\\0&1&1\end{pmatrix}$，$\vert C\vert=2\ne0$。选 C。
::steps
A：$(\alpha_1-\alpha_2)+(\alpha_2-\alpha_3)+(\alpha_3-\alpha_1)=0$，相关。
B：$(\alpha_1+\alpha_2)-(\alpha_2+\alpha_3)+(\alpha_3-\alpha_1)=0$，相关。
D：$2\alpha_1+\alpha_2=\alpha_1+(\alpha_1+\alpha_2)$，相关。
C：$(\beta_1,\beta_2,\beta_3)=(\alpha_1,\alpha_2,\alpha_3)\begin{pmatrix}1&0&1\\1&1&0\\0&1&1\end{pmatrix}$，$\vert C\vert=1\cdot(1-0)-0+1\cdot(1-0)=2\ne0$，$C$ 可逆，秩不变，线性无关。选 C。
::note
「首尾相加」型：三个是 $\vert C\vert=2$（无关），四个是 $\vert C\vert=0$（相关）——奇数个无关、偶数个相关。
**口诀**：新组看系数阵，行列式不为零就无关。
::vary
$\alpha_1+\alpha_2,\alpha_2+\alpha_3,\alpha_3+\alpha_4,\alpha_4+\alpha_1$ 呢？ >> 相关：第一、三个之和 = 第二、四个之和。
$\alpha_1+2\alpha_2,\ 2\alpha_2+3\alpha_3,\ 3\alpha_3+\alpha_1$？ >> $\vert C\vert=12\ne0$，无关。

解 (1) $A=\begin{pmatrix}a&1&1\\1&a&-1\\1&-1&a\end{pmatrix}$. ⛳1
$\vert\lambda E-A\vert=(\lambda-a-1)^2(\lambda-a+2)$，故 $A$ 的特征值为 $\lambda_1=\lambda_2=a+1$，$\lambda_3=a-2$. ⛳2
(2) $f$ 正定 ⟺ $A$ 的特征值全大于零 ⟺ $a+1\gt0$ 且 $a-2\gt0$，故 $a\gt2$. ⛳3
(3) 当 $a=2$ 时，特征值为 $3,3,0$. ⛳1
对 $\lambda=3$，解 $(3E-A)x=0$ 得 $\xi_1=(1,1,0)^T$，$\xi_2=(1,0,1)^T$；对 $\lambda=0$，解 $Ax=0$ 得 $\xi_3=(-1,1,1)^T$. ⛳1
正交化：$\beta_1=\xi_1$，$\beta_2=\xi_2-\dfrac{(\xi_2,\beta_1)}{(\beta_1,\beta_1)}\beta_1=\dfrac12(1,-1,2)^T$. ⛳1
单位化得 $q_1=\dfrac1{\sqrt2}(1,1,0)^T$，$q_2=\dfrac1{\sqrt6}(1,-1,2)^T$，$q_3=\dfrac1{\sqrt3}(-1,1,1)^T$. 令 $Q=(q_1,q_2,q_3)$，则 $Q$ 为正交矩阵，在正交变换 $x=Qy$ 下 ⛳1
$$f=3y_1^2+3y_2^2.$$⛳1
(4) 正交变换不改变曲面的形状，$3y_1^2+3y_2^2=1$ 表示圆柱面，故 $f(x_1,x_2,x_3)=1$ 表示圆柱面. ⛳1
::note
- {{扣|写「$Q$ 为正交矩阵」}}：正交变换题的标准句式。
- $B+E$ 与 $B-E$ 一字之差：秩 1 的那个要写出来确认，别心算——这就是考场上的验算习惯。
- (4) 的判断：标准形里正项个数 = 2、零项 1 个 ⟹ 柱面；两个系数相等 ⟹ 圆柱面。
::vary

$a=0$ 时 $f$ 的正、负惯性指数？ >> 特征值 $1,1,-2$：正 2，负 1。

（本题满分 12 分）设随机变量 $X_1,X_2$ 相互独立，都服从参数为 $1$ 的指数分布. 记 $Y=\max\{X_1,X_2\}$，$Z=\min\{X_1,X_2\}$.
(1) 求 $P\{Z\gt1\}$；
(2) 求 $Z$ 与 $Y$ 的概率密度；
(3) 求 $EY$ 与 $E(Y-Z)$.
@ans (1) $e^{-2}$；(2) $f_Z(z)=2e^{-2z}$（$z\gt0$），$f_Y(y)=2e^{-y}-2e^{-2y}$（$y\gt0$）；(3) $EY=\dfrac32$，$E(Y-Z)=1$
@tpl T分布函数法
::rev
- **该花** 14 分钟。
- **保底** ==第 (1) 问：$\{Z\gt1\}=\{X_1\gt1\}\cap\{X_2\gt1\}$，由独立性 $=e^{-1}\cdot e^{-1}$——两行就是 3 分==。第 (2) 问写出 $F_Z(z)=1-[1-F(z)]^2$、$F_Y(y)=[F(y)]^2$ 再拿 3 分。
- **卡点** max 和 min 的分布函数公式记混。
- **错了说明** 「最小值大于 $z$ ⟺ 全都大于 $z$」「最大值小于 $y$ ⟺ 全都小于 $y$」没想通。
- **带走** min 看「都大于」，max 看「都小于」，独立就相乘。
::read
$\min$、$\max$ 的分布 >> [[R.conv|max 与 min]]：$P(Z\gt z)=P(X_1\gt z)P(X_2\gt z)$，$P(Y\le y)=P(X_1\le y)P(X_2\le y)$
$E(Y-Z)$ >> 期望线性：$EY-EZ$；也可以注意 $Y-Z=\vert X_1-X_2\vert$
::think
1. $E(1)$：$F(x)=1-e^{-x}$，$P(X\gt x)=e^{-x}$（$x\gt0$）。
2. min：$P(Z\gt z)=e^{-2z}$，正好是参数 2 的指数分布 ⟹ $EZ=\frac12$。
3. max：$F_Y=(1-e^{-y})^2$，求导得密度；$EY=EX_1+EX_2-EZ=2-\frac12$（因为 $Y+Z=X_1+X_2$）——一步验算。
4. 打个比方：两个灯泡同时点亮，$Z$ 是第一个灭的时刻，$Y$ 是第二个灭的时刻，$Y-Z$ 是「剩下那个还要亮多久」——由无记忆性，它又是一个 $E(1)$，期望正好是 1。
::steps
$X_i$ 的分布函数 $F(x)=1-e^{-x}$（$x\gt0$），$F(x)=0$（$x\le0$）。
(1) $P\{Z\gt1\}=P\{X_1\gt1,X_2\gt1\}=P\{X_1\gt1\}P\{X_2\gt1\}=e^{-1}\cdot e^{-1}=e^{-2}$。
(2) $z\gt0$ 时 $F_Z(z)=1-P\{Z\gt z\}=1-[1-F(z)]^2=1-e^{-2z}$，$z\le0$ 时 $F_Z(z)=0$。
$f_Z(z)=2e^{-2z}$（$z\gt0$），其余为 0。
$y\gt0$ 时 $F_Y(y)=P\{X_1\le y,X_2\le y\}=[F(y)]^2=(1-e^{-y})^2$，$y\le0$ 时为 0。
$f_Y(y)=2(1-e^{-y})e^{-y}=2e^{-y}-2e^{-2y}$（$y\gt0$），其余为 0。
(3) $EY=\displaystyle\int_0^{+\infty}y\bigl(2e^{-y}-2e^{-2y}\bigr)dy=2\cdot1-2\cdot\frac14=\frac32$（$\int_0^{+\infty}ye^{-ky}dy=\frac1{k^2}$）。
$EZ=\displaystyle\int_0^{+\infty}z\cdot2e^{-2z}dz=\frac12$。
$E(Y-Z)=EY-EZ=\dfrac32-\dfrac12=1$。
~验算：$Y+Z=X_1+X_2$ ⟹ $EY+EZ=2$ ✓。

解 $X_i$ 的分布函数为 $F(x)=\begin{cases}1-e^{-x},&x\gt0,\\0,&x\le0.\end{cases}$
(1) 由独立性，$P\{Z\gt1\}=P\{X_1\gt1\}P\{X_2\gt1\}=e^{-1}\cdot e^{-1}=e^{-2}$. ⛳3
(2) $F_Z(z)=1-[1-F(z)]^2=\begin{cases}1-e^{-2z},&z\gt0,\\0,&z\le0,\end{cases}$ 故 $f_Z(z)=\begin{cases}2e^{-2z},&z\gt0,\\0,&z\le0;\end{cases}$ ⛳2
$F_Y(y)=[F(y)]^2=\begin{cases}(1-e^{-y})^2,&y\gt0,\\0,&y\le0,\end{cases}$ 故 $f_Y(y)=\begin{cases}2e^{-y}-2e^{-2y},&y\gt0,\\0,&y\le0.\end{cases}$ ⛳3
(3) $EY=\displaystyle\int_0^{+\infty}y\bigl(2e^{-y}-2e^{-2y}\bigr)dy=2-\frac12=\frac32$， ⛳2
$EZ=\displaystyle\int_0^{+\infty}2ze^{-2z}dz=\frac12$，故 $E(Y-Z)=EY-EZ=1$. ⛳2
