@stem
曲线 $y=x\ln\Bigl(e+\dfrac1x\Bigr)$ 的渐近线条数为（　）.
@A $1$
@B $2$
@C $3$
@D $0$
@ans B
@tpl T渐近线三查
::rev
- **该花** 3 分钟。
- **卡点** 只盯着 $x=0$ 找铅直渐近线，漏了 $x=-\frac1e$。
- **错了说明** 铅直渐近线要从**定义域的边界点**去找，不是只看分母为 0。
- **带走** 渐近线三查：铅直（定义域边界、无定义点）→ 水平 → 斜，正负无穷各查一次。
::read
$\ln(e+\frac1x)$ >> 定义域要 $e+\frac1x\gt0$：$x\gt0$ 或 $x\lt-\frac1e$，边界点 $0$ 和 $-\frac1e$ 都要查
「条数」 >> [[T渐近线三查|三类逐一查]]，$\pm\infty$ 分开
::think
1. 铅直：在 $-\frac1e$ 左侧，$e+\frac1x\to0^+$，对数 $\to-\infty$，乘以负的 $x$ 得 $+\infty$——是铅直渐近线。在 $0^+$ 处 $x\ln(\cdot)\sim x\ln\frac1x\to0$，不是。
2. 斜：$\frac yx=\ln(e+\frac1x)\to1$，$y-x=x\ln\bigl(1+\frac1{ex}\bigr)\to\frac1e$。正负无穷一样，算一条。
::fast
{{秒|定义域边界}}：$x=-\frac1e$ 一条铅直；$y\approx x+\frac1e$ 一条斜。共 2 条，选 B。
::steps
定义域：$e+\frac1x\gt0\iff\frac{ex+1}{x}\gt0\iff x\gt0$ 或 $x\lt-\frac1e$。
$x\to\bigl(-\frac1e\bigr)^-$：$e+\frac1x\to0^+$，$\ln(e+\frac1x)\to-\infty$，而 $x\to-\frac1e\lt0$，所以 $y\to+\infty$ ⟹ $x=-\frac1e$ 是铅直渐近线。
$x\to0^+$：$y=x\ln\frac{ex+1}{x}=x\ln(ex+1)-x\ln x\to0$，不是铅直渐近线。
$x\to\pm\infty$：$y\to\pm\infty$，无水平渐近线。
$k=\lim\dfrac yx=\lim\ln\Bigl(e+\dfrac1x\Bigr)=1$；$b=\lim(y-x)=\lim x\ln\Bigl(1+\dfrac{1}{ex}\Bigr)=\lim x\cdot\dfrac1{ex}=\dfrac1e$（$\pm\infty$ 相同）。
斜渐近线 $y=x+\frac1e$。共 2 条，选 B。
::note
**口诀**：铅直看边界，水平看无穷，斜线先 $k$ 后 $b$。
::vary
$y=\frac{x^2}{x+1}$ 的渐近线？ >> $x=-1$ 和 $y=x-1$，两条。
$y=xe^{1/x}$ 的渐近线？ >> $x=0$（$0^+$ 时 $\to+\infty$）和 $y=x+1$，两条。

@stem
函数 $f(x)=(x^2-3x+2)\,\vert x^3-4x\vert$ 的不可导点的个数为（　）.
@A $0$
@B $1$
@C $2$
@D $3$
@ans C
@tpl T绝对值可导
::rev
- **该花** 2 分钟。
- **卡点** $\vert x^3-4x\vert$ 有三个零点就选 3。
- **错了说明** 「$g(x)\vert x-a\vert$ 在 $a$ 处可导 ⟺ $g(a)=0$」没记住。
- **带走** 把绝对值里拆成一次因式，每个零点处看「剩下的部分」在该点是不是 0。
::read
$\vert x^3-4x\vert=\vert x\vert\vert x-2\vert\vert x+2\vert$ >> 可疑点 $0,2,-2$
前面的 $(x^2-3x+2)=(x-1)(x-2)$ >> 在 $x=2$ 处能「补上」一个零
::think
$g(x)\vert x-a\vert$ 在 $a$ 处的左右导数是 $\mp g(a)$，相等 ⟺ $g(a)=0$。逐个可疑点算「去掉这个绝对值后剩下的东西」在该点的值。
::fast
{{秒|口诀}}「绝对值的零点被前面的因子消掉才可导」：$x=2$ 被 $(x-2)$ 消掉，$0$ 和 $-2$ 消不掉 ⟹ 2 个，选 C。
::steps
$f(x)=(x-1)(x-2)\cdot\vert x\vert\cdot\vert x-2\vert\cdot\vert x+2\vert$，可疑点 $x=0,\pm2$，其余点处可导。
$x=0$：$g(x)=(x-1)(x-2)\vert x-2\vert\vert x+2\vert$，$g(0)=(-1)(-2)\cdot2\cdot2=8\ne0$ ⟹ 不可导。
$x=2$：$f=(x-2)\vert x-2\vert\cdot h(x)$，$\frac{f(x)-f(2)}{x-2}=\vert x-2\vert h(x)\to0$ ⟹ 可导。
$x=-2$：$g(x)=(x-1)(x-2)\vert x\vert\vert x-2\vert$，$g(-2)=(-3)(-4)\cdot2\cdot4=96\ne0$ ⟹ 不可导。
不可导点 2 个，选 C。
::note
**口诀**：绝对值里有零点，外面同样有零就可导。
::vary
$f(x)=(x^2-x-2)\vert x^3-x\vert$ 的不可导点？ >> $0$、$1$ 两个（$x=-1$ 被 $x+1$ 消掉）。
$f(x)=\vert x\vert\sin x$ 在 0 处？ >> 可导，$\sin0=0$。

@stem
反常积分 $\displaystyle\int_0^{+\infty}\frac{dx}{x^p(1+x)}$ 收敛的充要条件是（　）.
@A $p\gt1$
@B $p\lt1$
@C $0\lt p\lt1$
@D $p\gt0$
@ans C
::rev
- **该花** 2 分钟。
- **卡点** 只看了 $+\infty$ 端（得 $p\gt0$）或只看了 $0$ 端（得 $p\lt1$）。
- **错了说明** 两端都有问题的反常积分要从中间劈开，**两段都收敛**才收敛。
- **带走** 劈开 → 每段找主导项 → 和 $p$ 积分比较 → 取交集。
::read
下限 0、上限 $+\infty$ >> 两端都可能出问题，[[R.pint|从 1 劈开]]
::think
$0$ 附近 $1+x\approx1$，被积函数 $\sim\frac1{x^p}$，要 $p\lt1$；$+\infty$ 附近 $\sim\frac1{x^{p+1}}$，要 $p+1\gt1$ 即 $p\gt0$。
::fast
{{秒|两端各看一眼}}：零端要 $p\lt1$，无穷端要 $p\gt0$，交集 $0\lt p\lt1$，选 C。
::steps
$\displaystyle\int_0^{+\infty}=\int_0^1+\int_1^{+\infty}$，两段都收敛原积分才收敛。
$\int_0^1$：$x\to0^+$ 时 $\dfrac{1}{x^p(1+x)}\sim\dfrac1{x^p}$，收敛 ⟺ $p\lt1$。
$\int_1^{+\infty}$：$x\to+\infty$ 时 $\dfrac{1}{x^p(1+x)}\sim\dfrac1{x^{p+1}}$，收敛 ⟺ $p+1\gt1$ ⟺ $p\gt0$。
取交集：$0\lt p\lt1$，选 C。
::note
**口诀**：$p$ 积分，瑕点要小于一，无穷要大于一。
::vary
$\int_0^{+\infty}\frac{\ln(1+x)}{x^p}dx$ 收敛的条件？ >> 零端 $\sim x^{1-p}$ 要 $p\lt2$，无穷端要 $p\gt1$：$1\lt p\lt2$。
$\int_0^1\frac{dx}{x^p}$ 当 $p=1$？ >> 发散。

@stem
设 $A$ 为 $m\times n$ 矩阵，$r(A)=m\lt n$，$b$ 为任意 $m$ 维列向量，则（　）.
@A $Ax=0$ 只有零解
@B $Ax=b$ 有唯一解
@C $Ax=b$ 有无穷多解
@D $A^Tx=0$ 有非零解
@ans C
::rev
- **该花** 1 分半。
- **卡点** D 里转置后的矩阵大小没想清。
- **错了说明** 行满秩、列满秩各意味着什么没对上号。
- **带走** 行满秩 ⟹ $Ax=b$ 总有解；列满秩 ⟹ $Ax=0$ 只有零解。
::read
$r(A)=m$（行数） >> 行满秩：加一列 $b$ 秩也不会超过 $m$ ⟹ [[R.nonhomo|总有解]]
$m\lt n$ >> 未知数比秩多 ⟹ 有自由未知量
::think
$r(A\mid b)$ 夹在 $r(A)=m$ 和行数 $m$ 之间，只能等于 $m$ ⟹ 有解；$n-m\gt0$ 个自由量 ⟹ 无穷多解。
::fast
{{秒|夹逼秩}}：$m\le r(A\mid b)\le m$ ⟹ 有解，$n\gt m$ ⟹ 无穷多，选 C。
::steps
$(A\mid b)$ 是 $m\times(n+1)$ 矩阵，$m=r(A)\le r(A\mid b)\le m$，所以 $r(A\mid b)=r(A)=m$，$Ax=b$ 有解。
$r(A)=m\lt n$，解中有 $n-m\ge1$ 个自由未知量 ⟹ 无穷多解。C 对，B 错。
$Ax=0$：$r(A)\lt n$ ⟹ 有非零解，A 错。
$A^T$ 是 $n\times m$，$r(A^T)=m$ = 列数 ⟹ $A^Tx=0$ 只有零解，D 错。
∴ 选 C。
::note
**口诀**：行满秩方程总有解，列满秩齐次只有零。
::vary
$r(A)=n\lt m$ 时？ >> $Ax=0$ 只有零解；$Ax=b$ 可能无解。
$A$ 为 $3\times4$，$r(A)=3$，$Ax=0$ 基础解系有几个向量？ >> $4-3=1$。

设 $A$ 为 $3$ 阶矩阵，$A^2=A$，$r(A)=2$，则 $\vert A+E\vert=$（　）.
@A $2$
@B $4$
@C $8$
@D $1$
@ans B
@tpl T矩阵方程定特征值
::rev
- **该花** 2 分钟。
- **卡点** 知道特征值是 0 或 1，不知道各几个。
- **错了说明** $A^2=A$ 的矩阵能对角化，秩 = 特征值 1 的个数，这一步没接上。
- **带走** 矩阵满足 $g(A)=O$ ⟹ 特征值满足 $g(\lambda)=0$；再用秩或迹定个数。
::read
$A^2=A$ >> [[T矩阵方程定特征值|特征值满足 $\lambda^2=\lambda$]]：只能是 0 或 1
$r(A)=2$ >> 定出 1 有两个、0 有一个
::think
$A^2=A$ ⟹ $A(A-E)=O$ ⟹ $r(A)+r(A-E)\le3$，又 $r(A)+r(E-A)\ge r(E)=3$，所以 $r(A)+r(A-E)=3$：两个特征值的特征向量加起来正好 3 个，能对角化，$A\sim\mathrm{diag}(1,1,0)$。
::fast
{{秒|代入}}：特征值 $1,1,0$，$A+E$ 的特征值 $2,2,1$，行列式 $4$，选 B。
::steps
设 $A\xi=\lambda\xi$（$\xi\ne0$），则 $A^2\xi=\lambda^2\xi=A\xi=\lambda\xi$ ⟹ $\lambda^2=\lambda$ ⟹ $\lambda=0$ 或 $1$。
由 $A(A-E)=O$：$r(A)+r(A-E)\le3$；由 $A+(E-A)=E$：$r(A)+r(E-A)\ge3$。故 $r(A-E)=3-r(A)=1$。
$\lambda=1$ 的无关特征向量个数 $3-r(A-E)=2$，$\lambda=0$ 的个数 $3-r(A)=1$，共 3 个 ⟹ $A\sim\mathrm{diag}(1,1,0)$。
$A+E$ 的特征值 $2,2,1$，$\vert A+E\vert=4$，选 B。
::note
幂等矩阵的秩 = 迹 = 特征值 1 的个数，这一条值得背。
**口诀**：$A^2=A$，特征值非零即一，秩是几就有几个一。
::vary
同样条件 $\vert A-2E\vert=$？ >> 特征值 $-1,-1,-2$：$-2$。
$A^2=E$，$r(A+E)=1$（3 阶），$\vert A\vert=$？ >> 特征值 $-1$ 有 $3-r(A+E)=2$ 个，$1$ 有一个：$\vert A\vert=1$。

(1) $0\lt x\lt1$ 时 $f_X(x)=\displaystyle\int_0^x2\,dy=2x$；其余为 0。

(3) $EX=\displaystyle\int_0^1x\cdot2x\,dx=\frac23$，$EY=\int_0^1y\cdot2(1-y)dy=1-\frac23=\frac13$。
$E(XY)=\displaystyle\int_0^1dx\int_0^x2xy\,dy=\int_0^1x\cdot x^2dx=\frac14$。
$\mathrm{Cov}(X,Y)=\dfrac14-\dfrac23\cdot\dfrac13=\dfrac14-\dfrac29=\dfrac1{36}$。
