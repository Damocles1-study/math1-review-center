#1
@at 4
@src 自编（经典反例 $x^2\sin\frac1x$）
@stem
设 $f(x)=\begin{cases}x^2\sin\dfrac1x, & x\ne0,\\[4pt] 0, & x=0,\end{cases}$ 则 $f(x)$ 在 $x=0$ 处（　）.
@A 不连续
@B 连续但不可导
@C 可导，但 $f'(x)$ 在 $x=0$ 处不连续
@D 可导，且 $f'(x)$ 在 $x=0$ 处连续
@ans C
@tpl T分段点
::rev
- **该花** 2 分钟。
- **卡点** 先求出 $f'(x)=2x\sin\frac1x-\cos\frac1x$ 再代 $x=0$，代不进去就以为「不可导」。
- **错了说明** 「分段点只能回定义」还没成反射。
- **带走** 导数存在 ≠ 导函数连续：$f'(0)$ 用定义算，「$f'$ 在 0 连续」要另算 $\lim_{x\to0}f'(x)$。
::read
$x=0$ 处单独定义 >> {{圈|分段点}}，连续、可导都只能[[R.derdef|回定义]]
选项 C、D 问「$f'(x)$ 在 0 处连不连续」 >> 要算两样：$f'(0)$（定义）和 $\lim_{x\to0}f'(x)$（公式）
::think
四个选项是一层一层往上加的：连续 → 可导 → 导函数连续。从下往上逐层判，判到哪层不成立就停。
打个比方：「可导」是这一点本身光滑；「导函数连续」是这一点附近的斜率不乱跳。$x^2\sin\frac1x$ 在 0 附近斜率在 $-1$ 到 $1$ 之间狂抖，但振幅被 $x^2$ 压扁了，所以这一点本身还是光滑的。
::fast
{{秒|$x^n\sin\frac1x$ 三档口诀}}：$n=1$ 连续不可导；$n=2$ 可导但导函数不连续；$n=3$ 导函数连续。本题 $n=2$ ⟹ C。
::steps
连续：$\vert x^2\sin\frac1x\vert\le x^2\to0$，所以 $\lim_{x\to0}f(x)=0=f(0)$，连续。
可导：由定义 $f'(0)=\lim_{x\to0}\dfrac{x^2\sin\frac1x-0}{x}=\lim_{x\to0}x\sin\dfrac1x=0$（有界乘无穷小），可导。
$x\ne0$ 时用公式：$f'(x)=2x\sin\dfrac1x+x^2\cos\dfrac1x\cdot\Bigl(-\dfrac1{x^2}\Bigr)=2x\sin\dfrac1x-\cos\dfrac1x$。
$x\to0$ 时 $2x\sin\frac1x\to0$，而 $\cos\frac1x$ 在 $-1$ 与 $1$ 之间振荡、没有极限 ⟹ $\lim_{x\to0}f'(x)$ 不存在，$f'$ 在 0 处不连续。
∴ 选 C。
::note
==「求导再代入」只在导函数在该点连续时才对==，分段点上永远先写定义式。
**口诀**：分段点，回定义；导数在，导函数未必连。
::vary
$f(x)=x\sin\frac1x$（$x\ne0$），$f(0)=0$，在 0 处？ >> 连续但不可导：$\frac{f(x)-0}{x}=\sin\frac1x$ 没有极限。
$f(x)=x^3\sin\frac1x$ 呢？ >> 可导且 $f'$ 在 0 处连续：$f'(x)=3x^2\sin\frac1x-x\cos\frac1x\to0=f'(0)$。

#2
@at 3
@src 自编
@stem
当 $x\to0^+$ 时，$\alpha=\tan x-x$，$\beta=\displaystyle\int_0^{x^2}\ln(1+t)\,dt$，$\gamma=\sqrt{1+x^2}-1$。把它们按「从低阶到高阶」排列，正确的是（　）.
@A $\alpha,\beta,\gamma$
@B $\gamma,\alpha,\beta$
@C $\beta,\alpha,\gamma$
@D $\gamma,\beta,\alpha$
@ans B
@tpl T同阶无穷小, T变限积分阶数
::rev
- **该花** 2 分钟。
- **卡点** 变限积分不知道怎么定阶，去硬算积分。
- **错了说明** 「被积函数的阶 +1，再乘上限的阶」没记住。
- **带走** 比阶 = 每个都化成 $c\,x^k$，只比 $k$。
::read
「从低阶到高阶」 >> 每个都写成 $c\cdot x^k$，$k$ 小的是低阶
$\int_0^{x^2}\ln(1+t)dt$ >> [[T变限积分阶数|变限积分定阶]]：被积 $\ln(1+t)\sim t$ 是 1 阶，积完 2 阶，上限 $x^2$ 再乘 2 ⟹ 4 阶
::think
三个式子各用一把工具：$\tan x-x$ 是加减，用[[R.mclaurin|泰勒]]；根式用 $(1+u)^a-1\sim au$；积分用变限积分定阶。
::fast
{{秒|阶数}}：$\gamma$ 2 阶、$\alpha$ 3 阶、$\beta$ 4 阶 ⟹ $\gamma,\alpha,\beta$，选 B。
::steps
$\alpha=\tan x-x=\Bigl(x+\dfrac{x^3}3+o(x^3)\Bigr)-x\sim\dfrac{x^3}{3}$，3 阶。
$\gamma=\sqrt{1+x^2}-1\sim\dfrac12x^2$（$(1+u)^{a}-1\sim au$，$u=x^2$，$a=\frac12$），2 阶。
$\beta$：$\ln(1+t)\sim t$，$\beta\sim\displaystyle\int_0^{x^2}t\,dt=\frac{x^4}{2}$，4 阶。
~严格写法：$\lim\limits_{x\to0^+}\dfrac{\beta}{x^4}=\lim\dfrac{\ln(1+x^2)\cdot2x}{4x^3}=\lim\dfrac{2x^3}{4x^3}=\dfrac12$（洛必达＋变限积分求导）。
从低到高：$\gamma$（2）、$\alpha$（3）、$\beta$（4），选 B。
::note
**口诀**：变限积分定阶——「被积阶加一，再乘上限阶」。
$\tan x-x\sim\frac{x^3}3$、$x-\sin x\sim\frac{x^3}6$、$\tan x-\sin x\sim\frac{x^3}2$，三个一起背。
::vary
$\int_0^{\sin x}(e^{t^2}-1)dt$ 是几阶？ >> 被积 $t^2$ 是 2 阶，积完 3 阶，上限 $\sin x$ 是 1 阶 ⟹ 3 阶，$\sim\frac{x^3}{3}$。
$x-\ln(1+x)$ 是几阶？ >> $\frac{x^2}{2}$，2 阶。

#3
@at 23
@src 自编（经典反例 $\sqrt{\vert xy\vert}$）
@stem
二元函数 $f(x,y)=\sqrt{\vert xy\vert}$ 在点 $(0,0)$ 处（　）.
@A 不连续
@B 连续，但偏导数不存在
@C 偏导数存在，但不可微
@D 可微
@ans C
@tpl T举反例
::rev
- **该花** 2 分钟。
- **卡点** 偏导数都是 0 就以为可微。
- **错了说明** 可微的判定式没写过：减掉线性部分后除以 $\rho$ 要趋于 0。
- **带走** 判可微三步：偏导（定义）→ 写出增量减线性部分 → 除以 $\rho$ 看极限，沿 $y=x$ 试一下。
::read
$\vert xy\vert$ 带绝对值、在原点 >> 偏导用定义算；判可微要用[[R.totaldiff|可微的定义]]
::think
选项是一串「连续 → 偏导存在 → 可微」。偏导存在是沿两条坐标轴走，可微要求沿所有方向都像一个平面——所以找一条斜线（$y=x$）去试。
::fast
{{秒|口诀}}「坐标轴上为 0、斜线上不为 0」的函数：偏导存在（都是 0），但沿 $y=x$ 时 $\frac{f}{\rho}=\frac{\vert x\vert}{\sqrt2\vert x\vert}=\frac1{\sqrt2}\ne0$ ⟹ 不可微。选 C。
::steps
连续：$0\le\sqrt{\vert xy\vert}\le\sqrt{\dfrac{x^2+y^2}{2}}\to0$，所以连续，排除 A。
偏导：$f_x'(0,0)=\lim\limits_{h\to0}\dfrac{f(h,0)-f(0,0)}{h}=\lim\dfrac{0-0}{h}=0$，同理 $f_y'(0,0)=0$，偏导存在，排除 B。
可微 ⟺ $\lim\limits_{\rho\to0}\dfrac{f(x,y)-f(0,0)-0\cdot x-0\cdot y}{\rho}=0$，$\rho=\sqrt{x^2+y^2}$。
沿 $y=x$：$\dfrac{\sqrt{x^2}}{\sqrt{2x^2}}=\dfrac1{\sqrt2}\ne0$，所以极限不是 0，不可微。
∴ 选 C。
::note
二元的四个概念只有两条箭头一定成立：**可微 ⟹ 连续**、**可微 ⟹ 偏导存在**；偏导连续 ⟹ 可微。其余（偏导存在 ⟹ 连续 等）都不成立。
**口诀**：偏导是两条线，可微是一张面。
::vary
$f(x,y)=\frac{xy}{x^2+y^2}$（原点补 0）在原点？ >> 偏导存在（都是 0）但不连续（沿 $y=kx$ 极限 $\frac{k}{1+k^2}$ 随 $k$ 变）。
$f=\vert x\vert+\vert y\vert$ 在原点？ >> 连续，偏导不存在。

#4
@at 30
@src 自编
@stem
设 $a_n\gt0$（$n=1,2,\dots$），且 $\displaystyle\sum_{n=1}^\infty a_n$ 收敛，则下列级数中**必定收敛**的是（　）.
@A $\displaystyle\sum_{n=1}^\infty\sqrt{a_n}$
@B $\displaystyle\sum_{n=1}^\infty a_n^2$
@C $\displaystyle\sum_{n=1}^\infty(-1)^n n\,a_n$
@D $\displaystyle\sum_{n=2}^\infty a_n\ln n$
@ans B
@tpl T级数反例
::rev
- **该花** 3 分钟。
- **卡点** C 想不出反例。
- **错了说明** 「通项不趋于 0 就发散」这个最便宜的工具没想到。
- **带走** 「必收敛」选择题：对的那个用比较判别法一行证完，错的三个各配一个反例。
::read
「必定收敛」 >> 对的要能证、错的要能[[T级数反例|T举反例]]
$a_n\gt0$ 且收敛 >> $a_n\to0$，所以后面总有 $a_n\lt1$
::think
从「收敛 ⟹ $a_n\to0$」出发：$a_n\lt1$ 时 $a_n^2\lt a_n$，B 直接被[[R.serpos|比较判别法]]压住。另外三个都比 $a_n$「放大」了，各找反例。
::fast
{{秒|压得住的才必收敛}}：$a_n^2$ 比 $a_n$ 小（后面项都小于 1），A、C、D 都把 $a_n$ 放大了。选 B。
::steps
B：$\sum a_n$ 收敛 ⟹ $a_n\to0$ ⟹ 存在 $N$，$n\gt N$ 时 $0\lt a_n\lt1$，于是 $a_n^2\lt a_n$，由比较判别法 $\sum a_n^2$ 收敛。
A 的反例：$a_n=\frac1{n^2}$，$\sqrt{a_n}=\frac1n$，调和级数发散。
D 的反例：$a_n=\frac{1}{n\ln^2n}$（$n\ge2$），$\sum a_n$ 收敛（积分判别），但 $a_n\ln n=\frac{1}{n\ln n}$，$\sum\frac{1}{n\ln n}$ 发散。
C 的反例：$n$ 是完全平方数时取 $a_n=\frac1n$，其余取 $a_n=\frac1{n^2}$。$\sum a_n\le\sum\frac1{k^2}+\sum\frac1{n^2}$ 收敛；但 $n=k^2$ 时 $n a_n=1$，通项 $(-1)^n n a_n$ 不趋于 0，发散。
∴ 选 B。
::note
考场上 C 的反例不必想出来：B 已经证出必收敛，单选题就够了。
**口诀**：正项收敛平方也收敛，开方、乘 $n$、乘 $\ln n$ 都不保。
::vary
$a_n\gt0$、$\sum a_n$ 收敛，$\sum\frac{\sqrt{a_n}}{n}$ 必收敛吗？ >> 必收敛：$\frac{\sqrt{a_n}}{n}\le\frac12\bigl(a_n+\frac1{n^2}\bigr)$。
去掉 $a_n\gt0$，$\sum a_n$ 收敛时 $\sum a_n^2$ 还必收敛吗？ >> 不必：$a_n=\frac{(-1)^n}{\sqrt n}$。

@at 17
@src 自编
@stem
设 $A$ 为 $n$ 阶矩阵（$n\ge3$），$r(A)=n-1$，$A^*$ 是 $A$ 的伴随矩阵，则（　）.
@A $r(A^*)=n-1$
@B $r(A^*)=1$，且 $r\bigl((A^*)^*\bigr)=1$
@C $r(A^*)=1$，且 $(A^*)^*=O$
@D $A^*=O$
@ans C
::rev
- **该花** 1 分半。
- **卡点** 伴随的秩公式记不住，或忘了再套一次。
- **错了说明** 三档秩公式没背。
- **带走** $r(A^*)$ 只有三个值：$n$、$1$、$0$。
::read
$r(A)=n-1$ >> 伴随的秩公式[[R.rankprop|中间那一档]]：$r(A^*)=1$
$(A^*)^*$ >> 把 $A^*$ 当成新的 $A$ 再套一次公式
::think
第一次套：$r(A)=n-1$ ⟹ $r(A^*)=1$。第二次套：$A^*$ 的秩是 1，而 $n\ge3$ 时 $1\lt n-1$，落在「秩 $\lt n-1$」那一档 ⟹ $(A^*)^*=O$。
::fast
{{秒|三档}}：满秩→满秩，差一→1，差得更多→0。$A\to A^*$ 是「差一 → 1」，$A^*\to(A^*)^*$ 是「1 比 $n-1$ 小 → 0」。选 C。
::steps
由秩公式：$r(A)=n-1$ ⟹ $r(A^*)=1$，排除 A、D。
对 $A^*$ 再用一次：$r(A^*)=1\lt n-1$（因为 $n\ge3$）⟹ $r\bigl((A^*)^*\bigr)=0$，即 $(A^*)^*=O$，排除 B。
∴ 选 C。
::note
$n=2$ 时结论不同：$r(A)=1=n-1$ ⟹ $r(A^*)=1=n-1$ ⟹ $(A^*)^*$ 秩为 1。题目写 $n\ge3$ 就是为了堵这个口。
**口诀**：伴随的秩，满满、差一得一、再差就零。
::vary
$n=3$，$r(A)=1$，$A^*=$？ >> $O$（$1\lt n-1=2$）。
$A$ 为 4 阶，$\vert A\vert=2$，$\vert A^*\vert=$？ >> $\vert A\vert^{n-1}=8$。

@at 18
@src 自编
@stem
设向量组 $\alpha_1=(1,1,a)^T$，$\alpha_2=(1,a,1)^T$，$\alpha_3=(a,1,1)^T$ 的秩为 $2$，则 $a=$（　）.
@A $1$
@B $-2$
@C $1$ 或 $-2$
@D $2$
@ans B
@tpl T含参秩
::rev
- **该花** 2 分钟。
- **卡点** 行列式等于 0 的两个根都选上（选 C）。
- **错了说明** 「行列式为 0」只说明秩 $\lt3$，没有逐个回代看秩到底是几。
- **带走** 含参数求秩：先行列式找特殊值，**每个特殊值回代**。
::read
「秩为 2」 >> 先由[[T含参秩|行列式 = 0]] 找候选，再回代分别求秩
::think
三个三维向量 ⟹ 方阵，行列式为 0 才可能秩小于 3。但秩小于 3 可能是 2 也可能是 1，要回代。
::fast
{{秒|轮换矩阵}}：每行和都是 $a+2$，行列式 $=(a+2)(a-1)^2$。$a=1$ 时三个向量完全相同，秩 1；只剩 $a=-2$。选 B。
::steps
$\vert\alpha_1,\alpha_2,\alpha_3\vert=\begin{vmatrix}1&1&a\\1&a&1\\a&1&1\end{vmatrix}$，各列加到第一列得公因子 $a+2$，再化简得 $-(a-1)^2(a+2)$。
秩 $\lt3$ ⟹ $a=1$ 或 $a=-2$。
$a=1$：$\alpha_1=\alpha_2=\alpha_3=(1,1,1)^T$，秩为 1，不合要求。
$a=-2$：$\alpha_1=(1,1,-2)^T$，$\alpha_2=(1,-2,1)^T$ 不成比例，秩至少 2，又行列式为 0，秩为 2。
∴ $a=-2$，选 B。
::note
**口诀**：行列式为零只是「可能」，回代求秩才算数。
::vary
同一组向量，问「线性相关」时 $a=$？ >> $1$ 或 $-2$（相关 ⟺ 秩 $\lt3$）。
同一组向量秩为 1，$a=$？ >> $1$。

@src 自编
@stem
下列矩阵中，与对角矩阵 $\Lambda=\begin{pmatrix}1&0&0\\0&1&0\\0&0&2\end{pmatrix}$ 相似的是（　）.
@A $\begin{pmatrix}1&1&0\\0&1&0\\0&0&2\end{pmatrix}$
@B $\begin{pmatrix}1&0&1\\0&1&0\\0&0&2\end{pmatrix}$
@C $\begin{pmatrix}2&1&0\\0&1&1\\0&0&1\end{pmatrix}$
@D $\begin{pmatrix}1&0&0\\0&2&0\\1&0&1\end{pmatrix}$
@ans B
@tpl T对角化判别
::rev
- **该花** 2 分钟。
- **卡点** 四个都是三角阵，特征值全是 $1,1,2$，以为四个都相似。
- **错了说明** 「重根要配够特征向量」没练成：只看特征值不够。
- **带走** 与对角阵相似 ⟺ 每个 $k$ 重根 $\lambda$ 都有 $n-r(A-\lambda E)=k$。
::read
四个都是三角阵 >> 特征值就是对角线：全是 $1,1,2$，特征值一样，比不出来
二重根 $\lambda=1$ >> 只需看 $r(A-E)$ 是不是 $3-2=1$（[[R.diag|对角化的条件]]）
::think
特征值相同只是相似的必要条件。和对角阵相似 = 能对角化，关键在二重根 $\lambda=1$ 能不能配出两个无关的特征向量，即 $r(A-E)=1$。
::fast
{{秒|数秩}}：$A-E$ 只有一行非零才行。A 的 $A-E$ 有 $(0,1,0)$、$(0,0,1)$ 两行；B 的 $A-E=\begin{pmatrix}0&0&1\\0&0&0\\0&0&1\end{pmatrix}$ 秩 1 ✓。选 B。
::steps
四个矩阵都是三角阵（D 是下三角），特征值都是 $1,1,2$。
与 $\Lambda$ 相似 ⟺ 可对角化 ⟺ 二重根 $\lambda=1$ 有 2 个无关特征向量 ⟺ $r(A-E)=1$。
A：$A-E=\begin{pmatrix}0&1&0\\0&0&0\\0&0&1\end{pmatrix}$，秩 2，不行。
B：$A-E=\begin{pmatrix}0&0&1\\0&0&0\\0&0&1\end{pmatrix}$，秩 1，可以。
C：$A-E=\begin{pmatrix}1&1&0\\0&0&1\\0&0&0\end{pmatrix}$，秩 2，不行。
D：$A-E=\begin{pmatrix}0&0&0\\0&1&0\\1&0&0\end{pmatrix}$，秩 2，不行。
∴ 选 B。
::note
**口诀**：特征值相同是门票，重根配够向量才进门。
单根永远配得够，所以只查重根。
::vary
$\begin{pmatrix}1&a&0\\0&1&0\\0&0&2\end{pmatrix}$ 可对角化的条件？ >> $a=0$。
$\begin{pmatrix}1&0&a\\0&1&b\\0&0&2\end{pmatrix}$ 可对角化的条件？ >> 任意 $a,b$ 都可以：$A-E$ 只有第一、二行第三列和第三行非零，第三行 $(0,0,1)$，秩恒为 1。

#8
@at 35
@src 自编（经典概念题）
@stem
设 $X\sim N(0,1)$，$Y=X^2$，则 $X$ 与 $Y$（　）.
@A 相互独立
@B 不相关，但不独立
@C 相关，且不独立
@D 相关系数为 $1$
@ans B
::rev
- **该花** 1 分半。
- **卡点** $Y$ 由 $X$ 决定就以为「相关」。
- **错了说明** 「相关」只指**线性**相关，没分清。
- **带走** 不相关 = 协方差为 0（没有线性关系）；独立是什么关系都没有。
::read
$Y=X^2$ >> $Y$ 完全由 $X$ 决定 ⟹ 显然不独立
问「相关」 >> 算 $\mathrm{Cov}(X,Y)=E(X^3)-EX\cdot EX^2$（[[R.uncor|不相关与独立]]）
::think
打个比方：$X$ 往左往右走，$Y$ 都往上升。这种「V 形」关系不是一条斜线，线性相关系数测不出来，所以协方差是 0；但 $Y$ 又被 $X$ 牢牢拴住，所以不独立。
::fast

（本题满分 12 分）设总体 $X$ 的概率密度为 $f(x;\theta)=\begin{cases}\theta x^{\theta-1}, & 0\lt x\lt1,\\ 0, & \text{其他},\end{cases}$ 其中 $\theta\gt0$ 为未知参数，$X_1,X_2,\dots,X_n$ 为来自总体 $X$ 的简单随机样本.
(1) 求 $EX$；
(2) 求 $\theta$ 的矩估计量；
(3) 求 $\theta$ 的最大似然估计量.
@ans (1) $\dfrac{\theta}{\theta+1}$；(2) $\hat\theta=\dfrac{\bar X}{1-\bar X}$；(3) $\hat\theta=-\dfrac{n}{\sum_{i=1}^n\ln X_i}$
@tpl T最大似然
::rev
- **该花** 14 分钟。
- **保底** ==第 (1) 问就是一个定积分 $\int_0^1x\cdot\theta x^{\theta-1}dx$，写对积分式就 2 分，算出 $\frac{\theta}{\theta+1}$ 拿 3 分==；最大似然只要写出似然函数 $L(\theta)$ 和取对数，又是 2–3 分。
- **卡点** 矩估计里解方程解错，或最后忘了换成大写的 $X_i$。
- **错了说明** 估计量与估计值、大小写没分清。
- **带走** 矩估计：$EX=\bar X$ 解出 $\theta$；MLE：连乘 → 取对数 → 求导 → 写成估计量。
::read
求 $EX$ >> [[R.expect|期望]]：$\int x f(x)dx$
「矩估计量」 >> [[R.mom|令 $EX=\bar X$]]，解出 $\theta$
「最大似然估计量」 >> [[T最大似然|四步]]，结果用大写 $X_i$
::think
1. 三问是一条流水线：(1) 算出 $EX$ 正是 (2) 要用的式子。
2. MLE 的似然函数是幂函数连乘，取对数后变成 $n\ln\theta+(\theta-1)\sum\ln x_i$，对 $\theta$ 求导一步解出。
3. 检查：$0\lt x_i\lt1$ ⟹ $\ln x_i\lt0$ ⟹ $\hat\theta=-\frac{n}{\sum\ln X_i}\gt0$，符号合理。
::steps
(1) $EX=\displaystyle\int_0^1x\cdot\theta x^{\theta-1}dx=\theta\int_0^1x^\theta dx=\frac{\theta}{\theta+1}$。
(2) 令 $EX=\bar X$：$\dfrac{\theta}{\theta+1}=\bar X$ ⟹ $\theta=\bar X(\theta+1)$ ⟹ $\theta(1-\bar X)=\bar X$ ⟹ $\hat\theta=\dfrac{\bar X}{1-\bar X}$。
(3) 似然函数：$L(\theta)=\displaystyle\prod_{i=1}^n\theta x_i^{\theta-1}=\theta^n\Bigl(\prod x_i\Bigr)^{\theta-1}$（$0\lt x_i\lt1$）。
取对数：$\ln L=n\ln\theta+(\theta-1)\displaystyle\sum_{i=1}^n\ln x_i$。
求导令为 0：$\dfrac{d\ln L}{d\theta}=\dfrac n\theta+\displaystyle\sum\ln x_i=0$ ⟹ $\theta=-\dfrac{n}{\sum\ln x_i}$。
~二阶导 $-\frac{n}{\theta^2}\lt0$，确是最大值点。
最大似然估计量 $\hat\theta=-\dfrac{n}{\sum_{i=1}^n\ln X_i}$。
::paper
解 (1) $EX=\displaystyle\int_{-\infty}^{+\infty}xf(x;\theta)dx=\int_0^1\theta x^{\theta}dx=\frac{\theta}{\theta+1}$. ⛳3
(2) 令 $EX=\bar X$，即 $\dfrac{\theta}{\theta+1}=\bar X$，解得 $\theta$ 的矩估计量为 $\hat\theta=\dfrac{\bar X}{1-\bar X}$，其中 $\bar X=\frac1n\sum_{i=1}^nX_i$. ⛳4
(3) 设 $x_1,\dots,x_n$ 为样本值，似然函数为 ⛳1
$$L(\theta)=\prod_{i=1}^n\theta x_i^{\theta-1}=\theta^n\Bigl(\prod_{i=1}^nx_i\Bigr)^{\theta-1},\quad0\lt x_i\lt1.$$⛳1
取对数 $\ln L(\theta)=n\ln\theta+(\theta-1)\sum_{i=1}^n\ln x_i$， ⛳1
令 $\dfrac{d\ln L(\theta)}{d\theta}=\dfrac n\theta+\sum_{i=1}^n\ln x_i=0$，得 $\theta=-\dfrac{n}{\sum_{i=1}^n\ln x_i}$. ⛳1
故 $\theta$ 的最大似然估计量为 $\hat\theta=-\dfrac{n}{\sum_{i=1}^n\ln X_i}$. ⛳1
::note

- 矩估计要写清 $\bar X$ 的定义，阅卷对这一行很宽容但别省。
- 似然函数后面写上 $0\lt x_i\lt1$ 的范围，是规范写法。
- 本题三问的步骤固定，**练两遍就能稳拿 12 分**——这是全卷最值得保的一题。
