# 重读报

数学一的报刊版讲义：一轮过完后重捋一遍，读完上真题套卷。目标 120 分，能高就高。37 期，含每期实战约 16 小时，总版可切三天线、两天线。

## 改内容

- 讲解：只改 `_src/NN.txt`
- 实战：只改 `_src/shizhan.txt`（`:::q 期号 | 年份-题号 | 答案`，`---` 后是点评）
- 真题归类与分值：`_build/exam_map.py`（题号 → 期号；页面上交卷后才显示单题）

```bash
python3 _build/build.py          # 生成全部页面，校验不过退出码 1
python3 _build/verify.py         # 独立复算例题；可写 verify.py 15 21 只算一段
python3 _build/verify_q.py       # 独立复算实战答案和后补例题
```

不要手改 `qNN.html`、`index.html`、`套卷.html`、`错题.html`、`速记.html`、`定理索引.html`、`温故.html`、`assets/data.js`，它们都是生成的。前台页模板在 `_build/pages.py`。

## 硬校验

`build.py` 不通过就退出码 1：

- `[[定理]]` 只能引用已经刊登的定理。
- `TERMS` 里的术语不许早于首发期出现，实战题和点评也查。新加术语要登记。
- 问法考法（真题、常考、必考……）不进知识部分，只写在实战点评里；`:::skip` 的取舍声明除外。
- 实战只用 2010–2015。2016 年及以后的题构建直接报错，留作整卷；放的期必须与 `exam_map.py` 一致。
- 表格里的公式不能写 `|`，用 `\vert`。

## 排版约定

- 黑白为主。红 = 必背和易错，蓝 = 定理引用，赭 = 比方。
- 例题走教材常见题型，不照搬 2016 年以后的真题卷，把新鲜感留给套卷。
- 大题三层：思路 → 考场卷面 → 批注（可省）；选填不写卷面格式。
- 翻页版面是一次排好的：可点开的内容（实战点评、自测答案）用模糊占位，不改变高度。

## 套卷精解（2026-11-09 起，取代裁图版）

用户嫌裁图看不清、解析太省、精研太浅，套卷改成「文字题面 ＋ 逐步精解」。每年一个源文件 `_build/rich/YYYY.txt`，跑 `python3 _build/rich_build.py [年份…]` 生成 `assets/exam/rich/rYYYY.js`；引擎加载卷子时合并：有 `@stem` 就换掉题面图（原图收进「看原卷题面」），有解析块就换掉原解析（原解析收进「原书解析（备查）」）。没写精解的年份照旧显示原样。语法见 `rich_build.py` 开头，样板见 `_build/rich/` 里已写好的年份。

- **全局卡** `_build/rich/kp.txt`：`@kp` 知识点卡、`@tpl` 跨年套路卡（「看到什么信号 → 第一步做什么 → 不行换什么」）。精解里 `[[id]]` 变成可点的弹窗；`@tpl` 标在题上，构建自动统计「真题里出现在哪几题」，弹窗里列出来——这就是跨年模板库。并行写各年时**不要改 kp.txt**，新卡写在本年文件顶部（本年可用），汇总时再提上来。
- **每题的块**（按做题的顺序排）：`::read` 读题圈画（「原句 >> 想到什么」，每题必写）→ `::sk` 手绘草图（凡是人在纸上会画的：函数图、区域、几何、树、表、时空图）→ `::think` 思路 → `::fast` 秒杀/快法（选填）→ `::steps` 每一步（不许跳步；行首 `~` = 考场可省，显示成灰底）→ `::paper` 考场卷面（只给解答/综合题，三层铁律）→ `::note` 批注（扣分点、边界、提速）→ `::vary` 举一反三（「变式 >> 答案」，答案模糊、点开才显示）。
- **行内标记**：`{{省|}}` 可省 · `{{秒|}}` 秒杀 · `{{圈|}}` 圈 · `{{波|}}` 波浪线 · `{{扣|}}` 扣分点 · `{{注|}}` 红笔旁注 · `==红==` · `⛳2` 采分点。
- **硬校验**（不过退出码 1）：选择题答案与卷子不一致、`[[id]]` 未定义、`$` 不配对、`{{` 不闭合、HTML 标签不配平、草图代码报错。
- 已写精解的年份：2011–2023（2012、2011 于 2026-11-13 写完；2010 待写，2024–2026 仍是裁图）。写完一年后跑 `python3 _build/rich_promote.py 年份` 把本年卡提到 `kp.txt`，并改 `真题套卷.html` 与 `_build/exam_page.html` 导语里的「已重制」年份。
- 解析的正确性另外要程序复算（数学用 sympy/数值，408 用模拟/穷举），复算脚本放 `_build/rich/chk/YYYY.py`。

### 套卷引擎 v4（2026-11-12）

- 修：单题重绘（选选项、看解析、标记）后公式不重排、TeX 原样露出。现在凡是往页面塞 HTML 的地方都过 `typeset(el)`；没判分时选选项只换选中态，不重画整题。
- 模式三选一：考试 / 练习（做一题对一题）/ 读解析；看题方式：整卷往下翻 / 一题一屏；字号四档；解析里九类块可逐类隐藏。
- 「这题要用到的」：从 `q.tpl` ＋精解里的 `data-kp` 自动汇出，卡片就地展开（开关可设默认全开）；做题时可开「提示」只看知识点；交卷后成绩单下有失分题知识点清单；首页 `#kp` 是可搜的速查本。
- 解析可分两层揭开（先读题和思路，自己写完再看步骤和卷面）；每题有错因标签（`ss.why`）和「我的批注」（键 `<key>_notes`，重做不清）。
- 键盘：← → / K J 翻题，A–D 选，S 解析，H 提示，F 标记。
- 样式改成手写笔记：解析是带红页边线的一页纸，块标题是手写字加荧光笔，卷面是白答题纸，举一反三和知识点是便利贴。精解源文件不用改；`⛳` 在合并时去掉，采分点由 CSS 画成红笔圈。
- 注意：别把 `data-fs` 这类属性挂到 `<html>` 上后又用 `closest("[data-fs]")` 找按钮（会命中 html，任何点击都触发重画），选择器一律写 `button[data-…]`。

### 套卷引擎 v5 与精解统一规定（2026-11-12）

- 草图分三类，`::sk 宽 高 画|列|看 | 图注`，不标构建报错；页面图注前自动标「考场上画 / 草稿上列 / 看懂就行 · 考场不画」。
- 开关面板有「完整 / 精简」：精简＝隐藏考场可省的步骤、举一反三、看懂用的示意图。
- 交卷后只把失分、没登分、标记过、看过提示、选了错因、必吃透的题默认摊开；做对的题收成一行精研卡的「本质」。
- 新年份的篇幅预算、草图标准、知识点卡写法见 `_build/rich/BRIEF.md` 末节「统一规定」。新会话开工先读它。

## 分档 · 限时 · 三条线（2026-11-12）

- 源文件 `_build/tier/YYYY.txt`（每题：档 必/常/冲/弃 或按问拆分 a/b/c/x、考场限时、说明），跑 `python3 _build/tier_build.py` 生成 `assets/exam/tier.js`。语法和四档判据见脚本开头。脚本与引擎两个中心各一份，改了要同步。
- 三条线按预期得分率算：保底＝必×90%；正常＝必×95%＋常×70%；冲刺＝必＋常×90%＋冲×50%。
- 页面：题号旁标档和限时，顶栏显示本题已用时间（超了变红）；交卷后成绩单多一块「三条线」：你在哪条线上、各档丢在哪几题、哪几题超时。首页每年和做卷顺序表都带三条线。开关「做题时显示分档和每题限时」可关（模考卷建议关）。
- 每题用时记在 `ss.qt`（只在未判分、未暂停时累计当前题）。
- 套路卡下的「真题里的字眼」由 `rich_build.py` 自动汇总（每题 `::read` 第一句 ＋ `::rev` 的「带走」，按 `@tpl` 归卡），写新年份就自动变长，不用手工维护。
- 已定档：2011–2026。2010 等写精解时一起定。定档是按考点和精研难度判断的，觉得不准直接改对应年份的 txt 重跑。
