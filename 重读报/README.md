## 硬校验

`build.py` 不通过就退出码 1：

- `[[定理]]` 只能引用已经刊登的定理。
- `TERMS` 里的术语不许早于首发期出现，实战题和点评也查。新加术语要登记。
- 问法考法（真题、常考、必考……）不进知识部分，只写在实战点评里；`:::skip` 的取舍声明除外。
- 实战只用 2010–2015。2016 年及以后的题构建直接报错，留作整卷；放的期必须与 `exam_map.py` 一致。
- 表格里的公式不能写 `|`，用 `\vert`。

## 排版约定

- 黑白为主。红 = 必背和易错，蓝 = 定理引用，赭 = 比方。
- 例题走教材常见题型，不照搬 2016 年以后的真题卷，把新鲜感留给套卷。
- 大题三层：思路 → 考场卷面 → 批注（可省）；选填不写卷面格式。
- 翻页版面是一次排好的：可点开的内容（实战点评、自测答案）用模糊占位，不改变高度。

## 套卷精解（2026-11-09 起，取代裁图版）

用户嫌裁图看不清、解析太省、精研太浅，套卷改成「文字题面 ＋ 逐步精解」。每年一个源文件 `_build/rich/YYYY.txt`，跑 `python3 _build/rich_build.py [年份…]` 生成 `assets/exam/rich/rYYYY.js`；引擎加载卷子时合并：有 `@stem` 就换掉题面图（原图收进「看原卷题面」），有解析块就换掉原解析（原解析收进「原书解析（备查）」）。没写精解的年份照旧显示原样。语法见 `rich_build.py` 开头，样板见 `_build/rich/` 里已写好的年份。

- **全局卡** `_build/rich/kp.txt`：`@kp` 知识点卡、`@tpl` 跨年套路卡（「看到什么信号 → 第一步做什么 → 不行换什么」）。精解里 `[[id]]` 变成可点的弹窗；`@tpl` 标在题上，构建自动统计「真题里出现在哪几题」，弹窗里列出来——这就是跨年模板库。并行写各年时**不要改 kp.txt**，新卡写在本年文件顶部（本年可用），汇总时再提上来。
- **每题的块**（按做题的顺序排）：`::read` 读题圈画（「原句 >> 想到什么」，每题必写）→ `::sk` 手绘草图（凡是人在纸上会画的：函数图、区域、几何、树、表、时空图）→ `::think` 思路 → `::fast` 秒杀/快法（选填）→ `::steps` 每一步（不许跳步；行首 `~` = 考场可省，显示成灰底）→ `::paper` 考场卷面（只给解答/综合题，三层铁律）→ `::note` 批注（扣分点、边界、提速）→ `::vary` 举一反三（「变式 >> 答案」，答案模糊、点开才显示）。
- **行内标记**：`{{省|}}` 可省 · `{{秒|}}` 秒杀 · `{{圈|}}` 圈 · `{{波|}}` 波浪线 · `{{扣|}}` 扣分点 · `{{注|}}` 红笔旁注 · `==红==` · `⛳2` 采分点。
- **硬校验**（不过退出码 1）：选择题答案与卷子不一致、`[[id]]` 未定义、`$` 不配对、`{{` 不闭合、HTML 标签不配平、草图代码报错。
- 解析的正确性另外要程序复算（数学用 sympy/数值，408 用模拟/穷举），复算脚本放 `_build/rich/chk/YYYY.py`。
