# 重读报

数学一的报刊版讲义：一轮过完后重捋一遍，读完上真题套卷。目标 120 分，37 期，预计 12 小时左右。

## 改内容

只改 `_src/NN.txt`，然后运行：

```bash
python3 _build/build.py
python3 _build/verify.py        # 独立复算答案；可写 verify.py 15 21 只算一段
```

不要手改 `qNN.html`、`index.html`、`定理索引.html`、`温故.html`、`assets/data.js`，它们都是生成的。

## 文稿语法

```
@part 甲 / @kicker / @title / @deck
@keep 本期只记的一行            （头版）
@recall 问题 || 答案            （末版自测，进入温故版）
## 小节标题        ### 小标题        - 列表        | 表格 |
$$公式$$⛳3                      （展示公式必须独占一行，可带分值）
:::thm id | 名称 | 定理/定义/公式  … :::
:::ex 标签 … :::  :::think … :::  :::paper … :::  :::note … :::
:::like（比方）  :::trap（易错）  :::skip（本报不刊）  :::fml（公式框）
!fig 图名 | 图注                 （图在 _build/figs_a.py、figs_b.py，由真实函数计算）
正文：**粗体** ==红色== [[定理id]] ⛳2 ∎结论行
```

## 硬校验

`build.py` 不通过就退出码 1：

- `[[定理]]` 只能引用已经刊登的定理。
- `TERMS` 里的术语不许早于首发期出现。新加术语要登记。
- 表格里的公式不能写 `|`，用 `\vert`。

## 排版约定

- 黑白为主。红 = 必背和易错，蓝 = 定理引用，赭 = 比方。
- 例题走教材常见题型，不照搬 2010 年以后的真题卷，把新鲜感留给套卷。
- 大题三层：思路 → 考场卷面 → 批注（可省）；选填不写卷面格式。
